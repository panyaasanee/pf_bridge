## 2. ของที่ต้องเพิ่ม (3 ชิ้น)

### 2.1 ป้ายที่มา (provenance header) — สำคัญที่สุด
ทุก artifact หลักมีหัว 4 บรรทัด: **ใครสร้าง / เมื่อไหร่ / derive จากอะไร / แช่แข็งหรือแก้ได้**
แบ่งเป็น 3 ชั้นให้ชัด:

| ชั้น | ตัวอย่าง | สถานะ |

| หลักฐานจริง | `GameClient.local.bin`, capture corpus | อ่านอย่างเดียว ตลอดกาล |
| snapshot ส่งมอบ | `current/pf_login_game_server_v141.py` (งาน Codex) | แช่แข็งเป็นตัวเทียบ — **ไม่ใช่หลักฐาน** |
| งานปัจจุบัน | `src/`, `tools/`, `reports/`, ledger, matrix | แก้ได้ตามกติกา gate |

### 2.2 `HANDOFF.md` — ไฟล์เดียว เขียนทับทุกปลายกะ (~1 หน้า)

4. อะไรห้ามแตะและเพราะอะไร

เป้าหมาย: อีกฝ่ายอ่าน**ไฟล์เดียว**แล้วเริ่มได้ ไม่ต้องขุด CONTINUATION 84KB
