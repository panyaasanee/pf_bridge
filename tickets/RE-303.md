### ทำไมใบนี้ถึงบล็อก M2
`ประตู M` (`PANYA 1825`) ให้ `Player.TeleportWithVehicle` ทั้งขาออกเป็นของ LANE-A แล้ว
แต่เกณฑ์ผ่าน M2 ใน `NOW.md` คือ **ใกล้เกาะ → "รายงานกัปตัน" ขึ้นจอ → กด → วาปเข้าเกาะ 2 และ 3**
ท่อนที่เซิร์ฟเวอร์ยังเขียนไม่ได้คือท่อนกลาง: **เฟรมที่ทำให้ไคลเอนต์เปิดหน้าต่างนั้น**
`PANYA 1910` ห้ามส่งเฟรมเดา ⇒ ไม่มีผลใบนี้ = สายนี้เขียนโค้ดท่อนกลางไม่ได้เลย ไม่ว่ากี่รอบ
ผลใบนี้คือ "เฟรมอ้าง binary" ที่ `1910` เรียกร้องก่อนจะขอเครื่องเจ้าของได้

### คำถาม (สามข้อ ตอบแยกกัน · ข้อ 1 คือข้อที่บล็อก)
1. **vital ขาเข้า (server→client) ตัวไหน** ทำให้ไคลเอนต์เปิดหน้าต่างยืนยัน `Common_Confirm`
   ที่มีข้อความ "รายงานกัปตัน" (ข้อความที่ผู้เล่นเห็นตอนเรือเข้าใกล้เกาะ) — ขอ **vital id + ชื่อคลาส**
2. **layout ของเฟรมนั้น**: ฟิลด์อะไรบ้าง ลำดับ tag/offset/ความยาว และฟิลด์ไหนเป็นตัวเลือกข้อความ/ปลายทาง
3. **กด OK แล้วไคลเอนต์ส่งอะไรกลับ**: vital id ขาออก + layout + ค่าที่มันใส่ในแต่ละฟิลด์
   (ถ้าปุ่ม Cancel ส่งอะไรด้วย ขอด้วย — ถ้าไม่ส่ง เขียนว่าไม่ส่ง)

### วิธีที่ใบนี้ระบุ (เจ้าของกำหนดรูปไว้ ห้ามย่อ)
1. หา **string ของหน้าต่างนั้น** ใน client เป็น **UTF-16LE** (ข้อความไทย "รายงานกัปตัน" และ/หรือคีย์ resource ที่คุมมัน)
2. **xref ขึ้น** จาก string ไปหาฟังก์ชันที่เปิด UI (`Common_Confirm` / message-box builder)
3. **xref ขึ้นต่อ** จากฟังก์ชันเปิด UI ไปจนถึง **handler ขาเข้า** ของ vital ⇒ ได้ id + layout ของข้อ 1/2
4. ขาตอบ: จาก callback ของปุ่ม OK ในหน้าต่างเดียวกัน ลงไปหา serializer ขาออก ⇒ ได้ข้อ 3

🔴 **ผลลบต้องบอกขอบเขตที่กวาด ไม่ใช่คำว่า "ไม่เจอ"**: ถ้าหา string ไม่เจอ ต้องเขียนว่า
กวาด encoding อะไรบ้าง (UTF-16LE · cp874 · UTF-8) · ช่วง section ไหนของ image · และ
xref กี่ชั้นจากผู้ต้องสงสัยข้างล่าง แล้วตัน ณ จุดไหน — ผลลบที่มีขอบเขตคือผลที่ใช้ได้ ผลลบเปล่าไม่ใช่

### สมมติฐานที่ผมอยากให้ยิงก่อน (ยิงตกได้ = ผลที่มีค่าเท่ากัน)
**`TeleportCheckVital 0x4477` เป็นคู่ถาม-ตอบของหน้าต่างนี้**
เหตุผลจากไบต์: มันมี **ฟิลด์เดียว 2 ไบต์ layout เดียวกันเป๊ะทั้ง W และ R** ซึ่งเป็นรูปของ
"เซิร์ฟเวอร์ถามด้วยเลขหนึ่งตัว ไคลเอนต์ตอบเลขตัวเดิมกลับ" และ 2 ไบต์ tag `0x0F` คือรูปเดียวกับ
ฟิลด์แรกของ `TriggerVital 0x1FB2` ซึ่ง `RE-298` พิสูจน์แล้วว่าเป็น **wire trigger id**
ถ้าจริง ท่อนกลางของ M2 คือ: server ส่ง `0x4477(trigger_id)` → client เปิด `Common_Confirm` →
กด OK → client ส่ง `0x4477(trigger_id)` กลับ → server เรียก `Player.TeleportWithVehicle`
🔴 **ถ้ายิงตก ขอให้บอกว่าตกด้วยอะไร** (ชื่อฟังก์ชันที่ `0x4477` ไปโผล่ / ไม่มี xref ถึง UI ใด ๆ)

### เกณฑ์ผ่าน/ไม่ผ่านของใบนี้
- **PASS** = ตอบข้อ 1 ด้วย **vital id ที่มีไบต์อ้าง** (xref chain เขียนครบจาก string → UI → handler)
  แม้ตอบได้แค่ข้อ 1 ก็ปลดบล็อกแล้ว (ข้อ 2/3 ทำต่อได้อีกใบ)
