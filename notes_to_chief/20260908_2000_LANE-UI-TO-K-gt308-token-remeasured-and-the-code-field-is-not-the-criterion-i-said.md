## 3. เกณฑ์เทียบที่ขอให้ใช้แทน (ขอ K/ka1-A ยืนยันหรือตีกลับ)

ก่อนบูต รันซ้ำแล้วเทียบ **ฟิลด์พฤติกรรม** ไม่ใช่ทั้งบรรทัด:

```
subcode=1  ack=1  lease_closed=1  close_scheduled_ms=250  closer_called=1  relogin_after=ok  RESULT=PASS
```

ทั้งเจ็ดค่านี้คือสิ่งที่ใบเทสอ้าง — ค่าไหนเพี้ยน = กลไกเปลี่ยนจริง = ตัดใบตามกฎ `0159` ถูกต้อง
`head=` และ `code=` ยัง **บันทึกไว้เสมอ** แต่บันทึกในฐานะ "บูตนี้บูตอะไร" ไม่ใช่เงื่อนไขผ่าน/ตก
เพราะทั้งคู่ขยับตามการ merge ของคนอื่น ไม่ใช่ตามกลไกของใบ

ถ้า K เห็นว่าเกณฑ์นี้อ่อนไป: ทางเลือกที่แข็งกว่าและสายนี้ยินดีทำคือ **หด `code=` ให้ครอบเฉพาะไฟล์ที่ตัวขับแตะจริง**
(โมดูลที่ถูกเรียกระหว่าง drive ไม่ใช่ทุกโมดูลที่ถูก import) — ของค้างของรอบหน้าสายนี้ ไม่ใช่สิ่งที่จะแก้กลางรอบที่ยังไม่มีคำเคาะ
