# คำตัดสิน

## ข้อ 1 — ใบหนึ่งใบ มีผู้ทำได้คนเดียว (แก้ที่ต้นทาง)

ห้ามเขียนใบที่ระบุผู้ทำแบบเปิดกว้าง เช่น "รอบ gate-red-repair ของสาย GM **หรือ** chief"
`ADDRESSEE:` ต้องเป็นสายเดียวเสมอ

ถ้าผู้เขียนใบไม่รู้ว่าใครควรทำ → จ่าหน้าถึง **chief** แล้วให้ chief เป็นคนมอบหมาย
(chief เขียนชื่อสายที่รับผิดชอบลงในคิว) — ห้ามโยนความไม่แน่ใจไปให้สายอื่นมาแย่งกันหยิบ

## ข้อ 2 — ประกาศจองก่อนลงมือ (กันการชนที่เหลือ)

ก่อนเริ่มทำงานตามใบของสายอื่น (ใบที่ไม่ได้จ่าหน้าถึงตัวเองโดยตรง หรือใบที่ตัวเองอาสาหยิบ)
ให้หย่อนไฟล์จองลงกล่องก่อน **แล้วค่อยลงมือ**:

```
notes_to_chief/<YYYYMMDD_HHMM>_CLAIM-<LANE>-<ชื่อใบที่จอง>.md
  ใบที่จอง: <ชื่อไฟล์เต็ม>
  สายที่จอง: <LANE-A/B/GM/E>   รอบ: <round id>
  เริ่ม: <เวลา>   คาดว่าจบ: <เวลา>
```

- ก่อนจอง ให้ `ls notes_to_chief/*CLAIM*` ดูก่อน — **เจอใบจองของสายอื่นที่ยังไม่หมดอายุ = ห้ามเริ่ม**
  ให้ไปทำงานอื่นตามกฎ F แล้ววนมาดูรอบหน้า
- **อายุใบจอง 90 นาที** (ยาวกว่าหนึ่งรอบ สั้นพอที่รอบที่ตายจะไม่ล็อกงานข้ามคืน) หมดอายุแล้วถือว่าว่าง
- ทำเสร็จ: เขียน `.CONSUMED.txt` ของใบงานตามปกติ **และย้ายใบจองของตัวเองเข้า `consumed/` ด้วย**
- ใบจองไม่ใช่ล็อกของ bridge/git — ไม่เกี่ยวกับ LOCK_GAME/LOCK_GIT และไม่ต้องถืออะไรเพิ่ม

## ข้อ 3 — ขอบเขต

กฎนี้ใช้กับ **ใบที่มีผู้ทำได้มากกว่าหนึ่งสาย** เท่านั้น
ใบ RE ปกติที่ "ใครเปิดใบ คนนั้นบริโภค" ยังใช้กติกาเดิม ไม่ต้องจอง — อย่าเพิ่มพิธีกรรมให้งานที่ไม่เคยชนกัน

# เหตุผลของเจ้าของ (สำคัญ — ใช้ตีความเวลาเจอเคสก้ำกึ่ง)

เจ้าของเคยสั่งไว้กับ `RE-162` ว่า **ทุกใบต้องมีชื่อคนที่จะเอาผลลัพธ์ไปใช้ต่อ** ห้ามเปิดใบลอย
คำตัดสินนี้คือ**ด้านกลับของกฎเดียวกัน**: นอกจากต้องรู้ว่าใครจะใช้ผล ต้องรู้ด้วยว่า **ใครเป็นคนทำ**
ใบที่ไม่มีชื่อผู้ทำจะจบสองแบบเท่านั้น — ไม่มีใครหยิบ (งานค้าง) หรือหยิบพร้อมกัน (งานซ้ำ)
คืนนี้เจอแบบหลัง: สาย GM กับ chief วินิจฉัยบั๊ก fixture เดียวกันจนถึงวิธีแก้เดียวกันเป๊ะ
เสียไปหนึ่งรอบเต็มของสาย GM กับ PR สองใบ ทั้งที่ไม่มีใครทำอะไรผิดสักคน

# บังคับใช้

- **COO**: บันทึกกฎนี้ลงกติกาถาวร แล้วยืนยันกลับมาว่าไปอยู่ที่ไหน
- **chief**: ตรวจใบที่ค้างอยู่ตอนนี้ ถ้าใบไหนยังเขียนผู้ทำแบบ "X หรือ Y" ให้แก้เป็นชื่อเดียว
- **prompt ของ scheduled task**: เจ้าของยังไม่ได้สั่งให้แก้ prompt รอบนี้ — กะ1-A จะเสนอ diff ให้เจ้าของดูก่อน
  ตามกฎ ห้ามแก้ prompt จากความคิดตัวเอง จนกว่าจะได้รับอนุมัติ

— เขียนแทนโดย กะ1-A (ผู้เทส attended) ตามคำสั่งสดของเจ้าของ
