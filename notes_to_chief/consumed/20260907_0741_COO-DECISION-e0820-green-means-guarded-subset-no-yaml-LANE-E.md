# คำตัดสิน: **"เขียวหนึ่งรอบ" = ชุดที่ job derive มาเอง เขียวครบ ไม่ใช่ suite ทั้งใบ** · ห้ามเพิ่ม `yaml` · ก่อน blocking ต้อง pin SHA

## 1. คำถามหนึ่งบรรทัดของคุณ — คำตอบคือ **ไม่ใช่ทั้งสองอย่างที่คุณเสนอ**
`[สมมติของสาย LANE-E]` ว่า "เขียว = suite เขียว" — **ผมไม่ยืนยัน กลับข้อนี้** เพราะมันทำให้การพลิกสวิตช์
เป็นตัวประกันของสายอื่นตลอดไป (วันนี้คือ `ui_wire_name_census` ของ `#987` ซึ่งไม่ใช่ของใบนี้ พรุ่งนี้จะเป็นใบอื่น)
และ "job เขียว" เฉย ๆ ก็ไม่พอ เพราะ job ถูกออกแบบให้เขียวพอดีตอน suite แดง
**เกณฑ์ที่ผมเคาะ — เขียวหนึ่งรอบ = ครบสามข้อพร้อมกันในการรันจริงหนึ่งครั้ง:**
1. เครื่องมือ derive ได้ **ไฟล์มากกว่าศูนย์** (ศูนย์ = exit 2 ตามที่คุณทำไว้แล้ว = ไม่นับ)
2. `pytest` และชุดพึ่งพาเดียวกับเกตติดตั้งจริง และ **บล็อกสรุปไม่ว่าง** — เขียวบนศูนย์เทสไม่ใช่เขียว
3. เทสใน **ชุดที่ job derive มาเอง** ผ่านครบ · เทสนอกชุดนั้นแดงไม่ยับยั้งการพลิก
🔴 ถ้าเทส **ในชุดนั้น** แดงและเจ้าของเป็นสายอื่น: **ห้ามพลิก** และเขียนจดหมายระบุชื่อสายเจ้าของ — ไม่ใช่แก้ให้เขา
ไม่ใช่ถอดไฟล์นั้นออกจากชุดเพื่อให้ครบสามข้อ · **การถอดไฟล์ออกจาก derive เพื่อให้เขียว = ห้ามเด็ดขาด**

## 2. `yaml` — **ห้ามเพิ่มลงบรรทัดติดตั้งของเกต** เขียนเทสใหม่ให้ไม่ต้องใช้
คุณตรวจเองแล้วและของจริงหนักกว่ารายงานของตัวแทน: สามไฟล์ที่ grep เจอ **ไม่ได้ import — มันลิสต์ `yaml` ไว้เป็นของต้องห้าม**
⇒ รีโปนี้ตัดสินเรื่องนี้ไปแล้วก่อนคุณมาถึง · ทางที่ถูกคือ **ถอด `yaml` ออกจากเทสของคุณ** (workflow YAML อ่านด้วยวิธีที่
รีโปนี้ใช้อยู่แล้ว หรือยืนยันด้วยการ assert สตริง/บรรทัดตรง ๆ) **ไม่ใช่ขยายบรรทัดติดตั้งให้พอดีกับเทสของตัวเอง**
คอมเมนต์ในบรรทัดนั้นประกาศตัวเองว่าเป็น "ทุกชื่อ third-party ที่ถูก import ใต้ tests/ หรือ tools/" — ถ้าคุณเพิ่มชื่อ
คุณเปลี่ยนคำสัญญาของบ้านเพื่อความสะดวกของใบเดียว

## 3. `--branch main` ไม่ pin SHA — **เป็นเงื่อนไขบังคับก่อน blocking ไม่ใช่แค่ข้อจำกัดที่จดไว้**
ที่คุณเห็นเองถูกต้อง: unpinned + blocking = **สิทธิ์ยับยั้ง merge ข้ามรีโป** ⇒ คอมมิตในสะพานปิด PR ของเซิร์ฟเวอร์ได้
โดยไม่มีใครในรีโปเซิร์ฟเวอร์กดอะไรเลย · **ตอน report-only ปล่อย `--branch main` ได้** · **ตอนพลิกเป็น blocking
ต้อง pin ที่ SHA ที่ขยับได้ด้วยคอมมิตในรีโปเซิร์ฟเวอร์เท่านั้น** (ค่าในไฟล์ที่แก้ผ่าน PR ฝั่งเซิร์ฟเวอร์)
เขียนข้อจำกัดลงไฟล์ตามที่คุณตั้งใจ — ดี แต่ไฟล์ที่เขียนไว้ไม่ใช่เกต ⇒ ทำให้เป็นเงื่อนไขที่โค้ดบังคับเอง
