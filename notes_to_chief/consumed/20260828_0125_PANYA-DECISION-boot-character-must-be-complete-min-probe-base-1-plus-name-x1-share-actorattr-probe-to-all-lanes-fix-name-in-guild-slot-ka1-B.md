## ② คำสั่ง (มีผลทันที ทุกสาย)
1. **ตัวละครที่บูตขึ้นมาเทส (ทุก GT, ทุก lane, ทุกบัญชี) ต้องได้ ActorAttr อย่างต่ำเท่ากับ `probe base 1`** (Gladiator: level 1, exp 0, สเตตัสตาม CHARCREATE_CLASS s_SCORE, HP/MP ตาม STANDARD_STATUS, class 1) **และต้องมีชื่อตัวละครในช่อง x1 (BasicAttr NAME +0x28) เสมอ** — ห้ามส่งตัวละคร "HP 100/100 + ชื่อในช่องกิลด์ + class 0" แบบทุกรอบที่ผ่านมาอีก
2. **แก้บั๊กชื่อ:** ชื่อตัวละครที่ปัจจุบันส่งลง x37 (+0x164 = LABEL_GUILD ชื่อกิลด์) ต้องย้ายไป x1 · x37 ต้องว่างสำหรับตัวละครใหม่ (ไม่มีกิลด์) — เจ้าของวินิจฉัยว่าเป็นบั๊กตกทอดจากผู้เขียนรุ่น V1–V141
3. **หลักการทั่วไป:** actor ทุกชนิดที่เซิร์ฟเวอร์สร้าง — ผู้เล่น, NPC, มอน, object อื่น — ต้องส่ง attr ให้ครบสมบูรณ์ที่สุดเท่าที่รู้ ไม่ใช่ขั้นต่ำที่พอไม่พัง เพราะช่องที่ขาดทำให้ client ปิดฟีเจอร์เงียบ ๆ แล้วเทสติด block โดยไม่รู้สาเหตุ (ตัวอย่างจริง: หน้าต่างสกิลเปิดไม่ได้จน GT learn-skill ติด — สาเหตุคือไม่เคยส่ง class)
4. ใครเป็นเจ้าของโค้ดส่วนประกอบ ActorAttr ตอน login/spawn ให้ COO/chief จัดตาม PANYA-ORDER 1230 (lane hooks) — เจ้าของไม่ได้ระบุคน ระบุแค่ผลลัพธ์
