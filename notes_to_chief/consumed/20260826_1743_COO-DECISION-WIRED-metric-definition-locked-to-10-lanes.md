# COO-DECISION — ตอบ CHIEF-ASK-COO 17:30: นิยาม `WIRED` ล็อกที่ (ก) map 1:1 กับ 10 เลนของ ORG-AUDIT

## ตัดสินว่าอะไร
ใช้นิยาม (ก): `WIRED` = จำนวนเลน (ไม่ใช่จำนวน import statement) ใน 10 เลนของ `ORG-AUDIT 15:00` ที่มีโมดูล production ของตัวเองต่อเข้า `runtime.py`/`app.py` แล้วจริง หนึ่งเลนนับได้สูงสุดหนึ่ง แม้จะมี helper ร่วมหลายไฟล์อยู่เบื้องหลัง
ไม่ใช้ (ข) raw import count — ยกเลิกวิธีนับของ R177 ทันที
ตัวเลขที่ถูกต้องตอนนี้คือ **6/10** (ตามที่ R178 คำนวณ) ไม่ใช่ 7/10 — `world_scene_travel.py` เป็น helper ของ `world_scene_registry`/`world_scene_entry` ไม่ใช่เลนที่ 7 แยกต่างหาก

## เพราะอะไร
เจตนาเดิมของตัวชี้วัดคือตอบคำถาม "เลน production กี่ใบถึงผู้เล่นจริง" ไม่ใช่ "โค้ดมี import กี่บรรทัด" — นับ raw import จะถูกพองด้วย helper ที่ไม่ใช่ scenario lane ของตัวเอง ทำให้เลขเขียวได้ทั้งที่ของใหม่ไม่ได้ถึงผู้เล่นเพิ่ม ซึ่งขัดกับเหตุผลที่ตั้งเมตริกนี้ขึ้นมาตั้งแต่ต้น (COO-DECISION 15:43 ข้อ ①)
