## 1. สิ่งที่วัดได้ (ที่มาของคำสั่ง)

their gate/merge — routine, no blocker needing Panya's attention"* แล้วเซสชันปิด · ต่อมา PR ฝั่ง server
ตายที่เกตโดยไม่มีใครอยู่รับผล

| 2026-09-04 ถึง 11:49 | **4** (`#694 696 697 710`) |

วงจรที่ตามมาต่อใบ: push → เซสชันจบ → เกตแดง (2–14 นาที ตามตาราง chief `0936`) → PR ถูกปิด → sync แจ้งสาย →

🔴 **สิ่งนี้ต่างจากที่ chief แก้เมื่อเช้า (R335)** — R335 แก้ให้ workflow ตัดสินจาก `pull_request`-run แทน `push`-run
ซึ่งหยุด "โค้ดแดงหลุดขึ้น main" (ปัญหา A) · แต่ทำให้ PR แดง**ค้างอย่างถูกต้อง**แทน — ปัญหา B ("ไม่มีใครอยู่รับผล")

## 2. คำสั่งของเจ้าของ

**รอบใดก็ตามที่ push PR ไปแล้ว ห้ามจบรอบจนกว่าจะอ่านคำตัดสินของเกตของ PR นั้นได้** · ทำผ่าน `PROCESS_GATES.md`

## 3. ร่าง §22 สำหรับ chief (ปรับถ้อยคำได้ ห้ามปรับสาระ)

> ## 22. 🔴 รอบไม่จบจนกว่าเกตของ PR ตัวเองจะตัดสิน — "push แล้ว" ไม่ใช่ "เสร็จ" (กฎใหม่ · ที่มา: `20260904_1158_PANYA-DECISION-a-round-does-not-end-until-its-gate-has-spoken-*`)
>
> - ต้นเหตุ: 18 PR ฝั่ง server ตายที่เกตใน 35 ชม. (3–4 ก.ย.) ทุกใบจบรอบด้วย "routine, no blocker" ก่อนเกตจะตัดสิน 2–14 นาทีต่อมา
>   ใบแจ้ง `SYNC-NOTICE` เขียนเองว่า "the gate finishes minutes later with nobody left to receive the result" — วงจรกู้ 1–4 ชม.ต่อใบ
> - กฎใหม่ (ทุกสายรวม chief): หลัง push + marker ให้ **รออ่านผล job `gate` ของ run `pull_request`** (ไม่ใช่ run `push` — ตาม R335/`0936`)
>   ของ PR ตัวเองก่อนจบรอบ **สูงสุด 10 นาที** (poll ทุก ~60 วิ)
>   - **เขียว** ⇒ จบรอบตามปกติ
>   - **แดง** ⇒ **แก้ในรอบเดียวกัน** ขณะที่ยังจำได้ว่าแตะอะไรไป แล้ว push + รอใหม่ · นับเป็นการตายที่เกตหนึ่งครั้งตาม COO `0748`
>   - **ยังไม่ตัดสินเมื่อครบ 10 นาทีหรือหมดงบเวลา** ⇒ ห้ามเขียนว่า "routine"/"no blocker" · ให้เขียนเลข PR ลงไฟล์รอบและ memory ของสาย
>     ด้วยคำว่า `GATE_UNVERIFIED #<n>` · **รอบถัดไปของสายนั้นต้องเปิดด้วยการตรวจ PR นั้นก่อนงานใหม่** และกู้เองได้เลยถ้าแดง
>     โดยไม่ต้องรอคำตัดสิน COO (สาขายังอยู่เสมอ workflow ไม่ลบสาขา)
> - ห้าม: ปิดเซสชันด้วยประโยคทำนอง "waiting on gate/merge — routine" ขณะที่เกตยังไม่ตัดสิน — ประโยคนั้นคือคำสารภาพว่าทิ้ง PR ไว้ตายเอง
> - วัดผล: `sync_state_closed_prs.log` / จำนวนใบ `SYNC-NOTICE-*-closed-never-merged` ต่อวัน — เส้นฐาน 14 (3 ก.ย.) · นัดวัดซ้ำ 6 ก.ย.
>   ถ้ายังไม่ลดชัดเจน เจ้าของจะย้ายกฎนี้เข้า prompt ของทุกสายแทน
> - มีผลตั้งแต่รอบถัดไปของทุกสายหลัง chief ลงกฎ
