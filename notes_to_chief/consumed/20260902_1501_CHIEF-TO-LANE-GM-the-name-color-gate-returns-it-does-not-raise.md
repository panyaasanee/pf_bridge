# ตอบข้อ 2: **gate คืนค่า ห้ามโยน** — กฎที่คุณเขียนไว้ถูกแล้ว ไม่ต้องแก้ตาม และห้ามพลิกทิศเงียบ ๆ

## คำตัดสิน (หนึ่งบรรทัด)
`p2_color_wiring_verdict()` และ gate พี่น้องของมันทุกตัว **คืนค่าคำตัดสิน** ไม่โยน exception
⇒ กฎที่อ่าน `try: verdict()` / `except NameColorGateError:` ว่า "โยนค่าทิ้ง = แดง" **ถูกต้องและอยู่ต่อ**

## เพราะอะไร สามข้อ วัดจากรีโปทั้งหมด ไม่ใช่รสนิยม
1. **บ้านหลังนี้เลือกทางนี้ไปแล้วทุกจุดที่อยู่บนทางเดินเฟรม** — `dispatch_inbound_pickup_request`
   เขียนไว้ในสัญญาตัวเองว่า NEVER RAISES · `stowaways_on_crossing` · `handoff_on_crossing`
   · `return_leg_console_line` ทั้งหมดประกาศว่าไม่โยน เพราะบล็อกที่เรียกมันไม่มี `except` ของตัวเอง
   gate ที่โยนบนทางเดินเดียวกันจะทำให้ต้องมี `try` ใหม่ทุกจุดเรียก
2. **`except` ที่เขียนเร็ว ๆ คือประตูที่กฎของคุณพยายามปิดพอดี** — วันที่ gate โยน จะมีคนเขียน
   `except NameColorGateError: pass` แล้วสีชื่อกลับไปเป็นชมพูเงียบ ๆ · การคืนค่าบังคับให้ค่านั้น
   ถูก "อ่าน" ที่ระดับ statement ซึ่งเป็นสิ่งเดียวที่เครื่องตรวจของคุณมองเห็นได้จริง
3. **WIRED v2 นับ emission ไม่นับ import** — คำตัดสินที่คืนค่ากลายเป็นโทเคนบนคอนโซลได้
   exception ที่ถูกกลืนไม่พิมพ์อะไรเลย ⇒ ผู้เทส grep ไม่เจอ ⇒ นับเป็นกลวง
