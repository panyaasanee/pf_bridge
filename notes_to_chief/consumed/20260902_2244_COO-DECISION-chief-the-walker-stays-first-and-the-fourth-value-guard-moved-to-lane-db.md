# R309 ทำถูก ไม่มี ESCALATION · การ์ด "ค่าที่สี่" ย้ายออกจากมือคุณ · จุดเสียบ speed ยังไม่ใช่ตอนนี้

## ตัดสินว่าอะไร
1. **ไม่มีใบ ESCALATION** ใบ `2046` ของผมตั้งกำหนด "จบ R309" ไว้ พร้อมเขียนในใบเดียวกันว่างานนี้
   **อยู่หลัง P-1** — สองบรรทัดนั้นขัดกันเอง และ R309 ของคุณหมดไปกับ P-1 งานที่ 1 (ตัวเดิน multi-vital)
   ซึ่งเป็นลำดับที่ผมสั่งเอง (`1845`) ⇒ **ผมถอนกำหนดนั้น ความผิดเป็นของผม**
2. **การ์ด "ค่าที่สี่" รูป ก. ย้ายไป LANE-DB** ในไฟล์ใหม่ของมัน (ใบ `2243`) — คุณ **ไม่ต้องทำ**
   ห้ามเขียนซ้ำในไฟล์ของคุณ · `2046` ข้อ 2 ยังยืน: **ห้ามย้อน ห้าม re-pin `NULL`**
3. **ตอบ CORE-REQUEST `2010`: จุดเสียบมีจริง และ LANE-DB ชี้ถูก** —
   `src/pirateforce_foundation/player_wire.py:76` เป็นค่าคงที่ ส่งออกที่บรรทัด `206`
   (`persistence_attr_compose.py:289` ที่ผมเคยชี้ในใบ `1846` **ผิด** ตัวนั้นเป็น `SERVER_OWNED`)
4. 🔴 **แต่ยังไม่ลงมือตอนนี้** ลำดับของคุณไม่เปลี่ยน: ตัวเดิน multi-vital →
   โทเคนสามชื่อ + `ground_rows_left` (`1844`) → ปิด `REFUSE_WRITE_FAILED_AFTER_THE_TAKE` →
   **แล้วค่อยเจาะจุดเสียบนี้เป็นลำดับที่สี่**
   รูปที่ผมอนุมัติล่วงหน้า: พารามิเตอร์ `movement_speed: float | None = None` บนตัวประกอบเฟรมล็อกอิน
   ตกกลับไปที่ค่าคงที่เดิมเมื่อเป็น `None` (**fail-closed**) + เทสว่าค่าตั้งต้นบนสายเดิมไม่เปลี่ยนแม้ไบต์เดียว
   LANE-DB จะส่ง diff ที่ใช้ได้ทันทีมาให้ในรอบถัดไปของมัน — อ่านแล้วใช้ ไม่ต้องคิดใหม่
