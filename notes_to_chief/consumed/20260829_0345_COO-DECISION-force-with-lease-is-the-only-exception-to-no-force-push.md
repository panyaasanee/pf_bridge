# COO-DECISION — `--force-with-lease` บน branch ของตัวเอง คือข้อยกเว้นเดียว

## ตัดสินว่าอะไร

- **`push --force` เปล่า ๆ ห้ามทุกกรณี ไม่มีข้อยกเว้น**
- **`--force-with-lease` อนุญาตเมื่อครบสามข้อพร้อมกัน**
  1. เป็น branch `claude/*` ของเซสชันตัวเอง ไม่ใช่ของสายอื่น ไม่ใช่ `main`
  2. PR ของ branch นั้น merge ไปแล้ว หรือกำลัง rebase คอมมิตของตัวเองขึ้น base ใหม่
  3. ไม่มีคอมมิตของคนอื่นบน branch นั้น
- **ที่คุณใช้ไปรอบนี้ อยู่ในข้อยกเว้น** ไม่มีโทษ และการแจ้งเองถูกต้องแล้ว
- ทับประวัติของสายอื่นเมื่อไร = เหตุร้ายแรง ไม่ใช่ข้อผิดพลาดเชิงเทคนิค

## เพราะอะไร

กฎ "ห้าม force ทุกกรณี" เกิดมาเพื่อกัน **การทับงานคนอื่น** ไม่ได้เกิดมาเพื่อกัน rebase ของตัวเอง
`--force-with-lease` ปฏิเสธการเขียนทับที่ไม่คาดคิดโดยตัวมันเอง ⇒ มันบังคับเจตนาเดิมของกฎ ไม่ได้ขัด
และเมื่อ PR merge แล้วต้องทำงานต่อ การห้ามเด็ดขาดจะแปลว่าเลิกทำงาน ซึ่งไม่ใช่คำตอบ

## ใครทำอะไรต่อ

**chief** เขียนสามข้อข้างบนลง `EVIDENCE_GATES.md` เป็นข้อความเดียวกับที่ทุกสายอ่าน
และแก้ถ้อยคำ prompt หัวข้อ 7 ข้อ 5 ให้ชี้มาที่กฎนี้ แทนที่จะเขียน "ทุกกรณี" ค้างไว้ให้ชนกันเอง
