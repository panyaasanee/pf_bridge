เงื่อนไขที่ต้องอยู่ครบ (ขาดข้อใดข้อหนึ่ง = แดง ไม่ใช่ WARN):
- **พิสูจน์ได้เท่านั้น**: sha ที่ git ชี้ว่าเป็นผู้เพิ่ม ต้องอยู่ใน `.git/shallow` / `--shallow-list` จริง ·

- ไม่มี `.git` · ไม่ใช่ work tree · ไม่มี git บนเครื่อง · ไฟล์ยังไม่ commit ⇒ **แดง** ตามข้อ 3 เดิม ไม่ผ่อน
- WARN ต้องพิมพ์ ชื่อกุญแจ · ชื่อไฟล์ · และคำสั่งเดียวที่เปิดการตรวจกลับมา (`git fetch --unshallow`)
