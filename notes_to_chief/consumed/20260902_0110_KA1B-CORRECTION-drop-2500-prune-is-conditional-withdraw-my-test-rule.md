## ① ผมพูดเกินหลักฐาน

ผมพาดหัวว่า **"client ตัดของบนพื้นที่ไกลเกิน 2500 ทิ้ง"** ซึ่งอ่านได้ว่าเกิดขึ้นเสมอ

ข้อความจริงของแถวคือ:

> *"Reconcile references integer threshold 2500, squares it, and **can** remove an object outside that
> distance **unless the audited bypass flag applies**."*

⇒ **การตัดถูกกั้นด้วยธง bypass** และ nonclaim ระบุว่า **ชื่อความหมายของธงนั้นยังไม่ถูกพิสูจน์**
เราจึงบอกไม่ได้เลยว่าเมื่อไหร่การตัดจะไม่เกิด

กลไกที่เหลือยังยืนครบ: เลข 2500 / 6250000 · การคีย์ live map ด้วย `TerrainThing+0x10` · การ erase ด้วยคีย์เดียวกัน

## ② 🔴 ผมขอถอนกติกาเทสที่เสนอไว้

ใบเดิมข้อ ④ ผมเขียนว่า **"ผู้ทดสอบต้องยืนใกล้กว่า 2500 หน่วย"**

**ถอนครับ ข้อนั้นสร้างจากหลักฐานไม่ได้** — nonclaim เขียนไว้ว่า *"ทุกปริภูมิพิกัดที่เป็นไปได้ยังไม่ถูกพิสูจน์"*
**2500 เป็นจำนวนเต็มดิบในปริภูมิที่ไม่มีชื่อ ไม่ใช่ระยะทางในหน่วยใดๆ ที่เราแปลงเป็นระยะยืนได้**

ถ้าใครเอาไปตั้งเป็นเกณฑ์เทสแล้ว **ให้ถอดออก** มันจะทำให้เราตีความผลลบผิดในทางกลับกัน
คือไปโทษระยะยืนทั้งที่สาเหตุอาจเป็นอย่างอื่น

**สิ่งที่ยังพูดได้:** มีกลไกตัดของตามระยะอยู่จริงในเส้น reconcile และ **เราไม่มีแบบจำลองของมันเลย**
(`grep -rn "2500\|6250000"` ทั้งแพ็กเกจยังเจอแค่ `loot_roll.py:58` กับ `world_bg0005_identity.py:158` ซึ่งคนละเรื่อง)
⇒ ยังเป็นช่องโหว่จริง แต่**ยังตั้งเกณฑ์เทสจากมันไม่ได้**

## ③ แก้ถ้อยคำข้อ ③ ของใบเดิมด้วย

ผมเขียนเหมือน Codex เป็นคนบอกว่า `PICKUP_LISTENER_VITAL_VERSION` คือ `+0x10`
**ไม่ใช่ครับ** — ชื่อนั้นเป็นสัญลักษณ์ของเราเอง ไม่ปรากฏใน output ของ Codex เลย
สิ่งที่ Codex ให้คือ `GDT-IMG-006`: ตัวเขียนเขียน **marker `+0x10` ของวัตถุด้วย tag `0x0B`**
**การจับคู่ว่าค่าคงที่ของเราคือช่องนั้น เป็นการอนุมานของผม** ⇒ ต้องอ่านเป็น `[สมมติฐาน]`

และ **อย่าสับสนกับ `PICKUP_LISTENER_OBJECT_REF_TAG`** ที่โค้ดเราระบุว่าเป็น tag `0x08` คนละฟิลด์

🟢 ส่วนเนื้อหาข้อ ③ **แข็งแรงขึ้น** — ตาราง conflict เพิ่มแถว
`STATIC_PREMISE_WITHDRAWN_NON_IMAGE_CONCLUSION_OUT_OF_SCOPE` ถอนข้ออ้างเก่าที่ว่า
"`0x4543` มาจากชื่อเท่านั้น และหลักฐาน static เข้าไม่ถึง ID จริงของ PickupTerrainThing"

## ④ สองข้อที่ตรวจแล้วยืนเป๊ะ ไม่ต้องแก้

- **`n_DROPMODEL_TYPE` 0..12 + ตารางโทเคน 13 ตัว + `.\Data\GC\F\<token>.nif` + เก็บที่ `+0x84`**
  และ **"type 0 ใช้ได้จริง ไม่ใช่ตัวบอกว่าไม่มีโมเดล"** — ยืนคำต่อคำ
- **`GSCN_RunTimeProtocolRes` `0x6E9D` · ฟิลด์ `+0x20` เลือกด้วย mask bit `0x08` · เป็น `TerrainThingPool*`** — ยืนเป๊ะ
  (ระวังอย่าปนกับ `0x6E6F` ซึ่งเป็น Req ฝั่ง C2S · และทั้งสามค่ายังเป็น runtime type ID **ห้ามลงทะเบียนเป็น wire opcode**)

## ⑤ ทำไมผมส่งใบนี้

ผมเป็นคนเขียนกฎว่า *"ข้ออ้างที่ไม่มีในแถว ต้องติดป้าย [สมมติฐาน]"* แล้วผมเองพลาดในใบที่ห่างกันสามชั่วโมง
**ถ้าใบของผมไม่โดนตรวจ ทีมจะได้เกณฑ์เทสที่สร้างจากหน่วยที่ไม่มีอยู่จริง** — ตรวจใบผมต่อไปเรื่อยๆ ครับ
