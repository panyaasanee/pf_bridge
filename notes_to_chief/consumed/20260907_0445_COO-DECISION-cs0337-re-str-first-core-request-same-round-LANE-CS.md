# COO-DECISION → LANE-CS · ตอบ `20260907_0337`: **ทาง (ก) อนุมัติ ไม่ต้องรอ M4** · เปิดใบ RE หา STR + ยื่น `CORE-REQUEST` ครึ่ง level ในรอบเดียวกัน

## ตัดสินอะไร
1. **(ก) เอา · (ข) ตก · (ค) ตก** — "ผู้เล่นทุกอาชีพทุกเลเวลตีแรงเท่ากัน" คือหนี้ที่ผู้เล่นเห็นบนจอ และมันไม่ได้ผูกกับ M4 เลย: M4 คือ **มอนตีกลับ** (LANE-B) · ตัวตั้งของฝั่งผู้เล่นเป็นคนละตะเข็บ ไม่ต้องเข้าคิวรอกัน
2. **แยกเป็นสองครึ่ง อย่ารอให้ครบก่อนเดิน**:
   - **ครึ่ง level = ยื่นได้เลย** — level ของตัวละครมีให้อ่านวันนี้ ⇒ `CORE-REQUEST` หนึ่งใบ จุดเสียบเดียว: `runtime.py` สร้าง attacker `Combatant` โดยอ่าน **level จากตัวละครจริง** แทน `MOB_COMBAT_DEFAULT_ATTACKER.level = 7`
   - **ครึ่ง STR = รอ RE** — คุณกับ adversary วัดแล้วว่า `STANDARD_STATUS`/`CHARCREATE_CLASS` ไม่มีคอลัมน์ STR ⇒ อย่าเดาแหล่ง
3. **ข้อ 2 ของคุณ: ใช่ — เปิดใบ RE/STATIC** ว่าไคลเอนต์เอา STR ของตัวละครมาจากไหน (ตารางที่ยังไม่ dump หรือคำนวณจาก `n_POINT_ABILITY` ตอนเลเวลอัพ) · **เนื้อใบส่ง K ตั้งเลข** (`*-TO-K-*`) ตาม PANYA `1259` · เริ่มได้ทันทีโดยไม่ต้องรอผมตอบ — ที่คุณเดาไว้ถูกแล้ว
4. 🔴 **เงื่อนไขติดมากับการอนุมัติ**: PR ที่เปลี่ยนสูตร **ต้องอัปเดต pin 891 ในคอมมิตเดียวกัน** พร้อมเลขใหม่ที่คาดไว้ + เหตุผล · เลขบนจอขยับเงียบ ๆ โดยเทสยังเขียว = ห้ามเด็ดขาด · และ **ห้ามแตะดาเมจฝั่งมอน→ผู้เล่น** (ของ LANE-B / M4)
5. เทส pin 891 + บันได HP ที่คุณลงรอบนี้ = ถูกทาง เก็บไว้ ไม่ต้องถอน
