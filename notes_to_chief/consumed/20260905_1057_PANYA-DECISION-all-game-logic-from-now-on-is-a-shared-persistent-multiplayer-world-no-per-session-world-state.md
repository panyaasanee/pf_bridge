# PANYA-DECISION — ตั้งแต่นี้ทุก logic เกมต้องเป็น "shared persistent world" รองรับหลาย session/หลายผู้เล่นพร้อมกัน — ห้ามผูกสถานะโลกไว้กับ session ใด session หนึ่ง

## คำตัดสิน (ถ้อยคำของ Panya — ยกมาตรง ๆ)
> "ทำไมเราไม่เขียนโค้ด เขียน logic เซิร์ฟให้เหมือน MMORPG ทั่วไป ที่ไม่ lock world ไว้แค่ใน session เดียว (ฆ่ามอนตาย ของตก logout/login กลับมาก็เหมือน reset ใหม่ ไม่ได้เหมือนเป็น shared world จริง ๆ) ของก็กระพริบตอนผู้เล่นเปิดกระเป๋า แล้วถ้ากรณีผู้เล่นอื่นที่ login เข้ามาอยู่ด้วยล่ะ มันไม่ควรให้อะไร ๆ ก็อยู่แค่ใน session ใด session หนึ่ง · เป้าหมายเราคือ MMORPG ที่เล่นได้จริง (MMO หมายถึง Multiplayer หลาย sessions) เพราะฉะนั้นทุกการออกแบบ ทุกโค้ดของเราตั้งแต่ตอนนี้ ควรออกเกม logic ที่รองรับ multiplayer"

## กติกาที่ตามมา (ตีความโดยมือเขียนแทน — ให้ COO/chief แปลงเป็นข้อบังคับ · ถ้าตีความเกินคำ Panya ให้ถามเธอ ไม่ใช่เดา)
1. **สถานะโลกอยู่ที่เซิร์ฟเวอร์ + DB ไม่ใช่ที่ session**: มอนตาย/เกิดใหม่ · ของตกบนพื้น · ตำแหน่ง/สถานะ actor ในฉาก ต้องคงอยู่ข้าม logout/login และเห็นเหมือนกันจากทุก session ที่อยู่ฉากเดียวกัน · "ทะเบียนศพ/ทะเบียนของพื้นต่อ session" (GT-223 FAIL R309) และ "ทุกอย่างรีเซ็ตเมื่อ relogin" ถือเป็นข้อบกพร่องที่ต้องแก้ ไม่ใช่ข้อจำกัดที่ยอมรับ
2. **เฟรมที่ส่งเพราะการกระทำของผู้เล่นคนเดียว ห้ามทำให้ client ลบหรือวาดโลกใหม่ทั้งฉาก** (เช่น เปิดกระเป๋า → ประกาศของพื้นซ้ำจนกระพริบ · ตีมอนตัวใหม่ → เฟรมจัดแถวลบของพื้นของตัวเก่า — ทั้งสองเห็นจริง R316) ให้ส่งเฉพาะส่วนต่าง (delta) ของสิ่งที่เปลี่ยน
3. **ทุกใบงาน/PR ใหม่ตั้งแต่นี้ต้องตอบได้ว่า "ถ้ามี 2 session ในฉากเดียวกัน พฤติกรรมนี้ถูกไหม"** — ใส่เป็นข้อบังคับใน checklist ของ pf-adversary/เกต (chief ตัดสินรูปแบบ)
4. งานที่ค้างอยู่แล้วและเข้าข่าย (ให้ COO จัดลำดับ): ทะเบียนศพ/มอนเกิดใหม่ข้าม session (LANE-B 1649 / COO 0247) · ของพื้นข้าม session + อายุของจริง (LANE-B) · roster/census ที่ประกอบต่อ session (LANE-A) · ตำแหน่ง/ฉากผูก account (LANE-DB — ส่วนนี้ทำแล้วบางส่วน)

## เหตุผลของ Panya (สำคัญต่อการตีความ)
เป้าหมายโปรเจกต์คือ MMORPG ที่เล่นได้จริง = หลายผู้เล่นพร้อมกัน · ถ้าออกแบบแบบ single-session ตอนนี้ ทุกอย่างต้องรื้อใหม่ตอนมีผู้เล่นคนที่สอง · ปรากฏการณ์ที่เธอเห็นเองรอบ R316: ของตกหายตอนตีมอนตัวใหม่แล้วกลับมาโผล่ · ของกระพริบตอนเปิดกระเป๋า · relogin แล้วมอนที่ตายกลับมามีชีวิตและของหาย (R309)
