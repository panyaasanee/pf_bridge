# เกตวินโดวส์ยังมองไม่เห็นเทสของสายนี้อีก 120 ตัว ด้วยเหตุเดียวกับ D1

## เรื่องเดิมหนึ่งบรรทัด
`.github/workflows/gate-windows.yml` บล็อก "building the pytest exclusion list" กัน (`--ignore`)
ทุกไฟล์ใน `tests/` ที่ **เอ่ยชื่อ**คลาสหน้าต่างของไคลเอนต์ หรือโทเคนโฟลเดอร์ capture corpus
เจตนาถูกต้อง (ไฟล์พวกนั้นอ่าน image/corpus ซึ่งโคลนไม่มี) แต่มันจับ "ไฟล์ที่พูดถึงชื่อ" ไม่ใช่
"ไฟล์ที่ต้องใช้ของจริง" — และดอกสตริงของสายนี้ใช้ชื่อนั้น **เพื่อบอกว่าไม่ต้องใช้มัน**

รอบนี้ (`66q0p7`) แก้ไปแล้วหนึ่งไฟล์ตามที่ pf-adversary ชี้ (D1):
`tests/test_learn_skill_result_hypothesis.py` — จาก **เก็บได้ 0** เป็น **62 เทส**

## ที่ยังเหลือ (วัดแล้ว ไม่ได้เดา)
คำสั่งที่ใช้วัด:

    grep -n "no network, no GameClient" tests/*.py
    PYTHONPATH=src python3 -m pytest tests/test_learn_skill_request_hypothesis.py \
        tests/test_skill_attr_hypothesis.py -q --collect-only | tail -2

ผล:

    tests/test_learn_skill_request_hypothesis.py:4
    tests/test_skill_attr_hypothesis.py:4
    120 tests collected

ทั้งสองไฟล์เป็นของสายนี้ ทั้งสองไฟล์ **ไม่มี** `skip`/`xfail` และไม่อ่าน image/corpus จริง
⇒ วันนี้เกตรัน 0 จาก 120 และเกตเขียวไม่ได้บอกอะไรเกี่ยวกับมันเลย
