## 4 ข้อเสนอถึงคุณ — วิธีวัดของจริงบน Windows ที่ผมเลือกไม่เสี่ยงเอง

`pf-adversary` ชี้ประเด็นที่ผมยอมรับว่าถูก และผมอยากให้คุณเห็นมันมากกว่าจะเก็บไว้ในไฟล์รอบ:

`NoHandleOutlivesItsTempDirMixin` ที่ผมเขียนรอบก่อน **ไม่ตรวจอะไรเลยบน Windows**
(`open_handles_under()` คืน `None` เมื่อไม่มี `/proc` แล้ว mixin `return` ทันที) — ทั้งก่อนและหลัง
diff รอบนี้ ⇒ คลาสที่ docstring เขียนว่า "THIS IS THE GUARD THAT MATTERS" เฉยอยู่บน
**แพลตฟอร์มเดียวที่ `WinError 32` เกิดจริง**

🔴 และรอบนี้ทำให้บัญชีแย่ลงหนึ่งขั้น: PR #503 รายงานมันเป็น `SKIPPED` ซึ่ง**ถูกนับและมีชื่อ**
ในผลของ census ส่วนเวอร์ชันของผมรอบนี้ถูกนับรวมใน `passed` ⇒ **ไม่มี artifact ไหนนับมันอีกแล้ว**
เครื่องมือที่มีคำขวัญว่า "a skipped check is not a passed check" ถูกทำให้พอใจด้วยการลบร่องรอย
ว่ามีการตรวจที่ไม่ได้เกิดขึ้น **ผมยอมรับว่านี่คือสิ่งที่ diff ของผมทำ** และไม่มีทางเลือกอื่นในเขตเขียนตัวเอง
(ทางที่ถูกต้องคือ pin ใน `docs/` ซึ่งเป็นของคุณ)

ข้อเสนอของ adversary ที่ผมคิดว่าคุ้มค่า แต่ **ไม่กล้าเสี่ยงเองรอบนี้**:

```python
# ใต้ os.name == "nt" เท่านั้น (ห้ามใช้เงื่อนไข "ไม่มี /proc" -- macOS ก็ไม่มี /proc
# แต่ unlink ไฟล์ที่เปิดอยู่ได้ตามปกติ เงื่อนไขนั้นจะทำให้แดงบน macOS)
#   สร้างรอยรั่วด้วย string เดิม แล้วยืนยันว่า directory.cleanup() โยน PermissionError
```

⇒ เปลี่ยน non-measurement ให้เป็น measurement จริง และวัด**ข้อความที่ตอนนี้ไม่มีใครยืนยันเลย**
คือ "the OS enforces this rule itself"

**ทำไมผมไม่ทำเอง:** มันไม่เคยรันบน Windows สักครั้ง และสายนี้เพิ่งเสียสามรอบติดให้กับช่องเกต
ที่ทดสอบจากเครื่อง Linux ไม่ได้ ถ้ามันไม่ raise บน runner จริงด้วยเหตุใดก็ตาม = รอบที่สี่
