## 4. ผลลบที่มีขอบเขต (ใช้จำกัดพื้นที่ค้นของรอบหน้า)

- **ไม่มีโค้ดที่ไหนเทียบ id ขาเข้ากับตัวแปร id ของคลาส** — xref ของ id global ทุกตัวได้ **2 hit พอดี**: จุดเขียนตอนลงทะเบียน กับตัวคืนค่า (สล็อต `+0x10`) เท่านั้น
  (`TeleportCheck 0x01082074` → `0x00449432` + `0x00BEE833` · `PartyInvite 0x01083880` → `0x0062E1E2` + `0x00BF4093`)
  ⇒ ตัวแจกงานขาเข้า **ไม่ได้** ใช้การเทียบตรงกับ global เหล่านี้
- **id เป็นแฮชของชื่อคลาส** — ลงทะเบียนตอนบูตผ่านตาราง static-init (`0x00DA1858` ใน `.rdata`) โดยแต่ละคลาสทำ `push <ชื่อ>; call 0x0089C080` (คืน singleton ที่ `0x0108CF90`) `; call 0x0089BD00` ซึ่งเรียก `0x0089B220(ชื่อ)` ได้ u16 แล้วเก็บลง global ของคลาส · ทะเบียนนี้เก็บ **id → ชื่อ** (แทรกด้วย `0x0089BB60`)
- **serializer ถูกอ้างจาก vtable เท่านั้น** — xref ของ `0x005E6670` = 1 hit (`.rdata`) · `0x00664550` = 2 hit (`.rdata` ทั้งคู่) ⇒ **ถูกเรียกแบบ virtual เสมอ** ไม่มีผู้เรียกตรง
- **vtable ของคลาสถูกอ้างเฉพาะจาก ctor ของตัวเอง** — `0x00F34958` = 2 hit (`0x0062E1B9`, `0x0062E22A`) ⇒ **ไม่มีการลงทะเบียน prototype ที่ไหน**

## nonclaims (ห้ามตัดออก)

1. **ไม่อ้างว่ารู้ VA ของลูปรับแพ็กเก็ต** — ข้อ 5 บอกขอบเขตที่กวาดแล้วและที่ยังไม่ได้เดิน
2. **ไม่อ้างว่า handler ทั้งสามถูกเรียกจริงในรันไทม์สำหรับแปด id นี้** — ที่พิสูจน์คือ (ก) สล็อต `+0x1C` เป็นสล็อตตัวรับจริง (จาก `RE-303`) และ (ข) ค่าที่สล็อตนี้ของทั้งแปดเป็นโค้ดจริงไม่ใช่สตับ · **`observed_frames = 0` ทั้ง W/R ทั้งแปดคลาส ยังไม่มีใครวัดรันไทม์**
3. **ไม่อ้างว่าห้าคลาส `Community_*` ถูกแยกด้วยอะไร** — ยังไม่ได้อ่าน `0x0063F9B0`

5. **ไม่อ้างความหมายของฟิลด์ใดใน `0x00664550`** — `proven_semantics` ยัง UNKNOWN
6. **ไม่อ้างว่าตัวตรวจชนิด (`0x0062C290` / `0x00641FE0` / `0x00662160`) คืนชนิดอะไร** — วัดได้แค่ว่าเป็นตัวคืนตัวบ่งชนิดที่เอาไปเทียบด้วย `0x0088F2B0`

8. static ล้วน · ไม่มี client-observable · ไม่ได้แก้ไฟล์ใด ๆ
