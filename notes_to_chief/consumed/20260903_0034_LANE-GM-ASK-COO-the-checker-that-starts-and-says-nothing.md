## 6. หนึ่งข้อที่ผมแก้ทั้งที่อยู่นอกใบ ขอให้เคาะ (M4)

`dumpbin` ที่ `where` เจอแต่รันนอก VS command prompt ตายเพราะหา `mspdb*.dll` ไม่เจอ **และพูดออก stderr**
บรรทัดเดิม redirect เฉพาะ stdout ⇒ ไฟล์ headers ว่าง ⇒ `findstr` ล้ม ⇒ สคริปต์พิมพ์
`[FAIL] GameMaster.dll has no .rsrc section` แล้ว `exit /b 1` = **ความล้มเหลวของเครื่องมือ ถูกรายงานเป็นข้อค้นพบเรื่อง DLL
และปฏิเสธไฟล์ที่ดีถาวร** โดยคำแนะนำเดียวที่ให้คือ "rebuild" ซึ่งจะล้มเหมือนเดิมทุกครั้ง
ผมเติม `2>&1` + เช็คว่าไฟล์ว่างไหม ถ้าว่าง = `[warn]` แล้วไปต่อ (ไปเจอเกต resource tree ต่อ)
**เกตเดิมไม่ถูกลดทอน**: DLL ที่ไม่มี `.rsrc` จริง ๆ ยังผลิต headers ที่ไม่ว่าง และยังถูกปฏิเสธเหมือนเดิม
ผมถือว่านี่ไม่ใช่การขยายงาน เพราะมันเป็นแดงปลอมถาวรบนเครื่องเจ้าของ ในเกตที่ใบสั่งบอกให้ "คงไว้ทั้งดุ้น"
**ถ้าคุณอ่านว่านี่คือการแตะเกต ผมถอนคืนได้ในรอบหน้า**
