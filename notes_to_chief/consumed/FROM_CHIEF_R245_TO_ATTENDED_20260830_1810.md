# สรุปรอบนี้

**ไม่มีอะไรให้เทสในเกมรอบนี้** — ไม่บูต client ไม่แตะ DB จริง

## ทำอะไรไปบ้าง

1. **แก้บั๊กจริงตัวหนึ่ง**: เวิร์กโฟลว์ merge PR ของสาย E (`merge-claude-pr.yml`) เคยปล่อยให้ PR ค้าง
   draft ได้นานถึง 2 ชั่วโมงก่อนจะถูกเก็บกวาด ทั้งที่แต่ละเลนวิ่งทุกชั่วโมง — ถ้า PR ของเลนไหนค้าง draft
   (เช่นที่เกิดกับสาย A เมื่อครู่ `#507`) เลนนั้นจะเห็น PR ของตัวเองแล้วจบรอบทิ้งทุกครั้ง ซ้ำแล้วซ้ำอีกได้ถึง
   2 รอบก่อนระบบจะแก้เอง ลดเวลาเหลือ 45 นาที (สั้นกว่าคาบชั่วโมง) กันไม่ให้เกิดซ้ำนานขนาดนั้นอีก
2. **แก้ไบก์ในคิวเทส**: `GT-145` (วัด encoding คอนโซล — คุณรันโพรบให้แล้วเมื่อกี้ วัดครบสี่ค่าตรงคำทำนาย
   ทั้งหมด) หัวใบเคยฝัง sha256 ของ canonical DB ไว้ตายตัว ค่าเก่าจะทำให้บูตครั้งหน้า abort ผิดทั้งที่ DB
   ไม่ได้เสีย แก้ให้อ้างไฟล์ `CANON_SHA.txt` แทนแล้ว
3. **ตอบคำถามสาย GM**: `/spawn` (สร้างมอนสเตอร์ใหม่กลางเกม) ยังทำไม่ได้เลยเพราะ **ไม่มีฟังก์ชันสร้างมอน
   ใหม่กลางเซสชันอยู่ในโค้ดตอนนี้เลยสักจุด** (ตรวจสองรอบอิสระแล้ว) ถ้าอยากได้จริงต้องนับเป็นฟีเจอร์ใหม่
   ของเอนจิน ไม่ใช่แค่ต่อสาย — คำสั่ง `/npc` ใกล้ใช้ได้ที่สุดในสามตัวที่เหลือ (`npc`/`item`/`spawn`)

## ยังไม่ได้ทำ

- ปลดล็อก `FORCE_POS_VITAL_VERSION_CONFIRMED` (กำหนดใหม่พรุ่งนี้ 09:00 — ยังไม่เร่ง)
- คำถาม encoding อีกสองข้อของ GT-145 (นโยบาย CI vs ค่าจริงบนสะพาน) ยังไม่ตัดสิน รอรอบที่มีเวลาคิด
