## GT-203 GM-PLUGIN-THREE-CELL-BUTTON-001

- objective: ข้อเดียว — ปุ่ม GM ที่กดแล้วเงียบมาตั้งแต่ `RE-104` (27 ส.ค.) เปิดหน้าต่างได้หรือไม่
  เมื่อมี `GameMaster.dll` ที่เราสร้างเองอยู่ข้าง client · ใบนี้ **ไม่** ตัดสินว่าฟีเจอร์ GM ใดทำงาน
  และ **ไม่** ให้สถานะ GM กับใคร (สถานะ GM ยังตัดสินที่ `gm_accounts` ฝั่งเซิร์ฟเวอร์เท่านั้น)

- 🔴 ก่อนบูตทุกครั้ง (ขั้น 0): จาก checkout ของ `pirate-force-server` · `set PYTHONPATH=src` แล้ว
  `py -3 -m pirateforce_foundation.gm.plugin_image_check --dll <build>\GameMaster.dll --client-dir "<client>"`
  บันทึก verdict + sha256 ทั้งสองไฟล์ · exit code ไม่เป็น 0 = **หยุด ห้ามบูต** แก้ตามที่มันบอกก่อน

- 🔴 เปิด **DebugView** ค้างไว้ก่อนบูต — ทั้งใบตัดสินด้วยบรรทัด `[GM_PLUGIN]` ไม่มีตัวจับ = อ่านผลไม่ได้เลย

- 🔴 install: ใช้ `patches\gm_plugin\install.bat "<client folder>"` เท่านั้น ห้าม copy เอง
  ถ้ามันปฏิเสธเพราะเจอ `GameMaster.dll` เดิมอยู่แล้ว = **หยุดทั้งใบ** เก็บ sha256 ของไฟล์เดิม
  แล้วรายงาน chief/COO ทันที (ไฟล์นั้นคือของที่โปรเจกต์ตามหามาตั้งแต่ 27 ส.ค. `RE-164`)

- STEP (สามช่อง ตามลำดับ ห้ามข้าม ห้าม build ช่องที่สี่ — `COO-DECISION 20260902_0648`):
  1. **ช่อง 1** `build_vs2008.bat` เปล่า ๆ (= `GMUI_1` + `PLUS4=0`) → ขั้น 0 → install → บูต →
     ล็อกอินด้วยบัญชีใน `gm_accounts` → กดปุ่ม GM หนึ่งครั้ง → ปิดเกม
  2. **ช่อง 2** เฉพาะเมื่อช่อง 1 ขึ้นบรรทัด `loaded` แต่คลิกเงียบ:
     `set EXTRA_DEFS=/D PF_GM_KEY=L\"GMUI_BASIC\"` แล้ว build ใหม่ → ทำซ้ำข้อ 1
  3. **ช่อง 3** เฉพาะเมื่อช่อง 2 ยังเงียบ: `set EXTRA_DEFS=/D PF_GM_SLOT0_TOUCH_PLUS4=1` → ทำซ้ำข้อ 1
  🔴 **ห้ามใช้ "sha256 เปลี่ยน" เป็นหลักฐานว่าแฟล็กถึง compiler** — DLL ฝัง `__DATE__`/`__TIME__`
     ทุก rebuild จึงเปลี่ยน sha เสมอแม้ลืม `set` · ตัวควบคุมจริงคือบรรทัด `EXTRA_DEFS=` ที่สคริปต์พิมพ์
     และบรรทัด `[GM_PLUGIN] key=` / `slot +0x00 +4 init:` (RECHECK ข้อ 4) · sha256 ใช้พิสูจน์แค่ว่า
     **ไฟล์ที่ติดตั้ง = ไฟล์ที่เพิ่ง build** ซึ่ง `plugin_image_check` เทียบให้อยู่แล้ว
  - **ไม่มี `loaded` ในช่องไหน = หยุดทันที ห้ามไปช่องถัดไป** กลับไปขั้น 0 แล้วรายงานผลของมัน

- RECHECK (ตามลำดับ ข้อ 1 คือข้อที่ทำให้ข้ออื่นมีความหมาย):
  1. มีบรรทัด `[GM_PLUGIN] loaded build=<วันเวลา>` **ตอนบูต** — เป็นบรรทัดแรกสุดที่ `DllMain` พิมพ์
     ก่อนโค้ดใด ๆ ที่ fault ได้ ⇒ **ไม่มี = DLL ไม่เคยถูกโหลด** (ข้อ 2-7 ไม่ต้องอ่าน)
  2. 🔴 บรรทัด `client CRT: ...` / `msvcp90 wstring ctor: ...` / `self-pin: ...` จะขึ้น **ตอนคลิกครั้งแรก**
     ไม่ใช่ตอนบูต (revision 4 ย้ายการ resolve ออกจาก loader lock) ⇒ มี `loaded` แต่ไม่มีสามบรรทัดนี้
     = **client ยังไม่เคยเรียก `CreateGameMaster`** ซึ่งเป็นข้อมูลคนละชิ้นกับ "DLL ไม่ถูกโหลด" — บันทึกให้ตรง
  3. คัดลอกทั้งสามบรรทัดนั้นมาทั้งบรรทัด · ถ้า `client CRT:` เขียนว่า **REFUSING** ให้คัดลอกพาธที่ตามมาด้วย
  4. บรรทัด `key=` และ `slot +0x00 +4 init:` (ขึ้นตอนบูต) ตรงกับช่องที่กำลังเทสจริง ← ตัวควบคุมของ build
  5. **คลิกแล้วหน้าต่าง `GMUI_1` เปิด ถึง tab `GMUI_BASIC` หรือไม่** ← ข้อที่ตัดสินทั้งใบ
  6. ปิดเกมแล้วไม่แครช (มีความหมายก็ต่อเมื่อข้อ 1 ผ่าน) · แครชตอนปิด ให้ดูบรรทัด `self-pin:` ก่อนเสมอ
  7. 🔴 เห็นบรรทัด `slot +0x08 called with no MSVCP90 ctor` = **หลักฐานใหม่ ต้องรายงาน**
     (`GM-IMG-014` blocker `NO_PINNED_CALL_ROUTE_FOR_SLOT8`)

- หลักฐานสองชั้นที่ต้องเก็บ:
  · **client-observable** = ภาพหน้าจอตอนคลิก (เปิด/ไม่เปิด) + ข้อความ debug ทั้งชุดของแต่ละช่อง
  · **wire/DB** = ใบนี้ **ไม่มีชั้นนี้** และไม่ต้องมี — ปลั๊กอินเป็นฝั่ง client ล้วน ไม่แตะ vital ไม่แตะ DB
    (ถ้าใครอ้างว่าใบนี้พิสูจน์อะไรฝั่งเซิร์ฟเวอร์ = อ้างผิด)

- เกณฑ์ปิดใบ:
  · **PASS** = ช่องใดช่องหนึ่งเปิดหน้าต่างได้ → บันทึกว่าช่องไหน แล้วปิด P-3
  · **bounded negative** = ครบสามช่อง มีบรรทัด `loaded` ทุกช่อง แต่ไม่เปิดสักช่อง
    → อ่านว่า "โหลดได้ แต่ประตูไม่ได้อยู่ที่ตัวปลั๊กอิน" → กลับไป `RE-164` ผู้ต้องสงสัยข้อ 1
    (`GM-IMG-005` gate `GMModule_Client+0x19`) **ห้ามอ่านว่า "ปลั๊กอินใช้ไม่ได้"**
  · **BLOCKED** = ไม่มีบรรทัด `loaded` เลย → ผลของ `plugin_image_check` คือคำตอบ ไม่ใช่การเดา
    ⚠️ ถ้า `plugin_image_check` ตอบ `image_ok` แต่ยังไม่มีบรรทัด `loaded` **และเกมเปิดไม่ขึ้นด้วย**
    = คนละอาการ (DLL โหลดแล้วตายใต้ loader lock) ⇒ ลบไฟล์ออกแล้วยืนยันว่าเกมกลับมาเปิดได้
    บันทึกไว้แล้วรายงาน — อย่าวนกลับไป build ช่องถัดไป

- rollback: ลบไฟล์ `GameMaster.dll` ที่ติดตั้งทิ้ง client กลับไปเดิน fallback เดิม (`GM-IMG-002`)
  ไม่มีการ patch ไบต์ของ client ไม่มีการเขียน registry ไม่แตะ DB (canonical ไม่ถูกเปิดในใบนี้เลย)

- nonclaim ที่ต้องอยู่ในผล: หน้าต่างเปิด **ไม่ใช่** ข้อพิสูจน์ว่าคำสั่ง GM ใดทำงาน และ **ไม่ใช่** ไมล์สโตน
