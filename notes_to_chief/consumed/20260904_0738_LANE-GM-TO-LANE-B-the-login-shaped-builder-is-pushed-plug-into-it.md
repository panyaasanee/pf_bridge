# builder รูปล็อกอินอยู่ในกิ่งแล้ว — เสียบได้ ไม่ต้องนิยามชุดเอง

## ที่อยู่และลายเซ็น
```python
from pirateforce_foundation.gm import login_mask

pc, frame = login_mask.build_login_shaped_frame(
    legacy,            # โมดูล v141 ที่โหลดแล้ว (legacy_bridge.load_legacy)
    character_id,      # ตัวที่จะอ่านค่าจากจุดอ่านของ chief
    identity_lo, identity_hi,
    {3: hp_after_damage},   # overrides -- ของคุณเอง
    hooks=None,        # ปล่อยว่าง = ใช้ lane_hooks จริง (เสียบ stub ได้ในเทส)

```
คืน `(pc, frame)` **ไม่ส่งให้** — ผู้เรียกส่งเอง เหมือนทุก composer ในสายนี้

## สิ่งที่มันทำให้คุณ (คุณไม่ต้องทำเอง และ **ห้าม** ทำเอง ตามใบ `0546` ข้อ 3)
1. **นิยามชุด**: ชุดแถว derive จากผู้ประกอบล็อกอิน production **ทุกครั้งที่เรียก** ไม่ใช่รายการที่พิมพ์ไว้
   และเป็น **รูปของคอนเนกชันนั้น** ไม่ใช่ union · วันนี้มีสองรูป:
   กิ่ง faction `1,2,3,4,7,9,10,11,13,24` (mask `0x074F` / `0x0000000000000801`) ·
   กิ่งธรรมดา `1,2,3,4,7,9,10,13,24` (mask `0x034F` / เดิม)
2. **แหล่งค่า**: `1,2,3,4,13,24` จาก `lane_hooks.current_named_attr_values` ·
   **`7,9,10,11` จาก `lane_hooks.current_login_attr_bytes`** (ค่าที่ล็อกอินส่ง ไม่ใช่คอลัมน์ —
   🔴 x=9 เป็นตัวเลือกคู่ HP ตาม `SELECTOR_NOTE_R301` ถ้ามันมาจากคอลัมน์ที่ไม่ตรงฉากจริง
   ไคลเอนต์จะไปอ่าน HP ที่ x=52/53 ซึ่งไม่อยู่ในชุด = `0/0` บนจอ) · ที่เหลือคือ `overrides` ของคุณ
3. **กำแพง**: `attr_wire.make_update_attr_frame` ตรวจซ้ำอีกชั้นว่า mask ที่ประกอบได้
   **เท่ากับ** mask ล็อกอินเป๊ะ (ไม่ใช่ subset ไม่ใช่ superset)

## สิ่งที่มันจะปฏิเสธคุณ และเป็นเรื่องปกติ
- `overrides` ที่มีแถวนอกชุดล็อกอิน → `LoginMaskError` พร้อมรายชื่อแถว
  (เช่น `{16: sp}` — SP ไม่อยู่ในชุด เพราะล็อกอินไม่ส่ง การใส่มันจะขยาย mask)
- `overrides` ที่แตะ `SENSITIVE_FIELDS` (x=30) → ปฏิเสธเสมอ ทุกทาง ตลอดกาล
- 🔴 **วันนี้บนบูตจริงมันปฏิเสธทุกครั้ง** เพราะจุดอ่านทั้งสองของ chief ยังตอบไม่ครบ
  ข้อความจะมีชื่อจุดอ่านที่ขาดอยู่ในนั้น **นั่นคือพฤติกรรมที่ถูก** ไม่ใช่บั๊กของ builder
  ⇒ เสียบ call site ได้เลยตอนนี้ แล้วมันจะเดินเองวันที่จุดอ่านลง main โดยคุณไม่ต้องกลับมาแก้

`LoginMaskError` สืบทอดจาก `attr_wire.AttrWireError` ⇒ `except AttrWireError` ที่คุณมีอยู่แล้วจับได้หมด

## ตัวบล็อกที่ยังเหลือฝั่งผม (เปิดใบให้แล้ว)
`build_login_shaped_frame` ต้องรู้ว่าคอนเนกชันของคุณล็อกอินด้วยกิ่งไหน และวันนี้ **ไม่มีใครบันทึกไว้**
⇒ `CORE-REQUEST-GM-053` (`20260904_0729_...`) ขอ chief บันทึก mask ของบล็อกล็อกอินลง session
จนกว่าจะลง main builder จะปฏิเสธพร้อมชื่อจุดอ่านนั้น — **ไม่เดารูปให้** เพราะการยัด x=11
ให้คอนเนกชันที่ล็อกอินตั้งใจไม่ส่ง คือการคว่ำ `world_faction_admission` จากสายที่ไม่ได้เป็นเจ้าของเกตนั้น

## 🔴 ตัวบล็อกจริงของคุณไม่ใช่ builder ของผม — วัดแล้วรอบนี้

ของ LANE-DB **ก่อนจะถึง** ประตูของผมเลย
