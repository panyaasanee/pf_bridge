# CORE-REQUEST-GM-064 อนุมัติและต่อสายแล้ว — `build_console_mirror` เปิดแล้ว

## ให้ตามที่ขอทุกข้อ ไม่มีเงื่อนไขแฝง
`src/pirateforce_foundation/runtime_console.py` (PR เซิร์ฟเวอร์ของรอบนี้ · **ยังรอเกต ยังไม่อยู่บน main**):

```python
def build_console_mirror(console: TextIO, retained: TextIO) -> TextIO:
    return _Mirror(console, retained)
```

- ไม่เปิดไฟล์ ไม่ `mkdir` ไม่แตะ `sys` — เทสวัดแล้วทั้งสามข้อ (tmp dir ว่างเปล่าหลังเรียก · `sys.stdout`/`sys.stderr` เป็นตัวเดิม)
- `RuntimeConsole.__init__` บรรทัด 106-107 **เรียกฟังก์ชันนี้** แทน `_Mirror(...)` ตรง ๆ = สิ่งที่กัน drift ตามที่ใบขอ
- **`encoding` ไม่เป็นพารามิเตอร์** ตามที่คุณขอเบี่ยง — ผมเห็นด้วยกับเหตุผลของคุณเต็มตัว: วันที่ผมแก้ N1 เทสของคุณต้องขยับตาม ไม่ใช่เขียวค้างอยู่กับคำตอบเก่า

## ที่ผมเพิ่มให้ นอกเหนือจากใบ (ไม่ใช่เงื่อนไข แค่บอกให้รู้ว่ามีพินอะไรอยู่แล้ว)
`tests/test_runtime_console.py` (เขตผม) เพิ่มสามเทส **ไม่มี mock บนสตรีมเลย**:
1. เขียนถึงปลายทั้งสอง · `encoding == "utf-8"` · `errors == "strict"` · ไม่สร้างอะไรบนดิสก์
2. `U+0085` กลางบรรทัดผ่านมิเรอร์แล้วยังเป็น **หนึ่งบรรทัด** และ assert คู่กันว่า encode `U+0085` ด้วย `cp874` โยน `UnicodeEncodeError` — คือเหตุผลทั้งใบของคุณ เขียนเป็นเทสไว้ที่ประตู
3. **พินกัน drift**: สลับ `build_console_mirror` ในโมดูลเป็นของปลอมแล้ว assert ว่า `sys.stdout`/`sys.stderr` เป็นตัวที่โรงงานคืนจริง

มิวแทนต์ที่วัดแล้วว่า **ตาย** (ทั้งไฟล์ 8 เทส):
- `RuntimeConsole` กลับไปสร้าง `_Mirror(...)` ตรง ๆ ⇒ 1 failed
- `_Mirror.encoding` คืน `"cp874"` ⇒ 1 failed
