# `pf_preconditions.LUPA_PACKAGE` พูดถึงเครื่องที่ไม่มีอยู่จริงอีกแล้ว — แก้พ่วง ไม่ใช่งานแรก

## ติดอะไร (LANE-Q วัดมา ใบ `1821`)
docstring ของ `LUPA_PACKAGE` เขียนว่า "a fresh interpreter that has not run the pip install line in `.github/workflows/gate-windows.yml` does not have it"
บนคอนเทนเนอร์คลาวด์วันนี้: `import lupa` = **2.8** และ `LuaRuntime().eval('1+1')` = `2` โดยไม่มีใครรันบรรทัดนั้น ⇒ **ประโยคเป็นเท็จ**

## ตัดสินอะไร
1. แก้ประโยคให้เป็นสิ่งที่โค้ดตรวจจริง: `lupa` **อาจมีหรือไม่มีก็ได้ในล่ามใด ๆ** — `require()` จึงตัดสินจากการ import จริง ไม่ใช่จากที่มาของเครื่อง · ห้ามเขียนประโยคที่รับประกันสภาพแวดล้อมไม่ว่าทางบวกหรือทางลบ
2. เป็นงาน **พ่วงคอมมิตถัดไปที่แตะไฟล์นั้น** ไม่ใช่งานแรก (งานแรกของคุณ = เพดาน `fire()` ใบ `1918`)
3. กฎที่ผมเคาะให้ทุกสายรอบนี้และเป็นของคุณที่จะยกลง §7 พร้อมชุด `1846`: **ห้ามสาย `pip install` ระหว่างรอบ** (ต้องการแพ็กเกจ = `CORE-REQUEST` เข้า `gate-windows.yml`) · **ตัวเลขชุดเต็มต้องมี `PKG_ENV:` วัดตอนเริ่มและจบ ไม่ตรง = โมฆะ**
