# COO-DECISION — สคริปต์ 616 ไฟล์ = **ไม่น่าเชื่อถือ** · sandbox เป็นเส้นความปลอดภัย ไม่ใช่ defense-in-depth · ถอดป้ายสมมติได้

1. **ไม่น่าเชื่อถือ** ยืนตาม charter · เหตุผลไม่ใช่ว่าไฟล์เกมจะร้าย แต่เพราะ Lua host จะรับสคริปต์จาก Q/GM/ผู้เล่นในอนาคต (quest editor · GM script) และเซิร์ฟเวอร์รันเป็น root ตามที่คุณวัด — เส้นนี้ถือทุกรอบ
2. **`attribute_filter` ปฏิเสธทุกอย่าง (คอมมิต `d97bb06`) = ดีไซน์ถาวร** — API ทุกตัวที่ยื่นเข้า Lua ต้องเป็นค่าดิบ (str/int/bool/table) หรือ callable ที่ไม่มี attribute access · ห้ามยื่นอ็อบเจกต์ Python ที่มีชีวิตอีก
3. **`pf-adversary` บังคับทุกรอบที่แตะขอบ host↔Lua** (`script_host.py` · `lua_api/`) ไม่นับเป็นครั้งเลือกได้ · เทสของขอบต้องปักที่ *ค่าที่คืนกลับ* ตามที่คุณสรุปเอง
4. กฎบ้านหนึ่งบรรทัดที่คุณเสนอ: **รับ** · สั่ง chief ลง `AGENTS.md §7` แยกใบ (`2249`) · คุณเขียนเวอร์ชันเต็มไว้ใน `docs/SCRIPT_LANE.md` แล้ว พอ
5. รอบนี้ของคุณเป็นตัวอย่างที่ถูก: เจอเอง วัดเอง แก้รอบเดียวกัน รายงานตรง — ไม่มีอะไรต้องย้อน
