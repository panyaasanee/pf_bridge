## ที่มา — ผู้สังเกตเทียบภาพเซิร์ฟเวอร์เดิมกับของเรา แล้วเจอความต่างเชิงระบบ

หลังปิด GT-045 คุณ Panya เอา capture ของ **เซิร์ฟเวอร์ต้นฉบับ** มาเทียบกับจอของเรา
**นี่เป็นครั้งแรกที่โปรเจกต์ใช้ภาพเซิร์ฟเวอร์เดิมเป็นเกณฑ์เทียบผลของเรา**

| อะไร | เซิร์ฟเวอร์เดิม | ของเรา |
|---|---|---|
| ตัวละครตัวเอง (เหนือหัว + UI ซ้ายบน) | **ขาว** | 🔴 **UI ซ้ายบนไม่มีชื่อเลย** |
| ผู้เล่นคนอื่น | **เขียว** *(ยังไม่ชัดว่าขึ้นกับกิลด์ไหม)* | — |
| **ชื่อ NPC** | **เหลือง** *(ผู้สังเกตยืนยันว่าแน่นอน)* | 🔴 **`Tornado Eagle` = เขียว** |
| คำอธิบายเหนือชื่อ NPC | **ฟ้า** | — |
| Title ของผู้เล่น | **ฟ้า (คล้ายกัน)** | — |
| ชื่อไอเทมบนพื้น | **ขาว** | 🔴 **แดง/ส้ม** |

🔴 **ข้อที่คมที่สุด: เซิร์ฟเวอร์เดิม NPC=เหลือง ผู้เล่น=เขียว · ของเรา NPC ขึ้นเขียว**
⇒ **ไคลเอนต์กำลังจัด `0x201F` เข้าช่องเดียวกับ "ผู้เล่น" ไม่ใช่ "NPC"**
⇒ แรงกว่าข้อสรุปเดิมที่ว่า "แค่ไม่เป็นศัตรู" มาก และกระทบ **GT-035** โดยตรง

⚠️ **nonclaims ของตารางนี้:** สีอ่านด้วยตาจากภาพ ไม่ได้วัดค่าพิกเซล · ภาพอ้างอิงอาจเป็น client
คนละ build/ภูมิภาค · เรื่อง "ผู้เล่นเขียวเพราะกิลด์เดียวกันหรือเปล่า" **ยังไม่มีหลักฐาน**
· ผู้สังเกตแจ้งว่าจะหาคลิป/ภาพเซิร์ฟเวอร์เดิมเพิ่มมาให้ภายหลัง

## คำถามของใบ (ตอบจากอิมเมจล้วน ไม่ต้องเปิดเกม)

**อะไรตัดสินสีของ ① ป้ายชื่อไอเทมบนพื้น และ ② ป้ายชื่อ actor**

**ทางเดินที่เสนอ:** เริ่มจากจุดที่ `RE-066` พินไว้แล้ว — create path A `0x00892580` ที่อ่าน `s_NAME`
ไล่ขึ้นไปหาว่า **ใครเลือกสีของข้อความนั้น** และสีนั้นอ่านจาก field offset ไหน
แล้วเทียบกับ **mask `0x12` ที่เราส่ง** ว่าฟิลด์นั้นอยู่ในหรือนอก mask
· ฝั่ง actor: ไล่เส้นเดียวกันจากจุดที่วาดชื่อ actor แล้วดูว่าค่าไหนแยก "ผู้เล่น/NPC/ศัตรู"

**ทำไมต้อง static:** ตอบได้จากอิมเมจ · **ไม่เผารอบ attended** · และงบของเลนที่เกี่ยวข้องเหลือศูนย์แล้ว

**ผลลบมีค่าสูง** แต่ต้องเป็น bounded negative ที่ระบุขอบเขตครบ (ด่าน G1)

**นอกขอบเขตของใบนี้ (อย่าลากเข้ามา):** ชื่อที่หายไปจาก UI ซ้ายบน · แผงเป้าหมายที่เราไม่มี
— สองเรื่องนั้นเป็นฟิลด์ของ **บล็อกแอตทริบิวต์ตัวผู้เล่นเอง** คนละเส้นกับป้ายชื่อบนพื้น **ควรเป็นใบแยก**
