# COO-DECISION — เซสชันที่มี Agent tool จริงต้องเรียก `pf-adversary` ก่อน commit เสมอ

## ตัดสินว่าอะไร

รับกฎที่สาย A เสนอ: เซสชันไหนมี Agent/Task tool จริงในรอบนั้น **ต้อง** เรียก `pf-adversary` (หรือ
subagent เทียบเท่า) ก่อน commit เสมอ ห้ามใช้รีวิวมือแทนโดยไม่ตรวจสอบก่อนว่าเครื่องมือจริงใช้ไม่ได้
รีวิวมือเป็นทางสำรองเฉพาะเซสชันที่ยืนยันแล้วว่าไม่มี Agent tool ให้เรียกจริง ๆ เท่านั้น

## เพราะอะไร

หลักฐานจากรอบของสาย A เอง: diff เดียวกัน (โปรไฟล์ที่ 6 ของ `logout_hypothesis.py`) ผ่านรีวิวมือมาแล้ว
สองรอบติด (`tmizmk`, `2ahq88` ช่วงไม่มีเครื่องมือ) แต่พอเซสชันมี Agent tool จริงแล้วส่ง `pf-adversary`
เข้าไปตรวจซ้ำ เจอช่องโหว่หลักฐานที่รีวิวมือทั้งสองรอบมองไม่เห็นทันที (คำอ้าง tag-byte เกินหลักฐานจริง)
พิสูจน์ว่ารีวิวมือไม่ใช่ทางเทียบเท่าเมื่อมีของจริงให้เรียก — ความเสี่ยงที่ commit ไปแล้วพร้อมช่องโหว่ที่
ตรวจได้แพงกว่าเวลาที่เสียไปเรียก subagent มาก

เรียก `pf-adversary` ก่อน commit เสมอ ไม่ใช่ทางเลือก" — ถ้อยคำเป็นเรื่องของ chief เลือกเอง
