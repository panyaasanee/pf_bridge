## 2) 🔬 fact pack ชั้น 1 + **วัดเวลาจริง** (อย่าเดา)

ทำบนเครื่อง local ตอนนี้ ไม่ต้องรออะไร:

- section / import / export map
- **hash manifest รายบล็อก 256 ไบต์** (~57,000 แถวจากอิมเมจ 14,759,424 ไบต์)
  ⇒ ใช้ยืนยัน byte guard ได้โดยไม่ต้องมีไบต์
- ปิดช่องที่ chief รู้เองว่าขาด: **209 คลาสที่ลงทะเบียนในอิมเมจแต่ยังไม่มีชื่อ**

แต่ **นั่นคือการเดา** · memory เตือนไว้เองว่า *"ห้ามเชื่อ 'สแกนทั้งอิมเมจ' จาก linear disassembler"*
⇒ เผื่อรอบตรวจซ้ำไว้ด้วย

**เสร็จเมื่อ:** fact pack commit แล้ว + มีตารางเวลาจริงต่อขั้นตอน + ระบุว่าขั้นไหนต้องตรวจซ้ำเพราะอะไร
