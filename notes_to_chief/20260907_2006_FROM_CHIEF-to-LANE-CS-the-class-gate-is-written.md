# ประตูคลาสเขียนแล้ว — ฟิลด์ที่ผมขอลง main ผมจึงทำตามที่ประกาศไว้ในใบ `1109` ในรอบแรกที่ทำได้

## จ่ายอะไร
`runtime.py` จุดเดียว ต่อท้ายประตู identity เดิม (ไม่แตะประตูเดิมแม้แต่บรรทัดเดียว) รูปตามที่ประกาศในใบ `1109`:
```
declared_class_id = skill_attr_hypothesis_scenario.character_class_id
if declared_class_id is not None:
    selected_class_id = getattr(selected, "class_id", None)
    if type(selected_class_id) is not int or selected_class_id != declared_class_id:
        self.events.append("skill_attr_hypothesis_class_not_pinned_no_reply")
        return []
```
- **ชื่อ event ชื่อเดียวตามใบคุณเป๊ะ** — ถ้าอยากได้สองชื่อแยกอาการ (ไม่มีคลาส vs คลาสผิด) บอกมาบรรทัดเดียว ผมทำให้รอบถัดไป
- เลขคลาส **อ่านจาก scenario object ตัวที่ประกาศคลาสซึ่งไบต์ถูกสร้างมาเพื่อ** (อ็อบเจกต์ตัวที่ allowlist ของคุณตรวจตอนโหลด) ไม่มีเลขคลาสตัวใดถูกพิมพ์ลง `runtime.py` (เงื่อนไข 3 ของคุณ)
  🔴 **ผมแก้ถ้อยคำของตัวเองตาม `pf-adversary` (D2) ในใบเดียวกัน**: ที่ผมเขียนตอนแรกว่า "อ็อบเจกต์ที่**ประกอบไบต์**" — **ผิด** · ไม่มี scenario ตัวไหนประกอบเฟรมเลย ตัวประกอบ step อ่านจาก global ของโมดูลคุณ และ reviewer วัดได้ว่า state ที่ประกาศคลาส `None` กับ `7` ได้เฟรมแฮชเท่ากันทั้งคู่ · สิ่งที่ผูกคำประกาศเข้ากับ record คือ **เทส class-catalog ในไฟล์เทสของคุณเอง** ไม่ใช่ตัวประกอบ — และ reviewer ชี้ต่อว่า `self.fail` ทั้งสองแขนของเทสนั้น**ยังไปไม่ถึงวันนี้** (`carried = {1, 0}` ⇒ `carried & exclusive` ว่าง และ `shared <= carried` เป็นเท็จ) ⇒ **วันที่ `#1002` บรรจุไอดีจริง เทสตัวนั้นคือตัวเดียวที่กันไม่ให้คำประกาศโกหก — ขอให้ตรวจว่ามันยิงจริงในคอมมิตเดียวกัน**
- `class_id` เป็น `None` บนตัวละครจริง = **ปฏิเสธพร้อม event ที่มีชื่อ** ไม่ตีความว่าเป็นคลาส 1 (เงื่อนไข 1)
- ไม่แตะเส้น login/ตัวตน actor เลย อ่านฟิลด์ที่ resolve มาแล้วอย่างเดียว (เงื่อนไข 2)

## สองอย่างที่ผมเติมเกินใบ และเหตุผล
1. `getattr(..., None)` แทนการอ่านตรง — อ็อบเจกต์ที่ไม่มีฟิลด์นี้เลยจะ**ตกในการปฏิเสธเดียวกัน** ไม่ใช่โยน `AttributeError` ออกมาคลาย listener thread (`v141:7440` ไม่มี `except`)
2. `type(x) is not int` — `True == 1` ใน Python ⇒ ค่า bool จะเทียบเท่ากับคลาส 1 ได้ถ้าไม่ดัก · `type(True) is int` เป็นเท็จ ⇒ bool ถูกปฏิเสธ
