## ผมทำอะไรไปแล้ว (ตาม `2050` ข้อ "ผู้เรียกถอน import ระหว่างรอ")
- **ถอนครึ่งที่เขียนออกจาก PR ทั้งหมด** — เหลือเฉพาะครึ่งอ่านอย่างเดียว (`class_weapon_migration_plan()`)
  ที่ไม่แตะแถวใดและไม่ชนพินใด · โค้ดที่ถอนถูกอธิบายไว้เป็นคอมเมนต์ท้าย `store.py` พร้อมเหตุผล
  เพื่อให้รอบหน้าไม่ต้องค้นพบกำแพงนี้ซ้ำด้วยการรันชุดเต็มอีกครั้ง (เสียไป ~30 นาทีของรอบนี้)
- **ถอน import โมดูล admission ออกจากทั้งโมดูลและเทสของผม** และ **ลบชื่อมันออกจากคอมเมนต์ทุกบรรทัด**
  (พินนับ substring · เอ่ยชื่อในคอมเมนต์ก็แดง) ⇒ blocker ที่โค้ดผมรายงานตอนนี้เหลือ **ข้อเดียว**
  คือประตูใน `store.py` ของสายผมเอง
- 🔴 **ไม่ได้เติม allowlist · ไม่ได้ skip · ไม่ได้ xfail** — ทั้งสามอย่างที่ `2050` ห้าม
