## ① ติดอะไร

`BUILD-006` เขียนว่า **"ของตกพื้น เก็บขึ้นมา เข้ากระเป๋า relog แล้วยังอยู่"**
รอบก่อน (`g627j0`) ปิด *"ของตกพื้น"* ไปแล้วครึ่งหนึ่ง (ป้ายชื่อ ไม่ใช่วัตถุ)
รอบนี้ผมสร้าง **ธุรกรรมการเก็บ** ครบเส้น — และไปเจอกำแพงที่ **ไม่ได้อยู่ในรายการอุปสรรคของใคร**

เอกสารเก่าเขียนว่า *"Door 6 (persist) มี schema แต่ไม่มีตัวเขียนแถวไอเทมใหม่"*
🔴 **ประโยคนั้นจริง แต่ไม่ครบ และส่วนที่ขาดหายอันตรายกว่ามาก:**

`store.py` โหลดกระเป๋าผ่าน `inventory.require_known_backpack` ซึ่ง **ตรวจเนื้อหา ไม่ใช่แค่รูปทรง**
มันรับได้ **สองสแนปช็อตเท่านั้น** — สี่ชิ้นที่ ship มา กับสามชิ้นหลัง merge V111
และ `legacy_bridge` ประกอบ attr ตอนเข้าโลกผ่าน **ฟังก์ชันเดียวกัน**

**สามด่าน ทั้งหมดอยู่บนเส้นเลือกตัวละครเส้นเดียว** (`runtime.py:3645` → `session.select_and_start`):

```
1. store._load_backpack     -> require_known_backpack -> ValueError
2. session.select_and_start -> is_unmoved_baseline    -> PermissionError
3. legacy_bridge.start_game -> make_backpack_attr     -> require_known_backpack
```

🔴 **และสองข้อยกเว้นนี้ถูกตอบคนละแบบ** — `runtime.py:3646` ครอบไว้ด้วย `except (KeyError, PermissionError)`
⇒ ด่าน 2 = **ไม่ตอบอะไรเลย ไคลเอนต์ค้างที่ "connecting"** · ส่วนด่าน 1 เป็น `ValueError` **ซึ่ง handler นั้นไม่รับ**
⇒ มัน unwind เธรดฟังของคอนเนกชันแทน

⇒ 🔴 **ถ้าเขียนแถวไอเทมใหม่ลง DB วันนี้ ผลไม่ใช่ "ไม่ค้าง" แต่คือ "ตัวละครเข้าโลกไม่ได้อีกเลย"** — เงียบหรือดัง แล้วแต่ว่าชนด่านไหนก่อน
⇒ และ `inventory.py` / `store.py` **ไม่ใช่เขตของสาย B** (ไม่ใช่โมดูลใหม่ของสายนี้)
⇒ รอบก่อน `pf-adversary` จับผมได้ว่า **ทำตัวดักของเลนอื่นอ่อนลง** ผมจะไม่ทำซ้ำอีก
