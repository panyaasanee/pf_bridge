# ฟันที่ตั้งไว้กัน Windows วัดได้เฉพาะบน Linux — ผมเลือกทางไปแล้ว แต่ขอให้คุณเคาะ

## ติดอะไร
`tests/test_gm_login_scene_stage_descriptors.py` มีเหตุผลตั้งตัวอยู่บนผลของ **Windows** อย่างเดียว:
handle ที่ค้างทำให้ `os.replace(temp_path, path)` บรรทัดถัดไปโยน `PermissionError` ⇒ GM stage บนเครื่อง
คุณ Panya กลายเป็นการปฏิเสธ ขณะที่ทุกรอบบน Linux เขียวหมด (นี่คือรูปเดียวกับที่ปิด `#962`/`#970`)
**แต่** ตัว assert ที่เห็น descriptor ได้จริงอ่าน `/proc/self/fd` ซึ่ง Windows ไม่มี
⇒ บน `gate-windows.yml` (`py -3 -m pytest tests -q`) `read_fd_table()` คืน `None` ·
`assert_no_descriptor_leaked` เข้าแขน early-return · **จุดเรียกทั้ง 15 จุดกลายเป็น no-op เงียบ ๆ**
`pf-adversary` รอบนี้วัดยืนยัน: ใส่การรั่วจริงต่อการเรียก + จำลอง Windows ⇒ **`27 passed`**

## ทางเลือกที่ผมชั่ง
1. **ให้ไฟล์แดงบน Windows เมื่ออ่านตารางไม่ได้** — ตรงไปตรงมา แต่ทำให้เกต Windows แดงทุกรอบ ⇒ ปิด PR ทุกใบ
   ของทุกสาย ไม่ใช่แค่ของผม · **ตัดทิ้ง**
2. **`skipTest` บน Windows** เพื่อให้มีสัญญาณนับได้ — แต่ `pf_gate_preflight` `[skips]` แดงทันที
   (`docs/PYTEST_SKIP_PINS.json` ไม่มีแถวของไฟล์นี้ และไฟล์นั้นไม่ใช่เขตผม) ⇒ ต้องขอ chief พินให้ก่อน
3. **วัด "ผลของการรั่ว" แทน "ตัว descriptor" ให้ข้ามแพลตฟอร์มได้** — ฉีด `PermissionError` ที่ `os.replace`
   (คือสิ่งที่ handle ค้างทำบน Windows) แล้ว assert ว่าโมดูลปฏิเสธสะอาด ลบไฟล์ชั่วคราว ไม่แตะไฟล์ผู้ดูแล
4. **เขียน docstring ว่ามันวัดไม่ได้บน Windows** แล้วปล่อยช่องไว้เฉย ๆ

## ผมเลือกอะไรไปแล้ว `[สมมติของสาย LANE-GM - รอ COO ยืนยัน]`
**ข้อ 3 + ข้อ 4 พร้อมกัน** — เพิ่มสามเคสที่ฉีด `PermissionError` ที่ `os.replace` (รันทุกแพลตฟอร์ม
รวม Windows) และเขียนในหัวไฟล์ตรง ๆ ว่า **บน Windows คุณสมบัติเรื่อง descriptor ไม่ถูกวัดเลย**
สิ่งที่วัดได้ที่นั่นคือ *ผลของมัน* ไม่ใช่ตัวมัน และห้ามอ่านสองอย่างนี้เป็นอย่างเดียวกัน
- ไม่เลือกข้อ 2 เพราะ skip ที่ไม่ได้พิน = เกต preflight แดง และไฟล์พินไม่ใช่เขตผม
- ไม่เลือกข้อ 1 เพราะราคาตกกับทุกสาย ไม่ใช่แค่สายผม

## ถ้าคุณตัดสินว่าผิด ต้องย้อนอะไร
ย้อนแค่ย่อหน้า docstring กับสามเคส `*_rename_fails_*` ใน `tests/test_gm_login_scene_stage_descriptors.py`
ไฟล์เดียว ไม่มี `src/` เปลี่ยน ไม่มีเฟรม ไม่มีแฟล็ก · ถ้าคุณอยากได้ข้อ 2 ผมต้องได้แถวใน
`docs/PYTEST_SKIP_PINS.json` จาก chief ก่อน (นั่นคือ CORE-REQUEST ใบใหม่ ผมยังไม่ยื่นจนกว่าคุณเคาะ)

## คำถามที่ผมตอบเองไม่ได้
**อะไรวัดคุณสมบัติ "ไม่มี descriptor ค้าง" บน Windows?** ถ้าคำตอบคือ "ไม่มี และรับได้"
ขอให้เคาะเป็นลายลักษณ์อักษร เพื่อให้รอบหลัง ๆ เลิกเขียนฟันที่ยืนอยู่เฉพาะบนแพลตฟอร์มที่บั๊กเกิดไม่ได้

## nonclaims
- ไม่อ้างว่ามีบั๊ก descriptor บน main วันนี้ · ไม่มีเฟรม ไม่มีจอ ไม่มีแฟล็กใหม่ ไม่มีสิทธิ์ใหม่
- ไม่อ้างว่าเคสฉีด `PermissionError` เท่ากับการนับ descriptor — เขียนไว้ในไฟล์เองว่ามันไม่เท่ากัน
- ไม่ได้รันบนโฮสต์ Windows จริง (ไม่มี) — ครึ่ง Windows ยังเป็นการให้เหตุผล ไม่ใช่การวัด
