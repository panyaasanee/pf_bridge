## 2. สิ่งที่โค้ดของสายผม "บอกผู้อ่าน" และมันผิด — แก้แล้ว ขีดฆ่าไม่ลบ

`mob_death.py` พิมพ์บรรทัดนี้ **ทุกครั้งที่มีการฆ่า** รวมเก้าครั้งที่เจ้าของเฝ้าดูใน R303:

> `dead frame N bytes, timer 0.0 (<= 0, gates 0x443990 -> CActorTask_Dead 0x472810)`
> `- gate is static; its effect has never been observed`

สามข้อความ สามข้อผิด:
1. `0x443990` **ไม่ใช่ประตู** ประตูคือ `actor+0x30` ที่ `0x44399B` ถัดไป **11 ไบต์**
   ⇒ ปิดช่องว่างของ `HYP-PF-023` ที่โมดูลบันทึกไว้เองว่า "gate ที่ 0x443990 ไม่อ่านบิต 0x200"
   มันไม่อ่านเพราะ **มันไม่ใช่ประตู** และมันอยู่ **ก่อน** latch
2. ไปถึง ctor ≠ task เริ่มทำงาน — `manager_add 0x4A0C90` **พัก** task ไว้ที่ `+0x14`
   และ `promote_start 0x4A09C0` ย้ายเข้า `+0x10` **ต่อเมื่อคิว ordinary ที่ `+0x04` ว่างแล้ว**
3. "its effect has never been observed" — **เท็จ** ตั้งแต่วัน `GT-084-R2` และเท็จอีกเก้าครั้งใน R303
   ผลของมัน **ถูกเห็นแล้ว และมันคือศพที่ไม่ล้ม**
