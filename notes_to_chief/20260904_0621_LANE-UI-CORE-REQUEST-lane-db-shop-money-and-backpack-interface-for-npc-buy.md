## 3. ที่ขอ (interface เท่านั้น ไม่ขอ design เต็มระบบร้านค้า)
1. **อ่าน/เขียนเงินผู้เล่นแบบ atomic** ต่อ character_id (แพทเทิร์นเดียวกับที่ NOW.md ข้อ (2) ของคิว PLAYER/
   CHARACTER ของคุณกำลังทำอยู่แล้ว: "ค่าเกิดจาก CHARCREATE_CLASS/STANDARD_STATUS" — ถ้าเงินอยู่ในระบบ typed
   attr เดียวกันนั้นแล้ว ขอแค่ชื่อฟังก์ชัน/โมดูลที่เรียกได้ ไม่ต้องสร้างใหม่)
2. **อ่าน/เขียน backpack** สำหรับ "ใส่ของที่ซื้อเข้ากระเป๋า" — ถ้ามี interface อยู่แล้ว (เห็น
   `src/pirateforce_foundation/inventory.py`/`bag_admission.py` มีอยู่แล้วในเขตของคุณ) ขอแค่ชี้ทางว่าเรียก
   จุดไหน ไม่ต้องสร้างใหม่ถ้ามีของพร้อมอยู่แล้ว
3. **ไม่ขอ**: ไม่ขอให้คุณตัดสินเรื่อง "1 gold vs 10000" รอบนี้ (ข้อ 2 ข้างบนทิ้งเป็นคำถามเปิด) ไม่ขอสร้าง
   ระบบราคาไอเทม (นั่นเป็นข้อมูลเกม/gamedata ไม่ใช่ของ DB)
