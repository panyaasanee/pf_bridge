# รอบนี้ไม่มีอะไรใหม่ให้คุณกด — รอบนี้เป็นรอบซ่อมพื้น

## สั้นที่สุด

**ไม่มีใบใหม่ ไม่มีใบไหนเปลี่ยนสถานะเป็นพร้อมบูตในรอบนี้** · ใบที่พร้อมอยู่แล้วยังพร้อมเหมือนเดิม
รอบนี้ผมใช้ไปกับการกู้ `main` ของรีโปเซิร์ฟเวอร์ที่ **แดง** อยู่ตอนเริ่มรอบ ซึ่งไม่ใช่เรื่องที่คุณต้องทำอะไร
แต่เป็นเรื่องที่คุณควรรู้ ถ้าเห็นชื่อรอบนี้แล้วสงสัยว่าทำไมไม่มีของใหม่

## สิ่งเดียวที่กระทบใบของคุณโดยตรง

**`GT-207` (ปุ่ม GM) มีขั้นใหม่พ่วงเข้าไปหนึ่งขั้น ชื่อ `0N-b`** — อยู่ต่อจากขั้น `0N` ที่มีอยู่แล้ว

🔴 **ขั้นนี้ไม่มีน้ำหนักต่อ PASS/FAIL ของใบเลย** ข้ามได้ทุกเมื่อ ไม่มี `mt.exe` หรือเวลาหมด = จด `NO-RESULT`
บรรทัดเดียวแล้วเดินต่อ **ใบยังตัดสินได้ตามปกติ** · ไม่กินโควตา build ไม่บูตเกม ไม่แตะ DB

มันคือการทดลองหนึ่งครั้งว่า ถ้าฝัง manifest ที่ช่อง `;#1` แทน `;#2` แล้ว Windows จะยอมโหลด DLL ไหม
เหตุผลตรง ๆ: กฎ "ต้องเป็น id 2" ที่เราใช้กันอยู่ **ไม่เคยมีใครวัด** LANE-GM รายงานเรื่องนี้เอง
· โหลดได้ = กฎเราผิด แก้เอง · โหลดไม่ได้ = กฎถูก และเรามีหลักฐานแทนคำสั่ง
🔴 **ห้ามเอาสำเนาที่ทดลองไปวางในโฟลเดอร์ไคลเอนต์** ทดลองนอกโฟลเดอร์เกมเท่านั้น

## `GT-142` มีบรรทัดเตือนเพิ่ม (ยังบูตไม่ได้ ยังบล็อกอยู่เหมือนเดิม)

บรรทัดเดียวกับที่ `GT-146` มีอยู่แล้ว และมันมีไว้กันไม่ให้คุณเสียรอบทั้งรอบ:

> **ข้ามฉากแล้ววาปกลับ = เลือดมอนกลับเต็ม เป็นของที่รู้อยู่แล้ว ประกาศไม่แก้ ไม่ใช่ FAIL ของการตี**
> จะวัดว่าเลือดลดจริง ต้องตีและอ่านผล **ในฉากเดียวกัน ไม่ข้ามฉากคั่น** · เจอเลือดเต็มหลังข้ามฉาก
> ให้จด `known: wound reset on scene re-open` แล้วเทสต่อ **ห้ามปิดใบเป็น FAIL ด้วยเหตุนี้**
