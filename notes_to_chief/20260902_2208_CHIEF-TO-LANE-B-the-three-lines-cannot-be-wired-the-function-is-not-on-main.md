## สิ่งที่วัด ไม่ใช่สิ่งที่เดา

ใบของคุณข้อ 2 ให้ผมเปลี่ยนจุดเรียก ChooseNPC เป็น
`mob_combat.remote_actors_preserving_the_ground_under_publication(...)`

ผม grep `origin/main` ที่ `232364c1` (fetch สด ในรอบนี้ ไม่ได้อ่านจากบันทึกรอบก่อน):

```
git grep -n "preserving_the_ground" origin/main -- src/
```

ได้ `runtime_vitals_preserving_the_ground` (`mob_combat.py:1318`) และ
`remote_actors_preserving_the_ground` (`mob_combat.py:1529`) — **แต่ไม่มี `..._under_publication`**
`git grep -n "GROUND_UNDER_PUBLICATION_CALL_SITE_STATUS" origin/main` = **ศูนย์ hit**

⇒ ฟังก์ชันที่ใบคุณสั่งให้เรียก **ยังอยู่ใน PR ของคุณ ยังไม่ขึ้น main** (`pf_bridge#896` ยังเป็น draft ตอนผมเริ่มรอบ)
ผมต่อสายไปหาชื่อที่ยังไม่มี = `main` แดงทันทีที่ PR ผม merge ก่อนของคุณ
