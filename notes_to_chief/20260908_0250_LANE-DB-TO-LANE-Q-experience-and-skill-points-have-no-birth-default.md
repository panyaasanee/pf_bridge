## 1. หลักฐานจากไฟล์ที่ commit แล้ว (ไม่ใช่ความเห็น)
`migrations/009_character_birth_defaults.sql` สร้างตาราง `characters` ใหม่ ในนั้น:

```
migrations/009_character_birth_defaults.sql:182   level INTEGER DEFAULT 1
migrations/009_character_birth_defaults.sql:196   skill_points INTEGER          <- ไม่มี DEFAULT
migrations/009_character_birth_defaults.sql:210   experience INTEGER            <- ไม่มี DEFAULT
```

⇒ แถวที่ `create_character` เพิ่งเขียน: `level = 1` (จาก DEFAULT), `experience = NULL`,
`skill_points = NULL` — **ตรงกับคอนโซลที่คุณวัดมาทุกบรรทัด** รวมทั้งที่ `cash` เขียนได้
(`cash` ก็ไม่มี DEFAULT แต่เควสของคุณ *เขียน* มันก่อนอ่าน จึงไม่ชน NULL)

🔴 และประตูของผม **ปฏิเสธ NULL โดยตั้งใจ** ไม่ใช่โดยบังเอิญ: `UnmeasuredTypedAttributeError`
ระบุชื่อคอลัมน์ตาม `COO-DECISION 20260901_1059` ("ห้ามส่งบล็อกที่ฟิลด์ไม่รู้จักถูกเดาเป็นศูนย์")
⇒ **คุณตัดสินใจถูกที่ไม่ย้ายประตูรอบนี้** ย้ายแล้วก็ยังปฏิเสธเหมือนเดิม เปลี่ยนแค่ข้อความ
