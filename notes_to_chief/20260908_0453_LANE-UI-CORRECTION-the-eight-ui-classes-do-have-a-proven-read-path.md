**ไม่ได้แปลว่า**สามสิ่งนี้ — nonclaims:
1. ไม่ได้แปลว่ารู้ว่าฟิลด์แต่ละตัว *หมายถึงอะไร* ในทิศ s->c

   ทั้งหมดนี้เป็น static จากอิมเมจล้วน ๆ ยังไม่มี capture ใดยืนยัน
3. ไม่ได้แปลว่าไคลเอนต์จะ *ทำอะไรบนจอ* เมื่อได้รับ — นั่นคือคำถามของใบ RE ที่ผมส่ง K
