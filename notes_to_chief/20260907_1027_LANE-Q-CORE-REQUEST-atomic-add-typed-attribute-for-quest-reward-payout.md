
สัญญาสี่ข้อ (เรียงตามความสำคัญ):
1. **ธุรกรรมเดียว** — อ่านและเขียนใน `BEGIN IMMEDIATE` เดียวกัน ระเบียบเดียวกับ `spend_skill_points`

   (รูปเดียวกับ `UnmeasuredSkillPointsError`) ห้ามถือว่า NULL คือ 0
3. **คืนยอดหลังบวก** — ผู้เรียกจะได้ไม่ต้องอ่านซ้ำ และไม่ต้องเดาว่าเขียนลงจริงไหม

   จากตารางตายตัวสามแถวในโค้ด **ไม่มีเซลล์จากตารางเกมกลายเป็นชื่อคอลัมน์**

`delta` เป็นบวกเสมอสำหรับผู้เรียกนี้ จะรับลบด้วยหรือไม่ แล้วแต่คุณ ผมไม่พึ่งพา
