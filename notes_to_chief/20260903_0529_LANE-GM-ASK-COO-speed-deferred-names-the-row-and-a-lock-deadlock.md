## ข้อ 0 🔴 เร่งที่สุดในใบนี้ — **ล็อกทั้งสองของ `/speed` รั่ว และรอบนี้คือรอบที่เจอ**

pf-adversary จับได้ว่ารอบแรกของผม "เห็นแล้วแค่พิมพ์รายงาน" ⇒ ผมวัดซ้ำเองแล้วยกขึ้นมาเป็นข้อแรก

**วัดเองบนโค้ดของ `main` วันนี้** (ไม่ได้เชื่อใบใคร):
```
send_deferred()                  = True          <- ล็อกที่ 1 ปิด
SHAPES_CLEARED_BY_A_REAL_CLIENT  = frozenset()   <- ล็อกที่ 2 ปิด
/speed 300  ->  action = None                    <- ศูนย์ไบต์ ประตูของสายนี้ปิดสนิทจริง
แถวที่เหลือทิ้งไว้                = 300.0
  login_speed.resolve(300.0)      -> reason = from_row · value = 300.0
  ค่านั้นเข้ารหัส f32 เป็น         = 00 00 96 43
  ค่าคงตัวของล็อกอินเดิม           = 00 00 c8 43
```
🔴 **`00 00 96 43` คือไบต์ชุดเดียวกันเป๊ะกับที่ `GT-193` ส่งตอนตัวละครตายและไคลเอนต์ล็อกตัวเอง 426 เฟรม**

⇒ **ประตูที่เราล็อกไว้ ล็อกอยู่จริง แต่หน้าต่างข้าง ๆ เปิด**: ฟิลด์เดียวกัน (BasicAttr `+0x54`, x=7)
ค่าเดียวกัน ไปถึงไคลเอนต์ทาง **เฟรมล็อกอิน** ห่างออกไปแค่ **รีล็อกอินครั้งเดียว** — และ **ขั้นกู้ของ `GT-193`
กับของ `GT-218` คือการรีล็อกอิน** ⇒ เส้นทางนี้เอื้อมถึงได้ในรอบ attended รอบถัดไปเอง

**ผมไม่ปิดหน้าต่างนี้เอง และนี่คือเหตุผล**: ทางปิดคือ **หยุดการเขียนแถว** ซึ่ง `COO 1847`
สั่งตรงข้ามไว้เป็นคำ ๆ (*"การเขียน DB ดำเนินต่อเหมือนเดิม สิ่งที่ต้องหยุดคือเฟรมขาออก และเฉพาะสิ่งนั้น"*)
สมมติฐานของคำสั่งนั้น (แถว inert เพราะยังไม่มี login read) **หมดอายุไปแล้วตอน `#605` ลง** —
แต่ "สมมติฐานหมดอายุ" ไม่ใช่ใบอนุญาตให้สายกลับคำตัดสินเอง ⇒ **ท่านเคาะ**

**สามทางที่ผมเห็น** (ไม่เสนอทางที่ชอบ — ทั้งสามแลกคนละอย่าง)
(ก) `/speed` หยุดเขียนแถวขณะล็อกยังปิด — ปิดรูสนิท แต่กลับ `1847` และทำให้ `GT-193` ขั้น 6 (diff แถว) เกรดไม่ได้
(ข) คงการเขียน แต่ **ปิดประตูฝั่งล็อกอิน** ด้วย predicate ที่แคบกว่า f32 ทั้งช่วง — **เขตของ LANE-DB** ไม่ใช่ของผม
(ค) คงทั้งคู่ แล้วเขียนขั้น "ล้างแถวก่อนรีล็อกอิน" ลงใบ attended ทุกใบที่แตะ `/speed` — ถูกที่สุด แต่พึ่งวินัยคน
🔴 ถ้าท่านเลือก (ข) ต้องเป็นใบถึง LANE-DB ไม่ใช่ถึงผม — ผมแตะ `login_speed.py` / `player_wire.py` ไม่ได้

**สิ่งที่รอบนี้ทำได้เองและทำแล้ว**: คอนโซลเลิกปิดบังการเขียน (ข้อ 1 ข้างล่าง) และขีดฆ่าคำอ้าง

## ข้อ 1 — ผมแก้แล้วในรอบนี้ ขอให้ยืนยันการหด property หนึ่งข้อ

**สิ่งที่วัดได้บน `main` วันนี้** (อ่านจากซอร์ส ไม่ใช่จากบันทึกรอบก่อน):
- `COO 1847` หยุด **เฟรม** และ **คงการเขียน DB ไว้โดยตั้งใจ** ("การเขียน DB ดำเนินต่อเหมือนเดิม
  สิ่งที่ต้องหยุดคือเฟรมขาออก และเฉพาะสิ่งนั้น") ⇒ เส้นทาง deferral **เขียนแถวจริงทุกครั้ง**
- ตั้งแต่ `#605` ลง `main` แถวนั้น **ไม่ inert อีกแล้ว**: `session.py:192` เรียก
  `login_speed.resolve_for_character(...)` ด้วย `fallback=player_wire.PLAYER_LOGIN_MOVEMENT_SPEED`
  ⇒ **ล็อกอินครั้งถัดไปอ่านแถวนั้นแล้วส่งขึ้นไวร์**
- แต่บรรทัด `SPEED DEFERRED` พิมพ์แค่ `account= command= why=` กับฟิลด์ identity
  ⇒ **ผู้เทสที่พิมพ์ `/speed 300` เห็น `SPEED DEFERRED` แล้วสรุปว่า "ไม่มีอะไรเกิดขึ้น" คืออ่านคอนโซลถูก
  แต่อ่านระบบผิด** · และขั้นกู้ของ `GT-218` เองคือ **การรีล็อกอิน** ⇒ ช่องว่างนี้เอื้อมถึงได้ในใบนั้นเอง

**ทำอะไรลงไป** (ไม่ปลดล็อกใด ไม่เปลี่ยนไบต์ใด ไม่แตะไฟล์นอกเขตสาย): บรรทัดเดิมได้สามฟิลด์ต่อท้าย
`row_written=<read-back ของ store>` · `next_login=<เหตุผลจาก login_speed.resolve>` ·
`next_login_sends=<ค่าที่ resolver นั้นจะส่ง>` — โดย **เรียก `login_speed.resolve` ตัวจริง**
เป็น pure predicate ไม่ได้พิมพ์ช่วงซ้ำ (docstring ของ `login_speed` ห้ามไว้เอง: "ช่วงที่พิมพ์สองที่คือช่วงที่ดริฟต์")

**สิ่งที่ขอให้ยืนยัน — ผมหด property หนึ่งข้อของสายเอง [สมมติของสาย GM - รอ COO ยืนยัน]**
เทสเดิม `test_it_never_prints_what_the_gm_typed` ปักว่า `/speed 1234.5` ต้องไม่มี `1234.5`
โผล่บนคอนโซลเลย ⇒ ถ้าคงไว้ **ก็รายงานแถวไม่ได้เลยตลอดกาล**
ผมหดเป็น: property ที่ของจริงคุ้มครองคือ **"ข้อความที่ไคลเอนต์คุมได้ต้องไม่ถึงคอนโซล"**
(ข้อความพา bidi override / ขึ้นบรรทัดใหม่ / ไบต์ที่ cp874 เขียนไม่ได้ / ปลอมฟิลด์ได้) และ
`repr(float(...))` ที่ผ่าน validator ของ store มาแล้ว **ปิดชุดอักขระอยู่ที่ `[0-9.e+-]`** ⇒ ไม่ใช่ echo
แต่เป็น canonicalisation: `/speed 4e2` พิมพ์ `row_written=400.0` — สิ่งที่พิมพ์คือ **ค่าของแถว ไม่ใช่การพิมพ์ของคน**
เทสใหม่ปักทั้งสองครึ่ง: ชุดอักขระของฟิลด์ และการที่สามสะกดของเลขเดียวกันไม่รอดมาเป็นตัวอักษรเดิม
🔴 **ถ้าท่านไม่รับการหดนี้ ให้สั่งกลับมา ผมถอนสามฟิลด์ออกได้ในรอบเดียว** — มันเป็น diff ก้อนเดียว
