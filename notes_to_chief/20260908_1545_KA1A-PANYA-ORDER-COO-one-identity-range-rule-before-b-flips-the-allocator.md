## 2. คำเคาะ (เจ้าของเคาะข้อนี้ข้อเดียว)
**B ต้องทำ "กติกาช่วง identity ตัวเดียว" ให้เสร็จ *ก่อน* แตะตัวจ่าย** — งานแรกของ B ในเรื่องนี้ ห้ามสลับลำดับ:
1. **หนึ่งฟังก์ชัน หนึ่งกติกา หนึ่งที่**: ตัวตรวจช่วง identity ตัวเดียวที่ทุกโมดูลเรียก (ชื่อ/ที่อยู่ B เลือกเอง) · กติกา: **ค่า 64 บิตแบบมีเครื่องหมาย · ห้ามเป็น 0 · ห้ามชนช่วงของผู้เล่น** · ทุกจุดที่วันนี้เขียนกฎเอง (สี่ที่ในตารางข้อ 1 และจุดอื่นที่ B ไล่เจอเพิ่ม) ต้องเรียกตัวนี้แทน
2. **ห้ามเหลือ "ค่าบวกเท่านั้น" ค้างที่ไหน** — ไล่ให้ครบด้วยการค้นจริง ไม่ใช่ไล่จากความจำ · จุดที่แก้ไม่ได้จริงต้องเขียนเหตุผลลงใบ ห้ามเงียบ
3. **id เดียวตลอดวงจร** (คำเตือนของ Codex R4 ที่เจ้าของรับมาแล้ว): spawn / เลือกเป้า / ต่อสู้ / ตาย / ของดรอป ต้องอ้าง identity **ตัวเดียวกัน** · ห้ามกลับเครื่องหมายเฉพาะตอนประกอบเฟรมส่งภาพ แล้วเก็บอีกค่าไว้ฝั่งเซิร์ฟเวอร์
4. **`0` ห้ามใช้เด็ดขาด** — วัดแล้วบนจอว่าไคลเอนต์ไม่วาดตัวที่ identity = 0 เลย (เจ้าของนับได้ 23 จาก 24 ป้าย) · ตัวจ่ายต้องกันค่านี้และมีเทสปัก
5. **เทสที่ต้องมี** (ไม่ใช่ grep ข้อความตัวเอง): ประกอบมอนด้วย identity ไม่เป็นบวกแล้ว **ลงทะเบียนโลกได้ · จดเลือดได้ · ผูกของดรอปได้ · ตายแล้วเข้าทะเบียนศพได้** ครบสี่อย่างในเทสเดียว
6. เสร็จข้อ 1–5 แล้วค่อยเปลี่ยนตัวจ่าย `field_mobs.actor_identity` (วันนี้ `0x2000 + placement_index + 1`)
