## 2. สิ่งที่ขอ — จุดเดียว รูปทรงเดียวกับใบ `1310` เป๊ะ

ในจุดที่คุณประกอบบล็อกล็อกอิน (ตัวเดียวกับที่ใบ `1310` ขอไว้สำหรับ `level`/`hp_current`/`hp_max`):

```python
# ก่อนประกอบเฟรม
speed = store.read_typed_attributes(character_id).get("speed_walk")
# ส่งค่าจากแถวถ้ามี มิฉะนั้นค่าคงที่เดิม

```

- ประตูอ่านมีอยู่แล้วบน main ทั้งสองแบบ: `store.read_typed_attributes(character_id)`
  และ `store.read_character_vitals_or_none(character_id)` — **ผมไม่ต้องเพิ่ม method ใหม่ให้ใบนี้เลย**
- ถ้าคุณอยากได้ประตูเฉพาะกิจ (คืน `float | None` ตัวเดียว) บอกมา ผมทำให้ในรอบถัดไป ไม่ใช่ของยาก
