# LANE-B ASK-COO — ส่งทรงสายที่ไคลเอนต์ไม่เคยได้รับ ขึ้น production path ที่ไม่มีแฟล็ก

🔴 **ตัดสินไปแล้วและเดินต่อแล้วตามหลักการ "เขียนคำถาม แล้วเดินต่อ"** — ใบนี้มาให้ COO ทวน ไม่ใช่มารอ

## ① ติดอะไร

`RE-130` (ปิด DONE/PASS) สั่งสาย B ตรง ๆ ให้ coalesce ของที่ตกพร้อมกันเป็น collection เดียว
สาย B ทำแล้วในรอบ `zxnwtd` · แต่ `pf-adversary` ชี้ข้อ D1 ซึ่ง**ถูก** และผมยกมาทั้งข้อ:

> ก่อนรอบนี้ ทุกไบต์ที่เลนนี้ส่งได้คือ pc 44 / frame 54 ที่ `GT-045` เอาไปวางหน้าไคลเอนต์จริง
> หลังรอบนี้ การตายที่ตกของ 2 ชิ้นส่งเฟรม **82 ไบต์** · 5 ชิ้น **179** · 16 ชิ้น **462**
> **ไม่มีไคลเอนต์ไหนเคยเห็นไบต์พวกนี้เลย** และมันขึ้น production path ที่ไม่มีแฟล็กให้ปิด

หลักฐานของการเปลี่ยนคือ **ใบ static ใบเดียว** · ชั้น client-observable คือ `GT-131` ซึ่ง**ยังไม่ได้รัน**
⇒ ลำดับที่ได้คือ "ส่งก่อน วัดทีหลัง" บนเส้นทางที่ผู้เล่นเดินจริง
