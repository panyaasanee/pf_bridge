# ASK: ขอเติม **หนึ่งบรรทัด** ในใบ GT-203 ที่คุณคิวไว้อยู่แล้ว — มันจะปิดคำถาม `class_id` ของ M4 ให้ผมฟรี

## 0. หนึ่งประโยคว่าทำไมใบนี้ถึงมี

M4 เหลือ 17 คอลัมน์ที่ `006` สร้างไว้แล้วยังไม่มีค่า และตัวที่ผมติดอยู่คือ `class_id`
ผมจะ **ไม่** seed มันเป็น `PLAYER_LOGIN_CLASS_ID = 1` แบบเหมารวมเด็ดขาด เพราะผู้เล่นเลือกอาชีพเอง
การเขียน 1 ทับคือเปลี่ยน "ไม่รู้" ให้เป็น "ผิด" — ซึ่งเป็นสิ่งเดียวกับที่ `1059` ห้าม
รอบนี้ผมจึงไปหาว่า **อาชีพจริงกู้จากบล็อบ creation ของตัวละครเองได้ไหม** และคำตอบคือ "ยังไม่พิสูจน์"
แต่ทางที่จะพิสูจน์มัน **อยู่ในใบเทสที่คุณคิวไว้อยู่แล้ว** และห่างจากคำตอบแค่ประโยคเดียว

## 2. สิ่งที่ขอ — หนึ่งประโยคในใบ GT-203

`GT-203` ให้ผู้เทสสร้างตัวละคร **สองตัว** แล้วพิมพ์ `describe_avatar_body()` จาก DB ของเธอเองอยู่แล้ว
เกณฑ์ผ่านวันนี้ครอบแค่ เพศ/ผม/หน้า ขอเติมประโยคนี้:

> สร้างสองตัวด้วย **อาชีพที่ต่างกัน** จดว่ากดไอคอนอาชีพอะไร แล้วรายงาน
> `n_DRESS_CHEST` / `n_DRESS_LEGGINGS` / `n_SLOT_RHAND` ของทั้งสองตัวจากบรรทัด `AVATAR_DECODE`

ตัวเทียบคือแถวของอาชีพที่เธอกดใน `CONSTDATA_TH__CHARCREATE_CLASS.tsv`
**ตรงทั้งสองตัว = ยกจาก n=1 คลาสเดียว เป็นเทสแยกแยะสองคลาส · ไม่ตรง = อนุมานนี้ตายทันที**
ทั้งสองผลมีค่ากับผมเท่ากัน เพราะทั้งคู่บอกได้ว่าจะเขียนคอลัมน์นี้ได้หรือไม่ได้

ราคา: ไม่มีโค้ดใหม่ ไม่มีบิลด์ ไม่มีรอบ attended เพิ่ม — เกาะใบที่คุณจะให้เธอรันอยู่แล้ว
`GAME_TEST_QUEUE.md` เป็นเขตของคุณ ผมจึงขอ ไม่แก้เอง

## 4. ผมไม่อ้างอะไร

1. **ไม่อ้างว่ากู้อาชีพจากบล็อบได้แล้ว** — ที่มีคือสามฟิลด์ที่ *แยกอาชีพได้ในตาราง* กับแคปเจอร์เดียว
   ที่ตรงหนึ่งคลาส สมมติฐานที่ยังไม่พิสูจน์คือ "หน้าจอสร้างตัวส่ง id ของแถว preset มาตรง ๆ ไม่แก้"
   ซึ่ง `CONSTDATA_TH__CHARCREATE_LOOK.tsv` (218 แถว) ยังไม่เคยถูกวัดชนกับสามฟิลด์นี้
2. **ไม่อ้างว่า `CreateActorDataEx +0x1C` (tag `0x19` u32) คืออาชีพ** — tag ตรงกับ `ActorAttr.class_id`
   เป็นกับดักคนละคลาสคนละ offset `PF_TAG_CENSUS.tsv` แถว `0x19` = `UNKNOWN` ห้ามใช้เป็นหลักฐาน
3. **ไม่ขอเปิด RE ใหม่รอบนี้** ถ้า GT-203 กลับมากำกวมค่อยขอ (คำถามที่จะขอคือ producer store ของ
   `+0x19`/`+0x1A`/`+0x1C` บนเส้น UI สร้างตัว ซึ่ง JOB-001:54-55 ประกาศเองว่ายังกู้ไม่ได้)
4. **ไม่มีอะไรถูกเขียนลงคอลัมน์ `class_id` ในรอบนี้ และจะไม่เขียนจนกว่าจะมีผลจากเครื่องจริง**
5. ผู้ตรวจไม่ได้เปิด image ไม่ได้เปิด canonical DB ไม่ได้เปิด capture corpus (ไม่มีใน clone นี้)
   ทุกไบต์ข้างบนยกมาจากอาร์ติแฟกต์ที่ commit แล้ว ไม่ได้วัดใหม่จาก image
   และไม่มีข้อไหนตั้งอยู่บน `current/pf_login_game_server_v141.py` ตามกฎ
