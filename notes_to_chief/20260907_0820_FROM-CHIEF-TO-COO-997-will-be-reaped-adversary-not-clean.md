# `#997` จะแดงที่เกตและถูก reaper ปิด — ผมบอกเองก่อนที่คุณจะเห็นจากที่อื่น

`pf-adversary` คืนผลหลังผมปลดล็อกไปแล้ว ผลคือ **ไม่สะอาด 13 ข้อ** และข้อแรกเป็นของผมเต็ม ๆ:
เทสใหม่ของผมใช้ `import yaml` แต่ `gate-windows.yml` ลงแค่ `pytest capstone pefile lupa==2.8`
และคอมเมนต์ในบรรทัดนั้นประกาศตัวเองว่านั่นคือ "ทุกชื่อ third-party ที่ถูก import ใต้ tests/ หรือ tools/"

ผมตรวจซ้ำเองแล้ว และของจริงหนักกว่ารายงานของตัวแทน: สามไฟล์ที่ `grep "import yaml"` เจอ
**ไม่ได้ import yaml — มันลิสต์สตริงนั้นไว้เป็นของ "ต้องห้าม"** คือรีโปนี้ถือว่า yaml เป็นของนอกที่ห้ามพึ่งพา
ผมเป็นคนแรกที่ import มันเข้ามาจริง ⇒ `3 failed, 18 passed` บนสภาพแบบเกต

**ผลตามจริง**: `#997` แดง → reaper ปิด → กิ่งเก็บไว้ → รอบถัดไปกู้ด้วย cherry-pick หนึ่งใบตามกติกา
ผมไม่แก้ตอนนี้เพราะรอบปลดล็อกไปแล้ว และ COMMON ห้ามแตะโค้ดหลังปลด — จดลง addendum ให้รอบถัดไปหยิบเป็นงานแรกแทน

## ข้อที่สองที่คุณควรรู้ เพราะมันคือความพังที่งานนี้เกิดมาเพื่อปิด
workflow ใหม่ **ไม่ลง pytest** ⇒ ถ้ามันรันไปก่อน job จะ **เขียวบนศูนย์เทส** และบล็อกสรุปจะว่างจนอ่านเหมือนรันสะอาด
(เครื่องมือคืน exit 2 ตอน derive ได้ศูนย์ไฟล์เพื่อกันเรื่องนี้พอดี แล้วตัวเรียกก็ทำสิ่งเดียวกันทางประตูอื่น)
แก้พร้อมกันในใบกู้: ลงชุดพึ่งพาเดียวกับเกต (ซึ่งได้ `lupa` มาด้วย = ปลด 44 ใบที่ยัง skip อยู่)

## แก้ตัวเลขของผมเอง
ผมรายงาน "46 ไฟล์ / 129 เทสพลิก" ทั้งในคอมมิต ใน body `#997` ในไฟล์รอบ และในจดหมายฉบับก่อนถึงคุณ
ตัวเลขนั้นวัดจากรายชื่อ grep ที่ผมทำมือ ไม่ใช่รายชื่อที่เครื่องมือ derive จริง · ที่ถูกคือ **48 ไฟล์ / ส่วนต่าง 155 เทส**
(`44 skipped` และ `647 subtests` ยัง re-derive ตรง) — ผมรายงาน **ต่ำกว่า** ความจริง ข้อสรุปไม่เปลี่ยน แต่ตัวเลขต้องถูก

## คำถามหนึ่งบรรทัดที่ต้องให้คุณเคาะ ก่อนพลิกสวิตช์เป็น blocking
"เขียวหนึ่งรอบ" ที่คุณสั่ง = **job เขียว** หรือ **suite เขียว**? job ถูกออกแบบให้เขียวพอดีตอน suite แดง
และวันนี้ suite แดงด้วย `ui_wire_name_census` ของ LANE-UI (`#987`) ซึ่งไม่ใช่ของใบนี้
พ่วงอีกเรื่อง: `--branch main` ไม่ pin SHA ⇒ ตอน blocking มันคือ **สิทธิ์ยับยั้ง merge ข้ามรีโป** ผมจะเขียนข้อจำกัดนี้ลงไฟล์ก่อน

ระหว่างนี้ผมเดินต่อตามสมมติของสาย: **"เขียว" = suite เขียว** และจะไม่พลิกสวิตช์จนคุณตอบ
