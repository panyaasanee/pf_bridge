# หลักฐาน crosswalk ที่ใบ `RE-289` บอกว่า "ยังต้องมี" **มีอยู่แล้วในรีโป** ตั้งแต่ 4 ก.ย. — และมันหักล้างประโยคที่เราพูดกันสามที่

## ติดอะไร
สามเอกสาร (โมดูลของสายเอง · `tickets/RE-289.md` · nonclaim (1) ของ `RE-289`) บอกตรงกันว่า
ก่อนเติม `ISLAND_CONTACT_DISCRIMINATOR` ต้องมี **การวัดใบที่สอง** ที่ผูกกล่อง `.tgr` เข้ากับ id บนสาย
รอบก่อนจึงวางแผนออก "ใบ crosswalk" · รอบนี้ตั้งใจจะร่างใบนั้น แล้วไปเจอว่า **ไม่ต้องออกใบเลยก็ได้**

จดหมายผล `GT-228`/R308 (`20260904_1331_KA1A-R308-RESULTS-...md` · `OBSERVER_CONFIRMED 2026-09-04T13:22`)
มีพิกัดครบอยู่แล้ว: หัวข้อ (ข) ถอด `trigger_xyz` + `TargetPos` ของเรือ จาก 4 ใน 6 เฟรม `0x1FB2`
และตาราง (ก) มีพิกัด HUD ของทุกจังหวะชนอีก 5 จุด รวม **13 จุด แต่ละจุดมี id ที่ไคลเอนต์ส่งกำกับ**

## สิ่งที่วัดได้ (คำนวณใหม่จากสองตารางที่ commit แล้ว ไม่ได้อ่านคำตอบเก็บไว้)
**ทั้ง 13 จุด อยู่ในกล่องของ ordinal ที่ "เลขเท่ากับ id บนสาย" และไม่อยู่ในกล่องอื่นเลย**
สลับป้าย id ของทุกแถวเป็นเกาะอีกใบ ⇒ **ตกทั้ง 13 แถว** (นี่คือตัวฆ่าข้อแก้ตัว "กล่องใหญ่จนใส่ได้ทุกอย่าง")
สองตารางนี้เกิดคนละวัน คนละคน คนละ artifact — กล่องจาก `Bg3001.tgr` โดย RE runner · จุดจากสาย/จอ
โดย ka1-A ที่มีคุณนั่งดู — **ไม่มีอันไหน derive จากอีกอัน** นั่นคือความเป็นอิสระที่ช่องนั้นรออยู่

## เรื่องที่สองและใหญ่กว่า: premise ที่เราพูดกันสามที่ ถูกหักล้างโดยแหล่งปฐมภูมิของมันเอง
`RE-234` ข้อ (3) — อ้างต่อใน `CLIENT_RE_QUEUE.md:759` · `tickets/RE-289.md` · และคอมเมนต์ข้าง
`ISLAND_CONTACT_DISCRIMINATOR` ในโมดูลของสายเอง — เขียนว่า `GT-228` เห็น **id 3 ทั้งตอนชนเกาะและตอนแล่นน้ำเปล่า**
ซึ่งเป็นเหตุผลทั้งหมดที่เราเรียก id เปล่าว่า "ตัวจำแนกที่ไม่ปลอดภัย"

จดหมาย `GT-228` หัวข้อ (ข) นับเฟรม `0x1FB2` **ทั้ง session** ไว้ครบ และยืนยันตรงกันสามทาง
(raw capture + EVENTS + คอนโซลของ lane hook 6 บรรทัด ไม่มี `UNPARSED`):
`rx112 id=35` (แล่นเข้าหาเกาะ 2 ยังไม่แตะ = เฟรมน้ำเปล่า) · `rx130/rx152/rx248 id=2` · `rx433/rx491 id=3`
⇒ **เฟรมน้ำเปล่าคือ id 35 ไม่ใช่ id 3** · ใน `GT-228` ไม่มี id-3 ตอนน้ำเปล่าเลยสักครั้ง

## เลือกอะไรไปแล้ว (ตาม "เขียนคำถาม แล้วเดินต่อ")
1. **commit หลักฐาน ไม่เติมชื่อ** — `M2_WIRE_ORDINAL_CROSSWALK_OBSERVATIONS` + เทสที่คำนวณ containment ใหม่
   ทั้ง 13 แถว + เทสสลับเกาะ + เทสว่าจดหมายมีจริงและมีตัวเลขที่ลอกมา
   `ISLAND_CONTACT_DISCRIMINATOR` **ยังเป็น `None`** และมีเทสปักไว้ว่ายังเป็น `None`
   เหตุผล: การเติมชื่อคือ **การตัดสิน** ไม่ใช่การวัด · สามเอกสารส่งการตัดสินนั้นผ่านใบ crosswalk
   สายนี้ไม่ลัดคิวเพราะหลักฐานมาถึงเร็วกว่าที่คิด (รอบก่อนเพิ่งย้อน commit ตัวเองด้วยเหตุผลเดียวกันนี้)
2. **ไม่แก้เอกสารร่วม** (`CLIENT_RE_QUEUE.md` · `tickets/RE-289.md`) ด้วยการอ่านของสายเดียว — ส่งมาให้คุณ
   ในโมดูลบันทึกไว้ตรง ๆ ว่า premise นี้ถูกหักล้างและอ้างที่มา แต่ไม่เปลี่ยนพฤติกรรมอะไร (tier 3 ปฏิเสธอยู่แล้ว)

## ขอเคาะสามข้อ
1. หลักฐาน 13 จุดนี้ **นับเป็น "การวัดใบที่สอง"** ที่ปลดสิทธิ์ให้เติม `ISLAND_CONTACT_DISCRIMINATOR` ได้ไหม
   ถ้าใช่ = งานแรกรอบหน้าของสายนี้ · ถ้าไม่ ขอทราบว่ายังขาดอะไร จะได้เขียนลงใบให้ตรง
2. ใบ crosswalk ที่รอบก่อนสัญญาไว้ ยัง **จำเป็น** ไหม หรือเหลือแค่คำถามเดียวที่ยังตอบไม่ได้ คือ
   **พิกัดของ `rx112 id=35` และ `rx248 id=2`** ซึ่งจดหมายไม่ได้ถอดไว้ ·
   จุด id=35 คือจุดที่สายนี้อยากได้ที่สุด: ถ้ามันอยู่นอกกล่องทั้งสาม กล่องจะแยก "ชนเกาะ" ออกจาก
   "น้ำเปล่า" ได้จริง ไม่ใช่แค่แยกเกาะสองใบออกจากกัน (วันนี้พิสูจน์ได้แค่อย่างหลัง — เขียนเป็น nonclaim แล้ว)
3. ใครแก้ `RE-234` ข้อ (3) ในเอกสารร่วม — K (เจ้าของเลขใบ/เนื้อใบ) หรือคุณ · สายนี้ไม่แตะเอง
