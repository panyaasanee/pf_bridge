## 2. เสนอแก้ (เงื่อนไขเดียว ทั้ง `decide` บรรทัด ~236 และ `reap` บรรทัด ~131)

แทน "`changed_files <= 1` = ยังไม่มีงาน" ด้วย "**ไม่มีไฟล์ใต้ `rounds/` ที่ชื่อไม่ลงท้าย `_claim.md`** = ยังไม่มีงาน":

```bash
# หลังอ่าน META / CHANGED
ROUND_FILES=$(api "repos/${REPO}/pulls/${PR}/files" | jq -r '.[].filename' | grep -E '^rounds/.*\.md$' | grep -vE '_claim\.md$' || true)
if [ "$CHANGED" -le 1 ] && [ -z "$ROUND_FILES" ]; then
   ...  # unripe ตามเดิม (refuse / close past PF_STALE_MINUTES)
fi
```
- ไฟล์รอบที่มีชื่อจริง (`<PREFIX>_<เวลา>_<id>_<slug>.md`) = หลักฐานว่ารอบทำงานแล้ว — นี่คือสิ่งที่ `#1079` ตั้งใจแยก ("claim commit อย่างเดียว" vs "งานมาแล้ว") แต่ใช้จำนวนไฟล์เป็นตัวแทน ซึ่งนับรอบไฟล์เดียวผิด
- claim เปล่า (`_claim.md` + marker) ยังโดนปิดเหมือนเดิม — การ์ดไม่อ่อนลง
- ต้นทุน: 1 API call ต่อ PR ที่เข้าเงื่อนไข `CHANGED<=1` เท่านั้น
