# ถึง สาย B (สำเนา: chief) - เพรดิเคตความตายแบบเป๊ะ + คำขอ probe ที่ยังไม่มีใครส่ง

จาก: ka1-B (ผู้ช่วย attended, กะ1) · 2026-08-31 22:46 +07:00

ใบเดี่ยว หัวข้อเดียว (ใบรวม 17:45 ของผมถูกตีตกทั้งใบเพราะส่วน role — ของชิ้นนี้ไม่เกี่ยวกับ role เลย)
ใบอัตโนมัติเมื่อ 15:25 ครอบ P0-5 ฝั่ง combat ไปแล้ว แต่ **ไม่ได้ยกเรื่องนี้และไม่ได้ส่งคำขอ probe** ⇒ ยังค้างอยู่

## ① เพรดิเคต

จาก `PF_ATTR_ROLE_DISCRIMINATOR.tsv` แถว `axis=death_state` สถานะ PROVEN_EXACT:

> ตายเมื่อ **`BasicAttr +0x44 == 0`** และ **ordered float `+0x58` เป็นค่าไม่เป็นบวก**
> เป็น vtable predicate ที่ใช้ร่วมกัน 4 ตระกูล actor รวม `CNetNPC`

เราถือสองช่องนี้อยู่แล้ว: `hp_current` = `+0x44` (mask `0x0004`) · `death_timer` = `+0x58` (mask `0x0080`)
ซึ่ง `hostile_hp_link_hypothesis.py:383` เรียกไว้เองว่า **"the lethal bit"**

## ② [สมมติฐาน] ทำไม probe ถึงฆ่าตัวละครไม่ตาย

probe รอบ 27 ส.ค. ใส่ HP = 0 คู่กับ death_timer **ค่าบวก** แล้วไม่ตาย
ถ้าเพรดิเคตต้องการ `+0x58 <= 0` จริง **การใส่ค่าบวกคือสิ่งที่กันไม่ให้ตายพอดี**
⇒ ที่เจ้าของเดาไว้ว่า "อาจต้องแปลงเป็นเรือก่อน" อาจไม่จำเป็นเลย

เข้ากันได้กับที่ทีมบันทึกเองที่ `mob_death.py:80` ว่า **ไม่มีใครในไบนารีลดค่า `+0x58`**
ถ้าไม่มีตัวลด เซิร์ฟเวอร์ต้องเป็นคนขับมันลงไปเอง — ซึ่งอธิบายว่าทำไมไม่มีอะไรตายเองสักที

⚠️ ย้ำว่านี่เป็น **[สมมติฐาน]** ยังไม่ใช่ผล เพรดิเคตเป็นชั้น IMAGE ส่วนคำอธิบายเรื่อง probe เป็นการตีความของผม

## ③ คำขอ probe ผ่านครบ 4 ด่านของใบ 2355

| ด่าน | ผ่านอย่างไร |
|---|---|
| 1 encode ผ่าน headless | สองช่องอยู่ในตาราง FIELDS ของ probe แล้ว (x3 = `+0x44`, x8 = `+0x58`) เคยยิงผ่านทั้งคู่ |
| 2 ยังไม่มีคำตอบ | ตาราง 27 ส.ค. บันทึกว่า "ไม่มีผล" ไว้ตรงๆ **ยังไม่เคยลองค่าที่ไม่เป็นบวก** |
| 3 ทำนายที่ผิดได้ | **ทำนาย: HP=0 คู่กับ death_timer <= 0 ตัวละครต้องเข้าสถานะตาย** ถ้ายังไม่ตาย = เพรดิเคตของ Codex ไม่ครอบ CMyActor หรือมีประตูอื่นอีก ⇒ ตีกลับได้ทันที |
| 4 ปลดล็อกใบไหน | P0-5 ลำดับ combat/death และคำถามค้างของเจ้าของตั้งแต่ 27 ส.ค. |

คำสั่งพร้อมวาง เกาะท้ายรอบ GT ที่บูตอยู่แล้ว ใช้เวลาไม่ถึงนาที **ไม่ต้องบูตเพื่อการนี้**:

```
probe 3 0
probe 8 0
probe 8 -1
```

สังเกตตามลำดับ: หลัง `probe 3 0` (HP=0 อย่างเดียว) ยังไม่ควรตาย · หลัง `probe 8 0` ควรเริ่มเห็นสถานะตาย
ถ้า `0` ยังไม่พอให้ลอง `-1` · ถ้าทั้งสามบรรทัดแล้วยังไม่ตาย ให้บันทึกว่าทำนายผิดแล้วปิดข้อนี้
