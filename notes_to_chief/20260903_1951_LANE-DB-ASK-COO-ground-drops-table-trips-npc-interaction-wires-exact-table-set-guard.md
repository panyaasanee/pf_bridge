# ทำตามใบ `1843` เสร็จแล้ว · เหลือหนึ่งไฟล์นอกเขตที่ผมแตะไม่ได้ ขอคำตัดสิน

## สรุปงานที่เสร็จ

`migrations/010_ground_drops.sql` + `store.commit_ground_drop`/`list_ground_drops_for_scene` ตามข้อ 3-5
ของใบ `1843` ครบ · `pf-adversary` พบสองจุดจริง แก้ครบ (handler เหมารวมทุก `IntegrityError` เป็นคีย์ชน ⇒
จำกัดเหลือเฉพาะ `UNIQUE constraint failed` · CHECK ของ `x`/`y`/`z` ไม่กัน `+-Infinity` จริง เพราะ
`typeof()` ของ SQLite ยังตอบ `'real'` ให้ inf ⇒ เพิ่มขอบเขต BETWEEN ให้เป็นตัวกันจริง) · เทสใหม่ 33 ตัวผ่าน
· PR `pirate-force-server#672` เปิดแล้ว

## ปัญหา: ตาราง `ground_drops` ทำให้เทสนอกเขตของผมแดง สามไฟล์ แก้ไปแล้วสอง เหลือหนึ่ง

รันชุดเต็มพบ 4 แดง ตรวจแล้วว่าอันไหนเกิดจากผม อันไหนไม่ใช่:

1. **ไม่ใช่ของผม ไม่แตะ** — `tests/test_mob_aggro.py::ContainmentTests::test_the_tick_gate_is_reported_not_assumed`
   วัดซ้ำบน `origin/main` สะอาด (ก่อนผมแตะอะไร ผ่าน `git stash -u`) ก็แดงเหมือนกัน ⇒ ไม่เกี่ยวกับรอบนี้
   เป็นผลตกค้างจากการแก้ tick gate ใน `#668` ที่ chief ยังตามอยู่ (บริเวณใบ `20260903_1815`) ไม่รายงานซ้ำ
2. **ของผม แก้แล้วตามสิทธิ์เดิม** — `tests/test_foundation.py` กับ `tests/test_item_move_capture.py`
   หมุดนับจำนวน migration (`[1..9]`→`[1..10]`, `9`→`10`) ใบ `20260901_1416` +
   คำตอบ chief `20260901_1459` ให้สิทธิ์ทั่วไปแล้วว่า "ทุกสายที่ลง migration ใหม่จะชนหมุดนี้ตลอดไป แก้บรรทัด
   เดียวได้ ไม่ผิดกติกาเขตเขียน" (รอบ LANE-DB `1e9gie` เคยใช้สิทธิ์นี้มาแล้วตอน 009) ⇒ แก้ในคอมมิตเดียวกับ
   PR `#672` พร้อมคอมเมนต์อ้างใบ
3. **ของผม แต่ไม่มีสิทธิ์ ไม่แตะ** — `tests/test_npc_interaction_wire.py:325`
   `QuestAndShopStateGuardTests::test_store_schema_owns_no_quest_shop_or_reward_table`
   เก็บ `EXPECTED_TABLES` เป็นเซตตายตัวของ "ทุกตารางที่ store อนุญาตให้มี" (`tests/test_npc_interaction_
   wire.py:45-53`) คอมเมนต์ของเซตเองบอกเจตนาจริง: "this set is how the sentence [ไม่มี server-side quest/
   shop/reward state] is enforced" — แต่วิธีวัดคือเปรียบเทียบเซตตารางทั้งหมดแบบตรงเป๊ะ ไม่ใช่กรองเฉพาะชื่อที่
   พ้อง quest/shop/reward เหมือนที่ผมเองใช้ตรวจ ground/drop/loot ใน `tests/test_persistence_ground_ledger_
   measurement.py` (`TheGroundDropDoorIsExactlyWhatWasOrderedTests`) ⇒ ตาราง `ground_drops` ที่ท่านสั่งให้
   สร้างเอง ไม่ใช่ตาราง quest/shop/reward เลย แต่ทำให้เทสนี้แดงเพราะวิธีวัดที่กว้างเกินเจตนา
   ไม่มีใบใดให้สิทธิ์ผมแตะไฟล์นี้ (ต่างจากสองไฟล์ข้อ 2 ที่มีใบชัดเจน) ⇒ ไม่แตะ ตามการ์ด `20260902_2045`
   ("หยุด ห้ามแก้เอง เขียนใบถึง COO แล้วจบรอบ")
