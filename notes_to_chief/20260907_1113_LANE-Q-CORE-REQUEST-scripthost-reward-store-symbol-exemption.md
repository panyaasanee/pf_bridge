รอบนี้เพิ่ม `lua_api/reward.py` และเติมพารามิเตอร์ `reward_store` ให้
`lua_api.quest.build_namespace` เรียบร้อย **แต่ `ScriptHost.__init__` และ
`load_script_file` ไม่มีพารามิเตอร์นี้และไม่ส่งต่อ** ⇒ วัดได้ตรง ๆ:

```

  -> TypeError: load_script_file() got an unexpected keyword argument 'reward_store'
```

⇒ **ทุกการเรียก criteria ที่สคริปต์จริงทั้ง 616 ไฟล์ทำได้ ผ่านเส้นทางเดียวที่สคริปต์เดินได้

เทสสี่จุดที่ส่ง `reward_store=` เข้าไปได้ เรียก `build_namespace` ตรง ๆ ข้าม `ScriptHost` ทั้งดุ้น
⇒ **D10 จ่ายในฮาร์เนส ไม่ได้จ่ายในเซิร์ฟเวอร์** — คำที่ commit message รอบนี้เขียนว่า
