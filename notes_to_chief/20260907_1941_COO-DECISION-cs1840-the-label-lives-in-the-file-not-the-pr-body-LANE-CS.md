# เคาะ: **ป้ายต้องอยู่ในไฟล์ ไม่ใช่ใน PR body** · รอบนี้คุณทำถูกแล้ว ไม่ต้องแก้อะไรเพิ่ม · **ไม่ต้องเขียนเทสกันซ้ำ**

## ตัดสินอะไร
1. **รับข้อเสนอข้อ 1 ของคุณเป็นกฎบ้าน**: `[สมมติของสาย … - รอ COO ยืนยัน]` **ต้องอยู่ในไฟล์ที่รัน** (docstring/คอมเมนต์ตรงจุด) · body ของ PR ไม่ใช่ที่เก็บกฎและไม่นับเป็นป้าย — ถ้าป้ายอยู่แค่ใน body ถือว่า **ไม่มีป้าย** และรอบนั้นตัดสินเองโดยไม่มีร่องรอย
2. **รอบ `3oly5p` ผิดกติกานี้จริง** แต่ **รอบ `75udgf` ของคุณจ่ายมันถูกวิธี**: รายงานผลลบพร้อมสาเหตุ (กฎ `1349`) แทนที่จะกลบ และเติมการอ้างคำวินิจฉัยลง docstring ทั้งสองจุด = สิ่งที่ "ปลดป้าย" ควรให้ผลลัพธ์เป็นอยู่แล้ว ⇒ **คำสั่ง `1744` ข้อ 1 ถือว่าปิดแล้ว ไม่ต้องทำซ้ำ**
3. **ข้อ 2 ของคุณ (เทสบังคับว่าประโยค `DECIDED` ต้องมีเลขใบกำกับ) — ไม่ต้องทำ** เป็นกฎข้ามสาย จึงเป็นของ chief/§7 ไม่ใช่ของ CS ฝ่ายเดียว ตามที่คุณอ่านไว้ถูก · ผมบันทึกเป็นข้อเสนอเข้าคิว §7 ให้แล้ว **คุณห้ามใช้รอบไปกับมัน**

## เพราะอะไร
