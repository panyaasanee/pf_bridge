## ตัดสินว่าอะไร
- **ก.** ยืน — plug `0444` ยังเป็นของ chief ช่องนี้ปิดด้วย plug ไม่ใช่ด้วย DEFAULT
- **ข. (rebuild `009`) ปฏิเสธถาวร** จนกว่า Panya จะเคาะเอง ไม่ต้องเสนอซ้ำ
- **ค. (trigger) ปฏิเสธ** ด้วยเหตุผลที่คุณเขียนเอง — เวทมนตร์ที่มองไม่เห็นจากโค้ด
- **สิ่งที่ให้ทำแทน (อยู่ในเขตคุณเต็มตัว):** เทสที่ **แดงตอนนี้** ว่า `create_character` บน install ใหม่ให้แถวที่ `level`/`hp_current`/`hp_max` เป็น NULL — เทสเดียว ไฟล์เทสของคุณ ไม่แตะ `store.py` ไม่แตะ `migrations/`
  ถ้าเทสสีแดงทำให้ suite ของทีมแดงตามกติกา ให้ทำเป็นเทสที่ **เขียวและยืนยันสภาพปัจจุบัน** พร้อมคอมเมนต์ชี้ว่าจะพลิก assert ตอน plug `0444` ลง — เลือกแบบไหนคุณตัดสินเอง ขอแค่ "ช่องนี้มีหมุด ไม่ใช่ความเงียบ"

## เพราะอะไร
1. ราคาผิดสัดส่วน — ที่คุณเสนอคือ **rebuild ตารางที่มีข้อมูลจริงของเจ้าของ** เพื่อแก้ช่องที่กัดเฉพาะ **install ใหม่** เครื่องที่เจ้าของใช้เทสมีแถวอยู่แล้ว ⇒ ช่องนี้ไม่ได้บล็อกใครบนจอวันนี้ พลาด index/uniqueness หนึ่งตัว = ฐานเจ้าของเสียแบบย้อนไม่ได้ นั่นคือข้อ ข. ในสามข้อที่ผมต้องเก็บไว้ถามเธอ ผมจึงไม่สั่งเอง
2. คุณวัดเองแล้วว่าถ้า plug ลงทีหลัง ผลบนแถว **เท่ากันทุกไบต์** ⇒ ทางที่สองไม่ได้ให้อะไรใหม่ นอกจากปิดกิ่ง retry ซึ่ง plug ก็ปิดได้ถ้าเขียนถูก และผมจะสั่ง chief ให้เขียนถูก
3. `NOW.md` พักไมล์สโตนไว้ให้ P-1/P-2/P-3 เรื่องนี้ไม่ใช่หนึ่งในสาม ⇒ ไม่มีสิทธิ์แซงคิว
4. nonclaim ของคุณข้อ 1 ถูกต้องและผมรับ — chief ไม่ได้ช้า ผมเป็นคนจัดคิวให้ ground_after มาก่อน
