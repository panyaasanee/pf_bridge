# ตัวฟื้นตอนล็อกอินลงแล้ว ทั้งสี่ข้อ — และผมเพิ่มข้อที่ห้าที่ใบไม่ได้สั่ง

## สี่ข้อของใบ อยู่ตรงไหน

1. **เขียน `hp_current = hp_max` ของแถวนั้นเอง** — ผ่าน `store.restore_hp_to_full` ที่มีอยู่แล้ว
   มันอ่าน `hp_max` จากแถว **ในทรานแซกชันเดียวกับ UPDATE** (`store.py` `_apply_hp_transition`,
   `BEGIN IMMEDIATE`) ⇒ เลขคงตัวไม่มีทางเข้ามาได้ และโมดูลผมไม่ได้เขียนเลขไหนเอง
   **ไม่ได้เพิ่ม method ใหม่ใน `store.py` และไม่ได้แตะไฟล์นั้นเลย**
2. **ส่งค่าที่เพิ่งเขียน** — 🔴 ผมไม่เชื่อผลลัพธ์ของการเขียน: หลังเขียนเสร็จ **อ่านแถวกลับใหม่**
   ผ่านประตูเดิม แล้วเฉพาะการอ่านกลับที่สะอาด (`FROM_ROW`) เท่านั้นที่กลายเป็นคำตอบ
   ⇒ wire = สิ่งที่ DB ถืออยู่จริง ณ วินาทีนั้น ไม่ใช่สิ่งที่การเขียนอ้างว่าทำ
3. **reason ของตัวเอง** — `ROW_HP_NOT_POSITIVE_REVIVED_ON_LOGIN` (ค่าโทเคน = ชื่อในใบของท่าน
   ตัวพิมพ์เล็ก เพราะทุกค่าใน `REASONS` เป็นตัวพิมพ์เล็ก) ไม่กลบเป็น `row_has_no_value` มีเทสปักไว้
4. **เขียนล้ม = ไม่ล้มล็อกอิน** — ทุก exception จากการเขียน **และจากการอ่านกลับ** กลายเป็น
   `REVIVE_WRITE_FAILED` พร้อมค่าคงตัวสามตัวเดิม (ไบต์เท่ากับที่ `main` ส่งวันนี้)
   console line ถูก **ตะโกน**: `!! LOGIN_VITALS REVIVE_WRITE_FAILED ...` (โทเคนตัวใหญ่ = การสะกดในใบท่านเป๊ะ)

## ข้อที่ห้าที่ผมเพิ่มเอง และอยากให้ท่านรับทราบ

ใบสั่งว่า "เขียนไม่สำเร็จ" ผมตีความให้กว้างกว่านั้นหนึ่งขั้น: **เขียนสำเร็จแต่แถวยังไม่ฟื้น
ก็นับว่าล้มเหมือนกัน** (write หาย · ถูกตีตายซ้ำระหว่างสองคำสั่ง · store โกหก)
เพราะทางเดียวที่ wire กับ DB จะขัดกันได้อีกคือทางนี้ ถ้าท่านเห็นว่ากว้างเกินไป สั่งได้ ผมหดให้

## ที่ยัง **ไม่** ได้ทำ ตามข้อห้ามของท่าน

- 🔴 **ไม่ได้เสียบ seam** รอบเดียวกัน — ยังไม่มีใครเรียกโมดูลนี้ ⇒ **ยังไม่มีผู้เล่นคนไหนถูกฟื้น**
  และไม่มีอะไรจากรอบนี้ที่เห็นบนจอ ห้ามรอบไหนรายงานเป็นชัยชนะ
- ไม่มี migration ใหม่ ไม่แตะ `.db` จริง ไม่แตะแถวของใครนอกจากตัวที่ล็อกอินเข้ามาเอง
  ⇒ ไม่เข้าข้อห้าม backup ตามที่ท่านเขียนไว้ในใบ

## หนี้ที่การเปลี่ยนนี้ก่อ และผมจ่ายในรอบเดียวกัน

`tests/test_persistence_vitals_heal.py::NothingIsWiredTests` เคยประกาศว่า **ไม่มีใครเรียกประตูฮีลเลย**
รอบนี้ทำให้ข้อความนั้นเท็จ (ข้อความในเทสเองบอกให้เขียนใหม่ ไม่ใช่ให้ผ่อน) ⇒ ผมเปลี่ยนเป็น
**แผนที่ผู้เรียกที่ได้รับอนุญาต สร้างจาก AST ไม่ใช่ข้อความ**: `restore_hp_to_full` มีผู้เรียกได้ใบเดียว
คือโมดูลล็อกอินนี้ · `apply_hp_heal` ยังไม่มีผู้เรียก · ใครโผล่มาเพิ่ม = แดง
"เอ่ยถึง" กับ "เรียก" แยกกันแล้ว เพราะ prose ของผมอ้าง `heal_to_full` โดยไม่ได้เรียก
