# `item_operate_res` (บรรทัดเขียว "ได้รับ") ปลดแฟล็กเองไม่ได้ — ตัวจุดชนวนอยู่ในเขต LANE-B

`NOW.md` บรรทัด "เมื่อไม่มีงานด่วน — ท่อ promotion" เขียนว่า **"`item_operate_res` UI ปลดได้"**
รอบนี้ไปวัดจริงก่อนลงมือ แล้วพบว่ามันปลดไม่ได้ด้วยมือของสายเดียว — เหตุผลข้างล่างวัดด้วยคำสั่ง ไม่ใช่ความเห็น

## สิ่งที่ **รู้แล้ว** (ไม่ต้องทดลองซ้ำ)
`GT-063 ITEMOPERATE-RES-GREENLINE-SHAPE-001` = **PASS** แล้ว (R158 25 ส.ค. · Panya ขับเอง 01:12-02:09)
โมเดลปิด: `$V2` ในเทมเพลตข้อความ 131 คือ **ยอดรวมปลายทาง** ไคลเอนต์คำนวณ delta เอง
⇒ ทรง `BAGUPD` ที่ถือยอดรวมใหม่คือทรงที่วาดบรรทัดเขียว · ทรง control (count=0) เงียบ
⇒ **ไม่มีคำถามค้างเรื่อง "ทรงไหนขึ้นจอ" อีกแล้ว** สิ่งที่ค้างคือ "อะไรเป็นตัวยิงมันในบูตปกติ"

## ตัวบล็อก: ในบูตไร้แฟล็ก ไม่มีเหตุการณ์ "ผู้เล่นได้รับไอเทม" ให้เกาะ
- เส้นทาง production ที่ส่ง `ItemOperateVitalRes` (`0x4C13`) วันนี้คือ **การย้ายไอเทมในกระเป๋า**
  (`runtime.py:1972` → `inventory.make_item_move_delta_response`) — "ย้าย" ไม่ใช่ "ได้รับ"
  บรรทัดเขียวไม่ควรขึ้นตอนลากของในกระเป๋าตัวเอง
- จุดที่ไอเทม **เข้ามาใหม่** จริง ๆ คือ `store.commit_acquired_backpack_item` (STORE-INSERT-001)
  🔴 grep แล้ว: `grep -rn "commit_acquired_backpack_item" src/pirateforce_foundation/` — ผู้เรียก
  **ทุกตัว**อยู่ใน `mob_pickup*.py` (เก็บของจากมอน = **LANE-B**) ไม่มีผู้เรียกนอกนั้นเลย
  และ `grep -rn "def add_backpack_item\|add_item_to_backpack\|def give_item"` = **0 hit**
  ⇒ ไม่มี API "แจกไอเทม" อื่นในรีโปให้ UI เกาะ
- จุดเสียบ dispatch อยู่ใน `runtime.py` ซึ่งเป็น **CORE-REQUEST ใบเดียวต่อจุด** ตามพรอมป์สายเรา

## ที่เสนอ (ตัดสินแล้วว่าจะไม่ลงมือเองในรอบนี้ ไม่ใช่การรอเฉย ๆ)
บรรทัดเขียวควรเกิดที่ **จุดเดียวกับที่ไอเทมถูก commit เข้ากระเป๋า** ไม่ใช่จุดที่ UI ประดิษฐ์ขึ้นใหม่:
เมื่อเส้นทาง pickup ของ LANE-B commit ไอเทมสำเร็จ ให้ประกอบเฟรมด้วย **โคเดกที่พิสูจน์แล้ว**
(`inventory.make_item_move_delta_response` ทรง BAGUPD ถือ **ยอดรวมใหม่ของสล็อตนั้น**)
แล้วส่งต่อจากเฟรมยืนยันการเก็บ — ไม่มีไบต์ที่ต้องเดาสักตัว ทั้งโคเดกและโมเดล `$V2` ปิดแล้วทั้งคู่

ขอ COO เคาะสองข้อ:
1. **เจ้าของงานนี้คือใคร** — LANE-B (เจ้าของ pickup path) หรือ LANE-UI ผ่าน `CORE-REQUEST` หนึ่งใบ
   ที่ขอ hook ตรงจุด commit · สายเราทำได้ทันทีที่มีจุดเสียบ แต่เขียน `mob_pickup*`/`runtime.py` เองไม่ได้
2. ถ้าเป็นของ LANE-B ⇒ ขอให้ตัดบรรทัด "`item_operate_res` UI ปลดได้" ออกจากท่อ promotion ของ UI
   หรือแก้เป็น "รอ LANE-B pickup path" เพื่อไม่ให้รอบถัดไปของ UI เสียเวลาค้นซ้ำเรื่องเดิม
