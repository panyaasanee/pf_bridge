## 1. ที่ลงไปแล้ว (revision 5)

**`find_mt.bat` (ไฟล์ใหม่)** — ค้น `mt.exe` ตามลำดับ แล้ว *ล้มดัง ๆ พร้อมบอกว่าหาที่ไหนไปแล้ว* ถ้าไม่เจอ:
`PATH` → `%WindowsSdkDir%bin` → `%ProgramFiles%\Microsoft SDKs\Windows\` (ทั้งต้นไม้) → `%ProgramFiles(x86)%\...` → `%VCINSTALLDIR%bin`
**ไม่ฮาร์ดโค้ดพาธ** ตามใบสั่ง (พาธของเครื่องเจ้าของอยู่ในข้อความ FAIL เป็น *ตัวอย่าง* ไม่ใช่ทางที่โค้ดใช้)
เป็นไฟล์แยกเพราะสองสคริปต์ต้องใช้ตัวเดียวกัน — ค้นสองที่ที่คัดลอกกันไว้จะเพี้ยนกันเอง

**`build_vs2008.bat`** — ฝัง manifest หลัง link **ก่อนทุกเช็ค** (เช็คทุกข้อและ sha256 ต้องพูดถึงไฟล์ที่จะถูกติดตั้งจริง)
· เพิ่ม `check 0/4`: อ่าน RT_MANIFEST #2 **กลับออกมาจาก DLL** ด้วย `-inputresource` — `mt.exe` คืน 0 ไม่ใช่คำอ้างที่สำคัญ
· ลบ `GameMaster.dll.manifest` เก่าทิ้งตอนต้น (ของค้างจากบิลด์ก่อนจะถูกฝังเข้าบิลด์ใหม่เงียบ ๆ แล้วผูกกับ CRT ผิดตัว)
· 🔴 เขียนเป็น label ไม่ใช่บล็อกวงเล็บ เพราะ `%ProgramFiles(x86)%` มี `)` อยู่ในค่า — วงเล็บนั้นปิดบล็อก `if (...)` ก่อนเวลา แล้ว cmd จะรันข้อความที่เหลือเป็นคำสั่ง

**`install.bat`** — ปฏิเสธที่จะติดตั้ง DLL ที่ไม่มี manifest ฝัง (อ่านกลับด้วยตัวเดียวกัน)
**`README.md`** — เพิ่มแถวอาการนี้ในตารางไล่ปัญหา พร้อมขีดฆ่าว่าปิดแล้วที่ revision 5

## 2. 🔴 ข้อที่ผมตอบไม่ตรงถ้อยคำของใบ ขอให้เคาะ [สมมติของสาย GM - รอ COO ยืนยัน]

ผมจึง **ไม่** เพิ่มไฟล์ที่ต้อง copy แต่เพิ่ม *เกตว่าไฟล์เดียวนั้นครบจริง* แทน

(ของ EXE คนละเรื่อง) การเอาไฟล์ที่เดาว่าอาจได้ผลไปวางในโฟลเดอร์ client ของเจ้าของ คือสิ่งที่ `install.bat` ออกแบบมาไม่ทำ
**ถ้าคุณอ่านใบว่าต้อง copy จริง สั่งมา ผมเพิ่มสองบรรทัด**

## 2ก. pf-adversary จับได้ 9 ข้อในครึ่งนี้ แก้ไป 7 — สองข้อที่สำคัญที่สุด

- **`if errorlevel 1` เป็นการเทียบ `>=` แบบมีเครื่องหมาย** ⇒ `mt.exe` ที่ตายด้วย exit code ติดลบ (เป็นไปได้จริง เพราะเรารันมันจากโฟลเดอร์ที่ไม่อยู่บน PATH) จะทำให้สคริปต์พิมพ์ `[ok]` สองครั้งแล้ว **ส่ง DLL ที่โหลดไม่ได้ออกไป** ผ่านเช็คที่เพิ่มมาเพื่อกันเรื่องนี้พอดี ⇒ เปลี่ยนเป็น `%errorlevel% neq 0` ทั้ง 13 เกต
- **เช็ค 0/4 ของผมยืนบนคำสั่งที่ไม่มีใครเคยรัน** (`-inputresource ... -validate_manifest`) แล้วผมเขียนบรรยายว่าเป็นการวัด — **ผิด** ⇒ เกตแข็งย้ายไปยืนบนสิ่งที่ ka1-A วัดจริง (บิลด์ที่โหลดไม่ได้ **ไม่มีเซกชัน `.rsrc`**) ด้วย `dumpbin` ที่สคริปต์ใช้อยู่แล้ว · คำสั่ง `mt.exe` ลดชั้นเป็น `[warn]` ที่บอกสองสาเหตุที่มันแยกไม่ออก
  🔴 ถ้าทำเป็นเกตแข็งไว้แล้วมันไม่รองรับคำสั่งนั้น สคริปต์จะ **ปฏิเสธบิลด์ที่ดี** บนเครื่องเดียวที่เรามีหลักฐาน — เสียรอบ attended เท่ากันจากอีกด้าน
- อีก 5 ข้อ: quote `%TARGET%` ในบล็อกวงเล็บ (ติดตั้งลงพาธที่มี `(x86)` ไม่ได้เลย) · ย้ายเกตเครื่องมือลงใต้ `[STOP]` · ค่า sha256 ใน README เป็นของไฟล์ก่อนแก้ทั้งชุด · `find_mt.bat` ยัง untracked · `build_vs2008.bat` ลบ `GameMaster.dll` ทิ้งได้แม้เป็นไฟล์ที่ไม่ได้เกิดจากบิลด์ที่นี่
- ยังไม่แก้ (ข้อเสนอ ไม่ใช่ปิดเงียบ): `install.bat` เช็คซ้ำแค่ 1 ใน 4 เกตของบิลด์ · `copy /y` ไม่อะตอม · `plugin_image_check` รับ RT_MANIFEST id ไหนก็ได้ ทั้งที่ loader ของ DLL อ่าน id 2 (แก้ docstring แล้ว ยังไม่รัด)
