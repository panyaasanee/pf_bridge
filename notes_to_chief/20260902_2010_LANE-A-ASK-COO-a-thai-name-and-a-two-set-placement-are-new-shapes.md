# ตารางฉาก 126 มีสองทรงที่ไม่เคยเจอในสิบเกาะ — ผมตัดสินไปแล้วทั้งคู่ ขอให้เคาะ

## ทรงที่ 1 — ชื่อภาษาไทย (cp874 ได้ แต่ไม่ใช่ ASCII)

Mob-Set 56 -> CLINE 60455 -> MOBS 8180 เป็นแถวจริงมีร่าง (`M081_000_000_N`, level 60)
แต่ `MOBS_TIP.s_NAME` เป็น **ภาษาไทย** ไม่ใช่ ASCII

- ที่ผ่านมาสายนี้ **ตัดทิ้ง** เฉพาะชื่อ CJK เพราะ `cp874` เข้ารหัสไม่ได้เลย (bg0006 สามแถว)
- **ภาษาไทยคือสิ่งที่ cp874 เข้ารหัสได้พอดี** ⇒ เหตุผลเดิมใช้ไม่ได้กับแถวนี้
- **ตัดสินไปแล้ว: ตัดทิ้ง (เสีย 1 placement จาก 38)** ด้วยเหตุผลที่แคบกว่า —
  ชั้นหลักฐานของสายนี้ (`actor_lines` · บรรทัดสำมะโน · ใบเทสที่ผู้เทสคัดลอก) เป็น **ASCII ตามสัญญา**
  ชื่อที่การพิสูจน์แบบ headless พิมพ์ไม่ได้ = ความขาดที่มองไม่เห็น
- **ถ้า COO บอกว่าให้ส่ง** ผมส่งได้ในรอบเดียว: คลาย `isascii()` ใน `_self_check` เป็น cp874
  แล้วบรรทัดคอนโซลของฉากนี้จะมีอักษรไทย ⇒ **ต้องยอมรับพร้อมกันว่าใบเทสของฉากนี้ไม่ใช่ ASCII ล้วนอีกต่อไป**

[สมมติของสาย A - รอ COO ยืนยัน] · ย้อน: แก้ตารางแถวเดียว + `UNRESOLVED` หนึ่งคีย์

## ทรงที่ 2 — placement ที่ระบุ Mob-Set **สองตัว** ในคอลัมน์เดียว

6 placement (index 30-35) เขียนว่า `Mob_Set_53|Mob_Set_54` · **ทั้งสองขาแก้ได้จริง**
(53 -> MOBS 8167 · 54 -> MOBS 8171 · ทั้งคู่ `INVISIBLE` level 110 ไม่มีแถว `MOBS_TIP` เลย =
เครื่องหมายอากาศทะเลสองแบบที่ `world_m2_sea_destination` วัดไว้ตั้งแต่ ส.ค.)

- **ตัดสินไปแล้ว: ส่งขาแรก** เก็บสตริงเต็มไว้ใน `MULTI_SET_PLACEMENTS` และ `_self_check` ปฏิเสธถ้ามี `|`
  หลุดเข้าคอลัมน์ที่ส่งจริง · ขาที่สอง (54) บันทึกไว้ที่ `SECOND_LEG_ONLY` ไม่ให้ดูเหมือนของที่ลืม
- **ทำไมสมมตินี้ราคาถูก**: ทั้งสองขา **มองไม่เห็นทั้งคู่** และเท่ากันทุกคอลัมน์ที่ส่งยกเว้นเลข MOBS
  ⇒ เลือกอีกขาไม่เปลี่ยนพิกเซลและไม่เปลี่ยนป้ายชื่อ เปลี่ยนแค่ตัวเลขในหลักฐานคอนโซล
- ทรงนี้ **ไม่ได้มีแค่ฉากนี้**: `world_m2_sea_destination` วัดไว้ว่า 98 placement ใน 16 ฉากใช้ทรงเดียวกัน
  ⇒ กติกาที่ COO เคาะวันนี้จะเป็นกติกาของทุกฉากทะเลที่เปิดต่อจากนี้
