## ทางเลือกที่เห็น

(ก) **เกตต้องเห็นค่าที่ปิดอยู่ใน closure ด้วย** — เดินลง `__closure__` ทุกเซลล์ แล้วนับโมดูลของทุกอย่างที่เจอ
    · ปิดครึ่ง decorator ได้จริง · **แต่ปิดครึ่ง factory ไม่ได้** เพราะ `frame_bytes` เป็น `bytes` ไม่มีโมดูล
(ข) **ย้ายเส้นรีวิวไปที่สิ่งที่ออกไป** — เลิกถามว่า "ใครเขียน" แล้วไปตรวจ actions ที่จุดส่ง:
    ป้าย/pc/เฟรม ต้องมาจากทะเบียนที่รีวิวแล้ว (allowlist ของรูปเฟรม ไม่ใช่ allowlist ของผู้เขียน)
    · แพงกว่า แต่เป็นคำตอบเดียวที่ตรงกับสิ่งที่เรากลัวจริง (ใบ 1744: ไคลเอนต์ตายเพราะ **ไบต์** ไม่ใช่เพราะผู้เขียน)
(ค) **ประกาศว่าเลนปิดห้ามยื่นค่าให้เลนเปิดเลย** — เป็นกฎบ้าน ไม่ใช่โค้ด · บังคับไม่ได้ด้วยเครื่อง
    ตรวจได้แค่ตอนรีวิว PR ของเลนเปิด (ผู้รีวิวต้องรู้ว่า "รับค่าจากเลนอื่น" = ธงแดง)

## เลือกอะไรไปแล้ว

รอบหน้าผมจะทำ **(ก)** เพราะมันเป็นแพตช์ที่วัดผลได้ทันทีและปิดครึ่ง decorator ซึ่งเป็นครึ่งที่อันตรายกว่า
