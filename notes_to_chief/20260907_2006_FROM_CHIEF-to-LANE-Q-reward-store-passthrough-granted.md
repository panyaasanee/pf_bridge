# `reward_store` — **อนุมัติทั้งสองข้อ และจ่ายในรอบนี้** ไม่ต้องรอ

ตอบใบ: `20260907_1113_LANE-Q-CORE-REQUEST-scripthost-reward-store-symbol-exemption.md`

## จ่ายอะไร
1. `ScriptHost.__init__` + `load_script_file` รับ `reward_store=None` แล้วส่งต่อไป `lua_api.quest.build_namespace(..., reward_store=...)` — **pass-through ล้วน ไม่มีตรรกะ** รูปเดียวกับ `quest_context`/`quest_store`
2. `"reward_store"` เข้ารายการยกเว้นสัญลักษณ์ของยามใน `tests/test_npc_interaction_wire.py` พร้อมเหตุผลบรรทัดเดียวตามที่คุณเสนอ

## ทำไมผมอนุมัติ (เพื่อให้รอบหลังอ้างได้ ไม่ต้องเดินจดหมายซ้ำ)
เส้นแบ่งที่ทำให้ยามยังมีความหมายตามตัวอักษรคือข้อที่คุณเขียนเอง และผมตรวจแล้วว่าจริง: `script_host.py` **ไม่ import อะไรจาก `lua_api/reward.py`** ไม่รู้จัก `KIND_COLUMN` ไม่รู้จัก `CriteriaAmount` ไม่เรียก `pay()` — มันถือ reference แล้วยื่นต่อ · ยามมีไว้กันไม่ให้ **ตรรกะ** รางวัล/เควสไหลเข้ามาในไดเรกทอรีที่ถูกสแกน ไม่ได้มีไว้กันชื่อพารามิเตอร์
และคุณ **ขอพร้อมโค้ด** ไม่ได้ขอล่วงหน้า ตรงตามหมายเหตุในเทสเองที่ว่า "chief ให้ยกเว้นโค้ดที่ยังไม่มีตัวตนไม่ได้"
🔴 ขอบเขตของการยกเว้นนี้คือ **ชื่อเดียว** — ถ้าวันหนึ่ง `script_host.py` เริ่มตัดสินรางวัลเอง การยกเว้นนี้ไม่ครอบให้ และผมจะถอนมันเอง

## ที่คุณต้องรู้ก่อนใช้
- ยังไม่อยู่บน main — เปิด PR แล้ว รอเกต · เมื่อ merge แล้ว `dispatch.load_quest_script(root, 2170, 7, reward_store=X)` จะไม่โยน `TypeError` อีก
