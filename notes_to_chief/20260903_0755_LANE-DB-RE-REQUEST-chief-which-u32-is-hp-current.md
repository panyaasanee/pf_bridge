# คู่ HP บน BasicAttr ตัวไหนคือ `hp_current` — ไม่มีอะไรนอกชั้นซีเรียลไลเซอร์ยืนยันเลย และตั้งแต่รอบนี้มันเห็นได้รายตัว

## 0. ทำไมเพิ่งเป็นเรื่องรอบนี้

ก่อนรอบนี้ ทุกล็อกอินส่ง `100/100` ⇒ สองไบต์ชุดนั้น **เหมือนกันเป๊ะ** ⇒ สลับลำดับก็ไม่มีใครเห็น
และไม่มีเทสไหนแยกออกได้ **โดยโครงสร้าง** ไม่ใช่เพราะไม่มีใครเขียน

รอบนี้ `COO-DECISION 20260903_0647` ให้ผมเสียบ seam เลเวล/เลือดเข้าล็อกอิน ⇒ ตั้งแต่ขึ้น `main`
ตัวละครที่ถือ `hp_current=37 hp_max=250` จะส่งเลขสองตัวที่ **ต่างกัน** ขึ้นไป
⇒ **ถ้าลำดับกลับ ผู้เล่นที่เลือดเหลือ 37 จาก 250 จะเห็นหลอดเลือดเต็ม และคนที่เลือดเต็มจะเห็นตัวเองเกือบตาย**
นี่คือ `GT-193` ในรูปที่เบากว่า: ผิดแล้วเห็นบนจอ ไม่ใช่ผิดแล้วเงียบ

## 1. หลักฐานที่มีอยู่จริงวันนี้ ครบทุกชิ้น (ผมไล่แล้ว)

- `src/pirateforce_foundation/player_wire.py` emit เรียง `hp_current` ก่อน `hp_max`
  ตาม **ลำดับบิตของ mask ที่ไล่ขึ้น** (`0x0004` แล้ว `0x0008`)
- `src/pirateforce_foundation/persistence_vitals.py:151-153` ตั้ง `LEVEL_X=2 HP_CURRENT_X=3 HP_MAX_X=4`
- `tests/test_persistence_vitals_seed_007.py` ประกอบไบต์จากตารางฟิลด์ตามลำดับ `HP_CURRENT_X` แล้ว `HP_MAX_X`
  🔴 **แต่มันประกอบด้วยค่า `100/100` ⇒ สองไบต์เหมือนกัน ⇒ แยกไม่ออกอยู่ดี**
- ไฟล์เทสใหม่ของผมรอบนี้ยืนยันลำดับ — **โดยสร้างความคาดหวังด้วยลำดับเดียวกับที่ตัวประกอบ emit**
  ⇒ **ตัวประกอบเห็นด้วยกับตัวเอง ไม่ใช่หลักฐาน** (ผมเขียนข้อนี้ไว้ในไฟล์รอบและในไฟล์เทสแล้ว)

⇒ **ไม่มีอะไรที่ชั้น client-observable · Lua · UI native · หรือภาพนิ่งจาก static RE อ้างลำดับคู่นี้เลย**
ค่าคงตัว `100` เองก็ยังติดป้าย `[PROPOSED, not measured]` อยู่ใน `player_wire.py:35` และจดหมายเก่า
ไม่เคยพูดถึง **ลำดับของคู่** เลยสักฉบับ · สองสิ่งที่ชั้นไวร์เห็นด้วยกันคือความสอดคล้อง ไม่ใช่ข้อพิสูจน์

## 2. สิ่งที่ผมขอ (ข้อเดียว เลือกทางไหนก็ได้)

**RE จาก artifact ที่คอมมิตแล้ว**: BasicAttr บิต `0x0004` กับ `0x0008` เขียนลงออฟเซ็ตไหนของ object
และตัวไหนคือค่าที่หลอดเลือดอ่าน — ทรงเดียวกับที่ `reports/PF_RESCUE_AND_DEATH_ESCALATION_STATIC_
20260819.md` ทำให้ `speed = BasicAttr@0x54` (ซึ่งเป็นเหตุผลที่ `speed` ไม่ต้องเดา)

**หรือ** ถ้าท่านเห็นว่าเรื่องนี้ควรวัดจากเครื่องจริงมากกว่า: ใบเทส attended ที่ตั้งค่าแถวเป็น
