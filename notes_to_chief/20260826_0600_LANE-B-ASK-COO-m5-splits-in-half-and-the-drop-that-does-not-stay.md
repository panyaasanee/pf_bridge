# `LANE-B-ASK-COO` — `M5` แตกเป็นสองครึ่ง และของบนพื้นที่ **ไม่อยู่รอให้เก็บ**

🔴 **ผมไม่ได้หยุดรอคำตอบ** — ตัดสินเองไปแล้ว ของถูก push แล้ว ใบนี้คือ "เขียนคำถาม แล้วเดินต่อ"

## ① ติดอะไร

`BUILD-006` เขียนเกณฑ์ไว้ว่า **"ของตกพื้น เก็บขึ้นมา เข้ากระเป๋า relog แล้วยังอยู่"**
รอบนี้ไปอ่านหลักฐานที่มีอยู่จริงก่อนเขียนโค้ด แล้วเจอว่าเกณฑ์นั้น **ยังปิดไม่ได้ทั้งประโยค** ด้วยเหตุผลสองข้อ
ที่ไม่ใช่ความขี้เกียจของสายนี้:

| ครึ่ง | สถานะหลักฐาน (ไม่ใช่ความเห็นผม) |
|---|---|
| **ของตกพื้น** | ✅ ท่อมีจริงและ **มีคนเห็นมาแล้ว** — `GT-045` job 1135 / `GT-045 v3` job 1122-1124: element bit `0x08` ที่ payload `2200423` วาด **โมเดล + ป้ายชื่อ** บนพื้นตรงพิกัดที่เซิร์ฟเวอร์ส่ง · `2600001` วาดแค่ฝุ่น |
| **เก็บขึ้นมา** | 🔴 **ไม่มีท่อที่พิสูจน์แล้ว** — `PickupTerrainThing` มี producer ฝั่งไคลเอนต์จริง (`GT-046`) แต่ **vital id `0x4543` เป็นค่า hash-derive ที่ไม่เคยมีใครเห็นบนสาย** และ corpus มีศูนย์เฟรมทั้งสองทิศ · และของ monster-drop อาจไปทาง `FightingDrop*` ที่ยังไม่ถอดรหัส (`GT-046` job 6) |
| **relog ยังอยู่** | 🔴 ต่อจากครึ่งบน — ยังไม่มีตัวเขียนแถวไอเทมใหม่ลง DB (Door 6 มี schema ไม่มีคนเขียน) |

🔴 **และมีข้อที่หนักกว่านั้น ซึ่งเป็นการหักคำทำนายของโปรเจกต์เอง:**
`GT-045 v3` ผู้สังเกต **เดินไปยืนทับทั้งจุด NEAR และ FAR แล้วกวาดกล้อง — ไม่มีวัตถุเหลืออยู่**
และการวัดเฟรมเดิม (23 ส.ค.) ให้สเกลไว้ที่ **0.633 วินาที**
⇒ **ของที่ท่อนี้วางลงพื้น "แว็บแล้วหาย" ไม่ใช่ "นอนรอให้เก็บ"** ⇒ ต่อให้ `PickupTerrainThing` ถูกต้องทุกไบต์
ผู้เล่นก็ยังไม่มีเวลาคลิกมัน

## ③ เลือกอันไหนไปแล้ว

**ทางที่ 2 · ทำเสร็จและ push แล้วในรอบนี้** — `MOB-LOOT-001`
(`src/pirateforce_foundation/mob_loot.py` · `production_allowed = True` · ไม่มีแฟล็ก)

- ฆ่ามอนสเตอร์ตัวไหน **มันทิ้งของของตัวมันเอง** — อ่านจาก `DROPS_NORMAL` / `_EQUIPMENT` / `_SPECIALLY`
  ของแถว `MOBS` ตัวนั้นจริง ๆ ผ่านตารางที่ **generate** จาก gamedata ที่ commit ไว้
  (`field_drop_tables.py` · เครื่องมือ `tools/pf_mine_scene_drop_tables.py` มีสี่ตัวคุมที่มันยอมปฏิเสธตัวเอง)
- ของยืนอยู่ **ตรงที่มันล้ม** ด้วย element `bit 0x08` mask `0x12` — **ไบต์ต่อไบต์เท่ากับเลนที่มีคนเห็นแล้ว**
- ตัวอย่างที่ผู้เล่นจะได้เห็นจริง (roll จริงจากซีดคงที่): `Blood Cubic Crystal` · `Energy Cubic Crystal` ·
  `Dagger` · `Exile Glove` — **ชื่อในตารางของเกม ไม่ใช่ชื่อที่ผมตั้ง**
- 🔴 และเลนนี้ **ประกาศเป็นค่าคงที่** ว่า `GROUND_DROP_DOES_NOT_PERSIST = True` — ไม่ใช่หมายเหตุในย่อหน้า

**ครึ่ง pickup ผมไม่แตะ** และวาง **ตะเข็บ** ไว้ให้แทน: `DropLedger` / `take_drop(ledger, key)`
รู้ว่า key ไหนคือไอเทมอะไร จำนวนเท่าไร ใครฆ่า ⇒ วันที่ท่อ pickup ถูกพิสูจน์ ครึ่งที่สองต่อได้ทันที

## ③½ 🔴 สมมติของสาย B ที่ติดป้ายไว้ในโค้ดแล้ว — **รอ COO ยืนยันหรือคว่ำ**

ทุกข้อเขียนเป็น `[OUR DESIGN]` ในโมดูล และเป็น nonclaim ในใบพิน `scenarios/combat_loot_001.json`

1. **ลำดับ roll** = NORMAL → EQUIPMENT → SPECIALLY (ลำดับคอลัมน์ของแถว `MOBS` เอง)
   — ของเซิร์ฟเวอร์ต้นฉบับกู้คืนไม่ได้ตลอดกาล (fact pack รอบ 100 เขียนไว้เอง)
2. **บล็อกของ element key** `[0x00100000, 0x00200000)` — เพื่อไม่ชนกับ key `1`/`2` ที่เคยส่ง
   และไม่ชนกับ identity ของมอนสเตอร์ (`0x2000..0x20FF`) · **ไม่มีใครพิสูจน์ว่า key space นี้ว่างจริง**
3. **ระยะกระจายของ 30.0 หน่วยบนแกน X** — เพราะ 30.0 คือระยะเดียวที่ attended เคยยืนยันว่ามองเห็น
4. **`DROP_REFRESH_MS = 500`** — เดาล้วน · `refresh_frames()` มีไว้ให้ทดลอง **ไม่ใช่ฟีเจอร์**
   (การส่งซ้ำจะ "ค้างของไว้" หรือ "เล่นเอฟเฟกต์ใหม่ทุกครั้ง" **ไม่มีใครวัด**)
5. **ไม่ roll คุณภาพไอเทม (`E_DROPS_QUALITY`)** ทั้งที่ตารางมี — เพราะ element **ไม่มีช่องให้ใส่**
   ⇒ roll ไปก็ได้ตัวเลขที่ไม่มีผู้เล่นคนไหนเห็น · ที่ของมันคือครึ่ง pickup (ตอนเข้ากระเป๋า)
6. **เงินวางพื้นไม่ได้** — ช่องเงินไม่มี item id และ element มีช่องเดียวคือ item id
   ⇒ roll แล้วบันทึกไว้ ไม่ส่ง · และการอ่านว่า `n_ITEM = 0` แปลว่าเงิน เป็น `[INFERENCE]` ไม่ใช่ของพิสูจน์

## ④ ถ้าผิดต้องย้อนอะไรบ้าง

- **ย้อนง่าย:** ทุกอย่างของรอบนี้เป็น **ไฟล์ใหม่** + การแก้ตัวดักที่รอบนี้ทำให้เป็นเท็จ
  **ไม่มีอะไร dispatch มัน** (`runtime.py` เป็นของ chief และยังไม่มีบรรทัดนั้น)
  ⇒ คว่ำ = revert คอมมิตของรอบนี้ ไม่มีผู้เล่น ไม่มี DB ไม่มี state ค้าง
- **ที่จะต้องเขียนใหม่จริงถ้า COO คว่ำ:** ถ้าคำตอบคือ "monster drop ไปทาง `FightingDrop*` ไม่ใช่ bit `0x08`"
  ⇒ **ตัว composer ทิ้ง** (ประมาณ 80 บรรทัด) · **แต่ roll + ตาราง + ledger ยังใช้ได้ทั้งหมด**
  เพราะมันไม่รู้จักท่อเลย
- ถ้าคำตอบคือ "บล็อก key ผิด" ⇒ แก้ค่าคงที่สองตัว ไม่มีอย่างอื่นขยับ
