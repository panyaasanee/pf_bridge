## 1. reaper — จ่ายแล้ว (ใบ `0010` ข้อ 3 ทางแก้ ข.)
คำสั่ง: "PR ที่ CI เขียว + adversary ยังไม่คืนผล = มีชีวิต ห้ามปิด · reaper อ่านผลเกต/CI เป็น marker ชั้นหนึ่ง"
**จุดเดียวในไฟล์ที่ปิด PR ที่เกตเขียว** อยู่ที่ `.github/workflows/merge-claude-pr.yml` งาน `reap`:
reaper ลอง `gh pr merge` เอง แล้วปิดสิ่งที่ merge ไม่ได้ — และ **API ปฏิเสธการ merge draft เสมอ**
กฎ `1849` สั่งให้จุดเสียบที่วิ่งทุกเฟรมเปิดเป็น draft จนกว่า adversary จะคืน ⇒ reaper ปิด PR **เพราะมันทำตามกฎ**
คอมเมนต์ที่มันโพสต์ก่อนปิดพูดเรื่องนี้ไว้เองคำต่อคำ ("If this pull request was still a draft, that refusal is expected") แล้วปิดต่อ
แก้: `if [ "$DRAFT" = "true" ]` ⇒ `continue` + `::warning::` หนึ่งบรรทัด (ไม่ปิด ไม่คอมเมนต์ ไม่ un-draft)
แคบโดยตั้งใจ: PR เขียวที่ **ไม่ใช่** draft และ merge ไม่ได้ (403/ชนกัน/หัวขยับ) ยังปิดเหมือนเดิม · เกต **แดง** ยังปิดใน `decide` ไม่แตะ
เทสใหม่ `tests/test_reaper_keeps_green_drafts.py` ปักลำดับสามคำสั่ง (merge → guard → close) · มิวแทนต์ 4 ตัว ตายทั้งหมด
ตรวจไฟล์ workflow: YAML ไม่มี key ซ้ำ · `bash -n` เขียวทั้ง 3 ก้อน `run:` · preflight PASS
**สถานะ: PR เซิร์ฟเวอร์เปิดแล้วรอเกต ไม่ใช่ "อยู่บน main"**
