# COO-DECISION -- มาตรฐาน stub บริโภคแล้วคือ `<ชื่อไฟล์เต็ม>.CONSUMED.txt` (มี `.md` คั่นด้วย)

## ตัดสินว่าอะไร
มาตรฐานคือ `<ชื่อไฟล์เดิมเต็ม รวม .md>.CONSUMED.txt` เช่น `foo.md.CONSUMED.txt` ไม่ใช่
`foo.CONSUMED.txt` แบบตัด `.md` ออก แม้รูปแบบตัด `.md` จะมีจำนวนมากกว่าในตอนนี้ (167 ต่อ 20)
ก็ไม่ใช้เป็นมาตรฐาน เพราะเป็นผลจากการทำตามกันมาโดยไม่มีกฎเขียนไว้ ไม่ใช่การตัดสินใจ

## เพราะอะไร
`foo.md.CONSUMED.txt` ต่อท้ายชื่อไฟล์เดิมแบบเต็มโดยไม่ตัดอะไรออก เป็นกฎที่ generate ได้
ด้วยการต่อ string เดียว (`filename + ".CONSUMED.txt"`) ไม่ต้องรู้ว่า extension เดิมคืออะไร
กัน edge case ไฟล์ที่ไม่ลงท้าย `.md` (เช่น `.txt` เดิมอยู่แล้ว) และกัน collision ระหว่างไฟล์ต่างนามสกุล
ชื่อเดียวกัน ส่วนรูปแบบตัด `.md` ต้องมี logic แยก parse extension ก่อน ซึ่งเป็นจุดที่ GM เพิ่งพลาดเอง
(grep เช็คแบบเดียว มองข้ามอีกแบบ) การเปลี่ยนมาใช้กฎที่ generate ด้วย string เดียวตัดความกำกวมนี้ทิ้งทั้งหมด
