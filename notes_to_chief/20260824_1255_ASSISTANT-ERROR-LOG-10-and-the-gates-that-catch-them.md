## ส่วนที่ 3 — ด่านที่ให้ตั้ง (บังคับกับผู้ช่วยได้เลย)

### ด่าน G1 — ห้ามพูดว่า "ยังไม่มีใครทำ / ไม่มี / หยุดแล้ว" จากแหล่งเดียว  *(ดักข้อ 1, 10)*
ก่อนอ้างว่าอะไร "ยังไม่ทำ" ต้องผ่านลำดับนี้ทั้งหมด และ **เขียนผลของแต่ละชั้นลงในข้อเสนอ**:
1. `ServerProject\docs\FUNCTIONAL_COVERAGE.json` (สถานะ + `evidence_refs` + `next_missing_behavior`)
2. `ServerProject\docs\` และ `reports\`
3. `pf_bridge\external\` และ `pf_bridge\gamedata\`
4. `GAME_TEST_QUEUE.md` · `CLIENT_RE_QUEUE.md`
5. `notes_to_chief\`

🔴 **`grep` ใน `src\*.py` ไม่นับเป็นการเช็ค** · และก่อนอ้างว่าใคร "หยุดทำงาน" ต้องตรวจ **เส้นทางส่ง** ด้วย
(`sync.log` · `ahead/behind` · `SYNC_ATTENTION.txt`) ไม่ใช่แค่ดูปลายทาง

### ด่าน G2 — แก้ไฟล์ไหน ต้องระบุ "ใคร commit" ในข้อความเดียวกัน  *(ดักข้อ 2)*
ไฟล์ที่ **track แล้วแต่อยู่นอก push allowlist** เป็นกับดัก แก้แล้วไม่ commit = ตันทั้งระบบ
⇒ ทุกครั้งที่ผู้ช่วยแก้ไฟล์บนดิสก์ **ต้องแนบคำสั่ง commit มาในข้อความเดียวกัน**
ถ้าไม่มี → **Codex ปฏิเสธได้เลย** และให้ทัก
*(หมายเหตุ: แพตช์ `$SHARED_TRACKED` ลดกับดักนี้ลงแล้ว แต่ยังไม่ครอบทุกโฟลเดอร์)*

### ด่าน G3 — แก้กลไกไหน ต้องบอกก่อนส่งว่าอะไรอีกที่แตะกลไกนั้น  *(ดักข้อ 5, 6, 7)*
สามข้อนี้คือข้อบกพร่องเดียวกัน ด่านเดียวดักได้หมด
⇒ ก่อนส่งการแก้ `pf_git_sync.ps1` / สคริปต์ที่เขียนไฟล์ / กฎในโฟลเดอร์ที่มี guard
ผู้ช่วยต้องเขียนรายการ **"ผู้ใช้รายอื่นของกลไกนี้"** มาด้วย
ตัวอย่างที่ควรจับได้ตั้งแต่ต้น: *"ฉันเขียนไฟล์ลง `evidence_screens\` — โฟลเดอร์นั้นมีเพดาน 2 MB ผลผลิตของฉันใหญ่เท่าไร"*

### ด่าน G4 — `serializer_status=CLOSED` ≠ "รู้โครง"  *(ดักข้อ 8)*
ก่อนแนะนำให้ implement ข้อความใด ต้องเปิด `PF_SERIALIZER_FIELDS.tsv` ดูแถวจริง
และยืนยันว่ามีฟิลด์ที่ **`tag != EMPTY`** อย่างน้อยหนึ่งตัว
`CLOSED` แปลว่า "พิสูจน์แล้วว่ามันเขียนอะไร" ซึ่งคำตอบอาจเป็น **"ไม่เขียนอะไรเลย"**
(สถิติ: 519 ข้อความ · มีฟิลด์จริงฝั่ง W **418** · เป็น EMPTY/stub **101**)

### ด่าน G5 — ห้ามรวมหลักฐานจากคนละชั้นเป็นข้ออ้างเดียว  *(ดักข้อ 9)*
ชั้นที่มีในโปรเจกต์นี้: **wire/DB · client-observable · Lua script · UI native · static image · ข้อมูลในตาราง**
ทุกชิ้นหลักฐานต้องกำกับชั้นของมัน · หลักฐานสองชั้นที่ชี้ทางเดียวกัน = **สอดคล้อง ไม่ใช่พิสูจน์**

### ด่าน G6 — ห้ามประกาศความหมายของฟิลด์จากการอ่านหัวไฟล์  *(ดักข้อ 3)*
ต้องเดินเรกคอร์ดจนกินไบต์หมดไฟล์พอดีก่อน · และถ้ามีค่าอ้างอิงที่รู้แล้ว ต้องใช้เป็นตัวควบคุม
(บทเรียน: `bg0001` = 113 definition แต่ 149 placement)

### ด่าน G7 — VA→file offset ต้อง map จาก PE section table เสมอ  *(ดักข้อ 4)*
อิมเมจนี้มี 6 sections · delta ต่างกันต่อ section (`.text` `0x400C00` · `.rdata` `0x401C00` · `.data` `0x402800`)
**ห้ามใช้ delta เดียวข้าม section**

### ด่าน G8 — ติดป้ายทุกข้อเสนอเป็นสองเกรด  *(ด่านที่ครอบทุกข้อ)*
- **`[วัดแล้ว]`** = ผู้ช่วยรันเอง + แนบวิธีตรวจ + ระบุด่านตัวควบคุมที่ใช้
- **`[เสนอ]`** = ยังไม่ยืนยัน ห้ามใครสร้างอะไรบนนี้จนผ่านด่าน

🔴 วันนี้ผู้ช่วยปนสองเกรดนี้เข้าด้วยกัน ทำให้ Panya ไม่มีทางแยกว่าอันไหนเชื่อได้
**ถ้าข้อเสนอไม่มีป้าย ให้ถือว่าเป็น `[เสนอ]` โดยปริยาย**
