## แก้ข้อที่ 1 — ผมข้ามด่าน `+0x20` ซึ่งอยู่เหนือบรรทัดที่ผมอ้างสองคำสั่ง

ใบผมเขียนว่า "ลูปรับแพ็กเก็ตเรียกสล็อต `+0x1C` จริงที่ `0x005F38B2`" — จริง แต่ **ไม่ครบ** ลิสต์ของ `RE-312` RESULT-2 §1 เองคือ

    0x005F3888  mov eax,[edx+0x20]   ; ด่าน คืน bool
    0x005F3890  je  0x5F38DB         ; ด่านไม่ผ่าน -> xor al,al ; ret 4
    0x005F38B2  call eax             ; <-- บรรทัดที่ผมอ้าง

RESULT-2 §4 + BUILD_IMPACT 1 เขียนไว้ชัด: ถ้า `+0x20` คืน 0 ลูป **ทิ้ง sub-vital ที่เหลือทั้งเฟรม** และ handler นอกคืน false
"อาการที่ผู้เล่นเห็นคือของบางอย่างหายแบบสุ่มโดยไม่มี error" · และ nonclaim 2 ของ RESULT-2 บอกว่า
**ยังไม่มีใครอ่านว่า `+0x20` คืนอะไรสำหรับ vital ใดเลย**

🔴 **ผลต่อการอ่านใบ**: บล็อก `ATTENDED:` ของผมเขียนว่า "ไม่เห็นอะไรเลย = ผลที่มีค่าและปิดใบได้" — **ผิด**
ถ้า `+0x20` ของ `PartyInviteVital` คืน false ไคลเอนต์ทิ้งทั้งชุดเงียบ ๆ ผู้เทสเห็นจอนิ่ง และโทเคนฝั่งเซิร์ฟเวอร์
ยังขึ้น PASS ทุกบรรทัด ⇒ "ไม่เห็นอะไร" **แยกไม่ออก** ระหว่าง "ไคลเอนต์รับแล้วไม่วาด" กับ "ไคลเอนต์ไม่เคยรับ"
ใบที่ตัดสินไม่ได้ = ใบที่เผาบูต attended ฟรี

## แก้ข้อที่ 2 — ไบต์ version ที่ส่งกลับเป็นของเซิร์ฟเวอร์แต่ง ไม่ใช่ของผู้เล่น

ใบผมเขียนว่า "เซิร์ฟเวอร์สะท้อนไบต์ของผู้เล่นเองกลับไปเท่านั้น" — จริงเฉพาะ **payload**
ไบต์ version ใช้ค่าคงที่ `PARTY_INVITE_VITAL_VERSION = 0` ซึ่งคอมเมนต์ของตัวมันเองเขียนว่า *"Unproven default"*
