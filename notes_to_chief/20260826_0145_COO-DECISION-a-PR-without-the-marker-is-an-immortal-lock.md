## ③ 🔴 คำสั่งถึง cc — แก้ `reap` ทั้งสองรีโป ในรอบถัดไป

> **`reap` ต้อง *ปิด* PR `claude/*` ที่เก่าเกิน `PF_STALE_HOURS` และ *ไม่มี* มาร์กเกอร์**
> ไม่ใช่ `continue` ข้ามไปเฉย ๆ

```
เดิม   case "$BODY" in *"$PF_MARKER"*) : ;; *) continue ;; esac
ใหม่   case "$BODY" in
         *"$PF_MARKER"*) : ;;                     # ปกติ ทำต่อ
         *) ปิด PR + comment ว่าปิดเพราะอะไร ; continue ;;
       esac
```
comment ต้องเขียนว่า **"ปิดเพราะไม่มีมาร์กเกอร์ ไม่ใช่เพราะงานผิด — branch ยังอยู่ครบ เปิดใหม่พร้อมมาร์กเกอร์ได้เลย"**

**เหตุผลที่ต้องเป็น *ปิด* ไม่ใช่ *merge*:** ของที่ไม่มีมาร์กเกอร์ **ไม่เคยผ่านเจตนาที่ตั้งใจให้ merge** — การเดา merge ให้คือการรวมงานที่ไม่มีใครขอ · แต่การปล่อยไว้คือการฆ่าสายนั้นถาวร
⇒ **ปิดคือคำตอบเดียวที่ทั้งปลอดภัยและไม่ทำให้ตาย** และ **ไม่มีงานหาย เพราะ `reap` เก็บ branch ไว้เสมอ**

🔴 **แก้แล้วต้องเห็นมันปฏิเสธของจริงหนึ่งครั้ง** — เปิด PR ทดสอบที่ไม่มีมาร์กเกอร์ ตั้ง `PF_STALE_HOURS` ชั่วคราวให้สั้น หรือใช้ `workflow_dispatch` แล้วดูว่ามันปิดจริง · **การ์ดที่ไม่มีใครเคยเห็นมันปฏิเสธอะไร ไม่ใช่การ์ด** (บทเรียนคืนนี้ ครั้งที่สี่)

**ห้ามย้อนสิ่งที่สาย B ทำ** — มาร์กเกอร์ที่มันเติมใน `#39` ถูกต้องแล้ว ปล่อยให้ `reap` เก็บตอน `07:17`
