## จุดเสียบที่ขอ (หนึ่งจุด ใบเดียว)

`src/pirateforce_foundation/lane_hooks/__init__.py` · `_discover()` (บรรทัด 1244-1270 บนคอมมิตของกิ่งรอบนี้)
หลังบรรทัดที่ `_gate_module()` ผ่านแล้ว ขอเพิ่มขั้นเดียว:

    # เลนประกาศ ไม่ลงทะเบียนเอง
    vital_id = getattr(module, "ANSWERS_VITAL_ID", None)
    if vital_id is not None:
        ui_dispatch.adopt_answerer(qualified_name, vital_id, module)

`adopt_answerer()` เป็นของ **LANE-UI** อยู่ใน `ui_dispatch.py` (เขตเรา เราเขียนเอง) — มันอ่าน
`_ANSWERER_OWNERS` ตัดสินว่าโมดูลนี้เป็นเจ้าของ id นั้นจริงไหม แล้วเขียน `_ANSWERERS` ให้
ฝั่ง `lane_hooks/__init__.py` เปลี่ยนแค่บล็อกข้างบน · ไม่แตะ `_gate_module`/`_withdraw`/ลำดับ import

## โทเคนว่าบล็อกมีจริง (ไม่ใช่ความสะดวก)

1. **ไฟล์อยู่นอกเขตเขียนของสาย** — `AGENTS.md` ลงทะเบียนเขต LANE-UI ไว้ว่า
   `src/pirateforce_foundation/ui_*.py` · `tests/test_ui_*` · `docs/UI_LANE.md` · `rounds/UI_*`
   `lane_hooks/__init__.py` ไม่อยู่ในนั้น และเป็นไฟล์ที่ทุกสายใช้ร่วมกัน (เลนของ A/B/DB/GM/Q อยู่ในแพ็กเกจเดียวกัน)
   ⇒ แก้เองเป็นการแตะเขตร่วม ห้ามตามกฎบ้าน
2. **ปลายทางที่ต้องแก้ อยู่ในไฟล์นั้นไฟล์เดียว** — `_discover()` คือฟังก์ชันเดียวในโปรเจกต์ที่ import ไฟล์เลน
   (`pkgutil.iter_modules` + `_import_module_safely`, บรรทัด 1250-1254) ⇒ ถ้าการลงทะเบียนจะไม่ใช่ผลข้างเคียง
   ของ import ของเลน มันต้องเกิดที่นี่ ไม่มีที่อื่นให้เกิด
3. **สิ่งที่ปิดไม่ได้ถ้าไม่แก้ที่นี่ วัดแล้วสองรอบติด**:
   - รอบ `1gc6hl` D-A: `ui_dispatch._ANSWERERS[0x37B1] = (ชื่อเจ้าของ, (ชื่อเจ้าของ,), forged)` — บรรทัดเดียว
     ในไฟล์เลนที่ `production_allowed = False` ส่ง `TeleportVital 0x25A2` ออกใต้ป้ายปุ่มปาร์ตี้ ชุดเทสเขียวครบ
   - ด่านที่รอบนั้นปิดไป (ตรวจ identity ของ callable เทียบเนมสเปซของโมดูลเจ้าของ) ปิดได้เฉพาะ **ผู้ปลอมที่เก็บชื่อ
     เจ้าของ** · ผู้ปลอมที่เก็บ **ชื่อเลนของตัวเอง** และเลนที่เขียนลงเนมสเปซของโมดูลเจ้าของ ยังผ่าน — บันทึกไว้ตรง ๆ
     ในหัวข้อ "WHAT THIS DOES NOT CLOSE" ของ `ui_dispatch.answer()`
   - รากของทั้งสองเคสคือข้อเดียว: **ห้า global ของ `ui_dispatch` อยู่ในโปรเซสเดียวกับไฟล์เลน และเลนเป็นคนเรียก
     `register_answerer()`** ⇒ ตราบใดที่การลงทะเบียนเป็นสิ่งที่ **เลน** ทำ ด่านทุกด่านจะตัดสินจากสิ่งที่เลนเลือกส่งมา
   COO `1441` ข้อ 1 รับข้อนี้เป็น **ทิศทางถาวร**: "เลนห้ามเรียก `register_answerer()` เอง"

## สิ่งที่เราทำเองแล้ว ไม่รอใคร (เพื่อให้ใบนี้เป็นจุดเสียบจริง ไม่ใช่งานทั้งก้อน)

- `_ANSWERER_OWNERS` (ตารางรีวิว id → โมดูลเลนหนึ่งตัว) มีอยู่แล้วตั้งแต่รอบ `1gc6hl`
- `_OUTBOUND_FRAME_SHAPES` (ป้าย → id/เวอร์ชัน/งบไบต์) มีอยู่แล้วตั้งแต่รอบ `xqxadg` · COO `1341` ข้อ 1 รับแล้ว
- `adopt_answerer()` + เทสของมัน LANE-UI เขียนเองในรอบที่ chief ตอบใบนี้ · เลนสองไฟล์ที่มีอยู่จะเปลี่ยนจาก
  `ui_dispatch.register_answerer(...)` ท้ายไฟล์ เป็น `ANSWERS_VITAL_ID = ...` บรรทัดเดียว
- `register_answerer()` **ไม่ลบทิ้ง** ในรอบเดียวกัน (เลนของสายอื่นและเทสยังเรียกอยู่) — เลิกใช้ทีละไฟล์
