## ขั้นที่ 4 — กฎเหล็กของงาน static (พลาดข้อไหนก็ล้มทั้งใบ)

1. **หลักฐานมีหลายชั้น ห้ามใช้ชั้นหนึ่งพิสูจน์อีกชั้น (G5)** — `wire/DB` · `client-observable` · `Lua script` · `UI native` · `static image` · `data tables`
   บอกทุกข้อเท็จจริงว่าอยู่ชั้นไหน · สองชั้นชี้ตรงกัน = consistent **ไม่ใช่** proven
2. **ผลลบมีค่าเท่าผลบวก** — "ไม่มีเส้นทางนี้ใน shipped data" คือคำตอบ ต้องรายงานเข้มเท่าผลบวก · **ห้ามเดาให้เต็มหน้ากระดาษ**
3. **Provenance หรือไม่นับ** — ทุกตัวเลขต้องมี path+บรรทัด / commit hash / ชื่อตาราง+แถว · "จำได้ว่า" ไม่ใช่หลักฐาน
4. **re-derive ไม่ใช่ quote** — ถ้ารายงานเก่าบอกจำนวนไว้ ให้นับใหม่แล้วบอกว่ายังจริงไหม (pin เก่าเคยทำ gate แดงมาแล้ว 2 ครั้ง)
5. **ห้ามใช้ linear disassembler เป็นหลักฐานผลลบ** — ใช้ recursive CFG · รายงาน decode error = 0
6. **VA → file offset ต้องแมปผ่าน PE section table รายเซกชัน (G7)** — อิมเมจมี 6 เซกชัน delta ไม่เท่ากัน
   (`.text` 0x400C00 · `.rdata` 0x401C00 · `.data` 0x402800) · ใช้ delta เดียวข้ามเซกชัน = อ่านขยะ
7. **`serializer_status=CLOSED` ไม่ได้แปลว่ามีฟิลด์บน wire (G4)** — CLOSED แปลว่า "พิสูจน์แล้วว่ามันเขียนอะไร" และคำตอบอาจเป็น "ไม่เขียนอะไรเลย"
8. **ความหมายของฟิลด์มาจากการเดินเรกคอร์ด ไม่ใช่จาก header (G6)** — ต้องให้เรกคอร์ดกินไฟล์หมดแบบ byte-exact + มีค่าอ้างอิงเป็น control
9. **ความยาว ≠ ชนิด** — `PF_TAG_CENSUS.tsv` มี `proven_semantics = UNKNOWN` เกือบทุก tag (ยกเว้น `0x12`=uint16, `0x2A`=float32)
   ห้ามตั้งชื่อชนิดให้ tag จากความยาวอย่างเดียว
10. **ก่อนจะพูดว่า "ยังไม่มี / ไม่ได้ทำ / หยุดแล้ว" ต้องเดินบันได G1 ให้ครบ** —
    `docs\FUNCTIONAL_COVERAGE.json` → `docs\` + `reports\` ฝั่ง server → `external\` + `gamedata\` →
    ทั้งสองคิว (`GAME_TEST_QUEUE.md`, `CLIENT_RE_QUEUE.md`) → `notes_to_chief\`
    แล้วเขียนผลของแต่ละชั้นลงในผล · grep แค่ `src\*.py` **ไม่นับว่าตรวจ**
    (ถ้าจะอ้างว่า "ฝ่ายไหนหยุดทำงาน" ต้องเช็คท่อส่งด้วย: `sync.log` · branch ahead/behind · `SYNC_ATTENTION.txt`)
11. **sha256 ของทุกไฟล์ที่พึ่ง ก่อน-หลัง ต้องตรงกัน** และรายงานทั้งคู่ ·
    อิมเมจ `GameClient\GameClient.local.bin` เปิด **read-only** เท่านั้น — sha ต้องไม่ขยับ
12. **ห้ามแก้ของที่ไม่ใช่ของคุณ** — ห้ามแก้อิมเมจ · ห้ามแก้ตารางใน `external\` · ห้ามแก้ encoder / ledger / เฟรมร่างของ chief
    ใบ RE ให้ **หาหลักฐาน ไม่ใช่แก้โค้ด** · เจอโค้ด/คอมเมนต์ผิด = รายงานเสียงดัง ไม่ใช่ไปแก้เอง
13. 🔴 **ห้ามอัปโหลด `GameClient*.bin` · capture corpus · ไฟล์ `.dmp` ขึ้นเน็ตหรือเข้า git ตลอดกาล ไม่มีข้อยกเว้น**
