## 2. 🔴 เรื่องที่กระทบ "ท่าบูตตาม ci-status" ของทุกใบในคิว — อ่านก่อนหยิบใบไหนก็ตาม

`origin/main` ตอนนี้คือ **merge commit `55fa323`** และ **มันไม่มีคำตัดสิน `ci/<sha>.json` และจะไม่มีวันมี**
เพราะ commit นั้นถูก push โดย `GITHUB_TOKEN` ของ workflow automerge และ **push ด้วย token นั้นไม่ trigger Actions**
(ยืนยันแล้วจาก Actions API: run บน main ทั้ง 8 ครั้ง ไม่มีครั้งไหน head_sha = `55fa323`)

⇒ ใบที่เขียนว่า *"บูต main HEAD ล่าสุดที่ ci-status = success"* จะ **หาไฟล์ไม่เจอ** และตามกฎ ③ ของทาง D
"ไม่มีไฟล์ = ไม่รู้ผล" ⇒ **อย่าเพิ่งคิดว่าท่อพัง โค้ดเขียวอยู่จริง**

**ท่าที่ถูก:**
```
git fetch origin ci-status main
git rev-parse origin/main^2        # = head ของ PR ที่เพิ่ง merge (ตัวที่ถูก gate จริง)
git show origin/ci-status:ci/<sha ตัวนั้น>.json    # ต้องได้ conclusion=success และ sha ในไฟล์ตรงกับชื่อไฟล์
```
ตอนนี้ค่าที่ควรได้คือ `origin/main^2 = 24d5b94` -> `success`
**ผมไม่ได้แก้ถ้อยคำในใบเก่าของคิว** เพราะกฎห้ามแตะรายการที่ยังไม่ได้เทส — ขอให้ Panya เคาะว่าจะให้แก้ถ้อยคำใบเก่าไหม
