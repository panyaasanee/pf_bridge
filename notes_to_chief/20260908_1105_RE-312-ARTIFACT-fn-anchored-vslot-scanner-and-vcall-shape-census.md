## 1. `vslot_fnscan.py` — สแกนจุดเรียก virtual แบบยึดขอบฟังก์ชัน

```
python3 vslot_fnscan.py <image> 0x1c
```

**ทำอะไร**: ตัด `.text` เป็นก้อนตรงช่วง `CC CC` (ได้ 46,191 ก้อนในอิมเมจนี้) แล้วถอดรหัสจาก**ต้นก้อน**ทีละก้อน จับคู่ `mov r,[base+SLOT]` กับ `call r` / `jmp r` ที่ตามมาภายใน 10 คำสั่ง โดยตัด base ที่เป็น `esp`/`ebp` ทิ้ง

**ทำไมต้องมี**: การถอดรหัสเชิงเส้นจาก `.text` base เพี้ยนในไบนารีนี้เพราะมีข้อมูลปนใน `.text` วัดเทียบกันตรง ๆ ที่ slot `0x1c`:

| วิธี | จุดที่เจอ | เจอ `0x005F38B2` ไหม |
|---|---|---|
| linear จาก `.text` base | 96 | **ไม่** |
| ยึดขอบฟังก์ชัน (ตัวนี้) | 468 | ใช่ |

⇒ ของเดิมพลาดไปราว **80%** ของจุดเรียก ใครเคยได้ผลลบจากการสแกน slot ในไบนารีนี้ กรุณารันซ้ำด้วยตัวนี้ก่อนเชื่อผลลบนั้น

**ข้อจำกัดที่ต้องรู้** (อย่าใช้เป็นหลักฐานผลลบโดยไม่ระบุ):
- ยึด `CC CC` เป็นขอบ ⇒ ฟังก์ชันที่ไม่มี padding นำหน้าจะถูกกลืนเข้ากับก้อนก่อนหน้า และถ้าก้อนนั้นเพี้ยนก็ยังพลาดได้
- หน้าต่าง 10 คำสั่ง ⇒ ถ้าคอมไพเลอร์ spill พอยน์เตอร์สล็อตลงสแต็กแล้วเรียกทีหลังไกล ๆ จะไม่เจอ
- ไม่ตาม indirect ผ่านตัวแปร global

## 2. `vcall_shape_census.py` — สำมะโนรูปแบบ call ทั้งอิมเมจ

```
python3 vcall_shape_census.py <image>
```

ผลกับอิมเมจนี้:

```
  22378  N                          (call imm32)
   7341  dword ptr [N]              (IAT)
   2969  edx
   2113  eax
    518  ebp
    470  esi
    431  ebx
    342  edi
     29  ecx
      1  dword ptr [esp + ecx*2]
```

**ข้อสรุปที่ใช้ได้ทันที**: ไม่มี `call dword ptr [reg + disp]` เลยแม้แต่คำสั่งเดียว ⇒ virtual call ทุกจุดเป็นรูป `mov r,[vtbl+slot]` แล้ว `call r` ใครค้นด้วยไบต์ `FF 5x xx` จะได้ศูนย์เสมอ ไม่ใช่เพราะไม่มี virtual call

## 3. ถ้าจะเลื่อนขึ้นเป็นเครื่องมือใน `tools_bridge/` (ถึง LANE-K)

สิ่งที่ต้องเติมก่อน ผมไม่ทำเองเพราะ `tools_bridge/` ไม่ใช่เลนของ runner:
1. รับ path อิมเมจจาก `PF_ROOT` แทน argv ตัวแรก และตรวจ sha256 ให้ตรงกับที่ระบุก่อนรัน
2. ออกผลเป็น TSV คอลัมน์ `fn_va, load_va, call_va, slot, base_reg, target_reg, mnemonic` เพื่อ diff ข้ามรอบได้
3. รองรับหลาย slot ในการรันครั้งเดียว (ตอนนี้รันทีละ slot)
4. ใส่ `--section` ให้เลือกเซกชันได้ (ตอนนี้ล็อกที่ `.text`)
5. เขียน unit check เล็ก ๆ ที่ยืนยันว่า slot `0x1c` ต้องได้ 468 จุด และต้องมี `0x005F3840/0x005F38AE/0x005F38B2` — เป็น regression guard ของตัวถอดรหัสเอง

ต้องมี `capstone` และ `pefile` (มีอยู่แล้วบน bridge VM: capstone 5.0.7, pefile 2024.8.26) โพรบทั้งสองตัว **อ่านอย่างเดียว** ไม่เขียนไฟล์ ไม่ต่อเน็ต ไม่เปิดเกม
