# `016` ปลดล็อกเควสต์ให้ "ตัวละครที่มีอยู่แล้ว" ได้ · แต่ "ตัวละครที่จะเกิดพรุ่งนี้" ยังโดนปฏิเสธ — ขอคำเคาะข้อเดียว

## สรุปคำถาม (ตอบสั้นได้)
`migrations/016_character_experience_skill_points_backfill.sql` ที่ผมส่งรอบนี้ **backfill** `experience`
และ `skill_points` จาก NULL เป็น 0 ให้ทุกแถวที่มีอยู่ — แต่ **ไม่ใส่ `DEFAULT 0`** ให้คอลัมน์
คำถาม: **ให้ผมออก migration ตัวถัดไปที่ใส่ DEFAULT ด้วยไหม?**

## ทำไมถึงไม่ใส่มาเลย — ไม่ใช่เพราะขี้เกียจ วัดมาแล้ว
รอบนี้ผมเขียนเวอร์ชันที่ใส่ DEFAULT ครบก่อน (rebuild แบบ `009` · 10 guard · 45 เทส) แล้วรันชุดใหญ่:

```
39 failed  (30 อยู่ที่ fixture เดียว)
tests/pf_birth_state.py — "an insertion point that adds a FIFTH column
turns every file that imports this one red at its fixture"
```

`pf_birth_state.py` ประกาศ **สามสภาพ**ที่ตัวละครเกิดใหม่ถืออย่างถูกกฎหมาย และปฏิเสธอย่างอื่นโดยเจตนา
DEFAULT บนสองคอลัมน์นี้คือคอลัมน์ที่ห้าและหก · ตาม NOW.md `2050` **พินปลดโดยเจ้าของ ผู้เรียกถอน** ผมจึงถอน
และตาม `COO-DECISION 20260902_1607` เรื่อง DEFAULT เป็นเรื่องที่ **เจ้าของเคาะเองในเซสชัน** และระบุไว้ **สี่คอลัมน์**
ผมไม่ถือว่าตัวเองมีสิทธิ์ขยายเป็นหก

## ราคาที่ต้องจ่ายจากการถอน — เขียนไว้ในหัวไฟล์ migration แล้ว ไม่ซ่อน
`pf-adversary` รอบนี้ (D1) วัดให้เห็นชัด:

```
pre-016 character  grant_experience -> OK       spend_skill_points -> OK
born after 016     grant_experience -> REFUSES  spend_skill_points -> REFUSES
```

`store.create_character` INSERT แค่ `level,hp_current,hp_max` (`store.py:748`) ⇒ ไม่มี DEFAULT = แถวใหม่ NULL ตลอดไป
🔴 และนี่คือรูปเดียวกับที่ `009` เขียนไว้เองว่าเป็นความผิดพลาดของ `007`/`008`:
*"007 and 008 seeded the cohort that existed when they ran and can never run again, so on a fresh install
every character born afterwards held NULL in all four forever."* — **016 คือ cohort seed แบบนั้น โดยรู้ตัว**

## สิ่งที่ผมทำแทน เพื่อไม่ให้ปัญหาสะสมแบบมองไม่เห็น
`persistence_null_audit.NULL_AUDIT_COLUMNS` เดิมนับ NULL แค่สี่คอลัมน์ · รอบนี้ผมเพิ่มสองคอลัมน์นี้เข้าไป
(เทสของไฟล์นั้นเขียนคำสั่งไว้เองอยู่แล้วว่าต้องทำ) ⇒ ระหว่างรอคำตอบของท่าน **จำนวนตัวละครใหม่ที่ถือ NULL นับได้**
ไม่ใช่ตัวเลขที่ไม่มีใครเห็น
