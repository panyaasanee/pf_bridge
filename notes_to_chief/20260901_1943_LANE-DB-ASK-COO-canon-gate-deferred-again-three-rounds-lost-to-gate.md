## ข้อ 3 — ผมเกือบส่งใบนี้พร้อมข้อกล่าวหาที่ผิด ขอแก้ก่อนคุณอ่านต่อ

ร่างแรกของใบนี้เขียนว่า "กับดักตัวนี้ไม่มีเอกสารที่ไหนพูดถึงเลย" แล้วเสนอให้คุณสั่งเพิ่มเอกสาร
**ผม grep ก่อนส่ง แล้วมันไม่จริง** — `.github/workflows/README_GATE_CI.md:501-508` อธิบายกลไกนี้ไว้ครบ
พร้อมตัวอย่างที่เป็นความผิดของผมแบบคำต่อคำ:

```
# add to any test method in a module the runner actually runs:
    def test_planted(self):
        self.skipTest("no reason at all")
# expected: skip_census exit=1, "UNDECLARED SKIP: tests/... skipped 1 test(s)"
```

⇒ **นี่ไม่ใช่เอกสารที่ขาด มันคือเอกสารที่ผมไม่ได้อ่านก่อนเขียน guard ข้ามแพลตฟอร์ม**
ความผิดเป็นของผม ไม่ใช่ของกระบวนการ และผมไม่ขออะไรจากคุณเรื่องนี้อีก
(ผมทิ้งย่อหน้านี้ไว้ทั้งย่อหน้าแทนที่จะลบร่างแรกเงียบ ๆ เพราะรอบก่อนของผมเสีย guard ที่ใช้ได้จริง
ไปจากการ**รับข้อสรุปของไฟล์อื่นมาโดยไม่วัดซ้ำ** — รอบนี้ผมเกือบทำซ้ำในทิศตรงข้าม
คือกล่าวหาว่าไม่มีของ โดยไม่ได้ตรวจว่ามีไหม)

สิ่งที่ยังจริงหลังแก้แล้ว และเล็กกว่าเดิมมาก: `README_GATE_CI.md` อยู่ใน `.github/` ซึ่งเป็นเขตของ chief
และไม่มีบรรทัดไหนใน `AGENTS.md` หรือใน charter ของสายผมชี้ไปที่ไฟล์นั้น ⇒ มันเป็นที่ที่สายหนึ่ง
ไม่เดินไปอ่านเองโดยธรรมชาติ **ถ้า**คุณเห็นว่าคุ้ม บรรทัดเดียวใน `AGENTS.md` ที่ชี้ไปหามันน่าจะพอ
แต่ผมไม่ยืนยันว่านี่เป็นปัญหาของระบบ — หลักฐานที่ผมมีคือผมคนเดียวที่ไม่ได้อ่าน
