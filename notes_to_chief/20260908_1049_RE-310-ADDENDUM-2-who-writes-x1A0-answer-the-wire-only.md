## คำถามที่ค้าง

## คำตอบ: **`0x00466230` = ตัวเข้ารหัส/ถอดรหัส `ActorAttr` บนสาย และมันคือผู้เขียนตัวเดียวที่เหลือ**

🔴 **ที่รอบก่อนหาไม่เจอเพราะสแกนผิดรูป** — ตัวถอดเฟรมไม่ได้เขียนด้วย `mov [reg+0x1A0], r8` แต่ **ส่งพอยน์เตอร์ให้ primitive เขียนแทน** (`lea` แล้ว `push`) การกวาดรอบก่อนจึงมองไม่เห็น · รอบนี้กวาด `lea r,[reg+0x1A0]` (ไม่นับฐาน `esp`) ได้ **30 จุดทั้งอิมเมจ** และสองจุดที่อยู่ในโมดูล `ActorAttr` คือคำตอบ

```
ฝั่งเขียนลงสาย (W)                      ฝั่งอ่านจากสาย (R)
0x00466638  mov eax,[esi+0x1B8]         0x00466B54  mov eax,[esi+0x1B8]     ; mask dword ที่สอง
0x00466646  test al, 1                  0x00466B62  test al, 1              ; บิต 0 = mask bit 1<<32
0x00466648  je   0x0046665C             0x00466B64  je   0x00466B78         ; บิต 0 -> ข้ามฟิลด์นี้
0x0046664A  push 1                      0x00466B66  push 1                  ; width = 1
0x0046664C  lea  eax,[esi+0x1A0]        0x00466B68  lea  eax,[esi+0x1A0]    ; &field
0x00466652  push eax                    0x00466B6E  push eax
0x00466653  push 0x0B                   0x00466B6F  push 0x0B               ; tag = 0x0B
0x00466657  call 0x0089A600  (เขียน)     0x00466B73  call 0x0089A640  (อ่าน)  ; <<< ตัวที่เขียนค่าลง +0x1A0
```

⇒ **`ActorAttr+0x1A0` ถูกป้อนโดย primitive อ่านสาย `0x0089A640` ที่ `0x00466B73` เท่านั้น**
⇒ tag `0x0B` · width `1` · เกตด้วยบิต 0 ของ mask dword ที่ `+0x1B8` = **mask bit `1<<32`** — ตรงกับ `attr_wire.py` แถว 46 `(46, "actor", 1 << 32, 0x1A0, 0x0B, "u8", "u8_1A0", …)` **ทุกช่อง** (แถวถัดไป `+0x1A2` tag `0x12` width 2 บิต 1 ก็ตรงกับแถว 47 เช่นกัน)

🔴 **ไม่มีจุดใดในไคลเอนต์ที่คำนวณ `+0x1A0` เอง** — ไม่มีเส้นทางจาก `AI_WANDER.n_FACTION` (`record+0xF8`) หรือจาก `FACTION.n_ID` มาที่ฟิลด์นี้
⇒ **เซิร์ฟเวอร์เป็นแหล่งเดียวของค่าฝ่าย/แคมป์ที่ตัดสินสีชื่อ** — ยืนยัน `BUILD_IMPACT 1` ของจดหมาย `0505` และปิดความเป็นไปได้ที่ไคลเอนต์จะเซ็ตเอง

## 🟠 ของแถมที่ต้องรายงาน — ขั้วของ mask **ต่างกันระหว่างสองจุด** (วัดได้ ไม่ใช่ตีความ)

| จุด | รูปคำสั่ง | ความหมายของ "บิตติด" |
|---|---|---|
| **wire serializer** `0x00466230` | `test al,1` แล้ว **`je` ข้าม** | บิตติด = **ทำฟิลด์นี้** (มีอยู่บนสาย) |
| **masked apply** `0x00465E60` | `test al,1` แล้ว **`jne` ข้าม** | บิตติด = **ไม่คัดลอก** |

ทั้งสองอ่าน mask จากออฟเซ็ตเดียวกัน (`+0x1B4`/`+0x1B8`) แต่คนละอ็อบเจ็กต์ (ตัวที่กำลังเข้ารหัส vs ปลายทางของการ apply) และ masked apply เรียก **`0x00465610`** คำนวณ mask ใหม่ตอนเข้าฟังก์ชัน
⇒ **ข้อสรุปที่ปลอดภัย: mask บนสาย = "ฟิลด์นี้มีอยู่" ตามที่ `attr_wire.py` เข้าใจอยู่แล้ว** · คำเตือนเรื่องขั้วในจดหมาย `0505` ข้อ 3 ใช้เฉพาะกับ masked apply ไม่ใช่กับการประกอบเฟรม
🔴 **ยังไม่ได้ถอด `0x00465610`** ⇒ ยังไม่ยืนยันว่ามันเป็นตัวกลับขั้วหรือเป็น mask คนละความหมาย

## BUILD_IMPACT

1. **ส่งค่าได้ตรง ๆ**: เปิดบิต `1<<32` ในชุด mask ของ `ActorAttr` แล้วใส่ u8 tag `0x0B` ⇒ ไคลเอนต์เขียนลง `+0x1A0` และสาขาสีชื่อจะเปลี่ยนตามที่จดหมาย `0505` ข้อ 1 อธิบาย
2. **การนับบิตของ `attr_wire.py` ถูกต้องอีกครั้ง** — คราวนี้ยืนยันจากตัวประกอบเฟรมโดยตรง (ไม่ใช่จาก masked apply) ทั้งแถว 46 (`+0x1A0`) และ 47 (`+0x1A2`)
3. **ปิดสมมติฐาน "ไคลเอนต์อาจเซ็ต faction เองจากตาราง"** — ไม่มีเส้นทางนั้น
4. **คำเตือนขั้ว mask ในจดหมาย `0505` ข้อ 3 หดขอบเขตลง** — ใช้กับ masked apply เท่านั้น การประกอบเฟรมใช้ขั้วปกติ

## nonclaims (ห้ามตัดออก)

1. **ไม่อ้างความหมายของค่าที่เซิร์ฟเวอร์ส่ง** — ค่า `2`/`3` มีผลตามสาขาที่จดหมาย `0505` ถอดไว้ ค่าอื่นยังไม่ทราบความหมาย
2. **ไม่ได้จำแนก `lea r,[reg+0x1A0]` ครบทั้ง 30 จุด** — จำแนกเฉพาะสองจุดในโมดูล `ActorAttr` (`0x0046664C`, `0x00466B68`) · อีก 28 จุดอยู่ในช่วงที่อยู่ของคลาสอื่น (`0x0050Cxxx` `0x0066xxxx` `0x00AAxxxx` `0x00ACxxxx`) **ยังไม่ได้ตรวจว่าเป็นคลาสอะไร** — ห้ามสรุปว่าไม่ใช่ `ActorAttr` จากช่วงที่อยู่อย่างเดียว
3. **ไม่ได้ถอด `0x00465610`** (ตัวคำนวณ mask ของ masked apply) ⇒ ความต่างของขั้วยังไม่ได้อธิบายที่ต้นเหตุ
4. **ไม่ได้ถอด primitive** `0x0089A600` / `0x0089A640`
5. **ไม่ได้ยืนยันว่าเฟรมไหนพา `ActorAttr` มา** — `PF_SERIALIZER_FIELDS.tsv` เขียนว่าแถวของ `ActorAttr` เป็น `EMPTY` และ `serializer_va` ในรีจิสทรี (`0x0043BB80`) เป็นสตับสั้น (`ret 8` ที่ `0x0043BB8E`) ⇒ **`0x00466230` ไม่ใช่ตัวที่รีจิสทรีชี้** มันถูกเรียกจากที่อื่น (น่าจะจากเฟรม `UpdateAttr`/`0x309A`) — **ยังไม่ได้เดินหาผู้เรียก**
6. static ล้วน · ไม่เปิดเกม · ไม่แก้ไฟล์ใด ๆ · อิมเมจ sha256 `9627211412ac60d50ad189ce5a629443ce928ec23a9f8d219dfb2b157028b623` (ก่อน = หลัง)
