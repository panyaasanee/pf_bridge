## 6. ของแถมที่ไม่ได้ถาม แต่ LANE-A ต้องรู้ก่อนเขียนโค้ด

### 6.1 มีทางลัดที่ไคลเอนต์ **ตอบเองโดยไม่เปิดหน้าต่าง**

## nonclaims (ห้ามตัดออก)

1. **ไม่อ้างว่า marker id ตัวไหนคือเกาะไหน** — ตรงกับ nonclaim ของเจ้าของใบเอง (crosswalk ปลายทางยังไม่มีใบ) · ห้ามจับคู่ `MARKER.n_ID` กับเลขอื่นเพราะช่วงตัวเลขใกล้กัน
2. **ไม่อ้างว่าปุ่มไหนเขียนค่า 1 ลง `[ctx+0x94]`** — วัดได้แค่ว่า callback ส่งเฉพาะเมื่อ `== 1` และทางอื่นไม่ส่ง · `+0x94` เป็นออฟเซ็ตที่ใช้ทั่วอิมเมจ (344 จุดเขียนค่าคงที่) **จึงไม่ใช้ออฟเซ็ตอย่างเดียวเป็นหลักฐาน**
3. **ไม่อ้างว่า `0x005F9F60` ทดสอบอะไร** และ `0x33` / `0x24` / `0x51` แปลว่าอะไร — รายงานว่ามีประตูอยู่ ไม่ได้ถอดความหมาย
4. **ไม่อ้างว่ามีทางอื่นเปิด confirm 22 ไม่ได้** — กวาดผู้เรียก `0x005AB5F0` ครบ 37 จุด และผู้เรียก wrapper `0x005AB830` ครบ 47 จุด **ไม่มีจุดใดใส่ค่าคงที่ 22** ⇒ จุดที่พบเป็นจุดเดียวที่ใส่ 22 **ในบรรดาจุดที่ใส่ค่าคงที่** · จุดที่ใส่ผ่านรีจิสเตอร์ที่ยังไม่ได้ไล่ครบ: `0x00579230` `0x005C03BD` `0x00640A10` `0x00510F9B` และผู้เรียกที่หน้าต่างสแกนสั้นเกิน (6 จุด) — **ไม่ได้เดินทั้งหมด**
5. **ไม่อ้างว่า `TeleportCheckVital` ไม่ทำอย่างอื่นด้วย** — ถอดเฉพาะ handler `0x005F2190` ช่วง `0x005F2190..0x005F23E0`
6. **เลข `0x4477` ไม่ได้วัดจากอิมเมจในรอบนี้** — opcode ถูกผูกตอนรันไทม์ที่ `[0x01082074]` · เลขนี้อ้างจาก `teleport_wire.py:108` ของรีโปเซิร์ฟเวอร์และจากตารางในเนื้อใบ · **สิ่งที่วัดได้คือคลาส ไม่ใช่ตัวเลข**
7. **ผลใบนี้ไม่อนุญาตให้เซิร์ฟเวอร์ส่ง `EnterInstanceVital` เอง** (ตาม nonclaim ของเจ้าของใบและ `NOW.md`)
8. **ถ้ามี vital ตัวอื่นเปิดหน้าต่างคล้ายกันแต่คนละข้อความ ไม่ได้ยุบรวม** — รายงานแยกไว้แล้ว: `0x007321C0` เปิด confirm 24/25 (เข้า instance · เลือกจาก `[ebx+6]`) และ `0x00734D50` เปิด confirm 23 (เกาะกิลด์ · จากการกดปุ่มบนหน้าต่าง ไม่ใช่จากเฟรม) — **คนละเส้นทาง คนละตัวจุดชนวน**
9. **ไม่ได้ใช้ linear disassembler เป็นหลักฐานผลลบ** — ผลลบเรื่อง string มาจากการค้นแพตเทิร์นไบต์ 3 encoding ทุก section · ผลลบเรื่อง `push 22` มาจากการดิสแอสเซมเบิลแล้วอ่าน operand ทุกคำสั่ง `push` (เป็นตัวช่วยค้น ไม่ใช่หลักฐานปิด — ข้อสรุปมาจาก `mov edi,0x16` ที่พบจริง)
10. ชั้นผล = **static ล้วน** ไม่มี client-observable ไม่มี wire/DB · ไม่ได้แก้ไฟล์ใด ๆ ใน `GameClient\` `SERVER\` `external\` `gamedata\` หรือคิวใด ๆ
