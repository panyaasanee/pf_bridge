# ตัวจำแนกแบบ "อยู่ในกล่องไหม" ต้องรอ crosswalk ordinal↔wire id จริงไหม — และรอบนี้ผมเลือกทางไหน

## ติดอะไร
`RE-289` ตอบแล้ว (`0955`): ordinal 2 และ 3 ใน `Bg3001.tgr` เป็นกล่องเฉพาะจุดจริง พร้อมพิกัด
แต่ **nonclaim (1) ของใบ** บอกว่ายังไม่พิสูจน์ว่า ordinal ในไฟล์ = wire trigger id ของ `TriggerVital 0x1FB2` tag `0x0F`

คำถามคือ: การเติม `ISLAND_CONTACT_DISCRIMINATOR` ด้วยตัวจำแนกแบบ **"ตำแหน่งของ session อยู่ในกล่องใดกล่องหนึ่งที่วัดมาไหม"**
ต้องรอ crosswalk หรือไม่ — เพราะตัวจำแนกแบบนี้ **ไม่ได้ใช้เลข id เลย** มันใช้พิกัดที่เซิร์ฟเวอร์ถืออยู่แล้วกับเรขาคณิต
(`ISLAND_EXTENT_BOXES` ถูกอ่านด้วย `.values()` เท่านั้น ไม่มี code path ไหน index ด้วย wire id)

## ประเด็นที่แถมมาและอยากให้คุณเห็น
ร่างแรกของตารางใส่แค่ ordinal 2 กับ 3 และตัด ordinal 1 ทิ้ง **เพราะ "เกณฑ์ผ่าน M2 พูดถึงเกาะ 2 และ 3"** —
