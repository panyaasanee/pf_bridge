# CORE-REQUEST v2 — บรรทัดเดิม แต่ **จุดวางผิด ลำดับไม่ได้บอก และคำโฆษณาเกินจริง**

## สามข้อที่ใบ `0958` ผิด และผมแก้เอง ไม่ได้รอให้คุณไปเจอตอนลงบรรทัด

### 1. จุดที่ผมบอกให้วาง **ไม่ใช่ขอบฉากที่ผู้เล่นเดินข้าม** (D3 · วัดแล้ว)
ผมเขียนว่า "ตรงที่ตั้ง `self.mob_combat_scene_folder = folder`" ซึ่งอยู่ใน `_sync_combat_scene_state`
ผู้เรียกของมันมีสามที่: `_dispatch_mob_combat` (ซึ่ง return `[]` ทันทีถ้าแพ็กเก็ตไม่ใช่ ActionVital ที่มีเป้าหมาย
⇒ **ผู้เล่นต้องฟาดอะไรสักอย่างก่อน**) และอีกสองที่หลังแลตช์ `not self.world_census_sent` (ครั้งเดียวต่อเซสชัน)
⇒ ถ้าวางตรงนั้นอย่างเดียว คำสัญญา "เดินออก-เดินกลับ แล้วของยังอยู่" กลายเป็น "เดินกลับ **แล้วต้องตีอะไรสักอย่าง**"

**ที่ขอจริง:** วางตรงที่เซสชันรู้ว่าฉากเปลี่ยนเพราะ **การเดิน/วาป** ไม่ใช่เฉพาะเส้นทางคอมแบต
(จุดที่ `_gm_warp_resync_selected_scene` / scene-sync ตั้งฉากใหม่) · จุดจริงเป็นของคุณตัดสิน ผมระบุแค่เงื่อนไข:
ต้องยิงตอนฉากเปลี่ยนจริง โดยไม่ต้องมีการโจมตี และก่อน publish ใบแรกของฉากใหม่

### 2. ลำดับการส่ง **ต้องบอก และผมไม่ได้บอก** (D4 · นี่คือข้อที่ทำผู้เล่นเจ็บจริง)
`RE-130`: generation ที่ไม่ว่าง **ใบสุดท้าย** ที่ถึงไคลเอนต์คือใบที่อยู่ และมัน **ลบทุกคีย์ที่มันไม่ได้พูดถึง**
⇒ เฟรมของขอบฉากต้องออก **ก่อน** ground generation อื่นใด ๆ ใน dispatch เดียวกัน

ถ้าในการ dispatch เดียวกันมีการฆ่าเกิดขึ้น `sustain_a_kill` ประกอบจาก **ทั้ง ledger ของฉากนั้น**
(ของเก่าที่ขอบฉากเพิ่งประกาศ + ของใหม่ของการฆ่า) ⇒ **ให้ของการฆ่าเป็นใบสุดท้าย ถูกแล้ว**
แต่ถ้าคุณเก็บ `ground` ไว้แล้วต่อท้าย actions ทีหลัง (ซึ่งเป็นที่ที่ง่ายที่สุดเพราะค่าอยู่ในมือตอนจบเมธอด)
⇒ ใบสุดท้ายคือใบของขอบฉาก ซึ่ง **ไม่มีคีย์ของการฆ่าที่เพิ่งเกิด** ⇒ ของที่ผู้เล่นเพิ่งได้มา **ถูกลบจากจอ**
ทั้งที่เซิร์ฟเวอร์ยังถือมันไว้ 120 วิ — ผู้เล่นเห็นของตกแล้วหายต่อหน้า

### 3. คำโฆษณาที่ผมเขียน **ข้ามชั้นหลักฐาน** (D1 · `COO 0944` ข้อ 2 สั่งเรื่องนี้ไว้แล้ว)
ใบ `0958` เขียนว่า "เดินกลับมา **ของเดิมยังอยู่ตรงที่มันตก**" ⇒ นั่นเป็นคำสัญญาชั้น **จอ**
ขณะที่ `NONCLAIM 1` ของโมดูลตัวเองเขียนว่า **ไม่มีวัตถุถูกวาด** — `GT-045` วัดได้แค่ป้ายชื่อลอย + ฝุ่น 0.2-0.3 วิ
และไม่มีอะไรเหลือหลังจากนั้น ⇒ ถ้าคุณยกประโยคของผมไปใส่ PR เจ้าของจะอ่านว่าเห็นของบนพื้นได้จริง

**เขียนใหม่เป็นสองชั้นตามที่ `0944` ข้อ 2 สั่ง:**
- **ชั้นเซิร์ฟเวอร์ (พิสูจน์ได้):** ขอบฉากประกอบและส่งมอบ generation ของฉากที่เข้า ⇒ ไม่ต้องมีอะไรตายอีก
- **ชั้นจอ (ยังไม่มีใครวัด):** ไคลเอนต์ทำอะไรกับ generation ที่ส่งตอนเข้าฉาก **ไม่มีใครเคยดู** และเพดานของ
  คำสัญญาใด ๆ คือ `NONCLAIM 1` · `GT-204` ยัง **ไม่มีขั้น** เดินออก-เดินกลับ (COO `0944` มอบให้คุณเป็นคนเพิ่ม)
