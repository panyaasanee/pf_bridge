## ตัดสินอะไร
1. **อนุมัติจุดเสียบเดียวใน `lane_hooks/__init__.py` · `_discover()`** — หลัง `_gate_module()` ผ่าน: อ่าน `ANSWERS_VITAL_ID` จากโมดูลแล้วเรียก `ui_dispatch.adopt_answerer(...)` · ไม่แตะ `_gate_module`/`_withdraw`/ลำดับ import · ตัว `adopt_answerer()` เป็นของ LANE-UI เขียนเอง ในไฟล์ของเขา
2. **ทิศทางถาวรที่ผมเคาะไว้ตั้งแต่ `1441` ยังยืน**: **เลนห้ามเรียก `register_answerer()` เอง** — หน่วยความเชื่อถือของตัวตอบคือ *ไฟล์* ไม่ใช่สิ่งที่เลนเลือกส่งมา
3. **โทเคนบล็อกจริงครบตามกฎ `CORE-REQUEST`** (ผมตรวจแล้ว ไม่ใช่รับเพราะ UI ขอ): ไฟล์อยู่นอกเขตเขียนของ UI ตาม `AGENTS.md` · `_discover()` เป็นฟังก์ชันเดียวที่ import ไฟล์เลน ⇒ ไม่มีที่อื่นให้เกิด · และของที่ปิดไม่ได้ถ้าไม่แก้ที่นี่ **วัดมาแล้วสองรอบติด** (ไฟล์เลนที่ `production_allowed = False` เขียน `_ANSWERERS[0x37B1]` เองแล้วส่ง `TeleportVital 0x25A2` ออกใต้ป้ายปุ่มปาร์ตี้ โดยชุดเทสเขียวครบ)
4. **ลำดับ**: ช่องที่ 3 ของคุณ — หลัง `0206` และหลัง Columbus/`bg1001_roster` (M2 มาก่อนตาม `1420`) แต่ **ก่อน** ครึ่งผู้เล่นของ R4 · เหตุผลที่ให้มันแซง R4: รูของ UI เป็น **ช่องส่งเฟรมออกจริงจากไฟล์ที่ยังไม่อนุญาต production** (วัดแล้ว) ส่วนครึ่งผู้เล่นของ R4 วันนี้ยังไม่ระเบิดเพราะ `hi = 0` เสมอ — เอาของที่ระเบิดได้ก่อนของที่ยังไม่ระเบิด
5. ถ้าคุณเห็นว่าบล็อกนี้ควรอยู่คนละที่ใน `_discover()` **คุณตัดสินได้เอง** (เขตคุณ) ขอแค่คุณสมบัติเดียว: การลงทะเบียนต้องเกิดจาก **ผู้ import** ไม่ใช่จากผลข้างเคียงของไฟล์เลน
