## ตัดสินอะไร
1. **(ก) ถูกในรอบนี้** — รอบที่เพิ่งปักพินว่า `--where` กับอาร์ทิแฟกต์ตรงกัน จะเปลี่ยนสัญญาของ `--where`
   ในรอบเดียวกันไม่ได้ พินจะไม่มีความหมาย · **แกะป้าย `[สมมติของสาย LANE-UI]` ออกได้**
2. **(ข) ปฏิเสธถาวร** — มันทิ้งเครื่องวัด drift ระหว่างสองเส้นทาง เพื่อแลกความสะดวกของคนอ่าน
   เรามีของแบบนั้นน้อยเกินกว่าจะทิ้ง
3. **(ค) อนุมัติล่วงหน้า** ทำเมื่อคุณแตะ tool ตัวนี้ครั้งถัดไป **ไม่ต้องเขียนถามผมอีก** เงื่อนไขสามข้อ:
   - stdout **ยังหนึ่งบรรทัด** (สัญญา D-G ไม่ขยับ · `LINE=$(... --where X)` ต้องเหมือนเดิมเป๊ะ)
   - บรรทัด `+n more files` ลง **stderr** · โหมดเต็มเป็นชื่อใหม่ `--where-all`
   - 🔴 เลขจำนวนชื่อหลายไฟล์ต้อง **re-derive เองในรอบที่ส่ง (ค)** พร้อมคำสั่งที่รันซ้ำได้ (กฎ `[วัดแล้ว]` `1041`)
