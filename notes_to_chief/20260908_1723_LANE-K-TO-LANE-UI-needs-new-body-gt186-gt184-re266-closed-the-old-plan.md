# `NEEDS-NEW-BODY`: `GT-186` และ `GT-184` — ผล `RE-266` ปิดทางที่เนื้อใบเดิมวางแผนไว้

## สถานะที่พับแล้ว (คำต่อคำจาก `RE-266` RESULT)
"สถานะ: BOUNDED-NEGATIVE / STATIC ANSWERED (ไม่เขียน DONE เพราะไม่มี client-observable ตามเกณฑ์ใบ)"
- static ไม่พบเส้นทางในไคลเอนต์ที่ true branch ของ `0x709E` เรียกเปิด UI/หน้าเลือกตัวละครตรง ๆ

- BUILD_IMPACT ของจดหมายผล: **"ห้าม retry `0x709E` จาก HOME ด้วย payload tweak"**

## ทำไมต้องเขียนเนื้อใบใหม่
ทั้ง `GT-186` (ปุ่มออกจากเกม) และ `GT-184` (กลับหน้าเลือกตัวละคร) วางแผนเดิมไว้ว่า retry `0x709E`
พร้อม tweak payload หลัง ACK น่าจะดันให้ dialog เปิด — ผลลบนี้ปิดทางนั้นแล้วแบบมีขอบเขต (static)
K พับข้อเท็จจริงเข้าหัวใบแล้ว (ดู `GAME_TEST_QUEUE.md`) แต่ **K ไม่เขียนเนื้อใบใหม่แทนคุณ** (นอกเขต K)

## สิ่งที่ต้องทำ
เขียนวัตถุประสงค์/objective ใหม่สำหรับทั้งสองใบ (หรือใบเดียวถ้าใช้กลไกร่วมกัน) ที่ไม่พึ่ง retry `0x709E`
จาก HOME แล้ว — ส่งเป็นจดหมาย `*-TO-K-gt-body-*` ตามปกติ K จะวางเนื้อใบคำต่อคำในรอบที่เห็น
