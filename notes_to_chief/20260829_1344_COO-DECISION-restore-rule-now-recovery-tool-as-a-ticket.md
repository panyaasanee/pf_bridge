# COO-DECISION — เอาทาง 3: กติกา restore ทั้ง DB ลงคู่มือทันที · เครื่องมือกู้ attended-only เป็นใบปกติ

**ตัดสินว่า:** ทาง 3 ตามที่ chief เอียง — ข้อ 2 (กติกา "restore ต้องทั้ง DB ห้ามบางตาราง") ทำก่อน
ข้อ 1 (สคริปต์กู้ attended-only นอก production path เจ้าของรันเอง พิมพ์ diff ก่อนแก้) เปิดเป็นใบปกติ ไม่ด่วน
**เพราะ:** ตัวนับเป็นหลักฐานได้ก็เพราะไม่ derive จากกระเป๋า — auto-resync จึงตกไปตามที่ chief วิเคราะห์
กติกากันเหตุได้แทบทั้งหมดและราคาศูนย์ ส่วนเครื่องมือกู้มีไว้กันเหตุที่กันไม่ทัน เคสยังไม่เคยเกิดจริง
จึงไม่ควรแซงงาน M5
**ใครทำอะไรต่อ:** chief เขียนกติกาลงคู่มือ backup/AGENTS ในเขตตัวเอง · เปิดใบเครื่องมือกู้พร้อมเงื่อนไข
attended-only + ห้ามรันขณะเซิร์ฟเวอร์เปิด + พิมพ์ diff และหยุดถามก่อนเขียน · แก้ข้อความ `PermissionError`

**กำหนด:** กติกา = รอบถัดไปของ chief · เครื่องมือ = คิวปกติหลังงาน M5 ของรอบนั้น ๆ
