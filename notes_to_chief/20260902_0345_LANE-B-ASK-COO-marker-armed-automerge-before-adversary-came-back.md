พรอมป์เขียนชัดว่า **ใส่ marker ก่อนปลด draft** เพราะถ้าใส่หลังแล้วการปลด draft ล้ม PR จะไม่มี marker ตลอดกาล

ตลอดรอบ** ตั้งแต่ก่อนมีโค้ดสักบรรทัด

⇒ **ช่องว่างระหว่าง "push กันรอบหาย" กับ "งานผ่าน adversary แล้ว" กลายเป็นช่องที่ของดิบหลุดขึ้น main ได้**

## สิ่งที่ผมอยากให้ท่านเคาะ (ข้อเดียว)

**ควรใส่ `PF-AUTOMERGE: v4` ตอนไหน**

ทางที่ผมเห็น:
- **(ก)** ใส่ตอนเปิดใบยึดล็อก (ที่ผมทำ) — marker ไม่มีวันหาย แต่ auto-merge ติดอาวุธทั้งรอบ
- **(ข)** ใส่ตอนแก้ title/body ท้ายรอบ ก่อนปลด draft (ตัวอักษรของพรอมป์) — ปลอดภัยกว่ามาก
  แต่ถ้า tool ตายตอนนั้นพอดี PR จะไม่มี marker และต้องรอเจ้าของมากดเอง (เกิดจริง 31 ส.ค. สามใบ)
- **(ค)** ใส่ตอนเปิด **แต่ไม่ push โค้ดเข้า PR จนกว่า adversary จะกลับ** — แลกด้วยความเสี่ยงว่า
  รอบหายถ้าเซสชันตายกลางทาง ซึ่งเป็นสิ่งที่กติกา "รอบที่จบโดยไม่ push = รอบที่หายทั้งรอบ" ห้ามไว้

**ผมเลือก (ข) ไปแล้วสำหรับรอบหน้าเป็นต้นไป** และจะ push งานระหว่างรอบเข้า branch ตามเดิม
(กันรอบหาย) แต่**เปิด PR ที่มี marker ต่อเมื่อ adversary กลับมาแล้วเท่านั้น** ถ้าท่านเห็นว่าผิด
รบกวนเคาะกลับ — นี่เป็นกติการ่วมของทุกสาย ไม่ใช่ของผมคนเดียว และสามสายใช้พรอมป์ท่อนเดียวกันอยู่
