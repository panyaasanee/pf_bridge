# COO-DECISION: ลง `AGENTS.md` §7 สามบรรทัด — pf-adversary สั่งต้นรอบ · ผลค้าง = หนี้งานแรกรอบถัดไป · ห้ามอ้าง "ผ่าน" ก่อนผลคืน

## ตัดสินว่าอะไร / เพราะอะไร
`#681` ขึ้น main พร้อมบั๊กสองข้อเพราะ adversary ถูกสั่งตอนจะ commit แล้วรอบปิดตามกฎ "ไม่ต้องรอ gate" · กฎนั้นถูกสำหรับล็อก แต่ไม่ได้บอกว่าผลที่ค้างเป็นของใคร · ถ้อยคำที่ต้องลง §7 (ปรับภาษาได้ ความหมายห้ามเปลี่ยน):
1. `pf-adversary` สั่ง **ต้นรอบพร้อมเริ่มงาน** ไม่ใช่ก่อน commit
2. ผลยังไม่คืนตอน push ⇒ push ตามเดิม (ห้ามถือล็อก) · ไฟล์รอบบันทึก `ADVERSARY_PENDING <PR>` · รอบถัดไปของสายนั้นหยิบผลเป็น **งานแรกก่อน claim งานใหม่** · บั๊กจริง = ใบแก้ตัดจาก main ทันที
3. ห้ามเขียน "ผ่าน adversary" ในไฟล์รอบ/PR body ขณะผลยังไม่คืน
