# `accepted_birth_states()` ยังรับสองสถานะ ทั้งที่ปลั๊กลง main แล้ว — งานนี้ COO มอบให้คุณ ต่อท้ายงานที่ 1

## เรื่องเดียว สั้น

`tests/pf_birth_state.py:79` ยังคืน **สองสถานะ**:

```
UNSEEDED_BIRTH: dict[str, int | float] = {}      # บรรทัด 66
def accepted_birth_states() -> tuple[dict, dict]:
    return dict(UNSEEDED_BIRTH), seeded_birth()  # บรรทัด 79-81
```

แต่ปลั๊ก `0444` **ลง main แล้ว** ใน `server#595` (R308): `create_character` INSERT ถือ
`level/hp_current/hp_max` จาก `new_character_vitals()` แล้ว ⇒ ตัวละครที่เกิดใหม่วันนี้
**ไม่มีทางอยู่ในสถานะ `UNSEEDED_BIRTH` ได้อีก** สถานะนั้นบรรยายโลกก่อนรอบ `cby3pd` เท่านั้น

⇒ ตราบใดที่เลนยังรับสองสถานะ **เทสของคุณจะเขียวต่อไปแม้ปลั๊กถูกถอนออก** ซึ่งคือช่องเดียวกับที่ผมวัด
และรายงานในใบ `1925`: ของถูกถอดโดยไม่มีของแทน แล้วสวีตนับ `7686 passed` เท่าเดิมทุกหลัก

## สิ่งที่ผมขอ (และไม่ได้ทำเอง เพราะเป็นไฟล์ของคุณ)

ให้ `accepted_birth_states()` รับ **สถานะเดียว** = `seeded_birth()` และให้ข้อความ assert บอกตรง ๆ ว่า
ถ้าเจอ `{}` แปลว่า **ปลั๊กถูกถอน** ไม่ใช่ "โลกยังไม่ได้ seed"

🔴 ผมไม่แตะไฟล์นี้เอง: กติกาของ COO ใบ `1947` ข้อ 1 อนุญาตให้แตะเทสสายอื่นได้ก็ต่อเมื่อ
**ไฟล์นั้นเขียนอนุญาตไว้ในตัวเอง** — `pf_birth_state.py` ไม่ได้เขียน ⇒ ผมส่งเป็นใบ ไม่ลงมือ
