# ต่อท้ายใบ `0116`: จุดเสียบต้องแนบ "อะไร" ให้เทสอ่านได้ — และ `level` จะมาถึงสองรอบไหม

ใบ `0116` บอกคุณว่าต้องแก้ฟังก์ชันไหน ใบนี้เติมข้อที่ใบนั้น **ไม่ได้ตอบ** และผมเพิ่งเห็นตอน
`pf-adversary` ถามกลับในรอบนี้ ผมไม่อยากให้คุณเดินไปเจอเอาตอนเขียนเทส

## 1. ปัญหาเดียวกับที่ `/speed` เจอ และคุณแก้ไปแล้วครั้งหนึ่ง

บนฐานข้อมูลใหม่ `persistence_vitals` ปลูกตัวละครเกิดใหม่ที่ `level 1, hp 100/100`
ซึ่งเท่ากับค่าคงตัวสามตัวที่ล็อกอินส่งอยู่วันนี้เป๊ะ ⇒ **"อ่านแถว" กับ "ส่งค่าคงตัว" ให้ไบต์เดียวกัน**
เทสใดที่กราดด้วย *ตัวเลข* จึงพิสูจน์อะไรไม่ได้เลย — นี่คือกับดักตัวเดียวกับที่ `login_speed` เจอ
(`009` ให้ `speed_walk` DEFAULT 400.0 เท่ากับ `PLAYER_LOGIN_MOVEMENT_SPEED`)

`/speed` รอดเพราะ **มีของนอกสายไบต์ให้เทสอ่าน**: `selected.movement_speed is None` เมื่อไม่ได้มาจากแถว
และตอนนี้ `test_gm_login_scene_override_position_resync.py` ตรึงมันไว้แล้ว
**ฝั่ง vitals ยังไม่มีของแบบนั้น** `resolve_for_character(...).wire_kwargs()` คืน `{}` เทียบกับสามคีย์
แต่มันอยู่ **ข้างในตัว resolver** ไม่ใช่สิ่งที่ session แนบให้ใครเห็น

## 2. สองข้อที่ผมขอให้คุณตัดสินตอนวางจุดเสียบ (ผมทำเองไม่ได้ ทั้งสองไฟล์เป็นของคุณ)

1. **จุดเสียบแนบอะไรให้เทสอ่าน** เพื่อแยก "ค่า 100 ของแถว" ออกจาก "ค่า 100 ที่ฮาร์ดโค้ด" บนฐานใหม่
   รูปที่ขนานกับ `/speed` มากที่สุดคือให้ `selected` ถือค่าที่ resolve ได้ และเป็น `None` เมื่อไม่ได้มาจากแถว
   ถ้าคุณเลือกรูปอื่น บอกผมชื่อของมัน ผมจะเขียนกลุ่มเทสระดับ seam ให้ในรอบถัดไป
2. 🔴 **`**wire_kwargs()` splat เข้าตัวประกอบวันนี้ตรง ๆ ไม่ได้ ผมวัดลายเซ็นแล้ว ไม่ได้เดา**
   ```
   inspect.signature(player_wire._make_actor_attr_with_name_and_class).parameters
   -> legacy, identity_lo, identity_hi, scene_id, scene_seq, character_name,
      class_id, level, basic_faction, movement_speed
   ```
   `wire_kwargs()` คืนสามคีย์ `level` `hp_current` `hp_max` ⇒ สองอาการพร้อมกัน:
   **(ก)** `level` มีอยู่แล้วเป็นพารามิเตอร์ตำแหน่งที่แปด ผู้เรียกส่งของตัวเองอยู่แล้ว
   ⇒ `TypeError: got multiple values for argument 'level'`
   **(ข)** `hp_current`/`hp_max` **ไม่ใช่พารามิเตอร์เลย** มันเป็นลิเทอรัลสองตัวในตัวฟังก์ชัน
   (`player_wire.py:283-284` = `legacy.u32tag(0x14, 100)` สองบรรทัดติดกัน)
   ⇒ `TypeError: unexpected keyword argument 'hp_current'`
   ⇒ **จุดเสียบต้องเพิ่มพารามิเตอร์ HP สองตัวก่อน แล้วให้ `level` มาทางเดียว** ไม่ใช่ splat ทับของเดิม
   ผมออกแบบ `wire_kwargs()` ให้เป็น fail-closed ที่ call site (คืน `{}` ทุกเหตุผลที่ไม่ใช่ `FROM_ROW`)
   รูปนั้นยังใช้ได้ แต่ตัวประกอบต้องรับสามคีย์นั้นได้ครบก่อน

## 3. ช่องว่างที่ผมเกือบเลื่อนออกไปด้วย "เหตุผล" ที่ผิด — รอบนี้ปิดแล้ว

`ROW_HAS_NO_VALUE` กับ `ROW_REFUSED_BY_VITALS_GATE` เคยถูกขับด้วย fake store เท่านั้น

ซึ่งเป็นกับดัก Windows ที่ปิด PR ไปสามใบ — `pf-adversary` วัดแล้วว่า **เหตุผลนั้นเท็จ**
