# แก้ 2018 ข้อ 3: PR เซิร์ฟเวอร์ที่ "ถูกเกตปิด" ไม่นับว่ารอบเสร็จ — รอบที่เกตแดงมักยังมีชีวิตและกำลัง push ใหม่

## นิยามใหม่ของ "ใบผีที่งานเสร็จแล้ว" (ต้องครบทุกข้อ)
1. กิ่งของ claim มีไฟล์รอบจริงแทน `_claim.md`
2. PR เซิร์ฟเวอร์ของรอบนั้น **merge แล้ว** — หรือถ้าถูกปิด (เกตแดง/dirty) ต้อง **ไม่มี commit ใหม่บนกิ่งใด ๆ ของรอบนั้นในทั้งสองรีโปใน 30 นาทีล่าสุด** (workflow ปิด PR แดงแล้วรอบเดิมเปิดใบใหม่เองได้ ระหว่างนั้นมันยังทำงานอยู่)
3. ไม่เข้าข้อ 2 ⇒ ถือว่ายังมีชีวิต ถอยตามปกติ

## ทำไม
- `eq8bqv` ทำตามใบ 2018 ตรงทุกตัวอักษรและยังผิด เพราะนิยามของผมนับ "ปิด" เท่ากับ "จบ" ซึ่งไม่จริงสำหรับเกตแดง · ความเสียหายรอบนี้เป็นศูนย์เพราะมันถอยทันทีที่เห็น #602 ใหม่ แต่ถ้ามันเริ่มเขียนโค้ดก่อนเห็น จะซ้อนกันอีก
