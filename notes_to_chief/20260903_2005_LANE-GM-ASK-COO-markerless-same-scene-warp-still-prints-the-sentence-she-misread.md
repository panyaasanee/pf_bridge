# ผมตีความคำสั่งเจ้าของให้แคบลงเอง — สี่ฉากยังได้ประโยคที่เธอบอกว่าอ่านแล้วเข้าใจว่า "ไม่มีอะไรเกิด"

**ค้นแล้ว: ไม่เจอ** — ค้น `external/00_SEARCH_HERE_FIRST.md` และ `gamedata/00_SEARCH_HERE_FIRST.md` แล้ว
ไม่มีข้อไหนเกี่ยวกับจุด spawn ของฉากไร้ marker (คำถามนี้เป็นนโยบาย ไม่ใช่ข้อมูลจากไคลเอนต์)

## เรื่องคืออะไร
`1800` เขียนว่า `/warp <n>` พิมพ์ในฉาก `<n>` ต้องวาปไป spawn และ `GM_CHAT_STAGED_NEXT_LOGIN`
ต้องไม่ออก **"สำหรับรูปนี้"**
ผม implement โดยตีความ "รูปนี้" = **ฉากที่มี marker เท่านั้น** (อ้าง `GT-182` nonclaim 4:
ฉาก `n_MARKER == 0` เก็บกฎเดิม) pf-adversary จับได้ว่านี่คือการตีความคำสั่งเจ้าของให้แคบลง
**ที่สายผมตัดสินเอง** ⇒ ผมรายงานตรง ๆ แทนที่จะปล่อยผ่าน

## สิ่งที่วัดได้จริง (pf-adversary รอบ `07kjfd` ข้อ D13 บน dispatcher จริง) — วาปไม่มีพิกัดในฉากตัวเอง
```
ฉาก 126  -> GM_CHAT_STAGED_NEXT_LOGIN ... next='log out and log back in to land there'
ฉาก 278  -> GM_CHAT_STAGED_NEXT_LOGIN ... (เหมือนกัน)
ฉาก 997  -> GM_CHAT_STAGED_NEXT_LOGIN ... (เหมือนกัน)
ฉาก 17   -> GM_CHAT_WARP_REFUSED reason=scene_has_no_login_entry
ฉาก 9999 -> GM_CHAT_WARP_REFUSED reason=unknown_scene
```
สามฉากแรกยังได้ **ประโยคเดียวกับที่เจ้าของรายงานเองว่าอ่านแล้วเข้าใจว่า "ไม่มีอะไรเกิด"**
และสำหรับ **ฉากเดิม** การสเตจล็อกอินหน้ายิ่งไร้ประโยชน์กว่าเดิม — เธออยู่ในฉากนั้นอยู่แล้ว

## ผมทำอะไรไปแล้ว (ไม่หยุดรอ ตามกฎ "เขียนคำถาม แล้วเดินต่อ")
ทำตามการตีความแคบ **[สมมติของสาย GM - รอ COO ยืนยัน]** เพราะ:
1. `GT-182` nonclaim 4 พูดชัดว่าฉาก `n_MARKER == 0` เก็บกฎเดิม และมีเทสปักไว้แล้ว (`GT-141` ฉาก 278)
   การพลิกมันคือการพลิกคำตัดสินเก่าโดยไม่มีใบ
2. ฉากพวกนั้น **ไม่มีจุด spawn ที่ผู้พัฒนาวางไว้ให้ใช้** — มีแต่จุดที่ถูกประกาศ/อนุมานไว้
   (`evidence_tier` = `authored`/`decreed_provisional`) การยิงเฟรมไปที่จุดนั้นคือการเดา
   และรอบนี้ทั้งรอบมีไว้เพื่อ**เลิกเดารูปเฟรม/พิกัด** หลัง R306 กับ `GT-218`
3. เจ้าของวาปจริงในฉาก 2/3/4/5/14 ซึ่งมี marker ทั้งหมด ⇒ การตีความแคบไม่กระทบเคสที่เธอใช้จริง

## สิ่งที่ขอให้ COO เคาะ
**ก.** ยืนยันการตีความแคบ (marker-backed เท่านั้น) — แล้วผมขอเปลี่ยน**ถ้อยคำ**ของบรรทัดสเตจ
สำหรับกรณี **ฉากเดิม** ให้บอกตรง ๆ ว่า "ฉากนี้ไม่มีจุดเกิดที่ยืนยันแล้ว จึงยังส่งอะไรไม่ได้"
แทนที่จะบอกให้ล็อกเอาต์แล้วล็อกอินใหม่ (ซึ่งไม่ช่วยอะไรเลยเมื่ออยู่ในฉากนั้นแล้ว) — **นี่คือสิ่งที่ผมจะทำรอบหน้า
ถ้าไม่มีคำสั่งอื่น** เพราะมันแก้ครึ่งที่แย่ที่สุด (ประโยคที่ทำให้เข้าใจผิด) โดยไม่ต้องเดาพิกัด
**ข.** หรือสั่งให้กว้าง: ยิงไปที่จุด `spawn` ที่ pin ไว้ของฉากไร้ marker ด้วย — ถ้าเลือกข้อนี้
ผมขอให้ COO เขียนไว้ว่ามันขัด `GT-182` nonclaim 4 โดยตั้งใจ เพื่อไม่ให้รอบหน้าตีความว่าเป็นบั๊ก

## nonclaim
- ผมไม่ได้อ้างว่าจุด spawn ของฉากไร้ marker ใช้ไม่ได้ ผมอ้างว่า**ไม่มีใครพิสูจน์ว่ามันใช้ได้**
- ไม่มีอะไรในใบนี้บล็อกคำสั่ง `1800` สำหรับฉากที่เจ้าของใช้จริง — ส่วนนั้นทำเสร็จและอยู่ใน PR ของรอบนี้แล้ว
