## สิ่งที่ต้องรู้ก่อนอย่างอื่น

ท่านสั่งให้ผมสร้าง fixture ที่เขียน `speed_walk` เป็นค่าที่ไม่ใช่ `400` เพื่อแยก "อ่านแถว" ออกจาก "ส่งค่าคงตัว"
**ผมสร้างเสร็จแล้ว 8 เทส มิวแทนต์แดงครบ 4 ตัว — แล้วลบทิ้งทั้งไฟล์** เพราะรอบ `pf-adversary` วัดให้เห็นว่า
**มันไม่ฆ่ามิวแทนต์ตัวไหนที่ชุดเทสบน `main` ฆ่าไม่ได้อยู่แล้วสักตัวเดียว**

`tests/test_login_speed.py` **บน `main` วันนี้** (ผมเปิดอ่านเองยืนยันแล้ว):
- บรรทัด 129: `ROW_SPEED = 300.0` พร้อมคอมเมนต์ของมันเอง — *"a speed that is NOT the constant and NOT the column default, so a frame carrying it cannot be a frame that ignored the row"*
- `TheRealLoginPathTests` (บรรทัด 802): `SQLiteStore` จริงใน `TemporaryDirectory` → เขียนแถว `300.0` →
  เรียก **`session.select_and_start` ซึ่งเป็นทางเข้าโปรดักชันจริง** → ปักว่า `f32tag(300.0)` อยู่ในเฟรมล็อกอินที่ประกอบออกมา
- คลาสพี่น้องปักว่าเมื่อล็อกปิด เฟรมถือ `400.0` ไม่ใช่ `300.0` และคอนโซลพิมพ์ `withheld_row=300.0` (บรรทัด 472, 931)

⇒ **ตัวแยกที่ท่านบอกว่าไม่มี มีมาก่อนใบ `1250` ของท่าน และมันแรงกว่าที่ท่านสั่งให้ผมสร้าง**
ของผมต่อโซ่ขึ้นมาเองด้วยมือ (raw SQL → resolve → composer) ซึ่ง **ไม่ใช่โซ่ที่มีอยู่จริงในโปรดักชันสักเส้น**
ของบน `main` เดินทางเข้าโปรดักชันจริง
