## สามอย่างที่วัดได้ (คลาสละข้อ)

1. **`TheDefaultIsTheConstantTests` — ข้อสมมติของท่านใน `NOW.md` วัดแล้ว จริง**
   ตัวละครที่เกิดผ่าน store จริงถือ `speed_walk = 400.0` = `player_wire.PLAYER_LOGIN_MOVEMENT_SPEED` **ตัวเดียวกัน**
   และเฟรมที่ประกอบจากแถวนั้น **เท่ากันทุกไบต์** กับเฟรมที่ประกอบจากค่าคงตัว
   ⇒ ดาต้าเบสสดตอบคำถามนี้ไม่ได้ นี่คือเหตุผลที่ไฟล์นี้ต้องมี (และเป็นเหตุผลที่ `GT-218` ที่ `PF_SPEED_TRIAL=400` ตอบไม่ได้)
2. **`TheRowReachesTheComposerTests` — แถว `250.0` ⇒ ไบต์ `00 00 7a 43` และ *ไม่มี* `00 00 c8 43`**
   และแถวสองค่าที่ต่างกัน **ประกอบเฟรมไม่เหมือนกัน** (ตัวคุมที่ฆ่ามิวแทนต์ "ส่งค่าคงตัว")
3. **`TheDeferralStillHoldsTests` — ครึ่งที่ทำให้รอบนี้ซื่อสัตย์**
   ผ่าน seam ล็อกอินจริง (`login_speed.resolve_for_character`) แถว `250.0` เดียวกันนั้น **ยังไปไม่ถึงสาย**
   `send_deferred()` ถือไว้ · ค่าคงตัวออกไป · แถวโผล่ที่เดียวคือ `withheld_row=250.0` ในบรรทัดคอนโซล
   บรรทัดจริงที่วัดได้:
   `LOGIN_SPEED wire_deferred value=400.0 detail=gm.speed_wire.send_deferred() returned True, so the row does not reach this login either withheld_row=250.0`
   🔴 **`withheld_row=` นี่แหละคือตัวสังเกตตัวเดียวบน `main` ที่แยก "อ่านแถว" ออกจาก "ส่งค่าคงตัว" ได้ขณะล็อกยังปิด**
   บนดาต้าเบสสดมันพิมพ์ `withheld_row=400.0` = พูดไม่ได้ว่าอะไร · บน fixture นี้พิมพ์ `250.0`
