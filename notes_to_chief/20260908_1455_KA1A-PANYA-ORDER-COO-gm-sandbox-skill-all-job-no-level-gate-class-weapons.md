## 2. คำเคาะ — สี่ความสามารถ เจ้าของสั่งครบชุด
### 2.1 `/skill all` (LANE-GM เขียนคำสั่ง · LANE-DB ให้ทางเขียนแถว)
- แจก **สกิลของทุกคลาสทั้งหมด** ลง `character_skills` ของตัวละครที่พิมพ์ (ทุกแถวใน `class_skill_curriculum.tsv` รวมถังหมายเลข 1024 ด้วย — ถ้าถัง 1024 ทำให้ไคลเอนต์ผิดปกติ ให้แยกเป็น `/skill all raw` ภายหลัง อย่าเงียบ)
- ต้อง **idempotent** (พิมพ์ซ้ำไม่พัง ไม่ซ้ำแถว) · แหล่งของแถว = ตารางในรีโป ห้าม hardcode รายการ id ในคำสั่ง
- คอนโซลต้องพิมพ์โทเคนนับได้: `GM_SKILL_ALL cid=<n> granted=<k> already=<m> classes=<...>`
### 2.2 `/job <class_id>` (LANE-GM)
- เปลี่ยนคลาสของตัวละครเป็นค่าใน `CLASS_IDS` เท่านั้น (1/2/4/16/32) · ค่าอื่น = ปฏิเสธพร้อมข้อความบอกค่าที่รับได้ (ห้ามเงียบ ห้ามเดา)
- ต้องเขียนคลาสลงแถวตัวละครจริง (เส้นเดียวกับที่ `/lv` เขียนเลเวล) เพื่อให้รอบ login ถัดไปอ่านค่าใหม่
- คอนโซล: `GM_JOB cid=<n> class_id_from=<a> class_id_to=<b> relog_required=<yes|no>`
- 🔴 **ถ้าไคลเอนต์ต้อง relog ถึงจะเห็นคลาสใหม่ ให้เขียนไว้ในผลตรง ๆ** — ผู้เทสจะได้ relog เอง ไม่ใช่ให้เธอเดาว่าคำสั่งพัง
### 2.3 หน้าต่างสกิลต้องโชว์ "สกิลของคลาสปัจจุบัน" (LANE-CS)
- **นี่คือชิ้นที่ขาดจริง**: ต่อ `skill_list_at_login` เข้า `runtime.py` (งานแรกของ CS ตาม NOW อยู่แล้ว) โดยส่ง **ไบต์ท้าย = 0** ตามผล `GT-276` (R323C) มิฉะนั้นผู้เล่นเดินไม่ได้
- หลัง `/job` + relog หน้าต่าง K ต้องเปลี่ยนตามคลาสใหม่ · ถ้าไคลเอนต์เป็นผู้กรองตามคลาสเอง ให้ส่งทั้งหมดแล้วเขียนไว้ว่าใครกรอง (วัด อย่าเดา)
### 2.4 ใช้สกิลได้โดยไม่ต้องสนเลเวล (LANE-GM + LANE-CS)
- เซิร์ฟเวอร์ **ห้ามปฏิเสธด้วยเงื่อนไข `n_LEVEL_LEARN`** สำหรับบัญชี GM · ถ้าวันนี้ยังไม่มีด่านเลเวลในโค้ดเลย ให้เขียนในผลว่า "ไม่มีด่านให้ปลด" (ผลลบมีค่า) แล้วเปิดใบไว้ว่าตอนทำ production ต้องมีด่านนี้
### 2.5 อาวุธเริ่มต้นของทุกอาชีพลงกระเป๋า (LANE-DB ร่วม LANE-CS)
