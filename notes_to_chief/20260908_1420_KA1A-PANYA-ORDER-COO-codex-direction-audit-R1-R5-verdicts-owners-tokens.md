## 1. คำเคาะรายข้อ (เจ้าของรับทั้งหมด · ขอบเขตเป็นของเจ้าของ ห้ามขยายเอง)

### R1 HP ของมอนที่ยังมีชีวิตยังไม่เป็นสถานะร่วม — **รับ** · เจ้าของ = **LANE-A (world)** ร่วม **LANE-B (combat)** ตามคำเคาะ `1140` (5 ก.ย.) · ไม่ใช่ LANE-DB
- ทำ: ย้าย HP ของมอนมีชีวิตไปอยู่ใน **ทะเบียนต่อฉากเจ้าของเดียว** (`world_scene_registry`) แล้วให้ทุก session อ่าน/เขียนผ่านมัน · ต่อ `seed_the_session_ledger` + `note_balance` เข้าเส้นจริง (วันนี้เป็นโค้ดตายไม่มีผู้เรียก) · การลด HP ของผู้เล่นคนหนึ่งต้องไม่ทับผลของอีกคน
- 🔴 **แก้โทเคนปิดของรายงาน**: ข้อเสนอเดิมให้พิสูจน์ด้วย "ผู้เล่นสองคนตีมอนตัวเดียวกันบนจอ" — **เราทำไม่ได้วันนี้** (มี client เครื่องเดียว ผู้เทสคนเดียว) ⇒ โทเคนที่ใช้จริง:
  (ก) เทส headless: สอง session บนฉากเดียวกันอ่าน balance เดียวกัน · hit ไม่หาย ไม่ถูกนับซ้ำ (ทดสอบ interleave)
  (ข) เทส headless: ปิด-เปิด session ใหม่ขณะ server เดิมยังรัน → HP **ไม่ฟื้น**
  (ค) attended บนจอ: หนึ่ง session ตีมอนให้เลือดลด → relog → เลือดยังลดเท่าเดิม (ka1-A บูตให้เมื่อมี `ATTENDED:`+`HEADLESS_PROOF:`)
  รีบูต server = โลกใหม่ ตามคำเคาะ `1140` เดิม ไม่เปลี่ยน
- ห้ามย้าย HP ลง DB (ขัดคำเคาะ `1140`)
