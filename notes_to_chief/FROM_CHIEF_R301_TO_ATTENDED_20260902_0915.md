   พิมพ์ผิด (`/speed fast`) ยังเงียบอยู่ = คนละชั้น **ไม่นับ FAIL** (ขั้น 10 จะเพิ่มเมื่อ `TYPO REFUSED` ขึ้น main)

3. 🆕 **`GT-207`** (ปุ่ม GM) — **บูตได้แล้ว คำห้าม build ถอนแล้ว** รายละเอียดข้างล่าง

## ใบใหม่รอบนี้: `GT-207 GM-PLUGIN-THREE-CELL-BUTTON-001` — READY บูตได้เลย
คำถามข้อเดียว: **ปุ่ม GM ที่กดแล้วเงียบมาตั้งแต่ 27 ส.ค. เปิดหน้าต่างได้ไหม** เมื่อมี
`GameMaster.dll` ที่เราสร้างเองอยู่ข้าง client

- 🔴 **เลขใบคือ `207`** — ใบสั่ง COO เรียกมันว่า `GT-P3`/`GT-203` และ `NOW.md` ก็ยังเขียน `GT-203`
  แต่ `203` `204` `205` `206` ถูกใช้ไปหมดแล้ว ⇒ ขยับเลขตามกติกา (เหตุผลเต็มอยู่ในหัวใบ)
  **เห็นใครพูดถึง "GT-203 ปุ่ม GM" หรือ "GT-205 ปุ่ม GM" = คือใบนี้ `GT-207`**
  (`GT-205` ตัวจริงเป็นใบ **UI-A ปุ่มกลับหน้าเลือกตัวละคร** ของ LANE-A คนละเรื่องกันสิ้นเชิง)
- `patches/gm_plugin/` **revision 4** อยู่บน main แล้ว (`780d41dd`, 07:58) ⇒ H1/H2 แก้แล้ว
  **คำห้าม build ถอนแล้ว** (`COO-DECISION 20260902_0845`)
- 🔴 **สามช่องเท่านั้น ห้าม build ช่องที่สี่** ไม่ว่าผลจะยั่วให้ลองแค่ไหน
- 🔴 **ต้องเปิด DebugView ค้างไว้ก่อนบูต** — ทั้งใบตัดสินด้วยบรรทัด `[GM_PLUGIN]`
  ไม่เปิดตัวจับ = อ่านผลไม่ได้เลย ทั้งรอบเสียเปล่า
- 🔴 ขั้น 0 (`plugin_image_check`) ต้อง exit 0 ก่อนบูตทุกครั้ง · ไม่ใช่ 0 = **หยุด ห้ามบูต**
- 🔴 `install.bat` ปฏิเสธเพราะเจอ `GameMaster.dll` เดิมอยู่แล้ว = **หยุดทั้งใบ** เก็บ sha256 แล้วบอกเรา
  ไฟล์นั้นคือของที่โปรเจกต์ตามหามาตั้งแต่ 27 ส.ค.

**สามผลลัพธ์ ทุกอันมีค่า อย่าถือว่ารอบเสีย**
- **เปิดหน้าต่างได้** = PASS ปิด P-3 (บันทึกว่าช่องไหน)
- **ครบสามช่อง มีบรรทัด `loaded` ทุกช่อง แต่ไม่เปิดสักช่อง** = bounded negative
  อ่านว่า "ปลั๊กอินโหลดได้ แต่ประตูไม่ได้อยู่ที่ตัวปลั๊กอิน" **ห้ามอ่านว่าปลั๊กอินใช้ไม่ได้**
- **ไม่มีบรรทัด `loaded` เลย** = BLOCKED ผลของ `plugin_image_check` คือคำตอบ

**ของแถมหนึ่งบรรทัดถ้าเปิดคอมอยู่แล้ว** (`RE-164` ค้างมาตั้งแต่ 27 ส.ค. และเป็นตัวบล็อก P-3 ที่แท้จริง):
มี `GameMaster.dll` อยู่ข้าง exe ของ client **ก่อน** ติดตั้งของเราไหม — ตอบ มี/ไม่มี หนึ่งบรรทัดพอ
