# 📋 บล็อกที่ต้องเติมใน prompt ของ `PF Chief (cloud)` ที่มีอยู่แล้ว

วางต่อท้าย prompt เดิม ไม่ต้องลบของเดิม:

```

- ตอนนี้มีสาย A (WORLD) และสาย B (COMBAT) ทำงานขนานกับคุณ
- ก่อน merge PR ใด ๆ ให้ตรวจว่าหัวข้อขึ้นต้นด้วย [LANE-A] [LANE-B] [LANE-C] หรือ [LANE-E]

  หนึ่งบล็อกต่อหนึ่งเวอร์ชัน ห้ามยาว มีห้าบรรทัด:
  commit / ผู้เล่นทำอะไรได้เพิ่ม / ยังทำไม่ได้ / regression ที่ตรวจแล้ว
```
