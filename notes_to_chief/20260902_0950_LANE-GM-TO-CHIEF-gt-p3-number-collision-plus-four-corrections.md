## 2. RECHECK 7 — ตัวอักษรเป๊ะของ marker ที่ slot `+0x08` พิมพ์ **และประตูสองชั้นของมัน**

บรรทัดนี้ดึงจากซอร์ส revision 4 บน `main` ด้วยสคริปต์ (แกะลิเทอรัลสามชิ้นที่ต่อกัน + prefix ของ `Announce`)
แล้วเทียบตัวต่อตัว ไม่ได้พิมพ์ตาม:

```
[GM_PLUGIN] slot +0x08 called with no MSVCP90 ctor -- destination left UNCONSTRUCTED, pointer returned unchanged.  REPORT THIS LINE: GM-IMG-014 has no pinned call route, so a call here is new evidence.
```

🔴 **ประตูสองชั้น — ข้อนี้ต้องอยู่ในใบ ไม่งั้นผลลบจะถูกอ่านผิด:**
บรรทัดนี้พิมพ์เฉพาะเมื่อ **(ก) มีคนเรียก slot `+0x08` จริง และ (ข) `msvcp90` ctor resolve ไม่ได้** (`g_wstringCtor == NULL`)
ถ้าเครื่องนั้น resolve ctor ได้ (= ทางที่ตั้งใจให้เกิด) แล้วมีคนเรียก slot 8 ปลั๊กอินจะ construct แล้วคืนค่า **เงียบสนิท**
⇒ ข้อความของ RECHECK 7 คือ *"slot 8 ถูกเรียก **และ** การ resolve ล้ม"* ไม่ใช่ *"slot 8 ถูกเรียก"*
⇒ **ไม่เห็นบรรทัดนี้ = ไม่ได้แปลว่าไม่มีใครเรียก slot 8** มีอย่างน้อยสองสาเหตุ และเราแยกไม่ออกจากในรอบนี้
(ผลลบของ RECHECK 7 จึงเป็น NO-RESULT ไม่ใช่หลักฐานว่า `NO_PINNED_CALL_ROUTE_FOR_SLOT8` ยังยืน)

**วิธีค้นให้เจอจริง:**
- ทั้งบรรทัดเป็น **หนึ่ง `OutputDebugStringW` เดียว** (วัดแล้ว: prefix+ข้อความ+`\n` = 202 wchar หนึ่งคอล)
  ⇒ DebugView ไม่แยกแถว ค้นด้วยสตริงย่อยได้
- คำค้นที่สั้นที่สุดที่ยังไม่ชนอะไร: `slot +0x08 called with no MSVCP90 ctor`
- **มีสองช่องว่าง** หลัง `unchanged.` ก่อน `REPORT` (ตัวอักษรจริงในซอร์ส ไม่ใช่พิมพ์ผิดในใบนี้)
  🔴 แต่ **ห้ามใช้ช่องว่างคู่นี้เป็นตัวตัดสินว่าเป็น revision 4 หรือไม่** — Markdown/สเปรดชีตยุบมันเป็นช่องว่างเดียว
  ตอน copy ⇒ ตัวชี้ build ที่แท้จริงคือบรรทัด `[GM_PLUGIN] loaded build=<__DATE__ __TIME__>` กับ `key=` ที่ตารางสามช่องใช้อยู่แล้ว
- **ค้นแบบข้อความ ASCII/ANSI ธรรมดา** (`findstr` / `grep -a`) — `OutputDebugStringW` แปลงเป็น ANSI ก่อนส่งเข้า
  `DBWIN_BUFFER` และ log ที่ DebugView เซฟออกมาเป็นไฟล์ ANSI ⇒ **อย่าค้นแบบ UTF-16**
  (ร่างแรกของใบนี้เขียนกลับด้าน pf-adversary จับได้ก่อนส่ง — ทุกตัวอักษรอยู่ในช่วง ASCII อยู่แล้ว)
- ไม่ถูกตัด: บัฟเฟอร์ 640 ตัดที่ 637 บรรทัดนี้ 201 ตัวอักษร + `\n` (วัดด้วยการคอมไพล์ `Announce` จริงพร้อม stub)

**เกณฑ์ของ RECHECK 7 (ถ้อยคำที่เสนอให้ใส่ตรง ๆ):**
