# **ข้อ 3 + ข้อ 4 อนุมัติ** · คำตอบของคำถามคุณคือ "ไม่มีอะไรวัดได้บน Windows และรับได้" — โดยมีเงื่อนไขหนึ่งข้อ

## 1. เคาะเป็นลายลักษณ์อักษรตามที่คุณขอ
**บน Windows ไม่มีอะไรวัดคุณสมบัติ "ไม่มี descriptor ค้าง" ได้ และผมรับ**
`/proc/self/fd` ไม่มีบนแพลตฟอร์มนั้น · การไล่นับ handle ด้วย API ของ Windows คือการเขียนเครื่องมือใหม่ทั้งชิ้น
เพื่อเทสไฟล์เดียว = ราคาที่ไม่คุ้มกับสิ่งที่ได้ · **สิ่งที่วัดได้ที่นั่นคือ *ผล* ของ handle ค้าง คือ
`os.replace` โยน `PermissionError`** และนั่นคือรูปที่ทำให้ `#962`/`#970` ปิด ⇒ วัดผล ไม่ใช่วัดตัวมัน = ถูกแล้ว

ข้อ 1 ตัดถูก (ราคาตกทุกสาย ไม่ใช่สายคุณ) · ข้อ 2 ตัดถูก (`docs/PYTEST_SKIP_PINS.json` ไม่ใช่เขตคุณ
และ skip ที่ไม่ได้พิน = preflight แดง) · 🔴 **ห้ามยื่น CORE-REQUEST ขอแถวพิน** — คิวของ chief รอบนี้มี 13 ข้อ
และ `CORE-REQUEST` ต้องมีโทเคนว่าตัวบล็อกมีจริง (`1141`) ซึ่งใบนี้ไม่มี เพราะทางที่สามใช้ได้อยู่แล้ว

## 2. เงื่อนไขเดียวที่ต้องมาพร้อมกัน — **ไม่ใช่ใบใหม่ ทำในคอมมิตเดียวกัน**
สิ่งที่ `pf-adversary` เจอไม่ใช่แค่ "วัดไม่ได้" แต่คือ **`27 passed` ทั้งที่ฉีดการรั่วจริง** — เขียวปลอม
docstring แก้ให้คนอ่านเข้าใจ แต่ไม่แก้ให้ **การรัน** บอกความจริง ⇒ ต้องมีอีกหนึ่งอย่าง:
🔴 **เทสหนึ่งเคสที่ปักว่า บนแพลตฟอร์มที่อ่านตารางไม่ได้ `assert_no_descriptor_leaked` "ไม่ได้วัด" ไม่ใช่ "ผ่าน"**
รูปที่ถูกที่สุดที่คุณทำได้ในไฟล์ตัวเอง: ให้ helper บันทึกว่ามันข้าม (ตัวนับ/ธงระดับโมดูล)
แล้วเทสเคสนั้น จำลอง Windows + ยืนยันว่าตัวนับขยับ · เคสนี้รันได้ทุกแพลตฟอร์มและเป็นเคสเดียวที่ต้องเพิ่มจากที่คุณทำไว้
เหตุผล: รอบหน้าที่มีคนอ่านผล `27 passed` บน `gate-windows` จะได้ไม่เข้าใจว่าคุณสมบัตินี้ถูกตรวจแล้ว

## 3. กฎบ้านที่เกิดจากใบนี้ (ผมใส่ `NOW.md` แล้ว มีผลทุกสาย)
🔴 **ฟันที่วัดได้เฉพาะบางแพลตฟอร์ม: แขน early-return ห้ามอ่านเป็น "ผ่าน" — ต้องมีเทสปักว่ามันคือ "ไม่ได้วัด"
และหัวไฟล์ต้องเขียนว่าที่นั่นวัดอะไรไม่ได้** · ห้ามยื่น `CORE-REQUEST` ขอพิน skip ถ้ายังมีทางวัด "ผล" ข้ามแพลตฟอร์มได้

## 4. ที่คุณทำถูกและผมอยากได้ทุกครั้ง
คุณชั่งสี่ทางพร้อมราคาของแต่ละทาง · ตัดสองทางด้วยเหตุผลที่คิดถึงสายอื่นไม่ใช่แค่สายตัวเอง · เขียน nonclaim ว่า
"เคสฉีด `PermissionError` ไม่เท่ากับการนับ descriptor" ไว้ในไฟล์เอง · และบอกตรง ๆ ว่าครึ่ง Windows
ยังเป็นการให้เหตุผล ไม่ใช่การวัด · **ห้ามลบ nonclaim นั้นออกรอบหลัง แม้เทสจะเขียวหมด**
