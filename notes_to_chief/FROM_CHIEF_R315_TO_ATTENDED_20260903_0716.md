## 1. 🔴 `GT-193` ถูกพักชั่วคราว (`[🔴 HOLD]`) — อย่าเพิ่งบูตใบนี้

เหตุผลสั้นที่สุด: `/speed` วันนี้ **ไม่ส่งไบต์** ก็จริง **แต่มันยังเขียนลงฐานข้อมูล**
และตั้งแต่ต้นเดือน "ล็อกอินครั้งถัดไป" จะอ่านค่านั้นแล้วส่งให้ไคลเอนต์เอง
⇒ ค่าที่ `/speed 300` ทิ้งไว้ในแถวของตัวละครคุณ **จะไปถึงไคลเอนต์ตอนล็อกอินถัดไป** โดยที่คุณไม่ได้พิมพ์อะไรเลย
และมันคือไบต์ชุดเดียวกับที่ทำให้ไคลเอนต์ล็อกตัวเอง 426 เฟรมในรอบ `GT-193` เดิม
🔴 ที่แย่กว่านั้น: **"ปิดไคลเอนต์แล้วล็อกอินใหม่" คือขั้นกู้ที่เขียนอยู่ในใบเทสของเราเอง** — ทางกู้จึงเป็นทางเดินกลับเข้ากับดัก

รอบนี้ผมปิดรูนั้นแล้ว (โค้ด push แล้ว รอ merge) · **ปลด HOLD ได้เองเมื่อคำสั่งเดียวนี้เจอผลลัพธ์:**

```
cd pirate-force-server && git fetch origin && git show origin/main:src/pirateforce_foundation/login_speed.py | findstr /C:"wire_deferred"
```

**เจอ** = ปลอดภัยแล้ว `GT-193` กลับเป็น `[🟢 READY]` ตามเดิมทุกประการ บูตได้เลย ไม่ต้องรอผมหรือ COO
**ไม่เจอ** = ยังไม่ merge อย่าเพิ่งบูตใบที่มี `/speed` และอย่าเพิ่งรีล็อกอินหลังใช้ `/speed`
