## ข้อที่ผมไม่ทำตามคำต่อคำ — และย้อนอย่างไร
- ใบเขียน: **"importer ต้องเป็น 1 และชื่อคือ `inventory`"** · ผมเขียน: **"importer อย่างมาก 1 และทุกชื่อต้องอยู่ใน `('inventory',)`"**
- เหตุผลเดียว: `inventory.py` **ยังไม่ import** โมดูลนี้ และเป็นไฟล์ของ LANE-DB ที่ใบสั่งผมห้ามแตะ
  รูป `== 1` เป๊ะ ⇒ `pytest tests/test_class_starting_gear.py` **แดงตั้งแต่วินาทีที่ PR ผมลง main**
  จนกว่า PR ของ DB จะลง — และนั่นคือ **เกต preflight ที่ทุกสายต้องผ่านก่อน push** แดงไปด้วย
  · กติการอบเขียนไว้ตรง ๆ ว่า `pf_gate_preflight` ต้องเขียวก่อน push ⇒ ผมจะ push รูปนั้นไม่ได้เลย
  ไม่ใช่แค่ "ไม่ควร"
- ฟันของพินยังอยู่ครบทั้งสองทิศตามที่ใบต้องการ: **ผู้เรียกคนที่สอง = แดง** · **ผู้เรียกคนแรกที่ชื่ออื่น = แดง**
  (มีเทสขับทั้งสองทิศบนทรีจำลองที่มี `inventory` เป็นผู้เรียกจริงอยู่แล้ว ไม่ใช่คำสัญญา)
- วันที่ DB เดินสาย พินอ่านได้ว่า "1 ตัว ชื่อ inventory" **โดยไม่ต้องแก้ไฟล์อีกบรรทัดเดียว**
- ติดป้าย `[สมมติของสาย LANE-CS - รอ COO ยืนยัน]` ไว้ใน docstring ของโมดูล
- **ย้อน** = เปลี่ยนสามบรรทัด `assertLessEqual(len(stems), len(ALLOWED_IMPORTERS))` เป็น
  `assertEqual(len(stems), 1)` ในไฟล์เทสเดียว (คอมมิตเดียว) — แต่ต้องทำ **พร้อมกับ**หรือ**หลัง** PR ของ DB
  ไม่งั้นเกตแดงทั้งบ้าน

## ของแถมที่วัดได้รอบนี้ และสำคัญกว่าเรื่องข้างบน — ปลดพินไม่พอ DB ยังเดินสายไม่ได้อยู่ดี
`class_starting_gear` ทำ `from .inventory import INITIAL_BACKPACK` ที่ **ระดับโมดูล** (จำเป็น — `WEAPON_ROW_INDEX`
ถูกอนุมานตอน import เพื่อให้ตารางที่ drift พังตอน import ไม่ใช่ต่อหน้าผู้เล่น)
⇒ `from . import class_starting_gear` ที่ **หัวไฟล์** `inventory.py` = **circular import** ตายด้วย
`ImportError: cannot import name 'INITIAL_BACKPACK' from partially initialized module` **ก่อนเซิร์ฟเวอร์มีซ็อกเก็ต**
- วัดจริงรอบนี้ ไม่ได้เดา · รูปที่ **ใช้ได้** = import ในตัวฟังก์ชัน (deferred) และพินยังนับมันได้ (เดินบน AST ไม่ใช่อ่านหัวไฟล์)
- ทั้งสองทิศถูกพินไว้ใน `TheShapeLaneDbMustUseToWireItTests` บนทรีจำลอง (ลิงก์ทุกไฟล์ ยกเว้น `inventory.py` ที่เขียนทับ)
  เพื่อให้ LANE-DB เจอเรื่องนี้ **ที่นี่ ไม่ใช่จากบูตที่ตาย** · ผมไม่แตะ `inventory.py` เลย (ไฟล์ของเขา)
- ⇒ ถ้า `STARTING_BACKPACKS` ต้องเป็นค่าคงที่ระดับโมดูลของ `inventory.py` ต่อไป **ทางนี้ไม่มีทางเดิน** ต้องเปลี่ยนเป็นฟังก์ชัน
  หรือย้ายเจ้าของ `INITIAL_BACKPACK` — อันหลังไม่ใช่เขตผม ขอ COO เคาะถ้า DB ขอ
