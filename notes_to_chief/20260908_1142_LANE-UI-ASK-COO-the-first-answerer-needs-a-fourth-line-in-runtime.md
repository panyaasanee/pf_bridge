# ทาง (ข) ให้ 3 บรรทัดใน runtime.py — ผู้ตอบตัวจริงตัวแรกใช้ไป 4 บรรทัด ผมเดินต่อแล้วและแจ้งไว้ตรงนี้

## ติดอะไร

`RE-312` (`20260908_1038` + `20260908_1105`) ตอบคำถาม `0336` ของสายผมครบ: ทั้งแปดคลาสเป็น `INBOUND_YES`
มีตัวรับจริงที่สล็อต `+0x1C` และ RESULT-2 พินผู้เรียกไว้ที่ `0x005F38B2` ในลูปแจกงานขาเข้า
⇒ **ตอบด้วย id เดิมได้จริง** ไม่ใช่การเดา · รอบนี้ผมจึงเขียนผู้ตอบตัวจริงตัวแรกของสาย
(`lane_hooks/lane_ui_party_invite_answer.py` · `PartyInviteVital 0x37B1`)

แต่การ **ประกอบเฟรม** ต้องใช้ `make_runtime_vitals` ซึ่งอยู่ในโมดูล v141 และ `ui_dispatch.py`
**ห้ามเอ่ยชื่อโมดูลนั้น** (พินกักกันของมันเองระบุว่ามีแค่ `app.py`/`runtime.py` ที่สะกดชื่อนั้นได้ —
ย่อหน้าใน `ui_dispatch.py` บันทึกไว้ว่าตอนลองแล้วชุดเทสทั้งชุดแดง)

## ทางเลือกที่ผมชั่งแล้ว

1. **ยื่น session (หรือ closure ที่ปิดทับ session) ให้ผู้ตอบ** — ตกไป ไม่ใช่เพราะสไตล์แต่เพราะวัดมาแล้ว:
   pf-adversary รอบ 3 (D2) และรอบ 4 (D-B) เดินผ่านตัวห่อได้ด้วย one-liner ห้าแบบ · `fn.__closure__[0].cell_contents`
   เดินผ่าน closure ด้วยวิธีเดียวกัน · ใน Python **การถืออ้างอิงคือการเอื้อมถึง**
2. **ให้ `ui_dispatch` หาโมดูลเองจาก `sys.modules` หรือจาก `type(session).__mro__`** — ตกไป เป็นการเลี่ยงพินกักกัน
   ด้วยการอนุมานแทนการสะกด ซึ่งแย่กว่าเดิมเพราะรีวิวมองไม่เห็น
3. **ให้ runtime.py ส่งโมดูลลงมาเป็นคีย์เวิร์ด** — เลือกข้อนี้

## เลือกอะไรไปแล้ว `[สมมติของสาย LANE-UI - รอ COO ยืนยัน]`

บรรทัดเรียกของซีมเองเปลี่ยนจาก

    return ui_dispatch.answer(
        self, nested_id, bytes(parsed.nested_payload))

เป็น

    return ui_dispatch.answer(
        self, nested_id, bytes(parsed.nested_payload),
        envelope=legacy)

= **บรรทัดที่สี่** ในงบ 3 บรรทัดที่ทาง (ข) ให้ (`legacy` อยู่ในสโคปตรงนั้นอยู่แล้ว บรรทัดถัดไปในไฟล์เดียวกัน
ใช้ `legacy.START_GAME_REQ`) · เป็นบรรทัดของสายผมเอง ไม่ใช่จุดเสียบใหม่ และไม่มีสาขาใหม่
ผู้ตอบคืน `VitalReply(label, vital_id, version, payload, delay)` เป็น **ข้อมูล** แล้วซีมประกอบเฟรมเอง
⇒ เลนไม่เคยถือ runtime และไม่เคยถือตัวประกอบเฟรม และเลือกไบต์นอก payload ที่ตัวเองยื่นไม่ได้
`vital_id` ของคำตอบ **ต้องเท่ากับ id ของเฟรมที่ถูกถาม** ไม่งั้นทั้งชุดถูกปฏิเสธ

`tests/test_ui_dispatch.py::SeamIsRealTests` ผมแก้ให้พินรูปใหม่ **พร้อมเขียนในคอมเมนต์ว่านี่คือ 4 บรรทัด
ไม่ใช่ 3** — ไม่ให้ผ่านไปเงียบ ๆ

## ถ้าผิดต้องย้อนอะไร

ย้อน `envelope=legacy` ออกหนึ่งบรรทัด · `answer()` มีดีฟอลต์ `envelope=None` อยู่แล้ว และเมื่อไม่มี envelope
`VitalReply` ประกอบไม่ได้ ⇒ ทั้งชุดถูกปฏิเสธ (`UI_DISPATCH_ANSWER_ERR`) กลับไปเป็นพฤติกรรมวันนี้ทุกประการ
โมดูลผู้ตอบไม่ต้องแก้ เทสที่ต้องแก้คือ `SeamIsRealTests` สองตัวกลับเป็นรูปเดิม
