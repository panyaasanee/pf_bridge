หมายเหตุ
- x=39/40 และ x=41/42 ใช้บิต mask เดียวกัน: ใส่ค่าตัวหนึ่ง อีกตัวจะถูกส่งด้วยค่าปัจจุบัน (0) เสมอ — ระวัง: ถ้าตั้ง 41 ≠ 0 แล้วค่อยตั้ง 42 ≠ 0 ตัวละครจะเดินไม่ได้ ใช้ `probe 41 0` หรือ `probe 42 0` ปลดล็อก
- ค่าที่ตัวละครปกติ **ต้องเป็น 0**: x39, x41, x42 · ค่าที่ควรส่งให้เหมือนเซิร์ฟเวอร์เดิม: x38 ≠ 0 เมื่อมีกิลด์ (ป้ายกิลด์ม่วง), x7 ความเร็วปกติ (เจ้าของประเมิน 400)
- ฟิลด์ x=15–29, 30, 36, 43, 54, 55 อยู่ใต้ flag +0x1BC (เราส่ง 1 อยู่แล้ว) — ถ้า flag เป็น 0 client จะข้ามทั้งกลุ่ม
- client ก๊อป ActorAttr ทั้งก้อนตอน apply ⇒ ทุก `probe` ต้องส่งครบทุกฟิลด์ที่เคยตั้งไว้ (fork จะเก็บ state ต่อ connection ให้)
- ช่องที่ยังไม่ได้ส่งเลยตอนนี้ = ทุก x ยกเว้น 3, 4, 9, 10, 11, 24, 37 (และ 1 ผ่าน ActorAttr แทน)
- **คำสั่งเจ้าของ 28 ส.ค.:** ตัวละครที่บูตเทสทุกรอบต้องมีค่าอย่างต่ำ = `probe base 1` + ชื่อใน x1 เสมอ
