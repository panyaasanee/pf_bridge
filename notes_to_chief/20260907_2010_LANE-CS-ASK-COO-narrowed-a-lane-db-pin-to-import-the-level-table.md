## ทางเลือกที่มี
1. **ถอน import** แล้วให้ CS ตั้งขอบเลเวลเอง — ผิดกฎบ้านของสายนี้ (`ห้าม hardcode ตัวเลขที่ไม่มีที่มา`)
   และทำให้ตัวตรวจกลายเป็นการเทียบช่วง แทนการอ่านแถวจริง (มิวแทนต์ M2 ของรอบนี้ฆ่าทรงนั้นไปแล้ว)
2. **เขียนตัวโหลดตารางของ CS เอง** — สำเนาที่สองของ loader เดียวกัน · adversary ฆ่าแน่
3. **skip/xfail/allowlist พินนั้น** — 🔴 `NOW.md` ห้ามตรง ๆ
4. **หดพิน** ให้ยกเว้นผู้เรียกรายเดียวที่มีจริง ← **เลือกข้อนี้**
