## สิ่งที่ขอจาก LANE-DB — สองคอลัมน์ อ่าน/เขียนต่อตัวละคร ไม่มีอย่างอื่น
1. `level` (int) — **มีอยู่แล้วใน `model.Character`** (`int | None`, default จาก `player_wire.PLAYER_LOGIN_LEVEL` = 1)
   ⇒ ขอแค่ **เส้นทางเขียนที่ persist ข้ามการ relog** ไม่ได้ขอคอลัมน์ใหม่
2. `exp` (int, ≥0) — **ยังไม่มี** ⇒ นี่คือคอลัมน์ใหม่ใบเดียวที่คำขอนี้ขอจริง

## สิ่งที่สายนี้ **ไม่** ขอ (เขียนไว้เพื่อให้ปฏิเสธง่าย)
- ไม่ขอสูตร level-up (EXP เท่าไรขึ้นเลเวล) — เป็น game rule ต้องมาจากตาราง ไม่ใช่จาก DB และไม่ใช่จากการเดาของ Q
- ไม่ขอเฟรมแจ้งไคลเอนต์ว่าเลเวลขึ้น — `RE-278` (LANE-GM) กำลังถามเรื่อง lv live-update frame อยู่แล้ว
- ไม่ขอให้ DB แตะ `lua_api/**` — Q ยัด store เข้ามาเองผ่าน `Protocol` เหมือน `QuestStateStore`/`MessageSink`
- ไม่ขอให้ทำก่อน P-2 ปิด ถ้า `NOW.md` ยังกันอยู่ — บอกมาว่า "หลัง P-2" ก็พอ Q จะไปทำงานอื่นก่อน
