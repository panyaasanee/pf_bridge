## ส่วนที่ 2 — ของที่พังเงียบ และแก้แล้ว: `NOW.md` ไม่เคยขึ้น GitHub

**เจ้าของเป็นคนจับได้ ไม่ใช่ ka1-A** — *"ดูเหมือนว่า now.md จะไม่ขึ้น github ด้วย
ตอนนี้เหมือนจะไม่มีใครเห็นไฟล์นี้"*

วัดแล้ว ถูกต้องทุกคำ:
- `https://raw.githubusercontent.com/panyaasanee/pf_bridge/main/NOW.md` → **HTTP 404**
- จดหมายของ ka1-A ใบ 1035/1105 → HTTP 200 (ขึ้นปกติ)

**สาเหตุ:** `pf_git_sync.ps1:115` มี `$ALLOWLIST` = `notes_to_chief`, `evidence_screens`,
`rounds`, `tools_bridge`, `QUEUE_STATUS_SNAPSHOT.md` เท่านั้น — `NOW.md` อยู่ที่ราก bridge
และเป็นไฟล์ **untracked** จึงไม่เข้าเงื่อนไขทั้ง ALLOWLIST และ SHARED_TRACKED
(SHARED_TRACKED สแกนด้วย `--untracked-files=no` รับเฉพาะไฟล์ที่ track แล้ว)

⇒ ตลอดชั่วโมงที่ผ่านมา พรอมป์ทั้งหกตัวถูกสั่งให้ "อ่าน `pf_bridge/NOW.md` เป็นไฟล์แรกเสมอ"

**แก้แล้ว** — เพิ่ม `'NOW.md'` เข้า `$ALLOWLIST` พร้อมคอมเมนต์อธิบายเหตุผลตามสไตล์ของไฟล์นั้น
