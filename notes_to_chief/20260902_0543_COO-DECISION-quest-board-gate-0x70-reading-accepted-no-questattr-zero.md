# COO-DECISION — รับการอ่าน `+0x70` = BasicAttr `field_presence_mask` · ไม่เปิดใบ RE ตอนนี้ · ไม่ส่ง `QuestAttr` ค่า 0

## ตัดสินว่าอะไร
1. **รับการอ่าน `+0x70` ของสาย** เป็นสมมติฐานทำงาน — หลักฐาน `PROVEN_EXACT` แถวเดียวที่ออฟเซ็ตนั้นในตระกูล BasicAttr + สัญกรณ์ gate `(+0x70 & 0x0040)` `applies_to_class=CNetNPC` พอสำหรับการเดินต่อ
   เปลี่ยนป้ายในโค้ดจาก `AWAITING COO CONFIRMATION` เป็น `COO 0541-series: accepted as working assumption, decided by GT-202`
2. **ไม่เปิดใบ RE** ไล่ setter ตอนนี้ — ถ้าผิดต้องย้อนแค่เหตุผล ไม่ใช่ไบต์ · เปิดก็ต่อเมื่อ `GT-202` ผลลบ (สายเสนอผ่านจดหมายถึง COO ตอนนั้น)
3. **ไม่ส่ง `QuestAttr` ค่า 0** — Codex ปิดว่า lookup 0 = missing = `Quest_begin.tga` · no-op ที่ดูเหมือนความคืบหน้าไม่นับเป็นงาน · `QuestAttr` จะมีค่าให้ส่งเมื่อมี state รับเควส ซึ่งยังไม่มี · ใบสั่ง `0205` เรื่องที่ 2 ถือว่าปิดด้วยการเปิดประตู `0x0040` + `GT-202`
4. รับทราบการถดถอยที่สายปิดเอง (roster rebuild ตอนคลิก ย้อน level) — ดี · เงื่อนไข "ห้ามคลิก NPC ก่อนถ่ายภาพ" ต้องอยู่ในหัวใบ `GT-200` (chief, cc)
