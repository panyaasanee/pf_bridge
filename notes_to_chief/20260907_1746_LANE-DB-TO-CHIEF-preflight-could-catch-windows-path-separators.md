# หนึ่งรอบที่เสียไปกับตัวคั่นพาธของ Windows — และสำมะโนที่บอกว่ามีอีก 8 จุดรออยู่

จาก LANE-DB รอบ `fi5p5c` · ไม่ใช่ CORE-REQUEST · ไม่ขอจุดเสียบ · ตัดสินใจเองได้ทั้งใบ

## เรื่องที่เพิ่งเกิด (วัด ไม่ใช่ความเห็น)
`pirate-force-server#1048` ถูกปิดเพราะเกต Windows แดงที่ `pytest_subset` (`exit=1`) ทั้งที่ทรีเดียวกันวัดได้ `13517 passed, 0 failed` บนโคลนคลาวด์ และ `pf_gate_preflight.py` ขึ้น **PASS**

เหตุคือรูปเดียวที่เขียนไว้สองที่ใน `tests/test_persistence_hp_pair_selector.py`:
```
importers.append(str(path.relative_to(ROOT)))
found.append(str(path.relative_to(ROOT)))
```
ผลถูกเทียบกับค่าคงที่ที่เขียนด้วย `/` · บน Windows `str(PurePath)` ใช้ `\` ⇒ เทียบไม่ตรง ⇒ แดง
ก่อนรอบ `5vzis0` พินทั้งสองอ่านค่า `[]` **จึงไม่เคยมีตัวคั่นเข้าไปถึงการเปรียบเทียบเลย** — รอบนั้นคือรอบแรกที่รูปนี้มองเห็นได้ และมองเห็นได้เฉพาะบน Windows

## สำมะโนทั้งรีโป (AST ไม่ใช่เกรป) — `str(<x>.relative_to(<y>))` ใน `tests/ src/ tools/ migrations/`
- พบ **16 จุด** · **8 จุดตามด้วย `.replace("\\", "/")`** (สายอื่นรู้เรื่องนี้อยู่แล้ว และนั่นคือธรรมเนียมบ้านที่รอบ `5vzis0` ลืม) · **8 จุดที่ไม่ได้ทำให้เป็นรูปเดียวกัน**:
  `test_gate2_bag_admission_wiring.py:622,626` · `test_gm_source_is_cp874_safe.py:141` · `test_lane_b_mob_ai_tick.py:267` · `test_names_fold003_thunk_census.py:258` · `test_navigationex_survey_record.py:322` · `test_persistence_vitals.py:922` · `test_world_m2_provisioning_trial.py:332`
- **ทั้ง 8 จุดวันนี้ไม่แดง** และผมอ่านทีละจุดก่อนพูด: เทียบกับ `[]` (4 จุด) · เทียบกับชื่อไฟล์ segment เดียว `["session.py"]` / `["runtime.py"]` (3 จุด) · ใช้แค่แสดงผล (1 จุด) ⇒ ไม่มีตัวคั่นเข้าถึงการเปรียบเทียบ **เหมือนพินของผมก่อนรอบ `5vzis0` เป๊ะ**
- 🔴 สองในสามจุดที่เทียบกับชื่อ segment เดียว (`test_gate2_bag_admission_wiring.py:622,626`) `rglob` แพ็กเกจที่มี `gm/` และ `lane_hooks/` อยู่ข้างใน ⇒ ห่างจากแดงแค่ "มีไฟล์ในโฟลเดอร์ย่อยเอ่ยชื่อ `bag_admission` หนึ่งไฟล์"
- ⇒ ข้อสรุปที่ควรกลัว: จุดพวกนี้ไม่ใช่ "ปลอดภัย" แต่คือ "ยังไม่ถึงตา" — จะแดงวันที่ลิสต์ที่คาดหวังของมันมีพาธหลาย segment เป็นครั้งแรก และแดงบนเกตเท่านั้น เสียหนึ่งรอบต่อหนึ่งจุด

## ที่รอบนี้ทำเอง (ในเขตตัวเอง)
แก้เป็น `as_posix()` ในเฮลเปอร์ตัวเดียว (`_repo_relative`) และเพิ่มคลาสพิน `ThePinsSpellPathsTheSameWayOnEveryPlatformTests` ที่จับข้อบกพร่องนี้ **โดยไม่ต้องมี Windows**: `PureWindowsPath` สร้างการสะกดแบบเดียวกับที่เกตเจอ บนเครื่องนี้ ในเสี้ยววินาที + พิน AST ที่ห้ามรูป `str(x.relative_to(y))` กลับเข้าไฟล์นั้นอีก
🔴 **ไม่แตะไฟล์ของสายอื่นทั้ง 8 จุด** — ไม่ใช่เขตผม และวันนี้มันไม่แดง
