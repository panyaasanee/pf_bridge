# COO-DECISION — จุดมาถึง 304/305: อ่านตารางที่ให้ `7→304` / `69→305` ก่อน ถ้ามันชี้ marker ใช้ค่านั้น · ไม่ชี้ = (A) เกณฑ์ทิศเข้า ป้าย `decreed_provisional`

**ตัดสินว่า**
1. `1348` ข้อ 6 "แถวแรก" **ถอน** — เขียนตอนคิดว่ามี 3 แถว · ชุด 7/11 ที่มีแถวซ้ำ (70=347) และแถวเสื่อม (348 = 0,0,100) ทำให้ "แถวแรก" เป็นการเดา ตามที่คุณวัด
2. **ขั้นแรกก่อนปัก**: แถวที่บอกว่า id 7 ไป 304 และ id 69 ไป 305 (ตารางทริกเกอร์/ขอบฉากที่คุณใช้อนุมาน) มีคอลัมน์ marker ปลายทางหรือพิกัดปลายทางไหม · **มี = ใช้ค่านั้น** ป้าย `table_authored` ไม่ต้องเดา · ตอบในไฟล์รอบว่าดูตารางไหน คอลัมน์อะไร
3. **ไม่มี = (A) เกณฑ์ทิศเข้า** ตามที่คุณเลือก (304 → `n_ID 343` · 305 → `n_ID 345`) · ป้าย `decreed_provisional` (ไม่ใช่ `decreed_permanent` — เจ้าของยังไม่เคาะฉากนี้) · ตัด 348 ออกจากผู้สมัครทุกกรณี · บันทึก 70=347 ไว้ในแถว
4. (C) รอ RE **ไม่รับ** — งานสำรองต้องเริ่มได้ทันที (`PANYA 0904_14:4x`) · ตัวเลขผิดแก้ได้ในหนึ่งแถว JSON ไม่มีโค้ดตาม
5. ใบ `GT-267` ต้องมีขั้น "เรือโผล่ที่ไหน หันไปทางไหน" + ช่องให้ผู้เทสบันทึกพิกัดที่โผล่จริง · ผลลบ = A แก้ตัวเลขในรอบถัดไป ไม่ต้องใบใหม่
6. ลำดับที่คุณวางเอง (crosswalk + `COPY_SHA256` → แถว 304/305 → responder `0x1FB2` scope สามชั้น → `GT-267`) **รับ** · ห้ามทำครึ่งทาง = ถูก
