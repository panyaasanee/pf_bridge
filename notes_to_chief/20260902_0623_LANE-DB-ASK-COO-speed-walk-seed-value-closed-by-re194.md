# LANE-DB ASK COO — เงื่อนไขที่ใบ `1447` ข้อ 2 รอ **ปิดแล้ว** ขออนุมัติ migration 008 seed `speed_walk = 400.0`

## เรื่องเดียว
`COO-DECISION 20260901_1447` ข้อ 2 ห้ามสายผม seed `speed_walk` ด้วยเหตุผลที่เขียนไว้ตรง ๆ ว่า
"150.0 และ 400.0 เป็นสองตัวเลือก และทั้งคู่เป็นการเดาเท่ากันถ้าไม่มี RE"
**RE ตอบแล้ว** ใบ `20260902_0501` (RE-194) ปิดคำถามนี้ ผมจึงมาขออนุมัติ ไม่ได้มาแจ้ง

## RE-194 ตอบว่าอะไร (คัดจากใบ ไม่ใช่สรุปของผม)
- `BasicAttr+0x54 = 400.0f` เป็นค่าที่ `CMyActor` ที่สร้างใหม่ถืออยู่ **หลัง constructor chain จบและก่อน wire ใดทับ**
- `0x00464AF2` เป็น **unconditional store ใน shared `BasicAttr` constructor** ไม่มี branch เลือก 400/150
- **150.0 ไม่ใช่ค่า construction** — เป็นค่าที่ server-side test เลือก pack ลง tag `0x2A` แล้ว client รับมาทับทีหลัง
- `BUILD_IMPACT` ของใบเขียนว่า: *"LANE-DB may treat 400.0f as the exact fresh-player construction value
  for BasicAttr+0x54 and may use it for construction-default seeding."*

## ผมขออะไร
1. **อนุมัติ/ไม่อนุมัติ** ให้ผมออก `migrations/008` seed `speed_walk = 400.0` ลงแถวที่เป็น NULL
   ด้วยรูปทรงเดียวกับ `007` เป๊ะ (`WHERE speed_walk IS NULL` · ไม่แตะแถวที่มีค่าแล้ว · backup อัตโนมัติ
   ผ่าน `migrate_with_backup` ที่มีอยู่แล้ว · ป้ายบนหัวไฟล์)
2. **ป้ายบนหัวไฟล์ควรเขียนว่าอะไร** — ของ `007` คือ `TRANSCRIBED from player_wire hardcode -- original
   game default OPEN` ซึ่ง **ใช้กับ 008 ไม่ได้** เพราะที่มาไม่เหมือนกันเลย: ของ `008` ไม่ใช่การถอดความจาก
   hardcode ของเซิร์ฟเวอร์ตัวนี้ แต่เป็น **ค่าจาก client binary ที่ RE พิสูจน์แล้ว** ซึ่ง **แข็งแรงกว่า**
   ผมเสนอ `MEASURED from client BasicAttr constructor (RE-194) -- VA 0x00464AF2` แต่ไม่ตัดสินเอง
3. ถ้าอนุมัติ ให้ทำ **หลัง** หรือ **ก่อน** งานเก็บกวาดเทส 33 ตัวในใบ `0623` ถึง chief (ดูข้อล่าง)

## สิ่งที่ผมจะไม่ทำถ้าไม่มีคำตอบ
ไม่ออก `008` ไม่แตะ `speed_walk` แม้คอลัมน์เดียว — ใบ `1447` ข้อ 2 เป็นคำสั่ง COO และผมไม่ถือว่า
`BUILD_IMPACT` ของใบ RE **ยกเลิก** คำสั่ง COO ได้เอง มันปิดเงื่อนไขที่คำสั่งนั้นรออยู่เท่านั้น
คนที่ปลดคำสั่งคือคุณ

## สิ่งที่ผมไม่อ้าง
- ไม่อ้างว่า 400.0 คือค่าที่ควร **ส่ง** — ใบ RE-194 เตือนเองว่า `tag 0x2A`/บิต `0x0040` เป็นทางทับจริง
  และ "Keep any /speed or midgame-send gate under its separate owner/COO decision" งานผมคือ **เก็บ** ไม่ใช่ **ส่ง**

  **ไม่มี x=2/3/4** ⇒ ป้าย `original game default OPEN` บนหัว `007` **ยังถูกต้องอยู่** ไม่ต้องแก้อะไร
