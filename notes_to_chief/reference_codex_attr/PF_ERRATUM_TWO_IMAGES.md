# Erratum: GameClient สองอิมเมจไม่ใช่ไบต์ชุดเดียวกัน

หลักฐานชั้นนี้เป็น `source=IMAGE` และแก้ความเข้าใจเรื่องไฟล์ executable สองไฟล์ให้ชัดเจนดังนี้

| image | size (bytes) | SHA-256 |
|---|---:|---|
| `GameClient.bin` | 14,759,424 | `C528BF43070E2789170F41B6E3E28CCEC6B57BDC594EE73DFA061188A5D1E4BD` |
| `GameClient.local.bin` | 14,759,424 | `9627211412AC60D50AD189CE5A629443CE928EC23A9F8D219DFB2B157028B623` |

## ข้อแก้ไข

- ทั้งสองไฟล์มีขนาดเท่ากัน แต่ SHA-256 ต่างกัน จึงเป็นคนละ `IMAGE` source และห้ามรวมข้ออ้างเข้าด้วยกัน
- ผล A1–A4, ที่อยู่เสมือน, file offset, span hash และข้ออ้าง static ทั้งชุดในงาน v1 นี้ผูกกับ `GameClient.local.bin` เท่านั้น
- `GameClient.bin` ถูกใช้เฉพาะการตรวจเอกลักษณ์ข้างต้น ไม่ได้ถูกใช้เป็นหลักฐานทดแทนหรือเติมช่องว่างให้ A1–A4
- แม้เลข offset จะอยู่ในช่วงเดียวกันเพราะขนาดไฟล์เท่ากัน แต่ไบต์ที่ offset เดียวกันอาจไม่ตรงกัน การเปิด `GameClient.bin` เพื่อตรวจข้ออ้างที่ผูกกับ `.local.bin` จึงให้ผลผิดได้

ผู้ตรวจต้องยืนยันชื่อไฟล์และ SHA-256 `9627211412AC60D50AD189CE5A629443CE928EC23A9F8D219DFB2B157028B623` ก่อนตรวจ offset ทุกครั้ง
