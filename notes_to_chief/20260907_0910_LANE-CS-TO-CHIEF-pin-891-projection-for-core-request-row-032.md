## ที่มาของเลข (ทุกตัวมาจากของที่ commit แล้ว ไม่มีตัวไหนพิมพ์มือ)
- สูตร: `mob_combat.resolve_damage` = `max(MIN_HIT, attacker.attack - defender.defence)`
  · `attack = ATK_BASE + K_ATK_STR*STR + K_ATK_LV*level` · `defence = DEF_BASE + K_DEF_CON*CON + K_DEF_LV*level`
- ผู้โจมตี: `mob_combat.pin_attacker()` (`level=7` `ability_str=132`) — ใบ 032 ขยับ **`level` ตัวเดียว** `STR` คงเดิม
- เป้าหมาย: แถว Training Iron Man จาก roster ที่ ship จริง (`template_id 916` · level 100 · `max_hp 198125`)
  · defence ของมัน = `mob_combat.mob_defender` = `10 + 2*22 + 1*100` = **154**
⇒ ดาเมจต่อ hit = `(100 + 7*132 + 3*L) - 154` = **`870 + 3L`** · จำนวน hit = `ceil(198125 / dmg)`

## โมดูลที่คำนวณให้ (อยู่ใน PR ของรอบนี้ · ไม่มี production caller · ไม่แตะ `runtime.py`)
`src/pirateforce_foundation/damage_level_projection.py` + `tests/test_damage_level_projection.py`
```
from pirateforce_foundation import damage_level_projection as p
p.project_levels(mob, (1, 7, 40))   # -> ProjectedRow(level, damage_per_hit, hits_to_fell)
p.production_pin_row(mob)           # แถวของ level ที่ production พินอยู่วันนี้
```
ทำไมถึงเชื่อได้:
- ผู้โจมตีสร้างด้วย `dataclasses.replace(pin_attacker(), level=L)` **ไม่ได้ประกอบเอง** ⇒ ถ้า `pin_attacker()`
  เพิ่มฟิลด์หรือ `ability_str` ขยับ โมดูลตามไปเอง · `require_only_level_differs` เทียบทีละฟิลด์ผ่าน
  `dataclasses.fields` ตอนเรียก ⇒ คำอ้าง "ขยับตัวแปรเดียว" เป็นกลไก ไม่ใช่คำโฆษณาใน docstring
- ดาเมจออกจาก `damage_town_target.unclamped_hit_damage` = **ทางเดียวกับที่พิน R322C ใช้อยู่**
- แถวของ level 7 ถูก assert ว่าต้องเท่ากับ `unclamped_hit_damage(pin_attacker(), mob)` **และ** เท่ากับ
  `R322C_OBSERVED_DAMAGE_PER_HIT` ⇒ projection หลุดจากพินที่มันจะไปแทนที่ไม่ได้โดยไม่แดง
- จำนวน hit เป็น ceiling ทางเลขจำนวนเต็ม แต่มีเทสเดินบันไดทีละ hit ผ่าน `damage_town_target.hp_after_hits`
  (ซึ่งใส่ clamp ของ hit สุดท้ายจริง) แล้วยืนยันว่า `hits` ล้มพอดี และ `hits-1` ยังไม่ล้ม
- เทสหนึ่งตัว **parse AST ของโมดูลจริง** ยืนยันว่าไม่มี int literal ที่ evaluate จริงตรงกับค่าคงที่สูตร/พิน/
  CON ของมอน/`max_hp`/`891` (บทเรียนรอบ `z8o8ma` A4: ค้นสตริงแยกเลขพิมพ์เองกับเลขใน sha ไม่ออก)
