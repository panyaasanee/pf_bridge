1. **ข่าวดี:** เลน damage ของเรา (CHitResult 0x16F7) **ตรงกับที่ Codex ถอดจากอิมเมจทุกฟิลด์** —
   เขาไม่เคยเห็นโค้ดเรา เราไม่เคยเห็นตารางเขา แล้วออกมาตรงกัน = การยืนยันอิสระชั้น static ที่มีน้ำหนักจริง
   (ยังไม่นับเป็น verified กับอิมเมจจนกว่า GT-054 จะผ่าน)
2. **ข่าวที่ต้องเช็ค:** เจอ 2 จุดที่เรากับตารางเขา**อ่าน string บน wire คนละแบบ** — เคสที่น่าจะจริงที่สุด
   (ตามที่ปฏิปักษ์ชี้) คือ parser `DeleteActorVital` ของเราอ่านความกว้างอักขระผิด (UTF-16 ทั้งที่อาจเป็น
   string8) = บั๊กจริง ⇒ เปิดใบใหม่ **GT-055** (ท้าย `CLIENT_RE_QUEUE.md`) — จ็อบ 0 เปิดเอกสาร extractor
   นาทีเดียว · จ็อบ 1 grep capture — และเจอของแถมเชิงระบบ: ตารางส่งมอบไม่มี string tag สักแถวใน 6,931 แถว
   ทั้งที่ capture ของเราเห็น tag `0x48` จริง ⇒ แถว `UNTAGGED_*` ทั้ง 408 แถวห้ามอ่านเป็น wire ตรง ๆ
   จนกว่าใบนี้จะตอบ
3. **ข้อจำกัดของตารางส่งมอบที่เพิ่งวัดได้:** แถวของตัวพา Attr ทั้ง 5 (ActorAttr/MovementAttr/NPCAttr/
   ItemAttr/AvatarAttr) ในตารางเป็น `EMPTY` — **ชุดส่งมอบช่วยเลน Attr ไม่ได้เลย** อย่าวางแผนพึ่งมันในเลนพวกนั้น
