# ORD-002 เส้นโค้ง EXP + พิกัดหลอด XP บนจอ

- **objective (claim เดียว):** ระบุให้ได้ว่า (ก) client อ่านตัวเลข **EXP ที่ต้องใช้ต่อเลเวล**
  (`n_EXP_CURRENTLV` ในตาราง `STANDARD_STATUS`) มาจากไฟล์/ตารางไหน โครงหน้าตาอย่างไร และ
  (ข) **หลอด XP บนหน้าจออยู่ตรงไหนของ HUD และอ่านค่าจากอะไร** — เพื่อให้ผู้เทสรู้ว่าต้องซูมจุดไหน

- **ทำไมงานนี้สำคัญ:** รอบใหญ่ #6 (GT-017) ผ่านเกือบทุกข้อ — เลเวลบน HUD ขยับ 1→7 จริง
  ข้อความ "ได้รับ EXP 1234 / 986420 แต้ม" ขึ้นในแชตจริง ค่าพลัง 5 ตัวลงหน้า CHARACTER ครบ —
  **แต่ข้อ "หลอด XP ขยับ" ยังปิดไม่ได้** เพราะผู้เทสไม่รู้ว่าหลอดไหนคือหลอด XP
  (แถบใต้หลอดเลือดหน้าตาไม่เปลี่ยนเลย อาจเป็นหลอด SP) ⇒ ตอนนี้สถานะคือ **"ไม่ยืนยัน" ไม่ใช่ "ไม่ขยับ"**

- **inputs (อ่านอย่างเดียว):**
  - `GameClient\GameClient.local.bin` และไฟล์ข้อมูล/โมเดล UI ในโฟลเดอร์ `GameClient\`
  - รายงาน `PF_STATS_PROG001_*` (มีจุดตั้งต้นให้แล้ว — ดู known answers)

- **known answers (ต้อง reproduce ให้ตรง):**
  1. โค้ดที่วาดหลอด exp อยู่ที่ **`0x519299`** อ่าน `ActorAttr+0xA0` หารด้วย
     `STANDARD_STATUS[lv+1].n_EXP_CURRENTLV` แล้วคูณ 100
  2. level อยู่ที่ `BasicAttr u16 +0x5E` mask `0x0002` (getter `GetLv` `0x460050`)
  3. ability 5 ตัวอยู่ที่ `u16 +0x82..+0x8A` mask `0x20..0x200` และ **ยืนยันบนจอแล้วว่าเรียง
     STR→CON→DEX→INT→PER ตรงตามนี้** (รอบใหญ่ #6 เห็นเลข 16/27/38/49/60 ตามลำดับ)
  4. ค่า exp ที่ยิงไปแล้ว client รับจริง: `1234` แล้ว `986420` (เห็นเป็นข้อความในแชต)

- **สิ่งที่ต้องตอบให้ชัดเป็นพิเศษ (ผู้เทสจะใช้ทันทีในรอบใหญ่ถัดไป):**
  - หลอด XP เป็น **widget ตัวไหน อยู่ส่วนไหนของจอ** (บน/ล่าง/ในหน้าต่างไหน) — ถ้าเป็นไปได้
    ให้บอกเป็น **ตำแหน่งสัมพัทธ์กับหลอด HP** ("ใต้หลอด HP" / "แถบล่างเหนือ hotbar" ฯลฯ)
  - มี **ตัวเลข %** กำกับไหม และอยู่ตรงไหนของหลอด
  - ที่ **level 7 กับ exp 986420** หลอดควรแสดงกี่ % (คำนวณจากตารางจริง)
    ⇒ ถ้าคำตอบคือ "เกิน 100% แล้วถูก clamp" หรือ "เล็กกว่า 1% จนมองไม่เห็น" **นั่นคือคำตอบว่าทำไมตาไม่เห็นความต่าง**
    และเป็นผลลบที่มีค่ามาก
  - แถบที่อยู่ใต้หลอด HP ในตอนนี้ **คือหลอดอะไรกันแน่** (ถ้าไม่ใช่ XP)
