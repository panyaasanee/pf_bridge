# ORD-003 อะไรทำให้ `IsDead` เป็นจริงได้บ้าง — ไล่ให้จบสาย

- **objective (claim เดียว):** ระบุ **ทุกเส้นทางที่ทำให้ผู้เล่นของเราเองเปลี่ยนจาก "ร่อแร่ (IsDying)"
  ไปเป็น "ตายจริง (IsDead)"** พร้อมหลักฐานระดับไบต์ และตอบให้ชัดว่า **ฝั่ง client มีโค้ดที่ลดค่า
  `hp_death_timer` เองต่อเฟรมหรือไม่**

- 🔴 **ข้อเท็จจริงใหม่จากการเทสบนจอจริง (รอบใหญ่ #6, 2026-08-19) ที่ต้องใช้เป็นจุดตั้งต้น:**
  server ส่ง `hp_death_timer = 20.0` แล้ว `hp_current = 0` **แล้วไม่ส่งอะไรอีกเลย** →
  ตัวละคร **ค้างสถานะร่อแร่นานเกิน 4 นาที** (12 เท่าของ 20 วินาที) · ปุ่ม `Main_Dead` ค้างอยู่ ·
  **ไม่มีการ escalate เป็น IsDead · ไม่มีหน้าจอคืนชีพ · ไม่มีตัวเลขนับถอยหลังบนตัวละคร**
  ⇒ **หักล้างสมมติฐานเดิมของทีมที่ว่า "client escalate เองเมื่อ timer ถึง 0"**
  ⇒ งานนี้คือการหาคำอธิบายเชิงไบต์ของสิ่งที่เห็นบนจอ

- **known answers (ต้อง reproduce ให้ตรง):**
  1. `IsDying` (`0x454AC0`) = `hp_current == 0 && timer > 0`
  2. `IsDead` (`0x454A70`) = `hp_current == 0 && timer <= 0`
  3. `DURATION_DYING` = **20** (global `0x102249C` · reader เดียว `0x44A572`)
  4. หน้าต่าง `Main_Dead` เปิดตอน dying · **`Common_Death` (หน้าจอคืนชีพ) เป็นคนละหน้าต่าง** เปิดตอน IsDead
  5. `UpdateAttrVital` **ไปไม่ถึงโซ่ตายของ engine** (handler `0x5F2400..0x5F261A` ไม่มี dispatch shape ที่ต้องใช้)
  6. ท่อที่ไปถึงได้คือ `GSCN_RunTimeProtocolRes` id `0x6E9D` → `0x5E4060` → `0x446F30`

- **คำถามย่อยที่ต้องตอบทุกข้อ (ตอบว่า "ไม่มี" ได้ ถ้ากวาดครบแล้วไม่เจอ):**
  1. มีที่ไหนในอิมเมจที่ **เขียนค่าลง float ตัวนี้ (object `+0x58`) นอกจากทางที่ server ส่งมา** ไหม
     — โดยเฉพาะการลดค่าต่อเฟรมใน update loop
  2. ถ้าไม่มี ⇒ **ยืนยันว่า timer เป็นค่าที่ server ต้องเดินเอง** (ตรงกับที่เห็นบนจอ)
  3. ถ้ามี ⇒ เงื่อนไขอะไรที่ทำให้มันไม่ทำงานในเทสของเรา (เช่น ต้องมี flag/สถานะอื่นร่วม)
  4. **`Common_Death` ถูกเปิดจากที่ไหนบ้าง** (ทุก call site) และแต่ละที่มีเงื่อนไขอะไร
  5. เมื่อ `IsDead` เป็นจริงแล้ว client **ส่งอะไรออกสายเองไหม** (เกี่ยวกับ `ReliveVital 0x1AD4`
     ซึ่งรอบก่อนพบว่าเป็น request-only)
  6. **ลำดับที่น้อยที่สุดที่ server ต้องส่ง** เพื่อให้เห็น `Common_Death` บนจอคืออะไร
     (เดาไม่ได้ — ต้องมาจากเงื่อนไขที่อ่านจากโค้ดจริง) ⇒ นี่คือ output ที่มีค่าที่สุดของใบสั่งนี้
