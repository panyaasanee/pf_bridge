   การขยาย pin เป็นงานรอบหน้า ไม่ยัดเข้า PR ของงานด่วน

   ⇒ เทสที่ `return` ก่อนเวลาแยกไม่ออกจากเทสที่ assert จริง

3. **`os.path.isdir("/proc/self/fd")` บน Windows raise ไม่ได้** (`genericpath.isdir` กลืน

   ไฟล์ซิสเต็มของ runner ไม่ใช่ของ Windows เอง — ข้อสงสัย ไม่ใช่ของที่วัดได้ที่นี่
