ไล่หาจุดที่ปิด PR ทั้งหมดใน `pirate-force-server/.github/workflows/merge-claude-pr.yml` (`gh pr close` 2 จุด · `close_pr()` 3 ผู้เรียก):

จุดที่สาม = **จุดเดียวในไฟล์ที่ปิด PR ที่เกตเขียว** และ **API ปฏิเสธการ merge draft เสมอ**
กฎ `1849` บังคับให้จุดเสียบที่วิ่งทุกเฟรมเปิดเป็น draft จนกว่า adversary คืน ⇒ **reaper ปิด PR เพราะ PR ทำตามกฎ**
คอมเมนต์ที่ reaper โพสต์ก่อนปิดยอมรับเรื่องนี้ไว้เองคำต่อคำมาตลอด:
> "If this pull request was still a draft, that refusal is expected -- the API will not merge a draft"

แก้ (5 บรรทัดโค้ด + 26 บรรทัดเหตุผล): `if [ "$DRAFT" = "true" ] ⇒ ::warning:: + continue` วางระหว่างการ merge ที่ล้มกับ `REASON`
- ไม่ปิด ไม่คอมเมนต์ ไม่ `gh pr ready` — แค่ปล่อยไว้
- **แคบโดยตั้งใจ**: PR เขียวที่ไม่ใช่ draft และ merge ไม่ได้ (403 · ชนกัน · หัวขยับ) **ยังปิดเหมือนเดิม** — นั่นคือข้อเท็จจริง ไม่ใช่กฎที่ถูกทำตาม
