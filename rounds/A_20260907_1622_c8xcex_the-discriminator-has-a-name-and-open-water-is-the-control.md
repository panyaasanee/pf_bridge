## งานที่สาม — C1 ของ adversary (CRITICAL): ประตู un-freeze เป็น duck type
เดิม `_is_the_same_freeze` ถามแค่ `getattr(value, "_FrozenTier3Module__FROZEN", None) is not None`
สามบรรทัดของ adversary ปลดล็อกทั้งไฟล์:
```
class Unfrozen(ModuleType): _FrozenTier3Module__FROZEN = frozenset()
module.__class__ = Unfrozen
```
`Unfrozen` ไม่มี `__setattr__` เลย ⇒ หลังบรรทัดนั้นทุกชื่อเขียนได้หมด และฟังก์ชันสาธารณะที่ "ถูกแช่แข็ง" ยื่นเฟรมปลอมให้คนที่ยืนอยู่นอกฉาก

ตอนนี้ถามห้าข้อที่ reload ทำซ้ำได้เป๊ะ แต่คลาสสามบรรทัดทำไม่ได้: เป็นคลาส · เป็นคลาสของโมดูล · ชื่อและโมดูลตรง ·
**นิยาม `__setattr__` และ `__delattr__` ของตัวเองใน `vars()`** (ไม่ใช่ `getattr` — ที่ `Unfrozen` ได้มาคือของที่สืบทอด) ·
และเซตที่พกมา **เท่ากับ** ตัวจริง ไม่ใช่แค่ "มี" · เทสสี่ตัวคุม: `Unfrozen` · คลาสที่ลอกเซตจริงมาแต่ไม่มี `__setattr__` ·
`types.ModuleType` เปล่า · และ **`importlib.reload` ต้องยังผ่าน** (นี่คือเหตุผลที่ไม่ใช้เทสเชิง identity)
`_is_the_same_freeze` ห่อ `try/except` — `value` ที่การอ่านแอตทริบิวต์ระเบิด = "ไม่ใช่ freeze เดียวกัน" ไม่ใช่ข้อยกเว้นหลุดออกจาก `__setattr__`
