## สิ่งที่สร้าง

### 1. ไฟล์ vendor กลายเป็นสำเนาเต็มที่ตรวจได้ (คำสั่ง COO ข้อ 3)

`lua_api/message_catalog.tsv` เดิม = ครึ่ง ASCII สองคอลัมน์ · ตอนนี้ = **สำเนาสี่คอลัมน์
ครบทั้งแถว** ของ `pf_bridge/gamedata/tables/TEXTDATA_TH__MESSAGE.tsv` (907 แถว)
อักขระทุกตัวนอกช่วง ASCII ที่พิมพ์ได้ — **รวมทั้ง backslash เอง** — เขียนเป็น `\uXXXX`
⇒ ไฟล์เป็น **ASCII โดยโครงสร้าง** (วัดแล้ว: non-ASCII 0 ไบต์ · 180 KB) ซึ่งเป็นคลาสของ
ความล้มเหลวที่เผา `#961`/`#967` ไปแล้วสองรอบบนเกต Windows

**วัด ไม่ใช่เถียง** — encode แล้ว decode กลับได้ **ตรงเป๊ะทั้ง 907 แถว** และ catalog
ที่โหลดขึ้นมาเทียบเท่ากับการ parse ตารางต้นทางสด ๆ ครบทั้งสี่คอลัมน์ ·
ตารางต้นทาง **ไม่มี backslash เลยสักแถว** (0/907 grep แล้ว) — แต่นั่นคือข้อเท็จจริงเรื่อง
ตาราง*วันนี้* ไม่ใช่คุณสมบัติของรูปแบบ ⇒ encoder escape backslash ด้วย และมีเทสปักว่า
`เ` ที่นักแปลในอนาคตพิมพ์เข้ามาตรง ๆ จะรอดกลับมาเป็นหกตัวอักษร ไม่กลายเป็นตัวไทย

ข้อบังคับสามข้อที่ COO ผูกมากับสิทธิ์ — **เป็นโค้ดทั้งสามข้อ ไม่ใช่คำสัญญา**:
1. `tools/pf_regen_lua_message_catalog.py` เขียนไฟล์ใหม่จากต้นทาง · `--check` exit
   non-zero พร้อมพิมพ์บรรทัดแรกที่ต่าง · **import encoder จาก `lua_api.message`**
   ไม่ได้ก๊อปโค้ดตัวที่สอง (สอง copy ของ encoder = drift ที่มีตารางเวลา)
2. หัวไฟล์บอก path ต้นทาง · sha256 ของต้นทาง · จำนวนแถว · วันที่ดึง
3. ตัวผูกเป็น **เทส** ไม่ใช่ความเชื่อ: เทียบครบสี่คอลัมน์ **และ** รัน `--check` ของสคริปต์เอง
