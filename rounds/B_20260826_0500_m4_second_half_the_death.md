## ⑤ เพดานล่าง `1 -> 0` — ทำไมถึงเป็นการ "ปิดตะเข็บ" ไม่ใช่การ "ปลดข้อห้าม"

รอบที่แล้วเขียนเองว่าเพดาน `1` คือ **ตะเข็บ** ที่ครึ่งหลังจะมาต่อ · รอบนี้คือรอบนั้น
สิ่งที่ตามมาและถูกแก้ให้ตรงทั้งหมด:

- `MobBalance` ไม่มีชื่อ refusal `below_floor` อีกต่อไป (มันเอื้อมไม่ถึงเมื่อเพดานเป็น 0 —
  **ชื่อ refusal ที่เกิดขึ้นไม่ได้คือการโกหกคนที่นับมัน** กติกาของโมดูลเอง) → เขียนเหตุผลขีดฆ่าไว้แทน
- `bar_frames` ปฏิเสธ HP 0 ด้วยชื่อใหม่ `bar_frame_for_a_dead_body` เพราะ **บอดี้ที่ยังมีชีวิตที่ HP 0
  ไม่ผ่านเกตฝั่งไหนเลย** (ทั้ง `0x43BD70` และ `0x43BDA0` อ่าน `+0x58` ก็ต่อเมื่อ `+0x44 == 0`)
  ⇒ มันจะยืนหลอดว่างอยู่อย่างนั้นตลอดกาล
- `strike()` บนหมัดที่ฆ่า: คืน **announce เฟรมเดียว** · `describe_step` บอกให้ไปเรียก `mob_death.kill`
