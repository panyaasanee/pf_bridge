### 2.1 `SQLiteStore.write_speed_by_identity` — ประตูที่ LANE-GM ขอ ตรงตามใบ `0017` ทุกข้อ

```
write_speed_by_identity(identity_lo: int, identity_hi: int, speed: float) -> dict[int, float] | None
```
เมธอด **ใหม่** ใน `src/pirateforce_foundation/store.py` (charter อนุญาต: เพิ่มเมธอดใหม่ได้
ห้ามเปลี่ยนพฤติกรรมของเมธอดเดิม — `git diff` เป็น **การเพิ่มล้วน** ไม่มีบรรทัดเดิมถูกลบหรือแก้)
พร้อมของระดับโมดูลสามอย่าง: `SPEED_WALK_FIELD_X = 7` · `_SpeedWriteRefused` (ข้อยกเว้นส่วนตัว
ที่ raise **ข้างใน** ทรานแซกชันเพื่อให้ `connect()` rollback ให้) · `_require_identity_part`

ทำสี่ขั้นในทรานแซกชันเดียว: validate ค่า → หา `character_id` จาก identity pair
(`deleted_at IS NULL` = predicate เดียวกับ partial unique index ของ `migrations/004`) →
UPDATE → **อ่านกลับในทรานแซกชันเดียวกัน** แล้วเทียบ ถ้าไม่ตรง = ปฏิเสธทั้งคำสั่ง

### 2.2 ประโยคที่ประตูนี้ขาย และมันถูกวัดทั้งสองทิศ

- **`None` = แถวไม่ถูกแตะเลย** ทุกทางปฏิเสธ raise ข้างในบล็อกของ `connect()` ⇒ rollback ก่อนคืนค่า
  เทสวัด `speed_walk` **และ `updated_at`** ก่อน/หลังทุกกิ่ง
- **ได้ dict = มีการเขียนลงจริง** กับดักคือแถวที่ถือค่านั้นอยู่แล้ว: อ่านกลับตรง แต่ UPDATE ไม่โดนแถวไหน
  ⇒ มีเทสปักไว้ (`ADictMeansAWriteLandedTests`)
- **ไม่โยนอะไรข้ามขอบเขต** จับ `Exception` ไม่จับ `BaseException` (ตามที่ใบ `0017` ขอ)

### 2.3 ข้อที่ผมตัดสินเองและบอกไว้ทุกที่ที่เกี่ยวข้อง
