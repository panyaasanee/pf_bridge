### D3 (เหตุผลที่ marker ถูกถอน) — `git rev-parse --shallow-list` ไม่ใช่ออปชันของ git
`rev-parse` สะท้อนโทเคนที่ไม่รู้จักกลับมาแล้ว exit 0 ⇒ เซตกลายเป็น `{"--shallow-list"}` ⇒ ไม่มี sha ตรงเลย ⇒
**จดหมายทุกใบใน worktree ของโคลน shallow ถูกประกาศว่าปลอม** และนั่นคือต้นไม้ที่โปรโตคอล pf-adversary ของบ้านนี้สร้างเองทุกครั้ง
แก้เป็น: `--is-shallow-repository` ตัดสินก่อนว่ามี graft ไหม → `--git-path shallow` หาไฟล์ (ผ่าน worktree/submodule ที่ `.git` เป็นไฟล์)
→ **หาไม่เจอ = คืนเซตว่าง = แดง** ตาม `COO-DECISION 0945` ข้อ 1 ("ห้าม derive จากหาไม่เจอ") · sentinel `<unknown-graft>` ตายไปพร้อมกัน
เทสใหม่สร้าง `clone --depth 1` จริง แล้ว `git worktree add` จริงบนนั้น และบังคับว่า graft ทุกตัวต้องเป็น sha 40 ตัวอักษร
