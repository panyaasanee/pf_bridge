สิ่งที่มันเจอทำให้ **ต้องเขียนคลาสใหม่ทั้งก้อน จากบูลีนเป็น state machine**:

| # | ข้อบกพร่อง (ของจริง วัดแล้ว) | สิ่งที่แก้ |
|---|---|---|
| **D1** 🔴🔴 | **ตัวถามกับตัวให้คะแนนเป็นชิ้นเดียวกัน** — `git` ล้มด้วยเหตุใดก็ตามถูกแปลว่า "ไม่มี artifact" ⇒ **ลบ `.git` ทั้งโฟลเดอร์แล้วสวีตเขียว census PASS** (ก่อนรอบนี้เทสสี่ใบนั้นแดง) = ผมทำให้ repo **อ่อนลง** โดยไม่รู้ตัว | เปลี่ยนเป็น `state()` สี่สถานะ: **PRESENT / SHALLOW / PARTIAL / BROKEN** · **skip ได้เฉพาะ SHALLOW และ PARTIAL** · BROKEN = **`case.fail()` เสมอ** ⇒ ตอนนี้ลบ `.git` แล้ว **4 failed · census FAIL** |
| **D2** | ข้อความ skip **โทษความลึกของ clone ทั้งที่วัดไม่ได้ว่าเป็นเรื่องนั้น** — บนเครื่องที่ไม่มี `git` เลย มันยังบอกให้ไป `git fetch --unshallow` | ทุกข้อความพก **เหตุผลที่วัดได้จริง** ต่อท้าย (`[measured: ...]`) · "ไม่มี git" = ข้อความคนละแบบ และ **ไม่ใช่ skip** |
| **D3** 🔴 | **partial clone (`--filter=blob:none`) มี commit แต่ไม่มี blob** ⇒ การ์ดที่ถาม `^{commit}` ตอบ PRESENT แล้วปล่อยให้เทสตายอยู่ดี (วัดจริง: `cat-file -e <sha>^{commit}` = 0 แต่ `git show <sha>:<path>` = 128) | registry ระบุ **ตัวออบเจ็กต์ที่ผู้ใช้อ่านจริง** (`5c200e2:migrations/001_initial.sql` และ blob ตัวอย่างของ audit) · และมีสถานะ **PARTIAL** แยกต่างหาก |

## 7. ของที่รอบนี้ **ไม่ได้** ทำ / ไม่ได้พิสูจน์

- **ไม่แตะ `src/` แม้แต่บรรทัดเดียว** ⇒ พฤติกรรมเซิร์ฟเวอร์ไม่เปลี่ยน · coverage ไม่ขยับ · ledger ไม่ถูก cite
- **เขียว(cloud sanity) เท่านั้น** — Linux/Python 3.11 · **ไม่ใช่ gate** · cp874 และ Python 3.14 ตรวจที่นี่ไม่ได้
  (ตรวจด้วย encode: ทั้งเจ็ดไฟล์ ASCII ล้วน)
- **ไม่ได้รันบน partial clone จริงด้วยตัวเอง** — ลูกมือรัน และผมรับผลนั้นมาออกแบบ **แต่ไม่ได้วัดซ้ำเอง**
  ⇒ สถานะ `PARTIAL` เป็นทางที่ **มีเทสของตัวเองในสวีต** แต่ **ยังไม่เคยเจอ clone จริงในมือผม**
- **ไม่ได้อธิบายได้ว่า clone ทดลองอันแรกลึกขึ้นเองได้อย่างไร** (ดูข้อ 3.4) — ลูกมือเสนอว่าลายเซ็นตรงกับ
  `fetch --deepen` ที่ถูกสั่งจากที่อื่น แต่**ไม่มีใครยืนยันได้** ⇒ ทิ้ง clone นั้นและวัดใหม่ทั้งหมด
- **ไม่ได้แก้ prompt ของ routine** (chief แก้เองไม่ได้) ⇒ รอบถัดไปที่รันด้วย v5 จะเสียล็อกต้นรอบซ้ำอีกเป็นรอบที่ห้า
