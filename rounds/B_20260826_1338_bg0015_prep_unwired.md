## 4 `pf-adversary` -- ผ่านสะอาด สองรอบ

**รอบแรก (ตัวสาย B เอง วิจารณ์ตัวเอง เพราะเรียก subagent ไม่ได้ในตอนนั้น):** เจอ 1 บั๊กจริงในเทสการ์ด
"ยังไม่มีอะไร import โมดูลนี้" -- ดราฟต์แรกเช็คแค่ `ImportFrom.module` ไม่เช็ค `ImportFrom.names` ซึ่งเป็น
รูปแบบ import จริงที่โค้ดเบสนี้ใช้ (`from pirateforce_foundation import field_mob_tables, field_mobs`)
พิสูจน์ด้วยการสร้างไฟล์หลอกที่ import แล้วเห็นเทสผ่านทั้งที่ไม่ควร แก้แล้วพิสูจน์ซ้ำว่าจับได้จริง เพิ่ม floor
เช็คจำนวนไฟล์ที่สแกน (`>30` จริง 66 ไฟล์) กันเทสเขียวลมเพราะสแกนได้ 0 ไฟล์

**รอบสอง (เรียก `pf-adversary` subagent จริงจากฝั่งผู้ประสานงานรอบ อิสระจากสาย B):** ไล่ตามหัวข้อเดียวกัน
ซ้ำอีกครั้งอย่างอิสระ (เช็ค relative import `from . import field_mob_tables` ที่ดราฟต์แรกไม่ได้พูดถึงด้วย)
พังไม่ได้ ผ่านสะอาด พบข้อสังเกตไม่บล็อก 2 ข้อ: (1) ดอกสตริงเทสพูดว่า "สามตัวแรก" ทั้งที่ไม่ใช่ลำดับจริง --
แก้เป็น "สามตัวที่สำคัญที่สุด" แล้วในคอมมิตเดียวกัน (2) `BRIDGE_GAMEDATA` precondition เช็คแค่โฟลเดอร์
`tables/` ไม่เช็คโฟลเดอร์ `scene/<ชื่อ>/` เฉพาะแมพ -- เป็นแพทเทิร์นเดิมที่สืบมาจาก
`test_pf_scan_field_scene_candidates.py`/`test_mob_loot.py` อยู่แล้ว ไม่ใช่ของใหม่รอบนี้ ไม่บล็อก
ทิ้งไว้เป็นข้อสังเกตให้รอบถัดไปที่แตะพื้นที่นี้
