สิ่งที่ผมพยายามทำ: `GROUND_AFTER_CALL_SITE_STATUS` (ตัวที่ตัดสินว่า bag delta เก็บพื้นไว้หรือกวาด
และคอนโซลพูด `PUBLISHED` หรือ `COMPOSED_NOT_SENT`) วันนี้เป็นค่าที่คนพิมพ์เอง ผมจะให้มัน
**derive จากซอร์สของ `runtime.py` ตอน import** เพื่อให้บรรทัดเดียวของ chief เป็น "การเปลี่ยนแปลงทั้งหมด"

**pf-adversary ตีตกด้วยการวัด ไม่ใช่ด้วยความเห็น — และผมถอนออกทั้งก้อนก่อน commit:**
- **D1** ข้ออ้างหลักของรอบผิด: เทส `test_today_the_floor_is_cleared_...` ยังพิมพ์ `"composed_not_sent"`
  ด้วยมืออยู่ดี ⇒ วันที่ chief ลงบรรทัดจริง สวีตยังแดง (วัดจริง: 1 failed / 7497 passed)
  ค่าที่ต้องแก้ด้วยมือไม่ได้หายไป มัน **ย้ายจาก `src/` ไป `tests/`** เท่านั้น
- **D2 (ข้อที่ทำให้ผมถอน)** การอ่านซอร์สตอบคำถามผิดชั้น: ทดลองแล้วได้ `"sent"` จาก `runtime.py`
  อย่างน้อยห้ารูปที่ **ไม่ส่งอะไรเลยจริง ๆ** — ประกอบลิสต์แล้วไม่ return · อยู่ใน `if False:` ·
  อยู่ในกิ่งที่เปิดด้วย scenario (ซึ่ง `runtime.py` มีอยู่แล้วสองกิ่งบน id เดียวกันนี้) · `return out[:1]` ·
  เรียงพื้นก่อน delta (ลำดับเดียวที่โน้ตห้าม) ⇒ บนบูตไร้แฟล็ก **เก็บพื้นไว้โดยไม่มีใครถอน = ป้ายผีถาวร**
  และคอนโซลพิมพ์ `PUBLISHED` ให้เฟรมที่ไม่เคยออก = หลักฐานผิดฝั่งในรอบ GT
- **คำถามที่ดีไซน์ตอบไม่ได้ และเป็นเหตุผลที่ถอน:** สถานะนี้ตัดสิน **ข้อเท็จจริงฝั่งไคลเอนต์**

  ⇒ วันนี้ค่าคงที่ที่คนพิมพ์เอง + เทสที่แดงตอนบรรทัดลง คือ **จุดที่คนต้องมามอง** ซึ่งถูกกว่าการเดาจากข้อความ

## 5. เกตคอนโซล: เวอร์ชันแรกถูกตีตกด้วย แล้วแก้ตามในรอบเดียวกัน

- **D3 (วัดจริง)** เวอร์ชันแรกจับเฉพาะชื่อ `print` ⇒ mutant ที่ใช้ `sys.stdout.write` ใน
  `mob_pickup_persist.persist_pickup` **ผ่านทั้งสวีต 7496 ใบ** แล้วทำ item loss ของ lh21ua ซ้ำได้จริง
  ⇒ กฎเปลี่ยนเป็น "การเขียนคอนโซล" (print + `sys.stdout`/`sys.stderr` ทุกการอ้างถึง) ไม่ใช่ชื่อฟังก์ชัน
- **D8 (วัดจริง)** เวอร์ชันแรกถามแค่ว่า "มี print สักตัวอยู่ใน try ไหม" ⇒ print ตัวที่สองก่อน `try` ผ่านเขียว
  ⇒ เปลี่ยนเป็น "**ทุก** การเขียนในสองตัวช่วยต้องอยู่ใน try ที่กลืน" + ห้ามมี nested def ในสองตัวนั้น
  (nested def ทำให้ allow-list ตามการเขียนไปไม่ถึง)
- เขียนไว้ในหัวไฟล์ด้วยว่ากฎนี้ **ทำอะไรไม่ได้**: `p = print`, `getattr(sys, "stdout")`, logging,
  ส่วนขยาย C ที่เขียน fd 1 ⇒ มันคือ tripwire บนรูปที่คนพิมพ์จริง ไม่ใช่การพิสูจน์

**หลักฐานว่าเกตจับได้จริง (รันเอง ไม่ใช่เชื่อ):** mutant สามตัว — `sys.stdout.write` ใน persist,
nested def ที่มี print ใน `say`, print ตัวที่สองก่อน try ใน `_say` — **แดงทั้งสามตัว** แล้วถอน mutant ออกหมด
