สองประโยคแรกจริง **ประโยคที่สามเป็นข้อสรุปของผมเอง ไม่ใช่ผลวัด และมันผิด**

เกตขาด **พยาน** ไม่ใช่เจ้าของ: ออบเจกต์ฟังก์ชันพกที่อยู่ของโมดูลที่นิยามมันไว้ตลอดชีวิตผ่าน
`function.__globals__` — แอตทริบิวต์ **อ่านอย่างเดียว** และ dict ที่คืนมา **คือ** เนมสเปซของโมดูลนั้นเอง
(ไม่ใช่ชื่อที่ก๊อปมา) ⇒ ส่งเข้า `_module_name_of_namespace()` ที่ไฟล์นี้มีอยู่แล้วสำหรับเฟรม ได้คีย์
`sys.modules` ที่กลไก import เป็นคนตั้ง · `fn.__module__ = "<เลนที่ผ่านรีวิว>"` บรรทัดเดียวปลอมพยานตัวนี้ไม่ได้

`_defining_module_names()` แกะห่อธรรมดาก่อน: `functools.partial` (`func`) · `functools.wraps`
(`__wrapped__`) · `__func__` · **อินสแตนซ์ที่เรียกได้** (โค้ดอยู่บน `type(fn).__call__`)
ชื่อที่ได้ **เพิ่ม** เข้าเกต ไม่เคย **แทนที่** ⇒ ทิศทางของการโกหกไม่เปลี่ยนจากเดิม: ชื่อปลอมทำได้อย่างเดียวคือ
ปิดเกตใส่การลงทะเบียนของตัวเอง (บทเรียน D1 ที่รอบก่อนเกือบทำพัง)

## 2b. self-review ของผมเองหลัง push — เจอสองขอบในตัวแก้ของรอบนี้ และ **แก้ในรอบนี้เลย**

อ่าน `git diff --cached` ซ้ำแบบตั้งใจหาเรื่อง เจอสองข้อในตัวแก้ของรอบนี้เอง ทั้งคู่ทำให้เกต "หลวมลง"
ไม่ใช่ "หลุด" (แย่ที่สุด = ชื่อหนึ่งไม่ถูกเพิ่มเข้าเกต = กลับไปเท่าพฤติกรรมก่อนรอบนี้):

1. **คลาสที่ถูกส่งมาเป็น answerer** (`fn = SomeClass`) — คลาสเรียกได้ และการเรียกมันคือการสร้างอินสแตนซ์
   ⇒ โค้ดอยู่ที่ `__init__`/`__call__` **บนคลาส** · `type(SomeClass)` คือ metaclass ซึ่งไม่ชี้ใครเลย

   **แก้แล้ว**: คิวแกะ push `__init__`/`__call__` ของคลาส · เทส `test_a_class_registered_as_the_answerer_names_its_own_module`
   · มิวแทนต์ "ตัดทางคลาส" = **ตาย**
2. **`seen` เก็บ `id(target)` แต่ไม่ถือ reference** — `getattr(type(x), "__call__")` สร้างอ็อบเจกต์ใหม่ทุกครั้ง
   ถ้าตัวนั้นถูก GC หลัง pop แล้ว CPython เอา address เดิมไปใช้ซ้ำ ตัวถัดไปจะถูกข้ามว่า "เคยเห็นแล้ว"
