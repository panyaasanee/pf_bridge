และตอนนี้เป็นคำตัดสินที่ตรึงด้วยเทส ไม่ใช่พฤติกรรมที่บังเอิญเป็นอยู่ — เมื่อวานคำตอบยังเป็น

ชุดเทสแดงก่อนถึงมือผู้เทส แทนที่จะเป็นคอนฟิกที่หายไปเงียบ ๆ กลางรอบเทส

## ข้อจำกัดที่รอบนี้ปิดไม่ได้ เขียนเป็นคำถาม ไม่ใช่เป็นของที่แก้แล้ว

ด่านทุกอันในรอบนี้ถามว่า *"มีการเขียนเกิดขึ้นบนเส้นทางที่เทสขับหรือเปล่า"*
และ F1 F2 F5 คือคำตอบเดียวกันสามครั้ง: **เส้นทางที่สำคัญที่สุดคือเส้นทางที่ยังไม่มีเทสไหนขับได้**
เพราะมันอยู่หลังเกตที่ยังไม่เปิด หลัง default ที่มีแต่โปรดักชัน resolve หรือหลัง handler ที่ยังไม่มีใครเขียน

การเทียบกับ `COMMAND_NAMES` เห็นได้แค่ **ชื่อคำสั่ง** มันมองไม่เห็นเกต ไม่เห็น handler
และไม่เห็นว่าผู้เรียกละอาร์กิวเมนต์ตัวไหนไว้ ⇒ **"ไม่มีเส้นทางที่รัน" หดลงทุกครั้งที่สายนี้เพิ่มเกตหนึ่งอัน**

🔴 **คำถามถึง COO:** กฎอะไรเป็นตัวบังคับว่า กิ่ง GM ที่เพิ่มใหม่ทุกกิ่ง ต้องถูกเดินโดย**เปิดเกตของมัน**
และโดย**ใช้การ resolve path แบบโปรดักชัน** — และใครเป็นคนบังคับกฎนั้น
สายนี้ยังไม่มีกฎนั้น และรอบนี้ไม่ได้แก้มัน
