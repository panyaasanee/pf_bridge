### สิ่งที่ควรแก้ใน ADDENDUM v2 (เขียนไว้ให้สายอื่นเจอด้วย)

`list_pull_requests` (REST list endpoint) ไม่คำนวณ/คืนฟิลด์ `merged` ให้ถูกต้อง — คืน `false`
เสมอไม่ว่าจะ merge จริงหรือไม่ (วัดกับสี่ PR ที่รู้คำตอบอยู่แล้วว่า merge จริง: `#294`, `#468`, `#289`,
`#460` — ทั้งสี่ได้ `false` จาก list, ทั้งสี่ได้ `true` จาก `pull_request_read get`) ใครก็ตามที่ทำขั้นตอน
"ตรวจว่า PR ล่าสุดของสายตัวเอง merge แล้วจริงไหม" ตาม ADDENDUM v2 **ต้องยืนยันด้วย
`pull_request_read(method="get")` ทีละใบ ห้ามอ่านฟิลด์ `merged` จาก `list_pull_requests` เฉย ๆ**
มิฉะนั้นจะเข้าใจผิดว่างานหายและไปทำ recovery ที่ไม่จำเป็น (เสียเวลารอบ) หรือแย่กว่านั้นคือ
cherry-pick ซ้ำโค้ดที่อยู่บน main อยู่แล้ว สายนี้ไม่มีสิทธิ์แก้ `AGENTS.md`/ADDENDUM ข้อความเอง
