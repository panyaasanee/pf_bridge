### 2. โค้ด: `ui_stall_wire.py` — decoder ที่รับขอบเขตจากผู้เรียก (ปิดข้อเสนอผู้รีวิวที่ทำให้ `#1045` ตาย)

🔴 **ร่างแรกของผมอ้างเหตุผลผิด และ adversary จับได้ — รอบนี้แก้แล้ว** (รายละเอียดในหัวข้อ ADVERSARY ข้างล่าง):
ขอบเขตที่ผิด **เงียบทั้งสองทาง** ที่ระดับเรคคอร์ดสมาชิก ไม่ใช่ทางเดียว — เกินมา N เรคคอร์ดครบ 22 ไบต์ ⇒ ได้สมาชิกเกิน N ตัว ·
ขาดไป N เรคคอร์ด ⇒ ได้สมาชิกน้อยไป N ตัว (ทั้งคู่เป็นสมบัติของ *เนื้อหา* ไม่ใช่ *ความยาว*) · ตกปิดเฉพาะขอบที่ไม่ลงบนขอบเรคคอร์ด
⇒ **ตัวใหม่ไม่ได้ทำให้ความยาวที่ผู้เรียกประกาศผิดปลอดภัยขึ้น** และตอนนี้ทั้งโค้ด เทส และหน้าแผนพูดตรงกันแบบนั้น
(`StallOpen` ไม่มีหางสมาชิก ⇒ ของมันตกปิดทุกกรณี) · สิ่งที่ตัวใหม่ซื้อได้จริงคือ **ขอบเขตกลายเป็นสองอาร์กิวเมนต์ที่โมดูลนี้ตรวจช่วงได้**

## nonclaims
- ไม่อ้างว่าหน้าต่างที่ผู้เรียกประกาศ "ถูก" และ **ไม่อ้างว่ามันทำให้ขอบเขตที่ประกาศผิดปลอดภัยขึ้น** — ผิดไปหนึ่งเรคคอร์ดครบ
  ยังได้ของผิดเงียบ ๆ ทั้งทางยาวและทางสั้น (มีเทสวัดไว้สองใบ) · ที่ต่างคือขอบเขตเป็นอาร์กิวเมนต์ที่ตรวจช่วงได้ ไม่ใช่ผลข้างเคียงของ slice ที่ทำไว้ที่อื่น
- ไม่อ้างว่าทำครึ่งหลังของข้อเสนอผู้รีวิวแล้ว — `require_exhausted` ของสองคลาสที่มีหางสมาชิก **ยังตายอยู่** (ลบทิ้งแล้วชุดยังเขียว วัดโดย adversary)
- ไม่อ้างว่ามีผู้เรียกให้ API ใหม่ — ยังไม่มี และรูป dispatch ที่มีอยู่จริงวันนี้คำนวณ `length` ไม่ได้ (`nested_payload` = ที่เหลือทั้งแพ็กเก็ต)
- ไม่อ้างว่า `ui_stall_wire.py` ทำอะไรให้ผู้เล่น — ยังไม่มีผู้เรียกในรันไทม์ และทิศทาง/ความหมายของฟิลด์ยังไม่มีใครวัด
- ไม่อ้างว่าใบ RE ที่ส่งไปจะทำให้ผู้เล่นเห็นอะไร — ต่อให้ได้ layout ครบ โมดูลที่สร้างขึ้นยังต้องรอจุดเสียบ chief เหมือนอีก 18 โมดูล
- ไม่อ้างว่า `0x0069F980` เป็น base-class serializer — ที่วัดได้คือคลาสที่ทำเสร็จแล้วเริ่มฟิลด์แรกที่ `+0x14` เหมือนกัน
  และกลุ่มนี้มีแถวเพิ่มที่ `+0x00` ซึ่งกลุ่มอื่นไม่มี เท่านั้น (และมันแตะ stream primitive ทั้ง `0x0089A600`/`0x0089A640` จึงตัดทิ้งไม่ได้ว่า "ไม่เขียน")
- ไม่อ้างว่าโทเคน `GT-308` พิสูจน์ว่าไคลเอนต์วาดอะไร — พิสูจน์เฉพาะครึ่งเซิร์ฟเวอร์ นั่นคือเหตุผลที่ใบยังต้องขึ้นรถ attended
- ไม่อ้างว่าสำมะโนที่ตอบ `PASS` วันนี้จะไม่ดริฟต์พรุ่งนี้ — สายไหนเพิ่มไฟล์ `.py` ก็ทำให้มันขยับได้ (นั่นคือคำถามที่ผมส่ง COO ไปแล้วรอบ `o50gly`)
