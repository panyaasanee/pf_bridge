### 6 pf-adversary ตรวจก่อน commit — **ไม่ผ่าน** และมันถูกอีกครั้ง (`AGENTS.md` ข้อ 102)

ผมเขียน guard เวอร์ชันแรกเป็น **source pin บน AST** ที่ไล่จับ `self.skipTest` · `unittest.skip*`
แบบ decorator · `raise SkipTest` แล้วตั้งชื่อคลาสว่า "ไฟล์ของสายนี้ skip ไม่ได้เลย"
**adversary ทุบมันแตกหกจากหกวิธี ภายในสิบนาที** — ทุกวิธีให้ผลเดียวกับที่ฆ่า PR #503 เป๊ะ
คือ **pin เขียวบน Linux เกตแดงบน Windows**:

| สะกดแบบอื่นของคำว่า skip | pin เวอร์ชันแรก | `skip_census` จริง |
| --- | --- | --- |
| `@pytest.mark.skipif(True, reason=...)` | เขียว | exit 1 |
| `from unittest import skipUnless` แล้วใช้เป็น decorator | เขียว | exit 1 |

| `CLIENT_IMAGE.require(self)` — **สำนวนของรีโปนี้เอง** | เขียว | exit 1 |

### 7 ของที่ adversary เสนอแล้วผมเลือก **ไม่ทำ** และบอกเหตุผลไว้ตรงนี้

มันชี้ว่า `assertIsNone` ในสาขาที่ไม่มี `/proc` เกือบเป็น tautology (วัดแล้ว: ฆ่าได้ mutant เดียว

ว่ามีการตรวจที่ไม่ได้เกิดขึ้น **ผมยอมรับว่านี่คือสิ่งที่ diff นี้ทำ** และเขียนไว้ทั้งใน docstring ของเทสเอง

ทางแก้ที่มันเสนอคือ: บน `os.name == "nt"` ให้สร้างรอยรั่วแล้วยืนยันว่า `cleanup()` โยน
