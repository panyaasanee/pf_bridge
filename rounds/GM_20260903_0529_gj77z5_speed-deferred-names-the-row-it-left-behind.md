### `gm/chat_command_action.py` — `SPEED DEFERRED` บอกชื่อแถวที่มันทิ้งไว้

สามฟิลด์ต่อท้าย `why=` (โทเคนนำหน้ายังเป็นสองคำเดิมเป๊ะตาม `COO 1847`):

- `next_login=` / `next_login_sends=` — ตอบโดย **`login_speed.resolve` ตัวจริงที่เส้นทางล็อกอินรัน**
  เรียกเป็น pure predicate บน read-back นั้น ด้วยค่าคงตัวของ `player_wire` เป็น fallback
  **ไม่ใช่คำทำนาย ไม่ใช่ความเห็นที่สอง** — docstring ของ `login_speed` ห้ามพิมพ์ช่วงซ้ำไว้เอง
  (*"ช่วงที่พิมพ์สองที่คือช่วงที่ดริฟต์"*) ข้อนี้เชื่อฟังด้วยการ **เรียกมัน** แทนที่จะลอกกฎมา

ตัวอย่างบรรทัดจริงจากเทส:
```

  row_written=1234.5 next_login=from_row next_login_sends=1234.5 character_id=1 identity=1:0
```
