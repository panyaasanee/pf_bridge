## 2. ปิดช่องที่ pf-adversary รอบ `vxr32s` ทิ้งไว้ (งานแรกของรอบตามกติกา)

- **D2 `U+0085` (NEL)** — `_fold_line_breaking_controls` เขียนไว้ว่ากัน "C0 controls + สอง Unicode line
  separators" ซึ่ง**อ่านเหมือนครบ แต่ไม่ครบ**: `str.splitlines()` (ตัวที่เครื่องมือ grep คอนโซลที่เขียนด้วย
  Python ใช้จริง) แตกบรรทัดที่ **สิบ** ตัวอักษร และ NEL คือตัวเดียวที่หลุดทั้งสองกิ่ง (0x85 > 0x7F และไม่ใช่
  U+2028/9) ⇒ **ปลอมบรรทัดที่สองที่ขึ้นต้นด้วยโทเคนจริงได้** เติม `code == 0x85`
  + เทสที่ **ถาม `str.splitlines()` เองว่าแตกที่ตัวไหนบ้าง** แล้วบังคับให้ fold รอดทุกตัว (subtest 10 ใบ)
  ⇒ สมาชิกตัวถัดไปของเซ็ตนี้ลืมไม่ได้อีก
- **D3 ฟิลด์ไม่ถูก quote** — ป้องกันบรรทัดที่สองมาสองรอบแล้ว แต่ไม่มีใครกัน **ฟิลด์ที่สอง**:
  `capture_root` = `C:\clean account=admin attempts=3` พิมพ์ `account=`/`attempts=` **นำหน้า**ตัวจริง
  บนบรรทัดจริง **โดยไม่ใช้อักขระควบคุมเลย** · เทสทุกใบนับ *บรรทัด* ไม่มีใบไหนถามว่า key ซ้ำไหม
  ⇒ `_quote_console_field` แบบ CSV doubling (`"` → `""`) **ไม่ใช่ backslash** เพราะค่าพวกนี้คือ path Windows
  และ `"` เป็นอักขระผิดกฎในชื่อไฟล์ Windows อยู่แล้ว ⇒ เคสปกติได้แค่ `path="C:\clean"` วงเล็บคู่เดียว
  ไม่มีอะไรถูกแปลง (บทเรียน "`C:\Users\...` ที่ไม่มีใคร paste ได้" ยังอยู่ครบ)
  + เทสพร้อม **parser ตามไวยากรณ์ที่เอกสารบอกผู้ดูแล** ⇒ สัญญาเป็นโค้ดที่รันได้ ไม่ใช่ร้อยแก้ว
- **D7 assert ที่เป็น tautology** — `getattr(row, "opcode", None)` ขณะที่ฟิลด์จริงชื่อ `client_frame`
  ⇒ `getattr` ที่มี default แปลง "ไม่มีแอตทริบิวต์" เป็น "ผ่าน" · **ยืนยันที่ HEAD แล้ว** แก้เป็นฟิลด์จริง
  + กันไม่ให้ rename ครั้งหน้าสร้างจุดบอดเดิมเงียบ ๆ
- **บรรทัดใหม่ของรอบนี้ใช้ตัวประกอบชุดเดียวกัน ไม่ได้พิมพ์ใหม่** ⇒ การชุบแข็งของสองรอบก่อน (`nfbat1`, `vxr32s`)

## 🔴 ของแถมที่สำคัญกว่างานรอบนี้: เฟรมจริงสามใบ **ไม่ผ่าน pin RE-088**
positive control ข้างบนทำให้ section decode ในไฟล์ capture เขียนว่า
`# decode: FAILED against RE-088 pin -- presence=0 but 24 trailing byte(s) remain`
decoder อ่าน `0B 00` **คู่แรก** เป็น presence แล้วสรุปว่าไม่มี body ทั้งที่เหลืออีก 24 ไบต์
แต่ไบต์จริงเข้ารูป RE-283 FINAL **เป๊ะ ถ้านับ presence ที่คู่ที่สอง**:
`0B 01`=presence · `14 01000000`=บิตฟังก์ชัน · `14 00000000`=ตัวเลข · `0B 01`=แฟล็ก ·
`48 00000000` ×2 = string ว่างสองตัว (และเฟรมวาร์ป: `14 00100000`=0x1000 · `48 02000000 3000`=UTF-16 "0")
⇒ **มีฟิลด์นำหน้าที่ pin ไม่รู้จัก** · **รอบนี้ไม่แตะ decoder** (layout ของ vital นี้เป็นเขตสาย RE ตาม
prompt ของสายเอง และการเดา field แล้วส่งไบต์ออกคือสิ่งที่สายนี้ห้ามทำ) ⇒ ขอ K ตั้งเลขใบ RE ให้คำถามเดียวนี้
**มีไบต์จริงสามใบให้ใช้แล้ว ไม่ต้องขอเครื่องเจ้าของ**
