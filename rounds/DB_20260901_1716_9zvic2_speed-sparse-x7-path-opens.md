## nonclaims — สิ่งที่รอบนี้ **ไม่** อ้าง

1. **ไม่อ้างว่า `/speed` ใช้งานได้แล้ว** รอบนี้เปิดประตูฝั่ง persistence เท่านั้น chat command
   กับจุดส่งใน `runtime.py` ยังไม่มีใครต่อ (ของ LANE-GM/chief ตามใบ `1641`) ⇒ วันนี้กด `/speed`

2. **ไม่อ้างว่าโค้ดรอบนี้อยู่บน main** ตอนเขียนไฟล์นี้มันอยู่บนแบรนช์ `claude/inspiring-bohr-9zvic2`
   และ PR ยังไม่ merge รอบก่อนเสียไปทั้งรอบเพราะ PR ถูกบอตปิดด้วย `mergeable=false` ⇒ ไม่มีใคร
   ควรถือว่าแน่นอนจนกว่าจะเห็นบน main และผมเขียนเตือน LANE-GM ไว้ในใบ `1716` บรรทัดแรก ๆ แล้ว

12. **ไม่อ้างว่ามีเทสไหนพิสูจน์ว่าใช้ run-copy DB จริง** โค้ดมองไม่เห็นว่า `SQLiteStore` ชี้ไฟล์ไหน
13. **ไม่อ้างว่าเทสรอบนี้ตรวจ `gm/attr_wire` แทนสาย GM** เทส mask ใช้ stub แทนตัวเขียน tag —
