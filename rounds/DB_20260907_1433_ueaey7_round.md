`-rs` = short summary **เฉพาะ skip** ⇒ pytest ไม่เคยพิมพ์บรรทัด `FAILED ...` ⇒ บล็อกท้ายที่ grep `^FAILED |^ERROR ` ได้ศูนย์เสมอ ไม่ว่าอะไรแดง

```
python3 -m pytest tests -q -rs   -p no:cacheprovider | grep -cE "^FAILED |^ERROR "   -> 0
python3 -m pytest tests -q -ra   -p no:cacheprovider | grep -cE "^FAILED |^ERROR "   -> 1
python3 -m pytest tests -q -rfEs -p no:cacheprovider | grep -E "^FAILED |^SKIPPED "  -> ได้ทั้งสองอย่าง
```
(สคริปต์สองเทส หนึ่งแดงหนึ่ง skip · คำสั่งเต็มอยู่ในใบถึง chief) ⇒ คำแก้บรรทัดเดียว `-rs` → `-rfEs` **อินพุตของ skip census ไม่เปลี่ยนรูปเลย** · ส่งใบถึง chief แล้ว (เขต `.github/` ไม่ใช่ของผม ไม่แตะ)
