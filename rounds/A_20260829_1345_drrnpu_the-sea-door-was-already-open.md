1. รอบนี้ **ไม่ได้** ทำให้ใครเห็นอะไรใหม่บนจอ · ของที่เห็นได้ เห็นได้อยู่แล้วตั้งแต่ 27 ส.ค.
2. **ไม่อ้างว่า "z ไม่สำคัญ"** — `z = 0` รอดในฉากเดียว รอบเดียว ไคลเอนต์บิลด์เดียว
   และ `745.0` เป็นพิกัดที่ผู้เล่น**เดินไปยืน** ไม่ใช่พิกัดที่เขา**มาถึง**
3. **ไม่อ้างว่าฉากทะเลอื่น (18-23) ทำงานเหมือนฉาก 17** วัดมาแค่ว่า `n_MARKER` เป็น 0 เหมือนกัน
   ไม่มีใครเคยเข้าไปยืนในฉาก 18-23
4. **ไม่อ้างว่า `n_MARKER = 0` แปลว่าเข้าฉากไม่ได้** ฉาก 17 เป็น 0 และผู้เล่นเข้าไปยืนมาแล้ว
5. `destination_ready()` ที่ตอบ True **ไม่ได้แปลว่าประตูเปิดให้ล็อกอิน** — `login_entry_allowed: false` และ
   `persist_position_allowed: false` ของฉาก 17 ยังคาที่เดิม ทางเดียวที่เข้าได้คือ dispatch แถว 3021
6. รอบนี้ไม่ได้แตะไฟล์ของสายอื่น `.github/` หรือ canonical DB
7. 🔴 **ไม่อ้างว่าปลายทาง M2 คือฉาก 126** — การอ่านแบบ marker ยัง `[CONTESTED]` ยังไม่มีใครเห็นด้วยตา
   ว่าเซิร์ฟเวอร์ส่งฉาก 126 แล้วเกิดอะไร · ที่วัดได้คือ **การอ่านแบบ scene ถูกหักล้างในฐานะคำอ้าง "วัดแล้ว"**
   ไม่ใช่ว่าการอ่านแบบ marker ถูกพิสูจน์
8. **ไม่อ้างว่า `MARKER[Var2]` คือกลไกที่เซิร์ฟเวอร์เดิมใช้จริง** — ไม่มีใครดูเซิร์ฟเวอร์เดิม
   8/8 ที่ตรงกันเป็นหลักฐานที่หนัก แต่เป็นหลักฐานจากตาราง ไม่ใช่จากพฤติกรรม
