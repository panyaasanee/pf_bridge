## 3. งานเนื้อ ๆ ของรอบ: ทำให้ประโยค "บูต commit ไหน" **รันได้อีกครั้ง**

### 3.1 ทำไมเลือกงานนี้

รอบ 116 ทิ้งของที่แตกไว้หนึ่งชิ้นแล้วบอกตรง ๆ ว่าไม่ได้ซ่อม: **merge commit ที่ automerge สร้างจะไม่มี
`ci/<sha>.json` ตลอดกาล** (push ด้วย `GITHUB_TOKEN` ไม่ trigger workflow) ⇒ ทุกใบในคิวที่เขียนว่า
*"บูต `origin/main` HEAD ล่าสุดที่ ci-status = success"* กลายเป็นคำสั่งที่ **ทำตามแล้วต้องหยุด** —
เพราะกฎ ③ ของทาง D บอกว่า "ไม่มีไฟล์ = ไม่รู้ผล = ห้ามบูต" ซึ่งถูกต้องแล้ว **แต่ทำให้ผู้เทสติดค้าง
ทั้งที่ของเขียวนั่งอยู่ต่ำกว่า HEAD หนึ่ง commit**

นี่คือช่องว่างที่ **ผู้เทสจะชนแน่นอนในรอบเทสถัดไป** และเป็นงานที่ **จบได้ทั้งเส้นบนคลาว** (ไม่ต้องมีอิมเมจ
ไม่ต้องมี DB ไม่ต้องมีหน้าจอ) ⇒ เลือกงานนี้ทั้งที่มันไม่ใช่ gameplay

### 3.2 ของที่ ship: `pf_bridge/pf_resolve_green_boot.py` (ไฟล์ใหม่ 1 ไฟล์ · ไม่มีการลบ)

ตอบคำถามเดียว: **"ตอนนี้บูต commit ไหนของ `pirate-force-server` ได้"**
โดยเดินจากหัวของ `origin/main` ย้อนลง หา **ancestor ที่ใหม่ที่สุดที่มีคำตัดสิน `conclusion == "success"`
และฟิลด์ `sha` ในไฟล์ตรงกับ commit นั้น** — เป็น *การเดิน* ไม่ใช่ *การเปิดดูช่องเดียว* จึงต้องเป็นเครื่องมือ

- **ไม่ผ่อนกฎข้อไหนเลย:** ไฟล์หาย · `sha` ไม่ตรง · `skipped` · `cancelled` = **ไม่รู้ผล** (เดินต่อ ไม่ยอมรับ)
  · `failure` = แดง · ไม่เจอของเขียวในหน้าต่าง = **exit 3 = ห้ามบูต** ไม่ใช่ "น่าจะเขียว"
- **`ci/latest.json` ที่ห้ามมี:** ถ้ามันโผล่มา เครื่องมือ **ไม่อ่านมัน** และพิมพ์เตือนดัง ๆ
- **read-only:** ไม่ merge ไม่ checkout ไม่ fetch (ยกเว้นสั่ง `--fetch`) ไม่เขียนอะไรทั้งสิ้น
- **ASCII ล้วน** เพราะปลายทางคือคอนโซล cp874 ของสะพาน
- **`--selftest` ในตัว:** สร้าง git repo ของเล่นที่มีครบทุกเคส (เขียว · แดง · sha ไม่ตรง · cancelled ·
  ไม่มีไฟล์ · `latest.json` · หน้าต่างแคบเกิน · ไม่มี branch `ci-status`) แล้วตรวจคำตอบ — **11/11 ok**

**รันจริงกับ repo จริงในรอบนี้:**
```
BOOT_COMMIT: cdc52f11b8d93b0eec9db42c83a06f0ed57e2050
  conclusion=success run_id=32426106992 utc=2026-08-20T22:54:09Z event=pull_request
  distance from head of origin/main: 1 commit(s)
```
⇒ ยืนยันด้วยเครื่องมือเองว่า **โค้ด MOVE-AUTHORITY-002 ของรอบ 116 อยู่บน `main` และเขียวจริง**
และ HEAD (`520e2cf`) ไม่มีคำตัดสิน — ตรงกับที่รอบ 116 ทำนายไว้เป๊ะ
