`ScriptHost` เปลี่ยนสามอย่าง:
1. สร้าง namespace ทั้งแปดลง dict **ท้องถิ่น** ก่อน แล้วค่อยติดตั้งเป็น global ของ Lua — สำเร็จทั้งหมดหรือไม่เอาเลย (ครึ่งเดียว = host ที่ดูเหมือนทำงานแต่ API หายครึ่ง)
2. mirror พัง ⇒ **ยังสร้างได้** (`degraded = True`, ไม่มี namespace) ตามที่คำเคาะสั่ง แทนที่จะโยนออกจาก constructor
3. host ที่ degraded **ปฏิเสธ** `load`/`call` ด้วย `MirrorUnavailable` ซึ่งเป็นลูกของ `VendoredDataError` ⇒ สวีปทุกตัวในไฟล์นี้จัดเป็น **`LUA_HOST`** ไม่ใช่ `LUA_SCRIPT <ไฟล์เควส>` — นี่คือ D11 ที่จะกลับมาทางประตูใหม่ ถ้าปล่อยให้ Lua เป็นคนบ่นว่า "index a nil value (global 'Quest')"
4. `BLOCKED_GLOBALS` ตั้ง **ท้ายสุดและไม่มีเงื่อนไข**: host ที่ degraded ก็ยังเป็น sandbox · mirror พังไม่ใช่ข้ออ้างให้ `io`/`os`/`require`/`load`/`python` โผล่
