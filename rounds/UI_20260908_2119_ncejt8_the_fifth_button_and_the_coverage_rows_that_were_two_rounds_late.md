  ผลที่แย่ที่สุดถ้าแยกแล้วปฏิเสธ = ไคลเอนต์เมินเฟรมที่มันขอเอง = สภาพที่ผู้เล่นอยู่วันนี้อยู่แล้ว ⇒ ไม่ใช่เหตุผลให้ส่งไบต์อื่น และ**เป็น**เหตุผลให้สะท้อนไบต์ ไม่ประกอบเอง
- **ส่งอะไร**: ไบต์ของผู้เล่นเอง — decode แล้ว re-encode แล้วปฏิเสธถ้าไม่ตรงไบต์ต่อไบต์ · ไม่ตั้งชื่อฟิลด์ใดเลย
  (`20260904_1120` nonclaim (2) + `RE-312` nonclaim 5 ยังยืน · `proven_semantics` = UNKNOWN) — "field2 คือเพื่อนที่ถูกลบ" เป็นการอ่านที่ชัดที่สุด และ**ไม่ได้เขียนลงไฟล์**
- **ความกว้างคงที่ = เพดานคงที่ ไม่ใช่ headroom**: `u64+u64+u8` = **20 ไบต์เป๊ะ** ทุกค่าที่ชนิดถือได้ (วัด 4,000 ทริปเปิล รวมสุดขอบ u64 ทั้งสองด้าน)
  ⇒ แถวรีวิวเขียน 20 และผู้ตอบบังคับ **เท่ากับ** ไม่ใช่ ≤ (ท่าเดียวกับ `PartyCmdVital`) · `max_frame_bytes=64` จงใจไม่เป๊ะ (วัดจริง 52) เพราะซองไม่ใช่ของเลนนี้
- **ไบต์ที่ไม่ใช่ของผู้เล่นมีหนึ่งไบต์ และเขียนไว้**: `version` = ค่าคงที่ของโมดูลที่หัวไฟล์ตัวเองเรียกว่า UNPROVEN DEFAULT
  · version ขาเข้าถูก `runtime.py` แกะแล้ว**ไม่ส่งต่อ**ให้ `answer()` ⇒ ไคลเอนต์ส่งอะไรมาก็ตอบ 0 · ปิดต้องแก้ `runtime.py` = ใบที่ผู้ตอบ party เปิดไว้แล้ว ไม่หยิบในรอบนี้
- **หลักฐานสองชั้นแยกกัน**: (ก) กดผ่าน `state.dispatch()` จริงหลังล็อกอินจริง ได้ action หนึ่งตัวมีไบต์
