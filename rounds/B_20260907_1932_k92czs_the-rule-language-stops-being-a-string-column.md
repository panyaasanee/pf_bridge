## 1. งานหลัก: คอลัมน์สองคอลัมน์เลิกเป็นสตริง กลายเป็นกฎที่เดินได้

### กับดักที่อยู่ใต้ทุกอย่าง — ตัวคั่นบรรทัดไม่ใช่ขึ้นบรรทัดใหม่
ในตารางที่ commit ไว้ ตัวคั่นระหว่าง "บรรทัดกฎ" คือ **อักขระสองตัว `\` กับ `n`** ไม่ใช่ `chr(10)`
วัดแล้วทั้ง 34 แถว: ไม่มีแถวไหนมี `chr(10)` เลย และทุกแถวมี `\n` แบบสองอักขระ
ถ้าตัวแปลไปตัดด้วย `"\n"` จริง ๆ **ทั้งแถวจะกลายเป็นบรรทัดเดียว ที่ลงท้ายด้วย `GO(0)`** —
คือ AI ที่ตอบค่าปริยายตลอดชีวิต โดยหน้าตาเหมือนแปลสำเร็จ · ตัวแปลนี้จึงตั้ง `RULE_SEPARATOR` เป็นค่าคงที่ที่มีเทสปักไว้
และตัวแปลนี้ **ล้มดัง** (raise) ถ้าถูกป้อนแบบอ่านผิด ไม่ใช่เงียบแล้วตอบค่าปริยาย

### สิ่งที่วัดได้บนสไลซ์ที่รีโปนี้มี (`bg0001`, 34 แถว) — เป็น nonclaim ต่อ 276 แถวเต็ม
- แปลผ่าน **34/34 แถว โทเคนที่แปลไม่ได้ = 0** (เกณฑ์รับของใบ `2032`)
- **ทั้ง 34 แถวขนานกันสองคอลัมน์** และ **ทั้ง 34 แถวจบด้วย `GO(0)`**
  ⇒ "6 แถวไม่ขนาน + 8 แถวไม่จบด้วย `GO(0)`" ที่ใบ `2032` พูดถึง **อยู่นอกสไลซ์ที่รีโปนี้เห็น**
  ตัวแปลยังประกาศพฤติกรรมของทั้งสองรูปไว้ (บรรทัดเงื่อนไขที่ไม่มี action คู่ = **ไม่ทำอะไร ห้ามยืม action ของบรรทัดบน** ·
  แถวที่ไม่มีค่าปริยาย = ตอบ `None` ได้) และมีเทสปัก **"MEASURED, not desired"** ไว้ ถ้ารอบไหนขุดตารางเพิ่มแล้วรูปใหม่เข้ามา เทสจะแดงและบังคับให้พูด
- 🔴 **คลังคำที่ใบ `2032` ให้ไว้ไม่ตรงกับของจริงในสไลซ์**: สไลซ์ใช้ `HP_ALLY<` (แถว 293, 323) ซึ่งไม่อยู่ในรายการของใบ
  ส่วน `BUFF_ENEMY` กับ `HP_ENEMY` ที่ใบระบุ **ไม่ปรากฏในสไลซ์เลย** ⇒ โมดูลรับ **ยูเนียนของสองคลัง** ไม่งั้นต้นไม้ฝั่งหนึ่งจะ raise

### การอ่านที่ "เลือกเอง" ทุกข้อ อยู่ที่เดียว เปลี่ยนได้ด้วยค่าคงที่เดียว
| การอ่าน | ที่อยู่ | สถานะ |
|---|---|---|
| `RATE(n)` = โอกาส n% **ต่อการประเมินหนึ่งครั้ง** | `RATE_IS_PER_EVALUATION` | สมมติฐานตามใบ `2032` |
| `DOONCE(0)` = ครั้งเดียวต่อชีวิตมอน (ความจำอยู่ที่ผู้เรียก) | `EvalState.doonce_fired` | สมมติฐานตามใบ |
| `BUFF_I(id,a,b)` ในคอลัมน์เงื่อนไข = "ตัวมันเองมีบัฟ id" · เลขสองตัวหลังไม่ถูกอ่าน | `_condition_holds` | **สมมติฐานของสาย** — ไม่มีการวัดในรีโปนี้ที่บอกความหมายของสองตัวหลัง |
| `CHASE(n)` = ช่อง `n` ใน `MOBS.s_SKILLS` · ไม่ resolve เป็น skill id | `Action.skill_slot` | ใบบอกเองว่า n ยังไม่พิสูจน์ |
| หน่วยของ `IDLE;a;b` = **วินาที** | `WANDER_UNIT_SECONDS` (เทสปักว่ามีที่คูณที่เดียว) | **ไม่รู้จริง** — เลือกเพราะทุกคู่ที่ shipped เล็กและเรียงขึ้น (9..15, 10..30, 0..1, 1..2) ซึ่งอ่านเป็น "หยุด 9-15 วินาที" ได้ธรรมชาติ และอ่านเป็นระยะทางไม่ได้สำหรับตัวที่ยืนนิ่ง |
| โทเคนบนบรรทัดเดียวกันคั่นด้วย `;` = **AND** | `choose` | ไม่มีอะไรในข้อมูลที่แยก OR ออกมาได้ |

### ตัวประเมินต่อ tick
`choose(program, state, rng)` = **บรรทัดแรกที่เงื่อนไขจริงทั้งหมด** (first match wins — สิ่งที่ทำให้ `GO(0)` ท้ายแถวเป็น "ค่าปริยาย" ไม่ใช่ "ตัวครอบ")
`RATE` ที่ไม่มี `rng` ของผู้เรียก **raise** ไม่ยอมดึงจากสตรีมโมดูลกลาง (กฎบ้านที่ `mob_loot` ปฏิเสธไว้ด้วยชื่อ)
