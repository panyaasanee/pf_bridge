### ② `D3` ปิดแล้ว — และมันไม่ใช่การ "เพิ่ม 14 ลงในทูเปิล"

**ก่อนหน้านี้:** `player_wire` ถือ literal `scene_id not in (1, 2)` ⇒ ล็อกอินฉากอื่นได้ `ActorAttr` เปล่า
และ `runtime.py` latch `player_faction1_compose_refused_production_start_game` **โดยไม่มีอะไรแดง**
· `HYP-PF-027` วัดว่าความเป็นศัตรูเรนเดอร์จาก **คู่** faction ⇒ อาการคือมอน 81 ตัวที่ไม่อ่านว่าเป็นศัตรู

**รอบนี้:** โมดูลใหม่ของสายนี้ `src/pirateforce_foundation/world_faction_admission.py`
ถือ **นโยบาย** แทน literal · เกณฑ์คือ blast radius ที่ COO เขียนเป๊ะ:
**registry ประกาศเปิดที่ล็อกอิน `AND` `n_SAVE = 1`**

```
WORLD_FACTION_ADMISSION scenes=1,2,14 rule=login_entry_allowed_and_n_save_1 proven_floor=1,2
```

🔴 **`{1, 2, 14}` เป็นผลลัพธ์ที่ derive ไม่ใช่ลิสต์ที่เขียนไว้** — และเงื่อนไขที่สองทำงานจริง
ไม่ใช่คำประดับ: ฉาก **278 และ 997 เปิดที่ล็อกอินอยู่แล้ววันนี้** และถือ `n_SAVE = 0`
⇒ ถ้าใช้เงื่อนไขแรกอย่างเดียว **จะรับเวทีสองอันเข้ามาด้วย**

**สามอย่างที่ออกแบบมากันความผิดพลาดคนละทรง:**

1. **ห้ามลบของเดิม (`PROVEN_FACTION_SCENE_IDS = (1, 2)`)** — ฉาก 1/2 ผ่านด้วยคุณสมบัติตัวเองอยู่แล้ว
   (`n_SAVE 1` + ไม่ปักคีย์ = default เปิด) แต่ยังต้องมี **พื้น** เพราะความล้มเหลวทรงนี้**เงียบสนิท**:
   ถ้านโยบายพังแล้วปฏิเสธฉาก 1 ⇒ **ทุกล็อกอิน production เสียเฟรม faction โดยที่สวีตยังเขียว**
   (runtime จับ ValueError แล้ว latch event ไม่ raise) ⇒ มีเทสขับด้วย registry ที่โหลดไม่ขึ้นเลย
2. **fail-closed ทุกทิศ** — ฉากที่ไม่มีในทะเบียน · ทะเบียนโหลดไม่ขึ้น · อาร์กิวเมนต์ผิดชนิด · `bool`
   (`True == 1` ใน Python และฉาก 1 ถูกรับ ⇒ นโยบายที่ลืมข้อนี้จะรับ `True` เป็นบ้าน) ⇒ ปฏิเสธหมด ไม่ raise
   เหตุผล: **ปฏิเสธ = กลับไปเป็นพฤติกรรมของเมื่อวาน ซึ่งปลอดภัยเสมอ · รับผิด ไม่ปลอดภัย**
3. **ตัวประกอบแช่แข็งของ `GT-032` ไม่แตะ** — `make_actor_attr_with_basic_faction` ยังถือ `(1, 2)`
   ตามเดิม (มีเทสยืนยันว่ามัน **ยังปฏิเสธฉาก 14**) · ขยาย reference = reference เลิกเป็น reference
   แก้เฉพาะตัวที่ `runtime.py` เรียกจริงตัวเดียว (`make_actor_attr_with_name_class_and_faction`)

### ③ เทสสามตัวของรอบก่อนกำลังจะยืนยัน "คุณสมบัติตรงข้าม" โดยที่ยังเขียวอยู่

`TheAdmissionCheckIsTheGateTests` (รอบ `ga91m5-r2`) ขับด่านรับเข้าด้วย **registry จริง** ซึ่งตอนนั้นปิด

"composer ปฏิเสธสำหรับฉากที่ไม่มีใครลงทะเบียน" ซึ่ง**เป็นจริงกับโมดูลที่ไม่ทำอะไรเลย**

เข้าฉากที่ทะเบียนบอกว่าปิด"* ⇒ ต้องขับกับทะเบียนที่บอกว่าปิด ซึ่งเป็นทะเบียนเดียวที่ขับมันได้
· และเพิ่มเทสใหม่ที่ปักว่า **registry จริงวันนี้ประกอบ 81 ตัวจริง** (ครึ่งที่หายไป)

**คู่เทส dispatcher ก็สลับขั้วด้วยเหตุผลเดียวกัน:** เดิม "เปิดประตูในทะเบียนชั่วคราว → 81 ตัว" คู่กับ
"ทะเบียนจริง → ปฏิเสธ" · ตอนนี้เป็น **"ทะเบียนจริง (ไม่ patch loader เลย) → 81 ตัว"** คู่กับ
"ทะเบียนชั่วคราวที่ปิด → `WORLD_SCENE_ENTRY_REFUSED`" ⇒ ตัวแรกกลายเป็น**เส้นทาง production จริง**
