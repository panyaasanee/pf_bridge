- ต่างแม้แต่ path เดียวที่รันได้ (`src/` `scenarios/` `current/` หรือ **ไดเรกทอรีที่ยังไม่มีใครจัดประเภท**) ⇒ **ปฏิเสธ** และบอกชื่อ path ที่ทำให้ปฏิเสธ

🔴 **`current/` อยู่ฝั่ง "รันได้" โดยเจตนา** — `current/pf_login_game_server_v141.py` ถูก **โหลดเข้าเป็นโมดูลจริงตอนบูต** (`app.py:619`) มันคือโค้ดที่รัน ไม่ใช่เอกสารแช่แข็ง
🔴 **allow-list เป็น allow-list ไม่ใช่ deny-list** — ของที่ไม่รู้จักนับเป็นโค้ดเสมอ · การเพิ่ม prefix เข้าไปคือการตัดสินใจว่าเซิร์ฟเวอร์รันอะไรได้ ไม่ใช่ความสะดวก

**selftest ในตัวเครื่องมือ: 43 check ผ่านหมด (`SELFTEST PASS`)** — เพิ่มเคสใหม่ 5 ตัว: inert-only drift บูตได้ · บอกเหตุผล · พิมพ์ path ที่ต่าง · หนึ่ง path ที่รันได้ก็ปฏิเสธ · และตารางจำแนก `scenarios/ current/ src/ unclassified/` = ไม่ inert / `docs/ tests/ tools/ README.md` = inert
