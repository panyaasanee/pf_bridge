## ② เหตุที่เกตแดง และของจริงที่รอบนี้เพิ่ม

เทสที่แดงมีใบเดียว:
`tests/test_gm_login_scene_admission.py::TheLoaderTests::test_the_console_token_names_the_file_the_account_and_the_way_out`
บรรทัดที่แดงคือ `self.assertIn(str(self.standalone_path), console)`

รอบ `qq0i9u` แก้ของจริง (pf-adversary D2): คอนโซลสะพานเป็น `cp874`
ชื่อบัญชีที่ encode ไม่ได้เคยทำให้ `print` โยน `UnicodeEncodeError` ออกมาแทนคำปฏิเสธ ⇒ ผิดกฎบ้าน
"diagnostic ห้ามเปลี่ยน dispatch" ⇒ พับฟิลด์ของผู้ใช้ผ่าน `ascii()`

**`ascii()` พับ *และ* หนีอักขระ** ⇒ บน Windows บรรทัดพิมพ์ `path='C:\\Users\\RUNNER~1\\...'`
แต่เทส (และผู้เทส) ต้องการ `C:\Users\RUNNER~1\...` — บรรทัดบอกชื่อไฟล์ในรูปที่ก๊อปไปวางไม่ได้

รอบนี้เปลี่ยนเป็น `console_safe()` = `text.encode("ascii", "backslashreplace").decode("ascii")`
พับเฉพาะสิ่งที่ `cp874` ไม่มีที่ให้ ปล่อยอักขระ ASCII รวมทั้ง `\` ไว้ตามเดิม

### แต่ของที่รอบนี้เพิ่มจริง ๆ ไม่ใช่ `backslashreplace` — มันคือการทำให้ POSIX มองเห็น

`ascii()` ไม่ได้เลือกมาแบบมักง่าย มันวัดมา มันแก้ของที่พังจริง และรอบที่ใส่มันรันเทสทั้งชุดได้ **0 failed**
🔴 **และมันรายงานเป็นอย่างอื่นไม่ได้เลย** เพราะบน POSIX ไม่มี `\` ให้ซ้ำ
⇒ เครื่องเดียวที่เห็นความผิดพลาดนี้ได้ คือเครื่องที่มีอำนาจปิด PR

`\` เป็นอักขระที่ถูกกฎหมายในชื่อไฟล์ POSIX ⇒ เทสใหม่สองตัวจำลอง "รูปทรงแบบ Windows" **บนเครื่องที่เขียนรอบ**:

| เทสใหม่ (`TheLoaderTests`) | ปัก |
|---|---|
| `test_a_path_with_separators_in_it_is_named_verbatim` | เขียน config ที่ `dir\sub\standalone.json` แล้วขอพาธคืนแบบตรงตัว |
| `test_the_fold_survives_that_and_still_reaches_a_cp874_console` | อ่านง่ายแล้วต้องยัง encode ปลอดภัยด้วย — สองข้อนี้ดึงกันคนละทาง จึงปักไว้ที่เดียวกัน |

| กลายพันธุ์ | แดงที่นี่ (เดิม) |
|---|---|
| `console_safe` กลับไปเป็น `ascii()` | **2 (เดิม 0)** |
| `console_safe` คืนค่าเดิมไม่พับเลย | **2 (เดิม 1)** |

### 🔴 D3 — ของที่รอบนี้แก้ ทำผิดซ้ำแบบเดิม ในฟิลด์ที่อยู่ติดกัน

`str.encode("ascii", "backslashreplace")` **ไม่ได้**พับ "เฉพาะสิ่งที่ cp874 ไม่มีที่ให้" อย่างที่ผมเขียน
มันพับอักขระ non-ASCII **ทุกตัว** และ **`cp874` คือโค้ดเพจภาษาไทย** — `"ทดสอบ".encode("cp874")` สำเร็จ

⇒ ในโปรเจกต์ภาษาไทย ผู้เทสชื่อ `ทดสอบ` ได้บรรทัดคอนโซลที่ **ไม่มีชื่อบัญชีตัวเองอยู่ในนั้น** grep หาไม่เจอ

**ส่งโดยรอบที่มีข้อค้นพบว่า "การพับที่หนีอักขระด้วย ไม่ใช่การพับ"**

**แก้แล้ว**: `console_safe(text, stream)` **ถามสตรีมเอง** แล้วพับผ่าน encoding ของสตรีมนั้น
ไม่ยอมบอก (เช่น `StringIO`) ⇒ ถอยไป ASCII แคบสุดชนะเมื่อไม่รู้
⇒ พาธ Windows เก็บ `\` ไว้ · ชื่อไทยรอดบนโค้ดเพจไทย · `张三` ยังถูกหนีอยู่
