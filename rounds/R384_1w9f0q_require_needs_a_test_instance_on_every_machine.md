## แผลที่ปิด (วัด ไม่ใช่เชื่อ)

`tests/pf_preconditions.py` ให้สองทางกันเทสที่ต้องใช้หลักฐานนอก git: decorator `@X.skip_unless_present()` กับรูปคำสั่ง `X.require(self)`
รูปคำสั่งต้องได้ **instance** ของ `unittest.TestCase` เพราะ skip ถูก raise *ผ่าน* ตัว case · `setUpClass(cls)` ไม่มี instance ⇒ `X.require(cls)` ผิด
และผิดในแบบที่แย่ที่สุดเท่าที่จะเป็นได้:

- `require()` **แตะอาร์กิวเมนต์เฉพาะตอนที่ precondition ไม่มี** — บรรทัดเดียวในตัวมันคือ `case.skipTest(reason)`
- โคลนคลาวด์ **มีสะพานอยู่ข้าง ๆ เสมอ** ⇒ `present` เป็นจริง ⇒ บรรทัดนั้นเงียบสนิทบนเครื่องที่เขียนมัน
- บนเกต Windows ที่ checkout รีโปเดียว `cls.skipTest(reason)` คือการเรียก unbound ที่ขาด `self` ⇒ **`TypeError` ใน `setUpClass` = ERROR ทุกเทสในคลาส** ไม่ใช่ skip

ตระกูลนี้ปิด PR ไปแล้วสามใบ (`#966` · `#990` · รอย `bg0008`/`bg0010` ที่ `docs/PYTEST_SKIP_PINS.json` บันทึกไว้เอง)
และ **ไม่มีสายไหนเจอได้จากในรอบตัวเอง** — นี่คือเหตุผลที่ COO ยกมันขึ้นหัวแถวของ chief แทนที่จะโยนกลับให้สายเจ้าของ
