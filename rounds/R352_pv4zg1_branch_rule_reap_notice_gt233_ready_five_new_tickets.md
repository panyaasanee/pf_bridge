## 2. reap ทาง (ก): เลิกเงียบกับ PR ที่ automation มองไม่เห็น

แก้ `reap` ของ `merge-claude-pr.yml` **ทั้งสองรีโป** (bridge `0be3392c` · server `7986e61e`):
PR ที่ **มี marker แต่ head ไม่ใช่ `claude/*`** ⇒ comment **ครั้งเดียว** ว่า
`invisible to automerge: re-push on a claude/ branch` แล้วปล่อยไว้ · ไม่ merge ไม่ปิด ไม่ปลด draft ·
เกต `claude/*` เองไม่ถูกผ่อนแม้แต่นิดเดียว

**พิสูจน์ก่อน push (ไม่ใช่ "อ่านแล้วน่าจะถูก") [วัดแล้ว]:**
- ตัวโหลด YAML แบบจับ **key ซ้ำ** (GitHub ปฏิเสธไฟล์ที่ `yaml.safe_load` รับ — บทเรียน R189) = ผ่านทั้งสองไฟล์
- `bash -n` ทุกก้อน `run:` ของทุก job = ผ่าน (bridge 2 job · server 3 job)
- ไบต์ > 127 ในไฟล์ = **0** ทั้งสองไฟล์
- **จำลอง 5 เคสกับ stub API** (สคริปต์อยู่ใน scratchpad ของรอบ ไม่ commit): มี marker + head ไม่ใช่ `claude/*` + ยังไม่เคยบอก ⇒ comment **1 ครั้ง** ·
  เคยบอกแล้ว ⇒ **ไม่ comment ซ้ำ** · ไม่มี marker ⇒ **เงียบสนิท** (ไม่ใช่พฤติกรรมใหม่) · head เป็น `claude/*` ⇒ **ไหลลงล่างตามเดิม ไม่ถูกแตะ** ·
  อ่านคอมเมนต์ไม่ได้ (API ล้ม) ⇒ **ไม่พูดอะไรเลยรอบนั้น** (fail-closed ไม่ spam)

**ที่ยังไม่พิสูจน์**: workflow ตัวจริงยังไม่เคยรันโค้ดนี้ — ต้องยืนยันรอบหน้าตาม `AGENTS.md` §7 ข้อ 4
(หลัง merge ต้องเห็น run ของ `merge-claude-pr.yml` เกิดจริง มี job > 0) · ถ้าไม่มี = ไฟล์ตาย = `ATTENDED-URGENT`
