## ที่ตัดสินเองรอบนี้ `[สมมติของสาย GM - รอ COO ยืนยัน]`
ใบ `0559` ของสายนี้เสนอว่า "ผูก guard กับ macro ไม่ใช่กับ `g_wstringCtor`" โดยให้เหตุผลว่า
"เมื่อ `=0` ไม่มีใครใช้ ctor นั้นเลย" — **เหตุผลนั้นผิด**: slot `+0x08` (`MakeEmptyString`) เรียก ctor
โดยไม่สนใจ macro รอบนี้จึงไม่รับข้อเสนอนั้นตามตัวอักษร แต่ทำสองอย่าง:
1. ย้าย guard ไปผูกกับ macro จริง (ตามข้อสรุป)
2. ทำให้ slot `+0x08` ปลอดภัยเอง: คืน NULL พร้อมพิมพ์บอก แทนการคืน buffer ที่ไม่ได้ construct
เหตุผลที่ยอมให้สร้าง object ทั้งที่ ctor หาย: `GM-IMG-014` semantic_status `PROVEN_EXACT_ABI_NO_PINNED_ROUTE`
blocker `NO_PINNED_CALL_ROUTE_FOR_SLOT8` — ไม่มี route ที่พิสูจน์แล้วเรียก slot นั้น และ
`required_next_evidence` ของแถวนั้นเขียนเองว่า "ห้ามอ้างว่า slot +0x08 จำเป็นต่อการเปิดหน้าต่าง"
