| ที่เพิ่ม | ทำอะไร |
|---|---|
| `STATE_COMPOSED_HEALING` | สถานะจริงของสิ่งที่เกิด · อยู่ใน `COMPOSING_STATES` ⇒ ยังส่งได้ |

| `heals` / `healed_identities` | `None` = **วัดไม่ได้** ไม่ใช่ `0` |
| `describe_recompose` | `heals=` + บรรทัด FATAL ที่พก **ชื่อสถานะของ admission เอง** ไม่ใช่คำแปล |
| `register=` ที่ admission | โมดูล**ถืออยู่แล้วและไม่เคยส่ง** ⇒ `register_checked` เป็น False ทุกครั้งที่ recompose มา |

🔴 **`composed` ที่อ่านทูเพิลคือครึ่งที่สำคัญที่สุดของแพตช์** ถ้าปล่อยให้มันเป็นการเทียบสถานะเดียว
การตั้งชื่อสถานะใหม่จะทำให้ `if record.composed` ของจุดเรียกตกไป fallback ทันที
⇒ รอบที่ตั้งใจหยุดหลอดเลือดเด้งหนึ่งหลอด จะเริ่มลบทั้งแมพแทน · พินไว้เป็นเทสชื่อ
`test_the_healing_record_is_still_sendable`

**`register=` เปลี่ยนพฤติกรรมจริง วัดแล้ว** (ไม่ใช่แค่ป้าย): ledger ที่ขัดกับ death register
