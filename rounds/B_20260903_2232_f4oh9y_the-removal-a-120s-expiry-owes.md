  แยกตามฉากจงใจ: แถวที่หมดอายุในเมืองลบไม่ได้ด้วยเจเนอเรชันของสนาม

  (3) **หักคีย์ที่เจเนอเรชันยังถืออยู่ออกก่อน** — แถวที่ถูกกวาดระหว่างประกอบ (นอกล็อก) คือแถวที่เฟรมกำลังจะ
  บอกว่า "ยังยืนอยู่" ล้างมันคือสร้างผีถาวร

## 6. pf-adversary — 12 ข้อ แก้หมด ข้อแรกเปลี่ยนคำอ้างของรอบทั้งรอบ
ยิงกับ diff เต็มก่อน commit · มันสร้าง worktree แยก ขับผ่าน dispatch จริง และรันมิวแทนต์ ไม่ใช่แค่อ่านโค้ด

- **D1 (หนักที่สุด)** ของสองชิ้นใน R307 คือของ **ทั้งหมด** ของฉากนั้น ⇒ กวาดแล้วฉากว่าง ⇒ ไม่มีเจเนอเรชัน
  ไม่ว่างให้ประกอบ ⇒ **รอบนี้ไม่ได้แก้เคสที่วัดมาจริง** · เทสชุดแรกเลี่ยงเคสนี้ทุกใบด้วยการใส่ kill สด
  ⇒ สาขา HELD ไม่เคยถูกรันเลย · **แก้**: `NONCLAIM 25` + เทสที่ขับ 7 คลิกในรูปของ R307 แล้วปัก `frames = 0`
  + แก้คำอ้างใน PR body/จดหมาย/docstring ทุกที่
- **D2** หนี้ถูกล้างตอน "ประกอบ" ทั้งที่ค่าคงที่ในโมดูลเดียวกันบอกว่า runtime ทิ้งเฟรม ⇒ วันที่บรรทัด chief ลง
  จะไม่มีอะไรเหลือให้ส่ง · **แก้**: `will_send` ไม่มี default
- **D3/D4** `note_scene_published` ป็อปทั้งฉาก ⇒ แถวที่กวาดระหว่างประกอบถูกมาร์คว่าจ่ายแล้ว = ผีถาวร ·
  และสาขา filter ที่ docstring คุยไว้ **ไม่เคยถูกรัน** (มิวแทนต์ที่ลบทิ้งรอด 8987 เทส) · **แก้**: หักคีย์ที่ถืออยู่ + เทส
- **D5** `enter_scene_frames` ประกอบ ≠ ตีพิมพ์ · **แก้**: ขอบฉากไม่จ่ายหนี้อีก
- **D6** ประตูรับ **สตริงเปล่า** ก็ล้างหนี้ได้ · มิวแทนต์ "ไม่อ่านอาร์กิวเมนต์ scene" และ "คืน 0" รอดทั้งคู่ ·
  **แก้**: ตรวจชนิดแถว + เทสที่ publish คนละฉากกับที่ cell ยืน + ปักค่าที่คืน
- **D7** ยาม AST หลวมทั้งไฟล์ · พิสูจน์ของปลอม: ลงบรรทัดของ chief แล้วใส่ decoy ที่อื่น → ยังเขียว = โกหกได้ ·
  **แก้**: ยึดกับฟังก์ชันที่เรียก `dispatch_inbound_pickup_request` เท่านั้น · ผมรันของปลอมชุดเดิมซ้ำ = ตกแล้ว
- **D8** หน่วยความจำหนี้ไม่มีเพดาน · **แก้**: deque `EXPIRED_KEY_MEMORY` ต่อฉาก + เทสสองใบ
