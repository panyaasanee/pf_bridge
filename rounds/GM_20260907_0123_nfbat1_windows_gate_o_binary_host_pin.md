เทสคู่แฝดสองใบที่รอบ `lkwmkp` เขียนคู่กับ fix `O_BINARY` **ตรึงว่า "โฮสต์เป็น POSIX"** ไม่ใช่ตรึงโค้ด ·
`os.O_BINARY` **มีจริงบน windows-latest** ซึ่งเป็นเครื่องที่เกตของบ้านนี้เดิน ⇒ เทสที่เขียนขึ้นเพื่อพิสูจน์ว่า
fix ของ Windows ไม่กระทบ POSIX กลายเป็นเทสที่ **ทำให้เกต Windows แดงเอง** — เจ็บแต่ตรงไปตรงมา

**สิ่งที่แก้**: ทั้งสองใบเลิกสมมติแพลตฟอร์ม แล้ว **จำลองการไม่มีแฟล็ก** ด้วย context manager
`_o_binary_removed` (ลบ attribute ออกจากโมดูล `os` ชั่วคราว คืนใน `finally`) ⇒ สาขา fallback ของ
`getattr(os, "O_BINARY", 0)` ซึ่งเป็น**สิ่งที่เทสตั้งใจตรวจจริง ๆ** ถูกเดินบนทุกแพลตฟอร์ม
ไม่ใช่เฉพาะเครื่องที่บังเอิญไม่มีแฟล็ก · บ้านนี้มีแบบอย่างการแยกทางตาม OS อยู่แล้วในไฟล์เดียวกัน
(`if os.name == "posix":` ของเทสโหมดไฟล์) — รอบนี้ไม่ได้เลี่ยงด้วยการ skip บน Windows ซึ่งจะทำให้เทสตายบน
เครื่องที่สำคัญที่สุด
