## วิธีเอาไฟล์ขึ้น main (อ่านให้จบก่อนเขียน)
push main ไม่ได้ (ปฏิเสธที่ sandbox) ทางเดียว = PR: (1) git fetch --all + pull --rebase (2) เขียนไฟล์ลง notes_to_chief/ (แก้ NOW.md ได้ถ้าจำเป็น) `git add --` เฉพาะไฟล์ที่แก้จริง ห้าม add -A (3) commit ASCII ขึ้นต้น `COO:` (4) push ขึ้น branch `claude/*` ที่ระบบสุ่มให้ (5) เปิด PR หัว `[COO]` body มีบรรทัด `PF-AUTOMERGE: v4` เป๊ะ (6) ปล่อยให้ merge เอง (pf_bridge ไม่มี gate merge ในไม่กี่วินาที)
🔴 ห้าม merge/ปิด PR เอง · ห้ามใช้ gh (ใช้ GitHub API/tool) · push/เปิด PR ล้ม = จบรอบทันที ห้าม retry ห้าม force · PR ของสายอื่น `[LANE-*]` ไม่ใช่ของคุณ ห้ามแตะ ห้ามจบรอบเพราะเห็นมัน
ล็อกรอบของสาย = PR หัว `[LANE-x] round <id>: claim` ที่ยังไม่มี marker · คุณไม่ต้อง claim แต่รอบผู้บริหารต้องนับ claim ผีอายุเกิน 3 ชม. แล้วแจ้ง Panya ปิดมือ

git fetch แล้วดู `notes_to_chief/` ใบที่รอคำตัดสิน (หาแบบนี้ ไม่ใช่แค่ชื่อไฟล์): บรรทัดแรกมี "ถึง: COO"/"FOR COO" · หรือชื่อไฟล์มี ASK-COO/COO-ruling/FOR-COO · หรือขึ้นต้น FROM_CHIEF_R · ใบที่มี COO-DECISION ตอบแล้วหรือมี `.CONSUMED.txt` คู่ = ข้าม

- มีใบรอ → ตอบทุกใบ ใบละหนึ่งจดหมาย `notes_to_chief/<YYYYMMDD_HHMM>_COO-DECISION-<เรื่อง>.md` (เวลา +07:00): ตัดสินอะไร/เพราะอะไร/ใครทำอะไรต่อ/เมื่อไร · 🔴 สั้นและชี้ขาด หนึ่งเรื่องหนึ่งจดหมาย
