# prompts/ — พรอมป์กลางของทุก routine (แหล่งเดียว แก้ที่เดียว)

ทำไมมีโฟลเดอร์นี้: routine ตัวเดียวกันกระจายหลาย account และหลายรอบ cron — เปลี่ยนพรอมป์ทีต้องไล่แก้ทุกที่ ตามไม่ไหว
วิธีแก้: พรอมป์จริงอยู่เป็นไฟล์ที่นี่ · ในช่องพรอมป์ของ routine ใส่แค่ **บูตสแตรปสั้น ๆ** ที่ชี้มาอ่านไฟล์ · แก้พฤติกรรมสาย = แก้ไฟล์เดียวที่นี่ ทุก account/cron ของสายนั้นได้เหมือนกันทันทีที่ไฟล์ถึง main

## ไฟล์ในโฟลเดอร์
- `COMMON_LANE_ROUND.md` — เครื่องยนต์รอบ ใช้ร่วม 6 สาย builder (ล็อกรอบ · PR · จบรอบ · เวลา · ภาษา · หลักฐาน · empty-round)
- `LANE-A.md` `LANE-B.md` `LANE-DB.md` `LANE-GM.md` `LANE-CS.md` `LANE-UI.md` — เฉพาะตัวตน/ภารกิจ/เขตเขียน/คิว/งานสำรอง ของแต่ละสาย (สั้น · อ่าน COMMON ต่อ)
- `CHIEF.md` — chief (LANE-E) · ชี้ COMMON สำหรับล็อกรอบ/PR แล้วเก็บเฉพาะงาน platform/gate/milestone/แม่บ้าน
- `COO.md` — COO · จบในตัว (ไม่เดินเครื่องยนต์รอบแบบ builder)

ลำดับความจริงของทุกสาย: **NOW.md > จดหมายที่จ่าหน้าถึงสาย > AGENTS.md §7 > ไฟล์รอบล่าสุดของสาย > คิวในไฟล์สาย**
ไฟล์พรอมป์เป็น "โครงถาวร" · งานเฉพาะกิจ/priority ที่เปลี่ยนบ่อยไป NOW.md ไม่ใส่ในพรอมป์ (นั่นคือเหตุผลที่พรอมป์ลีนได้)

## บูตสแตรปที่วางในช่องพรอมป์ของแต่ละ routine (แทนพรอมป์เดิมทั้งก้อน)
วางข้อความนี้ แทน `<FILE>` ด้วยไฟล์ของสายจากตารางข้างล่าง:

```
Speak in Thai.
คุณคือสายงานในโปรเจกต์ Pirate Force ของคุณ Panya พรอมป์จริงของคุณอยู่เป็นไฟล์ในรีโป pf_bridge
ขั้นแรกทุกรอบ ก่อนทำอย่างอื่น:
1. clone/เปิดรีโป pf_bridge แล้ว `git fetch origin main`
2. อ่านไฟล์ `prompts/<FILE>` จาก origin/main ให้จบ แล้วทำตามนั้นทั้งหมดในรอบนี้
   (ไฟล์นั้นจะสั่งให้อ่าน pf_bridge/NOW.md และ prompts/COMMON_LANE_ROUND.md ต่อเอง)
3. อ่านไม่เจอไฟล์ prompts/<FILE> บน origin/main (เช่นถูกลบ/ยังไม่ sync) = อย่าเดางานเอง
   เขียนจดหมาย notes_to_chief/<เวลา>_<สาย>-ALERT-prompt-file-missing.md แล้วจบรอบ
NOW.md อยู่เหนือทุกอย่างในไฟล์พรอมป์เสมอ
```

ตาราง `<FILE>` ต่อ routine (ทุก account/ทุก cron ของสายเดียวกันใช้ค่าเดียวกันเป๊ะ):

| routine | `<FILE>` |
|---|---|
| LANE-A (ทั้งสอง cron/ทุก account) | `LANE-A.md` |
| LANE-B | `LANE-B.md` |
| LANE-DB | `LANE-DB.md` |
| LANE-GM | `LANE-GM.md` |
| LANE-CS | `LANE-CS.md` |
| LANE-UI | `LANE-UI.md` |
| Chief (LANE-E) | `CHIEF.md` |
| COO | `COO.md` |

🔴 cron/ตารางเวลา **ไม่เปลี่ยน** — บูตสแตรปนี้แทนแค่ "เนื้อพรอมป์" ไม่ยุ่งกับจังหวะ

## แก้พฤติกรรมทีหลังทำยังไง
- แก้เฉพาะสายเดียว → แก้ `prompts/<สาย>.md`
- แก้กฎที่ใช้ร่วมทุกสาย (ล็อกรอบ/PR/จบรอบ) → แก้ `prompts/COMMON_LANE_ROUND.md` ที่เดียว ทุกสายได้พร้อมกัน
- แก้ผ่าน PR เข้า main (หรือแก้บนสะพานแล้ว pf_git_sync ดันขึ้นให้ — โฟลเดอร์นี้อยู่ใน .gitignore allowlist + push allowlist แล้ว)
- routine หยิบไฟล์เวอร์ชันล่าสุดจาก origin/main ทุกรอบ ไม่ต้องแตะช่องพรอมป์ของ routine อีก
