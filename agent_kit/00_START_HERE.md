## 3) กติกาที่พลาดบ่อยที่สุด 6 ข้อ

1. **bash ของคุณคือ Linux sandbox คนละเครื่องกับ Windows** — คำสั่งที่ต้องรันจริง (บูตเซิร์ฟ, gate,
   commit) ต้องเขียนเป็น `.ps1` **ASCII ล้วน** หย่อนลง `pf_bridge\inbox\` แล้วอ่านผลจาก `outbox\`
2. **commit ต้องทำบน Windows bridge เท่านั้น** (index ของ sandbox stale ทำ phantom deletions)
3. **ธงสองใบ** — วางจ็อบลง inbox ไม่ต้องถือธง · ถือ `LOCK_GAME` เมื่อจะบูตเซิร์ฟ/เปิดเกม ·
   `LOCK_GIT` ถือเฉพาะช่วง gate/commit · **เลขจ็อบ: chief 1xx · ผู้เทส 9xx**
4. **canonical DB ห้ามแตะ** — เทสทุกครั้งบนสำเนา · เทียบ sha กับ `CANON_SHA.txt` เสมอ (อย่าจำค่า)
5. **วินัยหลักฐานสองชั้น** — `client-observable` (ตาเห็นบนจอ) กับ `wire/DB` **ห้ามใช้ชั้นหนึ่ง
   อ้างเป็นหลักฐานของอีกชั้น** · ทุกผลต้องมี **nonclaims** · **ผลลบมีค่าเท่าผลบวก**
6. **เครื่องมือห้ามพิมพ์อักขระนอก cp874 ออก console** (อีโมจิทำ gate แดงเฉพาะบน Windows มาแล้ว)
