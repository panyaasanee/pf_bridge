## ② ข้ออ้างของ v1 ที่ **ถูก** และถูกยกมาทั้งดุ้น
- **"commit ต้องทำบน Windows" เกษียณได้ แต่ห้ามลบเหตุผลเดิม** — เหตุผลจริงคือ *shared mount ⇒ index stale ⇒ phantom deletions* ไม่ใช่คำว่า Windows · v2 เขียนเป็นเงื่อนไขตรวจได้ 6 ข้อ
- **CI ไม่ใช่ gate ตัวเต็ม · ห้ามเขียนคำว่า "เขียว" ลอย ๆ** — v2 บังคับรูปแบบ `เขียว(cloud sanity)` / `เขียว(Actions run #N)` / `เขียว(gate เต็ม)`
- **`verify_foundation.ps1` ไม่ใช่ gate และผ่านไม่ได้** (พิน 79 vs release 105) · `README.md:15` + `AGENTS.md:117` ยังโฆษณาผิด
- **ห้าม force push · check ที่รันไม่ได้ต้อง skip อย่างเปิดเผย**
- **`IMAGE_ACCESS_COST.tsv`** — จดต้นทุนของการอยู่ห่างอิมเมจทุกครั้ง
- **ท่อน "ถ้าปิดคอมแล้วทำอะไร"** — v2 เขียนเป็น **ตารางเลน** (ทำที่นี่ได้ / ต้องเข้าคิวรอเครื่อง) แทนคำว่า "หางานอื่นทำ"
