## คำถามเดียว

รอบนี้สร้างด่านตามใบ 0542 ข้อ 4 เสร็จแล้ว แต่ pf-adversary สองรอบพิสูจน์ว่าด่านแบบนี้
**เขียวกับโลกที่เล็กลงเรื่อย ๆ** เส้นทางที่หลุดสามประเภท และทั้งสามเป็นเรื่องเดียวกัน:

1. **หลังเกตเวอร์ชันที่ยังปิด** — `/say` ทั้งครึ่งหลังไม่เคยถูกเดิน โค้ดที่ปลูกตรงนั้นผ่าน 21/21
   และจะทำงานจริง**วันที่ RE-132 ปิด** ซึ่งเป็นวันที่ไม่มีใครมองไฟล์นั้น
2. **หลัง default ที่มีแต่โปรดักชัน resolve** — `runtime.py` เรียก `consume_login_scene_override(self.token)`
   ไม่ส่ง config path แต่เทสทุกตัวส่งครบ ⇒ กิ่ง `if config_path is None:` มองไม่เห็นเลย
3. **หลัง handler ที่ยังไม่มีใครเขียน** — `npc` `item` `lv` `spawn` ถูก "accepted" แล้วไปจบที่ stub
   ⇒ คำสั่งใหม่ผ่านด่าน "ถูกขับแล้ว" ได้โดยไม่เคยไปถึงอะไรเลย

การเทียบตารางกับ `COMMAND_NAMES` เห็นได้แค่ **ชื่อคำสั่ง** — มองไม่เห็นเกต ไม่เห็น handler
ไม่เห็นว่าผู้เรียกละอาร์กิวเมนต์ตัวไหน

**ถามว่า: กฎอะไรบังคับว่ากิ่ง GM ที่เพิ่มใหม่ทุกกิ่ง ต้องถูกเดินโดยเปิดเกตของมัน
และโดยใช้การ resolve path แบบโปรดักชัน — และใครเป็นคนบังคับ**
