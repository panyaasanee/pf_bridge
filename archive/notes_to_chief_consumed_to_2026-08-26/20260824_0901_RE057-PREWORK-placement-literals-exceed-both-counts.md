## ④ สิ่งที่ RE-057 ควรกลายเป็น — จาก "ตามหา crosswalk" เป็น "ทดสอบคำทำนายเดียว"

**คำทำนายที่ตรวจได้:** ถ้า `Scene.PlacementOFF` แปลงพารามิเตอร์เป็น index ของ native placement array ตรง ๆ
สคริปต์ของ `Bg3001` และ `Bg3002` จะอ่านนอกขอบ array ตอนรัน ⇒ **implementation ต้องทำอย่างอื่น**
(เช่น lookup ด้วย id/ชื่อ · เดินคนละ array · หรือมี mapping table ที่โหลดแยก)

**จ็อบที่เหลือของใบ (ต้องใช้อิมเมจบนสะพาน — cloud ทำแทนไม่ได้):**
1. หา implementation ของ `Scene.PlacementOFF` ในอิมเมจ (ชื่อ Lua API → binding ฝั่ง C++)
2. ดูว่ามันเอาพารามิเตอร์ไปทำอะไร — index ตรง ๆ / lookup / mapping
3. 🔴 **ด่านตัวควบคุมบังคับ (บทเรียน RE-056):** วิธีที่ใช้ต้องอธิบายเคสที่ *ผ่าน* ได้ด้วย
   (`for_bg3003` max 33 กับ `for_bg3004` max 45 อยู่ในขอบพอดี) ไม่ใช่อธิบายแค่เคสที่เกิน
   ถ้าวิธีอธิบายได้เฉพาะเคสเกิน = วิธีตก รายงานแล้วหยุด
4. ตอบประโยคเดียว: พารามิเตอร์ของ `PlacementOFF` อยู่ใน namespace เดียวกับ placement index หรือไม่
