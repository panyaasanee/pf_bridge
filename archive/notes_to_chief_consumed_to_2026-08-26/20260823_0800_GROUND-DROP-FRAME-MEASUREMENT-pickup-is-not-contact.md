# ③ สิ่งที่ยัง **ไม่รู้** (ห้ามเขียนลงดีไซน์เซิร์ฟเวอร์)

1. **ใครเก็บ** — เพ็ตแบบมีระยะ / ผู้เล่นแบบมีระยะ / ตัวจับเวลาฝั่งเซิร์ฟเวอร์ / ลูกเรือ (Olivia) — แยกไม่ออกจากคลิปเดียว
2. **ทำไมต้อง 0.633 s** — เป็นหน่วงคงที่ เป็นแอนิเมชันของตกลงพื้น หรือเป็นคาบสแกนของเซิร์ฟเวอร์ ยังไม่รู้
3. **รัศมีเก็บ** — วัดไม่ได้ เพราะแปลง px -> หน่วยโลกไม่ได้ (ไม่รู้ FOV/มุมกล้อง)
4. **สิทธิ์/ล็อกเจ้าของ** — คลิปนี้อยู่ในทีม (มี `[ทีม] ShooterX`, `[ทีม] Namzicaเ-ω-` ในแชท) แต่ไม่มีหลักฐานว่าใครหยิบได้บ้าง
5. **ของหายเองไหมถ้าไม่มีใครเก็บ** — ในคลิปนี้ไม่มีเคสที่ปล่อยทิ้งไว้
6. **ของเควสเด้งเข้าตัวทันที** — Panya เล่าไว้ แต่**ยังไม่มีเฟรมยืนยันในคลิป B** ต้องหาเคสในคลิปอื่น

# ④ สิ่งที่ใช้ได้ทันทีฝั่งเซิร์ฟเวอร์ (ระดับพฤติกรรมที่สังเกตได้ ไม่ใช่ระดับ wire)

1. ต้องมี **entity ชั่วคราวบนพื้น** ที่มี: ตำแหน่งในโลก + ชื่อไอเทมสำหรับป้ายลอย + โมเดล 3 มิติ
2. อายุของ entity นั้นในเคสนี้ = **0.633 s** (สั้นมาก — ไม่ใช่กองของค้างพื้นแบบเกมอื่น)
3. **การลบของ + ข้อความ "ได้รับ" เป็นเหตุการณ์เดียวกันในสายตาไคลเอนต์** ⇒ ฝั่งเซิร์ฟเวอร์ควรส่งเป็น response ก้อนเดียว ไม่ใช่สองก้อนที่มาไล่กัน
4. ข้อความ `ได้รับ [<ชื่อ>] * <จำนวน>` เป็น **สีเขียว** ต่างจาก `ได้รับ EXP <n> แต้ม!` และ `ได้รับค่าฝีมือ <n> แต้ม!` ที่เป็น**สีขาว** ⇒ คนละประเภทข้อความ/คนละ channel ไม่ใช่ข้อความระบบก้อนเดียวกัน
5. ลำดับที่เห็นหลังมอนตาย: `ได้รับ EXP 1159 แต้ม!` -> `ได้รับค่าฝีมือ 579 แต้ม!` -> `ได้รับ [ Red leaves Hammer ] * 1`
6. รางวัลจบดันเจียนเป็น**หน้าต่างเลือกรางวัล** ไม่ใช่ของตกพื้น (จากรายงาน `01_ground_loot.md` t000882/t000886) — คนละกลไก อย่าเอามารวมกัน
