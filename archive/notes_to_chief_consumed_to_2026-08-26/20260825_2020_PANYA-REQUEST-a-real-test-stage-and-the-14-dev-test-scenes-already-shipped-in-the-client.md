## ③ 🔴 สิ่งที่ **ยังไม่รู้** — และห้ามใครอ่านข้อ ② ว่าเป็นคำตอบ

1. **`.npc` เก็บแต่ placement ของ NPC — ไม่ได้บอกภูมิประเทศ** ⇒ `0 placements` แปลว่า "ไม่มี NPC" **ไม่ได้แปลว่า "ห้องขาวเรียบว่าง"** · เรขาคณิต/พื้น/น้ำ อยู่ในไฟล์ฉากส่วนอื่นที่ยังไม่มีใครเปิด
2. **แมพเทสของนักพัฒนา (`AirTest` · `PlayerViewer` · `MobTest` …) ไม่มี `n_ID` ในตารางฉาก** ⇒ **อาจส่งไคลเอนต์ไปด้วย scene id ปกติไม่ได้** — ยังไม่มีใครลอง
3. **ยังไม่มีใครส่งไคลเอนต์ไปฉากอื่นนอกจาก `scene_id = 1` เลยสักครั้งในประวัติโปรเจกต์**
   🟢 แต่ทางเดินมีอยู่แล้ว: `scene_id` เป็นพารามิเตอร์จริงในโค้ดเรา (`pf_login_game_server_v141.py:1139 make_npc_attr(..., scene_id: int = 1, ...)`) และมีเลนเทเลพอร์ต (`V113_TELEPORT_SCENE1_*`) ⇒ **เป็นคำถามที่วัดได้ ไม่ใช่ความฝัน**
