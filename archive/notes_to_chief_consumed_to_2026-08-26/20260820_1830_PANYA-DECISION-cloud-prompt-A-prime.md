## 🆕 ทาง A′ — **"chief merge ให้ตัวเองในรอบถัดไป"**

**ที่มา:** ทาง A ที่ chief แนะนำถูกต้องในหลักการ (โค้ดต้องผ่าน Actions ก่อนแตะ `main`)
**แต่มันตั้งอยู่บนสมมติฐานว่า Panya กด Merge เอง** — พอ cadence เป็นรายชั่วโมง
แปลว่า **เธอต้องกด Merge วันละ 24 ครั้ง** ซึ่งคือการกลับไปเป็นสายพานส่งของด้วยมือ
**ซึ่งเธอปฏิเสธชัดเจนแล้วเมื่อ ~15:20** (*"ฉันต้องมานั่ง push อะไรๆ ต่อจากนี้อย่างงั้นหรอ"*)

### กลไก
**รอบ N (ตอนจบรอบ):**
- commit งานของรอบ → push ขึ้น **`claude/rNNN-<เรื่อง>`** · **หนึ่งรอบหนึ่ง branch เท่านั้น**
- **ห้ามแตะ `main` ในรอบเดียวกับที่สร้างงาน**

**รอบ N+1 (งานแรกสุดของรอบ ก่อนทำอะไรทั้งสิ้น):**
1. `git fetch --all`
2. หา branch ของรอบก่อน แล้ว **อ่านผล Actions ของ commit ปลาย branch นั้น**
   (Claude GitHub App มีสิทธิ์ **Actions: Read and write** ⇒ อ่าน conclusion ได้)
3. แยกสามทาง:
   - **เขียว** ⇒ **fast-forward `main` ไปหา branch นั้น** → push `main` → ลบ branch → **แล้วค่อยเริ่มงานใหม่**
   - **แดง** ⇒ 🔴 **ห้าม merge · ห้ามเริ่มงานใหม่** — **งานทั้งรอบคือทำให้มันเขียว** แล้ว push ทับ branch เดิม
   - **ยังรันอยู่/ไม่พบผล** ⇒ **ไม่ merge รอบนี้** · ทำงานใหม่บน branch ใหม่ได้ · **เขียนในจดหมายว่ามีกี่ branch ค้าง**

### ข้อบังคับ
- 🔴 **fast-forward เท่านั้น** — ถ้า `main` ขยับไปแล้วจนไม่ ff ได้ **หยุดและรายงาน ห้าม force ห้าม merge commit**
- 🔴 ต้นรอบ **rebase branch งานใหม่บน `main` ล่าสุดเสมอ**
- 🔴 **ถ้ามี branch ค้างยังไม่ merge ตั้งแต่ 2 อันขึ้นไป ⇒ หยุดเปิดงานใหม่ ทั้งรอบใช้ไล่เคลียร์ของค้าง**
  (กันไม่ให้ branch ซ้อนกันจนไม่มีใครตามได้ ซึ่งเป็นข้อเสียข้อเดียวของทาง A ที่ยังเหลืออยู่)
- **รอบแรกสุดไม่มี branch ก่อนหน้า** — เขียน bootstrap case ไว้ให้ชัด อย่าให้มันงงแล้วหยุด
- **`pf_bridge` ยังเป็น "commit ลง `main` ตรง ๆ" ตามทาง A เดิม** — เอกสารล้วน ไม่มี gate ผู้เทสต้องได้ใบสั่งทันที

### ผลที่ได้
✅ `main` ของโค้ด **ไม่มีวันแดง** · ✅ Panya **ไม่ต้องกดอะไรเลย** · ✅ ผู้เทส `pull main` ได้ของที่ **พิสูจน์แล้วว่าเขียว** เสมอ
⚠️ ราคาที่จ่าย: **`main` ตามหลังงานล่าสุดหนึ่งรอบ** ⇒ **ถ้ารายการเทสในคิวต้องใช้ commit ที่เพิ่งลง branch
ต้องเขียนกำกับในคิวว่า "รอ merge รอบหน้าก่อน"** ห้ามปล่อยให้ผู้เทสไปหา commit ที่ยังไม่อยู่บน `main`
