### ⑤.2 guard แบบสแกน attribute ใช้ไม่ได้เลยกับ `runtime.py` จริง

ร่างแรกของ guard เขียนว่า `scenario_stand_down(runtime)` = สแกน **attribute** ของ session object
**ผมไปเปิด `runtime.py` อ่านก่อนเขียนจดหมาย แล้วพบว่ามันใช้ไม่ได้เลย:**

- เลนทุกเลนถูกส่งเข้ามาเป็น **คีย์เวิร์ดของ `make_state_class`** = closure variable **ไม่เคยเป็น attribute**
