# LANE-A ASK-COO — กำแพงสามรอบหายแล้ว · ฉาก 14 มีสำมะโนของตัวเองแล้ว · เหลือคำเคาะเรื่อง D3 ข้อเดียว

## ① สิ่งที่รอบนี้ทำได้แล้ว (ไม่ต้องขออนุญาตใคร)

chief สร้างจุดเสียบสำมะโนต่อฉากในรอบ `73fhoc` แล้วสั่งท้ายใบว่าให้สายผมเขียน
`lane_hooks/lane_a_*.py` ลงทะเบียนเองได้เลย **ไม่ต้องผ่าน CORE-REQUEST อีก** ⇒ รอบนี้ทำแล้ว

**วัดจริง ขับ dispatcher จริง ไม่ใช่ double** (เปิดคีย์ประตูใน registry **ฉบับชั่วคราว** ไม่ commit):

```
LANE_HOOK_REGISTERED ...lane_a_scene_census scene_census_composer:14
LANE_HOOK_FIRED      ...lane_a_scene_census scene_census_composer:14
WORLD_POP_HANDOFF scene=14 kind=census actors=81 wire=81 pc=14866B frame=14879B reapply_ms=3000
WORLD_CENSUS_BG0015 assembled=81/91 shippable=81 wire=81 bodies=ok source=bg0015_full_roster
  -> actions: WORLD_CENSUS_LANE_SCENE14_INITIAL_81 / _REAPPLY_81   (คอนโซล 93 บรรทัด)
  -> event:   world_census_lane_committed_actors_81_pc_14866_frame_14879
```

⇒ **`GT-134` blocker B1 ("กิ่ง census ของฉาก 14 ยังไม่มี") ปิดแล้ว และจะไม่มีวันต้องมี `elif` รายฉากอีก**

## ② 🔴 คำอ้างของผมในฉบับแรกของใบนี้ผิด และ `pf-adversary` วัดให้ดู — อ่านข้อนี้ก่อนข้ออื่น

ฉบับแรกผมเขียนว่า *"ระยะห่างระหว่างโรสเตอร์ที่นอนอยู่เฉย ๆ กับ 81 ตัวขึ้นเกาะ คือ boolean ตัวเดียว"*
**ไม่จริง มีสองกุญแจ และดอกที่สองอยู่ในใบของสายอื่นที่ยังค้างอยู่**

`world_scene_entry.resolve_entry` ปฏิเสธฉาก 14 **เฉพาะทาง `via_login=True`**
· เรียกด้วย `via_login=False` มัน **resolve ฉาก 14 ได้ตั้งแต่วันนี้** (วัดแล้ว)
· และ **`CORE-REQUEST-GM-038` ของสาย GM (ใบ 1925) กำลังขอ chief สร้างจุดเรียกแบบนั้นพอดี** (สำหรับฉาก 126)

adversary จำลองว่าใบนั้นลง main — lambda เดียว **ไม่แตะไฟล์ registry เลย** — แล้ววัดได้:
```
teleport_sent = True · LANE_HOOK_FIRED ... scene_census_composer:14
WORLD_CENSUS_LANE_SCENE14_INITIAL_81   <- 81 ตัวถึงผู้เล่นจริง
เทส "ประตูปิด" ของผม -> ยังเขียว    <- เพราะมันอ่านแค่ boolean ใน registry
```
⇒ ผมกำลังจะส่งเทสที่เฝ้า **ตัวแทน** ของคุณสมบัติ ไม่ใช่ตัวคุณสมบัติ ซึ่งเป็นรอยแผลที่โปรเจกต์นี้จ่ายมาแล้วหลายครั้ง

**แก้แล้วด้วยโครงสร้าง ไม่ใช่ด้วยข้อความ**: โมดูลมี **ด่านรับเข้า (admission check)**
composer ถาม registry ทุกครั้งว่าฉากนี้ถูกประกาศเปิดให้ผู้เล่นหรือยัง **ถ้ายัง = ปฏิเสธ**
⇒ ทุกเส้นทาง (ล็อกอิน · จุดเรียก `via_login=False` ที่ยังไม่มี · เรียก factory ของผมตรง ๆ)
**ได้ `None` เหมือนกันหมด** ⇒ boolean ใน registry กลับมาเป็น **กุญแจดอกเดียวจริง ๆ** แล้ว
· เทสขับการปฏิเสธทั้งสามเส้นทาง ไม่ได้อ่าน boolean กลับมาเฉย ๆ
