# PANYA-ORDER — ทิ้งไมล์สโตนไว้ก่อน ทุ่มทุกสายไปที่สามเรื่องนี้

## provenance

ผู้สั่ง: **Panya (เจ้าของ)** · เคาะในแชท attended ~02:0x-02:1x น. 1 ก.ย. 2026 หลังจบรอบเทส GT-172 ด้วยตัวเอง
ผู้เขียนแทน: กะ1-A · คำพูดของเธอ (ตามที่พิมพ์มา):

> *"ทุ่มทุกอย่าง ทุกกำลังทุกทีมไปกับสามอย่างนี้ก่อน ไอเท็มอยู่บนพื้นนาน ต้องมองเห็นมอนถูกต้อง
> และต้องเปิดปุ่ม gm ได้ ลืมเรื่อง mile stone ไปก่อน codex จะคอยป้อนข้อมูลที่มีประโยชน์จากการ
> แกะ binary เข้ามาอยู่เรื่อยๆจงใช้ให้เกิดประโยชน์"*

## 1. สามเรื่องนี้มาก่อนทุกอย่าง (เรียงตามที่เจ้าของพูด)

**P-1 ไอเท็มที่ดรอปต้องวาดค้างอยู่บนพื้นให้นาน** — ตอนนี้ของที่ตกไม่อยู่นานพอให้เดินไปเก็บได้จริง

**P-2 ต้องมองเห็นมอนสเตอร์ในสถานะที่ถูกต้อง** — เกณฑ์ของเจ้าของ ชัดเจน ไม่ต้องตีความ:
| สถานะ | สีชื่อที่ต้องเห็น |
|---|---|
| ปกติ | **ส้ม** |
| กำลังสู้ | **แดง** |
| ตายแล้ว | **เทา** |
🔴 **ห้ามเป็นสีชมพู** ซึ่งเป็นสิ่งที่เห็นอยู่ตอนนี้

**P-3 เปิดปุ่ม GM ให้ได้สักที** — เจ้าของจะเร่งให้ Codex ถอดวิธีเปิดจากไบนารีให้

## 2. สิ่งที่หยุดไว้ก่อน

- **ไมล์สโตน M1-M6 ทั้งหมด: พักไว้** ไม่ต้องนับ ไม่ต้องรายงานว่าเลยกำหนด ไม่ต้องใช้เป็นเหตุผล
  จัดลำดับงาน จนกว่าเจ้าของจะสั่งกลับมา
- **เจ้าของจะไม่เทส `GT-146` (คลิกของดรอป) และใบตีมอนทั้งหมด** จนกว่า **P-1 และ P-2 จะเสร็จ**
  ⇒ อย่าเสนอสองใบนี้เข้าคิว attended อีกจนกว่าจะถึงตอนนั้น (นี่คือเหตุผลว่าทำไม M5 ถึงพักได้)

## 3. งานสร้างใหม่ที่เจ้าของสั่งเพิ่ม (หลังจาก P-1..P-3 หรือคู่ขนานถ้าคนละสาย)

**GM-A `/warp <เลขแมพ>` แบบไม่ใส่พิกัด ต้องไปโผล่ที่จุดเกิดมาตรฐานของแมพนั้นอัตโนมัติ
และข้ามฉากได้ทันทีในเกม ไม่ต้องออกเข้าใหม่** — วันนี้มีสองท่าและไม่มีท่าไหนทำแบบนี้:
ใส่พิกัด = ข้ามฉากทันทีแต่ต้องพิมพ์พิกัดเอง (และ z ผิดจนตัวติดแมพ), ไม่ใส่พิกัด = ตั้งฉากล็อกอิน
รอ relog เจ้าของต้องการ **สองอย่างรวมกัน**: ไม่ใส่พิกัด + ไปที่จุดเกิดจริง + ทันที

**GM-B `/speed <ค่า>`** — เพิ่มความเร็วเคลื่อนที่ของตัวละคร เพื่อให้เดินสำรวจแมพได้เร็ว
(กลไกนี้เคยพิสูจน์แล้วว่าทำได้จริงจาก `PF_ADHOC_ATTR_PROBE` ที่เจ้าของเคยเทสเอง)

**UI-A ปุ่มกลับหน้าเลือกตัวละคร และกลับเข้าเกม ต้องใช้งานได้** — วันนี้ใช้ไม่ได้ ทางเดียวคือปิด
หน้าต่างด้วย X ซึ่งทำให้ทุกรอบเทสแพงขึ้นมาก (บูตใหม่ทั้งรอบเพื่อเปลี่ยนฉากหนึ่งครั้ง)

**UI-B ปุ่ม logout จริง ต้องใช้งานได้** (ตัวที่ไม่ใช่ X ปิดหน้าต่าง)

## 4. เซิร์ฟเวอร์ต้องส่ง NPC เอง ห้ามรอให้เจ้าของเดิน

🔴 คำสั่งตรง: **"ต่อไปนี้เซิฟเวอร์ต้องส่ง npc เองเลยก่อนที่ฉันจะต้องเริ่มก้าวเดิน ... ห้ามให้มีรอบไหน
ที่ฉันต้องเดินเพราะ spawn เรียก npc ขึ้นมาอีก"**

เจ้าของยืนยันว่า**เคยทำได้แล้ว** ตอนเทสเกาะคุกรอบแรก ๆ ⇒ ไม่ใช่ของใหม่ที่ต้องคิดค้น เป็นของที่เคยมี
แล้วหายไป ขอให้สายที่เกี่ยวข้องไปหาว่าตอนนั้นทำอย่างไรแล้วเอากลับมา

## 5. Codex (สาย RE) เป็นแหล่งข้อมูลหลักของ P-3

เจ้าของจะสั่ง Codex ให้เร่งแกะไบนารีเรื่องปุ่ม GM และจะป้อนผลเข้ามาเรื่อย ๆ
🔴 **"ถ้ามันส่งข้อมูลที่มีประโยชน์มาจงรีบใช้ซะ"** — ใบผลจาก Codex ที่แตะ P-1/P-2/P-3 ต้องถูกหยิบ
ในรอบถัดไปทันที ไม่ใช่เข้าคิวรอ

## 6. ที่ขอจาก chief โดยตรง

1. ประกาศลำดับใหม่นี้ให้ทุกสายรับรู้ในรอบถัดไป และจัดสายเจ้าของงานให้ P-1 / P-2 / P-3 อย่างละสาย
   **ระบุชื่อสายให้ชัด หนึ่งเรื่องหนึ่งสาย** ตามกฎผู้รับสายเดียว
2. ปรับหัวไฟล์คิวให้สะท้อนว่าไมล์สโตนพักแล้ว และ `GT-146`/ใบตีมอน **ไม่รับเข้าคิว attended** ชั่วคราว
3. เปิดใบสำหรับ GM-A / GM-B / UI-A / UI-B ตามรูปแบบปกติ พร้อมป้ายหมวด
   (`STATIC-ON-BRIDGE` / `STATIC-ON-CLOUD` / `NEEDS-ATTENDED-CAPTURE`) ตามกฎที่เพิ่งคืนมารอบ R276
