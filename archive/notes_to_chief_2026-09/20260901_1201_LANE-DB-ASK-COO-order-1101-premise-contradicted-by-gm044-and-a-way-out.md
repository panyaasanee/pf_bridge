## ทางออกที่วัดมาแล้วรอบนี้ ไม่ใช่ข้อเสนอลอย ๆ

ถ้าเลิกมองหา "บล็อบดิบของจริง" แล้วให้ **DB เป็นเจ้าของทั้งบล็อกทุกฟิลด์** ตามภารกิจของสายนี้เอง
คำถามจะเปลี่ยนจาก "จะไปเอาบล็อกปัจจุบันจากไหน" เป็น "ทุกฟิลด์มีแหล่งที่ไม่ใช่การเดาไหม"
ผมจับคู่ตาราง `FIELDS` ทั้ง 55 แถว (`gm/attr_wire.py:166-224`) กับคอลัมน์ `default_value` /
`default_writer_va` ใน `reference_codex_attr/PF_ATTR_FIELD_SEMANTICS.tsv` รอบนี้ ได้การแบ่งที่ลงตัวพอดี:

```
55 = 28 + 20 + 7
28  ฟิลด์  มี default ของ client เอง structural_status=PROVEN_EXACT ในตาราง codex
          (เกือบทั้งหมดคือฟิลด์ที่ FIELDS ทำเครื่องหมาย known=False = ฟิลด์ "ไม่รู้จัก" นั่นแหละ)
20  ฟิลด์  ไม่มีแถวใน codex แต่เป็นฟิลด์ที่ "เซิร์ฟเวอร์ต้องเป็นเจ้าของ" อยู่แล้ว —
          level hp_current hp_max mp_current mp_max class_id skill_points unspent_points
          str con dex int per experience cash bonus_str bonus_con bonus_dex bonus_int bonus_per
          = typed column ของสายนี้เป๊ะ ๆ ตามภารกิจ (และคือ M4 ทั้งดุ้น)
 7  ฟิลด์  ช่องว่างจริงที่เหลือ ไม่มีทั้ง default และชื่อ:
          x=14 nameboard_key 0x090 u32 · x=25 wstr_B0 0x0B0 · x=36 u8_18C 0x18C u8 ·
          x=41 q_140_pairB 0x140 u64 · x=42 u8_9B_pairB 0x09B u8 (สองตัวนี้แชร์ mask bit เดียวกัน) ·
          x=43 wstr_CC 0x0CC · x=54 u16_1B0 0x1B0 u16
```

ความหมาย: ทางตันเรื่อง "ทาง 1 vs ทาง 2" ที่ค้างมาหลายวัน **หดเหลือคำถามที่นับได้ 7 ข้อ** —
"ค่า default ที่ client เขียนเองตอนสร้างวัตถุของ 7 ฟิลด์นี้คืออะไร" ซึ่งเป็นคำถามชนิดเดียวกับที่
ตาราง codex ตอบไปแล้ว 28 ครั้ง ด้วยวิธีเดียวกัน (`default_writer_va`) ไม่ใช่คำถามเปิด

ถ้าได้ 7 ค่านั้น เซิร์ฟเวอร์จะประกอบบล็อกเต็มได้โดย **ทุกฟิลด์มีที่มา**: ค่า typed ของตัวละครจาก DB
หรือ default ของ client เองที่พิสูจน์แล้ว — ไม่มีฟิลด์ไหนถูกเดาเป็นศูนย์เลยแม้ฟิลด์เดียว ตรงตาม
ข้อห้ามของเจ้าของในใบ `1059` และตรงกับคำว่า "typed columns เป็นแหล่งความจริง" ในใบ `1100`

   `/speed` อยู่ตอนนี้ ไม่ใช่โค้ด
3. **กำหนดใน `1101` (`/speed` เข้าคิวเทส attended ภายใน 2026-09-02 12:00) มีความเสี่ยงพลาด**

2. ไม่อ้างว่าคำว่า "ละฟิลด์ไว้ = client เซ็ตเป็นศูนย์" (bulk copy `0x464F30`) เป็นจริง — มันยังเป็น
   static claim ที่ `gm/attr_wire.py:67-73` เองบอกว่าไม่เคยวัดกับค่าที่ไม่เป็นศูนย์จริง

3. ไม่อ้างว่า 20 ฟิลด์กลุ่ม B ครบตามที่ game client ต้องการจริง — เป็นการอ่านชื่อจาก `FIELDS`
   ไม่ใช่การพิสูจน์ว่า client แสดงผลครบทุกตัว
4. ไม่ได้แตะไฟล์ของสายอื่นแม้ไฟล์เดียวรอบนี้
