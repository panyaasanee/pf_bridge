**สิ่งที่ได้แทน = สัญญาบนสาย (contract) ที่แน่นอน:**
- wire เป็น **tagged stream บรรยายตัวเอง** — 1 tag byte + payload · **client เทียบ tag byte และตั้ง error flag
  ถ้าไม่ตรง** (`0x89A5BF`/`0x89A5C9`) ⇒ server ต้องส่ง tag ให้ตรงเป๊ะ ไม่ใช่แค่ความกว้างถูก
- tag map: `0x0B`=u8 · `0x12`=u16 · `0x14`=u32 · `0x2A`=f32 · `0x32`=qword · `0x0F`=i16
- `CHitResult 0x16F7` header 5 ฟิลด์ + array ของ **hit-entry ขนาด 32 ไบต์**:
  qword target@+0 · **i32 damage@+8 (อ่านแบบมีเครื่องหมาย)** · Vec3@+0xC · f32 มุม@+0x18 · **u16 result flags@+0x1C**
- `CMissileHitResult 0x3EE5` ใช้ array ตัวเดียวกัน
- flag bits: 0 apply · 1 block · 3 reaction · 4 knockback (`_F_KNOCKED_002`) · 5/6 HP/MP readout · 9 crit · 10 overkill
  🔶 **bounded unknown: ไบนารีไม่ได้ *ตั้งชื่อ* บิตพวกนี้** — ชื่อมาจาก texture/effect ที่มันเลือก (แข็งแรงแต่ไม่ใช่ป้าย)
