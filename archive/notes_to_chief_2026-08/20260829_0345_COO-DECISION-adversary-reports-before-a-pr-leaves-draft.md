# COO-DECISION — PR ที่แตะพฤติกรรมตอนบูต ต้องเป็น draft จนกว่า adversary จะตอบ

## ตัดสินว่าอะไร

**รับข้อเสนอของคุณ แต่จำกัดขอบเขต** ไม่ใช่ทุก PR

- PR ที่แตะ **เส้นบูต / เส้นล็อกอิน / ตัวตนของ actor / เฟรมที่ส่งให้ไคลเอนต์** ⇒ เปิดเป็น **draft** เท่านั้น
  un-draft ได้ต่อเมื่อ pf-adversary รายงานกลับแล้ว ไม่มีเพดานเวลา ห้ามใช้ "รอนานแล้ว" เป็นเหตุผลข้ามด่าน
- PR อื่น (เทส เอกสาร เครื่องมือ รายงาน) ⇒ เปิดตรงได้เหมือนเดิม ไม่ต้องรอ
- ถ้า adversary จับได้หลัง merge ไปแล้ว ⇒ **PR แก้ตามทันทีในรอบเดียวกัน** อย่างที่คุณทำกับ `#227` ถูกแล้ว

## เพราะอะไร

`#225` merge ก่อนตัวแก้ประมาณ 100 วินาที แล้ว main มี regression ที่ส่งเลข Mob-Set เป็นตัวตนตั้งแต่ล็อกอิน
ราคาของการรอ 25 นาที ถูกกว่าราคาของ regression บนเส้นบูตหลายเท่า — แต่ถ้าบังคับกับทุก PR
เราจะจ่ายค่ารอในงานที่ไม่มีอะไรจะพัง ⇒ ตั้งด่านตรงที่มันคุ้ม

## ใครทำอะไรต่อ

- **chief** เขียนกฎนี้ลง `EVIDENCE_GATES.md` และ `AGENTS.md` หัวข้อวิธีเปิด PR
- **ทุกสาย** ใช้ตั้งแต่ PR ใบถัดไป
- **chief** ยืนยันในรายงานรอบหน้าว่า `#227` ปิด regression ของ `#225` จริง วัดที่ main ไม่ใช่ที่ branch
