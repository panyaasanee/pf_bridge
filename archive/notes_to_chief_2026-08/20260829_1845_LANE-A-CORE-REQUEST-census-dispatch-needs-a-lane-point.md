## ขออะไร (หนึ่งอย่าง เล็ก และเป็นแบบที่ repo นี้ใช้อยู่แล้ว)

🔴 **ไม่ได้ขอให้เปลี่ยนสัญญาของ `fire()`** — รู้อยู่ว่า `fire()` คืนค่าไม่ได้โดยตั้งใจ
และการประกอบสำมะโนต้องส่ง actor กลับ ⇒ hook แบบเดิมใช้ไม่ได้กับงานนี้

ขอ **แบบที่ `lane_gm_chat_command` ใช้อยู่แล้ว** (COO-DECISION 20260829_0041 ทางเลือก (b)):
call site อ่านแฟล็กก่อนแล้วเรียกตรง

ที่จุดเลือกสำมะโนตามฉาก แทนที่จะเพิ่ม `elif` ที่สี่ ขอให้ถามตารางเดียว:

```python
composer = lane_hooks.scene_census_composer(scene_id)   # None = ไม่มีสายไหนลงทะเบียนฉากนี้
if composer is not None and lane_hooks.module_production_allowed(composer.module):
    ...ใช้ผลของมัน...
else:
    ...สาขาเดิมทั้งหมด ไม่แตะ...
```

- ฉาก 1 / 2 เดินสาขาเดิมเป๊ะ ไม่ต้องย้ายอะไร **ไม่มี regression path**
- สายไหนอยากรับผิดชอบฉากไหน ลงทะเบียนเองในไฟล์ `lane_hooks/lane_<x>_*.py` ของตัวเอง
- `production_allowed` ยังเป็นเกตเดิม · fail-closed เดิม · โทเคนคอนโซลตอนลงทะเบียนและตอนยิงจริงเหมือนเดิม
- chief ยังรีวิวทุก PR ที่แตะ `lane_hooks` เหมือนเดิม — ที่หายไปคือ chief ในเส้นทางวิกฤต **ของการเดินสาย** เท่านั้น
