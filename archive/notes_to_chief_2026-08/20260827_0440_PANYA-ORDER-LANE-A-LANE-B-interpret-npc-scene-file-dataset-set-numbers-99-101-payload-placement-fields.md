## คำถามที่ขอให้ตอบ (แต่ละสายตอบในมุมตัวเอง)

**สาย A (WORLD/เมือง):**
1. เลขชุด 1..N / 99 / 101+ ตีความว่าอะไร — มีตาราง/สคริปต์ฝั่งไคลเอนต์ที่กินเลขชุดไหม (crosswalk จริง ไม่ใช่เลขเท่ากัน)
2. 11 placements ที่มี extra triples = เส้นทางเดินจริงไหม — ถ้าใช่ เสนอวิธีส่งให้ NPC เดิน (ผูกกับ `RE-083` actor_type 2 / ActorMove)
3. version2_byte = 0 (33 จุด) กับ b5/b15 ของ definition — ตัวไหนน่าจะเป็น "แสดง/ซ่อน" · ถ้าเราส่งเฉพาะ version2_byte=1 (116 จุด) จะใกล้ "จำนวน NPC จริงของเมือง" กว่า 115 ไหม
4. ขอ**ตารางเสนอ "ชุดไหน = NPC ไหน" สำหรับ Port Royal** ทีละแถวเท่าที่อนุมานได้จาก (ก) พิกัด vs ภาพ REF (ข) ชุดที่มีหลายจุด (Mob_Set_42 ×11 ไม่น่าเป็น NPC บริการ) (ค) เส้นทางเดิน — ติดป้ายทุกแถวว่าเป็นสมมติฐาน แล้วให้ Panya เป็นคนยืนยันบนจอ

**สาย B (COMBAT/สนาม):**
1. field ของ placement ในสนาม (u16_0, u16_1/3, u16_2, u16_5, f32_3/4/5) ตีความเป็นอะไร เทียบกับสิ่งที่สายรู้แล้วเรื่อง mob AI/aggro/leash/respawn (`RE-067/068`, `field_mob_ai_tables`)
2. b5/b15/u32=100 ของ definition — สัมพันธ์กับ level/rank/อัตราเกิดของมอนสเตอร์ไหม (ลองเทียบ Bg0015 ที่สายมี `field_mob_tables_bg0015.py` อยู่แล้ว)
3. ถ้ากลุ่ม 101+ คือ NPC บริการ/บอส และ 1..N คือมอนสเตอร์ — ตรวจกับ Bg0015 ได้ไหมว่า placements ของชุด 1..36 vs 101..115 ต่างกันตรง field ไหน
