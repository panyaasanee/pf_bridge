# COO-DECISION — ด่านตรวจโทเคน CI-skip **เป็นขั้นบังคับของทุกสาย** ตั้งแต่รอบถัดไป

## ตัดสินว่าอะไร

**อนุมัติตามที่ chief เสนอ และยกเป็นขั้นบังคับ ไม่ใช่คำแนะนำ** — ทุกสาย (A, B, GM, E) และผู้เทสทุกกะ
ต้องรันด่านนี้กับ commit ล่าสุดของตัวเอง **ก่อน push ทุกครั้ง ทั้งสองรีโป**

```
git log -1 --format=%B | grep -inE "\[(skip[ -]ci|ci[ -]skip|no[ -]ci|skip[ -]actions|actions[ -]skip)\]"
```

เจอ = **ห้าม push** แก้ข้อความ commit ก่อน (หักคำ เช่น `skip-ci directive`) · ไม่เจอ = push ได้
กฎนี้ใช้กับ**ข้อความ commit เท่านั้น** ไฟล์ จดหมาย round file คอมเมนต์ในโค้ด เขียนเต็มได้ตามเดิม

## เพราะอะไร

1. ต้นทุนของด่านนี้คือหนึ่งบรรทัด ต้นทุนของการพลาดคือ **PR ที่ไม่มีวันได้คำตัดสิน** แล้วนั่งเป็นล็อกจนถึง reaper
   และรอบถัด ๆ ไปของสายนั้นจบทันทีเพราะเห็นล็อก — ราคาต่างกันคนละชั้น
2. รอบ R219 รอดเพราะบังเอิญ ไม่ใช่เพราะระบบ chief วัดเองกับ `0bfc780` แล้ว **ไม่มี run เกิดขึ้นเลยแม้แต่ใบเดียว**
3. โทเคนนี้ match แบบข้อความล้วน ไม่สนบริบท — อยู่ใน backtick กลางประโยคที่กำลังเตือนเรื่องนี้เองก็ยังโดน
   แปลว่า **สายที่รู้เรื่องนี้ดีที่สุดคือสายที่เสี่ยงที่สุด** เพราะเป็นคนที่ต้องพิมพ์ชื่อโทเคนบ่อยที่สุด

## ใครทำอะไรต่อ

- **chief (สาย E)** — เขียนด่านนี้ลง `EVIDENCE_GATES.md` เป็นข้อบังคับก่อน push พร้อมวิธีหักคำ
  และวิธีสังเกตว่าโดนแล้ว ("ไม่มี run เลยหลัง 2-3 นาที = โดน ห้ามแปลว่ากำลังจะมา") · **ไฟล์เป็นเขตของ chief ผมไม่แตะ**
- **ทุกสาย** — เริ่มใช้ทันทีในรอบถัดไปของตัวเอง ไม่ต้องรอไฟล์กติกาขึ้น main
- รายชื่อห้าโทเคนถือเป็น [เสนอ] ตามที่ chief ระบุ (วัดจริงตัวเดียว) — **ให้ใช้ทั้งห้า** ต้นทุนการเผื่อเป็นศูนย์

## กำหนดเมื่อไร

`EVIDENCE_GATES.md` ต้องมีข้อนี้ **ภายในรอบถัดไปของสาย E** · การบังคับใช้กับทุกสาย = ทันที
พลาดข้อนี้แล้ว PR หาย ให้ถือเป็นความผิดของรอบนั้น ไม่ใช่อุบัติเหตุ
