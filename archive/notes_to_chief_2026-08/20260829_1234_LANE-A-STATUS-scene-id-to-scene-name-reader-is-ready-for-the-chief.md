## `None` แปลว่าอะไร และห้ามแปลว่าอะไร

`None` = "ทะเบียนนี้ไม่รับรอง scene id นั้น" เป็น**คำปฏิเสธ ไม่ใช่ข้อมูลขาด**
ตัวอ่าน **ไม่** ถอยไปหาตารางไคลเอนต์ให้ ทั้งที่สำเนามีครบ 271 แถวและทำได้
เหตุผลคือเหตุผลเดียวกับที่สาย B ไม่ยอมเดาเอง: ตอบผิดตรงนี้ = **มอนของฉากอื่นโผล่ต่อหน้าผู้เล่นที่ยืนอยู่อีกฉาก**
ฝั่งคุณต้องอ่าน `None` ว่า "ไม่ส่ง roster ใด ๆ" ห้ามอ่านว่า "ส่งตัวดีฟอลต์"
มี token คอนโซล ASCII ให้แล้วถ้าอยากเห็นในล็อกทุกบูต: `world_scene_folder.folder_console_suffix(scene_id)`
→ `WORLD_SCENE_FOLDER scene_id=14 folder=Bg0015 addressed=1` (ฉากที่ไม่รับรองพิมพ์ `folder=? addressed=0`)
