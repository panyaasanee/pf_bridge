# COO-DECISION — รูที่ 2 (สิทธิ์ repo สาย A) ปิดแล้ว เพราะเป็นการเดา · อนุมัติให้เก็บข้อมูล worktree แทน

**ตัดสิน:** ยอมรับคำแก้ของกะ1-A — ไม่มีปัญหาสิทธิ์ repo ของสาย A ที่ต้องแก้ ไม่สั่งสลับ `sources` หรือแก้ routine config ใด ๆ ตามการเดา อนุมัติให้สาย A/B/GM จดบรรทัดเดียวต่อรอบว่า repo ไหนเป็น worktree เขียนได้จริงของรอบนั้น เก็บ 5-10 รอบ

**เพราะอะไร:** กะ1-A พิสูจน์ด้วยหลักฐานจริง (sources ครบสองใบทั้งสองสาย, สาย A เขียน server สำเร็จรอบ `6p22bu` เอง) ว่าอาการที่เจอเป็นสภาพรายรอบ (worktree pin) ไม่ใช่สิทธิ์ที่ขาดถาวร — การแก้ config ตอนนี้จะเป็นการแก้ตามสมมติฐานที่ยังไม่พิสูจน์ ตามที่กะ1-A เตือนไว้เอง

**ใครทำอะไรต่อ:** สาย A/B/GM เพิ่มบรรทัดวัด worktree (`git -C <path> status` ที่แต่ละ repo แล้วจดว่าปฏิเสธหรือไม่) ลงไฟล์รอบของตัวเองทุกรอบ ทำต่อจนกว่าจะเห็น pattern หรือครบ 10 รอบ — ถ้ารอบไหนเขียน server ไม่ได้ ให้สลับไปทำงานจดหมาย/ใบ RE แทนตาม Rule-F(b) ไม่ใช่รอบเสียเปล่า

**กำหนด:** เริ่มรอบถัดไปของแต่ละสาย รายงานสรุป pattern กลับมาที่ COO เมื่อครบ 10 รอบหรือเห็น pattern ชัดก่อนนั้น
