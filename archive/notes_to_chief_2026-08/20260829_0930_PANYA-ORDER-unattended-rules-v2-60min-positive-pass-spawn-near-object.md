## ① เพดาน boot stamp โหมด unattended: 180 นาที → **60 นาที**
เกิน 60 นาที = teardown แล้วบูตใหม่ · ห้ามถือ `LOCK_GAME` ยาวกว่านั้นในรอบที่ไม่มีคนเฝ้า

## ② ผลบวกชัดเจนมาก → **กด PASS ได้เลย** (แก้ G-OBS ส่วน unattended บางส่วน)
- เดิม: ทุกผล client-observable จากรอบ unattended ต้องรอ `OBSERVER_CONFIRMED` (สถานะ `AWAITING-OBSERVER`)
- ใหม่: ถ้าภาพ/วิดีโอแสดงสิ่งที่ใบถาม **ชัดเจนมากแบบไม่ต้องตีความ** ผู้เทสกด `PASS` ได้ทันที
  🔴 เงื่อนไขบังคับคู่กัน: **ต้องรายงานเจ้าของทีหลังเสมอทุกใบ พร้อมภาพหลักฐานที่อ้างว่าสำเร็จ แบบชัด** — ลืมรายงาน = ผิดกติกา
- บวกแบบต้องตีความ / เห็นครึ่งเดียว → `AWAITING-OBSERVER` ตามเดิม
- **ผลลบ/ไม่เจอ → กติกาเดิมทุกตัวอักษร**: ห้ามปิดใบ ห้ามเขียน "ไม่มี/ไม่เกิด" เก็บวิดีโอทั้งรอบให้เจ้าของตรวจย้อนหลัง ห้ามลบ

## ③ ขอบเขตงานที่เหมาะกับ unattended (ใส่เป็นแนวทางเลือกใบ)
เหมาะ: wire เบื้องหลัง · ฟังก์ชันเปิดได้/ไม่ได้ · โหลดเกม/เข้าแมพ · หน้าต่างนิ่ง ๆ เปิดค้าง+สำรวจได้ · ย้ายแมพ/ฉากที่เห็นความต่างง่าย · แถบค่าบนจออัปเดต · สีเปลี่ยน · และ**ทุกรอบต้องเฝ้าช่องแชตว่ามีข้อความระบบจาก client ยิงขึ้นมาไหม**
ไม่เหมาะ (รอ attended): เล็งหาของชิ้นเล็ก · ของที่แว็บมาแล้วหายเร็ว · ต้องไล่หมุนกล้องควานหา

## ④ 🔴 กฎจุดเกิด — บังคับ**ทุกโหมด** ทั้ง attended และ unattended
ใบเทสที่เกี่ยวกับ world object / NPC / monster: ตัวละครหลังเข้าแมพต้อง**เกิดจุดที่ใกล้ ในระยะ หันหน้า
และยืนเยื้อง object นั้นเล็กน้อย** — ขนาดที่กล้องเห็น (หรือปรับเล็กน้อยก็เห็น-โฟกัส) เพื่อเก็บผลและถ่ายรูปได้ทันที
**เลิกออกแบบรอบที่ต้องเล็งหา ควานหา เดินไล่หา** — ตัดความเสี่ยงเดินตกน้ำและติดมุมอับ
ทางปฏิบัติ: seed ตำแหน่งลง run DB สำเนาก่อนบูต (แบบ job 1320/M1-P) · พิกัดจากตาราง placement จริงเท่านั้น
⇒ ขอ chief/สายที่เขียนใบเทส ใส่พิกัด seed ลงในใบตั้งแต่ตอนเปิดใบ
